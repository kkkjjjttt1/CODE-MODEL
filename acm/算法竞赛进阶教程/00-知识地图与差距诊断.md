## 三、未覆盖清单（这正是本教程的内容）

按**重要程度**（考试/比赛出现频率）与**依赖关系**排序：

### 缺口 A：图论连通性 —— Tarjan 全家桶 ★★★★★

| 缺失知识点 | 为什么必须补 |
|---|---|
| 强连通分量 SCC + 缩点 | 有向图题的通用起手式（"先缩点变成 DAG"） |
| 割点、桥 | 无向图连通性基础，很多题的判定核心 |
| 点双 / 边双连通分量 | 图论进阶的分水岭，圆方树的前置 |
| 圆方树 | 仙人掌、必经点、路径计数类题的利器 |
| 2-SAT | 布尔约束满足的标准建模工具 |
| 支配树 | 区域赛/集训队级别考点（了解 + 会用） |

> 你现在只会 Tarjan 的**离线 LCA**，SCC/割点/双连通这些"同一个 Tarjan 的另一半"完全没写。

### 缺口 B：网络流 ★★★★★

| 缺失知识点 |
|---|
| 最大流：Dinic（当前弧优化 + 多路增广）、ISAP |
| 最小割与建模：最大权闭合子图、最小点权覆盖、最大密度子图、二元关系建模 |
| 费用流：SPFA 版 / Dijkstra 势能版、最小费用最大流、费用流建模 |
| 上下界网络流：无源汇可行流、有源汇上下界最大/最小流 |
| 二分图匹配：匈牙利、Hopcroft-Karp、带权 KM、二分图最小点覆盖/最大独立集 |
| 最大流与最小割定理、Dilworth 定理（偏序集最小链覆盖 = 最长反链） |

> 网络流是 ICPC 区域赛的常客，也是"建模能力"的主战场。你的模板库里**完全没有流**。

## 六、怎么用这套教程

1. **先核对第二节**：如果你发现某个"已覆盖"的其实不会，先去补那份教程，不要跳；
2. **每章按顺序读**：原理推导 → 模板 → 例题套路 → 易错点；
3. **模板一定要自己敲一遍并对拍**（本教程每章附对拍程序，用法见 `tools/README.md`）；
4. **不要只看不写**：这些板块的共同特点是"看懂容易，写对很难"（Tarjan 的 low 更新、Dinic 的当前弧、点分治的重心、CDQ 的归并顺序，都是经典翻车点）；
5. **遇到卡题先查《题目特征 → 方法》速查表**（第 09 章）。
