# 第 05 章 分治与离线算法

> 前三章里你已经见过"时间轴线段树分治"（第 04 章）。这一章补上另外两把**离线降维**的利器：
> **CDQ 分治**（把"动态问题"变成"静态问题"、把高维偏序变成低维）与**整体二分**（把所有询问的二分答案合并成一次分治）。
> 共同点：**都是"离线"，都是"分治着统计跨区间的贡献"**。

---

## 5.1 CDQ 分治

### 解决什么问题

**多维偏序统计**：给定 $n$ 个带多个属性 $(a_i, b_i, c_i)$ 的元素，统计满足 $a_i \le a_j \wedge b_i \le b_j \wedge c_i \le c_j$ 的对数。

朴素做法 $O(n^2)$。**CDQ 分治把"三维偏序"降到 $O(n\log^2 n)$**（或用归并优化到 $O(n\log n)$）。

**更重要的用法**：**动态问题 → 静态问题**。带修改、带时间顺序的问题，可以把"时间"当作一维偏序，用 CDQ 把"修改对询问的贡献"一次性算出来。

### 核心思想

把序列按第一维（$a$）排序后分治：每次把区间 $[l, r]$ 分成 $[l, mid]$ 与 $[mid+1, r]$，然后：

1. **递归处理左右两半**（各自内部的贡献）；
2. **统计"左半对右半"的贡献**：此时左半的 $a$ 全部 $\le$ 右半的 $a$（由排序保证），所以只需处理 $b, c$ 两维 —— 按 $b$ 双指针 + 树状数组维护 $c$；
3. 撤销树状数组的修改。

**为什么正确**：任意一对 $(i, j)$（$i$ 的 $a \le j$ 的 $a$）在分治树上恰好被判一次——在它们"第一次被分到不同半边"的那个节点处。

### 模板：三维偏序

```cpp
// ==================== CDQ 分治：三维偏序 ====================
// 统计满足 a_i<=a_j, b_i<=b_j, c_i<=c_j 的对数（i != j，i 在前 j 在后按 a 排序后）
// 复杂度 O(n log^2 n)（每层一次 sort）；换成归并合并可优化到 O(n log n)
const int MAXN = 200005;
typedef long long ll;

struct Node {
    int a, b, c;
    int cnt;        // 相同三元组的个数（去重后合并）
    int ans;        // 满足条件的元素个数
} p[MAXN], tmpN[MAXN];

int n, valMax;      // n 个三元组，b/c 的值域 [1, valMax]
int bitC[MAXN];

void bitAdd(int i, int v) { for (; i <= valMax; i += i & -i) bitC[i] += v; }
int bitSum(int i) { int s = 0; for (; i > 0; i -= i & -i) s += bitC[i]; return s; }

bool cmpA(const Node &x, const Node &y) {
    if (x.a != y.a) return x.a < y.a;
    if (x.b != y.b) return x.b < y.b;
    return x.c < y.c;
}
bool cmpB(const Node &x, const Node &y) {
    if (x.b != y.b) return x.b < y.b;
    return x.c < y.c;
}

void cdq(int l, int r) {
    if (l == r) return;
    int mid = (l + r) >> 1;
    cdq(l, mid);
    cdq(mid + 1, r);

    // 左半与右半各自按 b 有序；双指针统计「左半对右半」的贡献
    std::sort(p + l, p + mid + 1, cmpB);
    std::sort(p + mid + 1, p + r + 1, cmpB);
    int i = l;
    for (int j = mid + 1; j <= r; j++) {
        while (i <= mid && p[i].b <= p[j].b) { bitAdd(p[i].c, p[i].cnt); ++i; }
        p[j].ans += bitSum(p[j].c);
    }
    for (int t = l; t < i; t++) bitAdd(p[t].c, -p[t].cnt);      // 撤销

    // 归并（可选优化：用 inplace_merge 替代，保持有序、常数更小）
    std::inplace_merge(p + l, p + mid + 1, p + r + 1, cmpB);
}

// 使用流程：
//   1) 读入所有三元组，按 cmpA 排序；
//   2) 把相同的三元组合并成一项，记录 cnt；
//   3) cdq(1, m)，其中 m 是去重后的项数；
//   4) 对第 i 项，答案为 ans[i] + cnt[i] - 1（含自身）
```

> **说明**：分治中 `sort` 只重排**区间内部**元素，不会让元素跨出区间，所以"左半的 $a$ ≤ 右半的 $a$"这一性质始终成立 —— 这正是 CDQ 能"降一维"的原因。
> 用 `inplace_merge` 而不是两次 `sort`，可把每层复杂度从 $O(n\log n)$ 降到 $O(n)$，总复杂度 $O(n\log n)$。

### CDQ 处理动态问题（时间维）

**套路**：把"修改"和"询问"按时间排成一个操作序列，问题变成：

$$\text{答案} = \sum_{\text{修改 } i}\ \sum_{\text{询问 } j,\ i \text{ 在 } j \text{ 之前}} [\text{修改 } i \text{ 影响询问 } j].$$

把**时间**当作第一维、**位置**当作第二维、**权值**当作第三维，就回到三维偏序问题。

**经典应用**：

| 题目 | 转化 |
|---|---|
| 动态逆序对（[P3157](https://www.luogu.com.cn/problem/P3157)） | 每个元素被删除的时间作为一维 |
| 带修改区间和 | 修改与询问按时间 + 位置偏序 |
| 矩阵修改 + 单点查询 | 差分后变二维偏序 |

## 5.2 整体二分

### 解决什么问题

**多组询问 + 二分答案**：每组的答案都能"二分判定"，但逐组二分太慢。
**整体二分**：把所有询问放在一起，对**答案值域**分治，一次分治同时推进所有询问的二分。

**复杂度**：$O((n + q)\log V \cdot T)$，$T$ 是单次"插入/查询"的代价。

### 模板：静态区间第 $k$ 小

```cpp
// ==================== 整体二分：静态区间第 k 小 ====================
const int MAXN = 200005;
struct Query {
    int l, r, k, id;
};
Query qs[MAXN], qL[MAXN], qR[MAXN];
int a[MAXN];
int ansQ[MAXN];
int bitQ[MAXN];
int n, m;                    // 序列长度、询问数

void bitAddQ(int i, int v) { for (; i <= n; i += i & -i) bitQ[i] += v; }
int bitSumQ(int i) { int s = 0; for (; i > 0; i -= i & -i) s += bitQ[i]; return s; }

// 处理询问区间 qs[ql..qr]，答案值域为 [vl, vr]
void solveAll(int ql, int qr, int vl, int vr) {
    if (ql > qr) return;
    if (vl == vr) {
        for (int i = ql; i <= qr; i++) ansQ[qs[i].id] = vl;
        return;
    }
    int mid = (vl + vr) >> 1;
    // 关键：只加入「值落在当前值域左半 [vl, mid]」的位置
    //（若写成 a[i] <= mid，递归到右半值域时会把已排除的元素也算进去，导致答案偏小）
    for (int i = 1; i <= n; i++) if (vl <= a[i] && a[i] <= mid) bitAddQ(i, 1);

    int cntL = 0, cntR = 0;
    for (int i = ql; i <= qr; i++) {
        int c = bitSumQ(qs[i].r) - bitSumQ(qs[i].l - 1);      // 区间内 <= mid 的个数
        if (c >= qs[i].k) qL[++cntL] = qs[i];                 // 答案在左半
        else { qs[i].k -= c; qR[++cntR] = qs[i]; }            // 答案在右半，注意减掉 c
    }
    // 撤销树状数组（也可以用"只撤销刚才加过的位置"来优化常数）
    for (int i = 1; i <= n; i++) if (vl <= a[i] && a[i] <= mid) bitAddQ(i, -1);

    for (int i = 1; i <= cntL; i++) qs[ql + i - 1] = qL[i];
    for (int i = 1; i <= cntR; i++) qs[ql + cntL + i - 1] = qR[i];
    solveAll(ql, ql + cntL - 1, vl, mid);
    solveAll(ql + cntL, qr, mid + 1, vr);
}
```

> **关键细节**：分到右半时要把 `k -= c`（因为"答案在右半"意味着前 $c$ 小的数已经排除掉了）。这一步忘了就是经典的"答案整体偏移"。

### 带修改的区间第 $k$ 小

把操作序列统一成两类：

- **修改操作**：`(type=1, pos, val, delta)`——在 $pos$ 位置插入/删除一个值为 $val$ 的数；
- **询问操作**：`(type=2, l, r, k, id)`。

整体二分时，把"值 $\le mid$ 的修改"应用到树状数组上，然后统计每个询问区间内的个数，分到左右两侧。**修改操作也要跟着分到左右两侧**（因为它们对未来的询问有影响）。

复杂度 $O((n+q)\log V\log n)$。

**经典题**：[P1527 矩阵乘法](https://www.luogu.com.cn/problem/P1527)（二维整体二分）、[P3332 K大数查询](https://www.luogu.com.cn/problem/P3332)（带修 + 区间第 $k$ 大）、[P3527 MET-Meteors](https://www.luogu.com.cn/problem/P3527)（整体二分 + 环形差分）。

## 5.3 三种"分治"的对比

| 方法 | 分治的对象 | 解决的问题 | 复杂度 |
|---|---|---|---|
| **CDQ 分治** | **下标/时间**（把序列一分为二） | 多维偏序、动态问题转静态 | $O(n\log n)$ ~ $O(n\log^2 n)$ |
| **整体二分** | **答案值域** | 多组"二分答案"型询问 | $O((n+q)\log V\log n)$ |
| **线段树分治** | **时间轴**（时间区间挂到线段树） | 操作有生效区间、需要撤销 | $O(n\log T\cdot T_{\text{op}})$ |
| **点分治 / CDQ 中的分治** | **树 / 序列** | 路径统计 / 偏序统计 | $O(n\log n)$ |

**选择口诀**：

- 看到一个询问的答案可以二分、且有**很多**询问 → **整体二分**；
- 看到"第 $i$ 个操作对第 $j$ 个询问的贡献"且有时间顺序 → **CDQ 分治**；
- 看到操作有"生效时间区间"且需要撤销 → **线段树分治**。

## 5.5 易错点清单

| 编号 | 易错点 | 说明 |
|---|---|---|
| 1 | CDQ 中忘记撤销树状数组 | 会污染后续统计 |
| 2 | CDQ 用 `sort` 后忘记"区间内元素不跨区间"这一前提 | 只要不跨区间就没问题；若手写归并写错位置会致命 |
| 3 | 相同三元组未合并 | 相等的元素互相满足条件，必须合并并记录 `cnt` |
| 4 | 三维偏序答案忘记加 `cnt - 1`（含自身） | 题目要"包含自己"时容易漏 |
| 5 | 整体二分分到右半时忘记 `k -= c` | 最经典的错误 |
| 6 | 整体二分树状数组撤销不干净 | 用"记录修改位置"的方式撤销更稳 |
| 7 | 整体二分值域边界写错（`vl == vr` 才能确定答案） | 必须是相等才返回 |
| 8 | 用 `int` 存偏序对数 | 答案可达 $O(n^2)$，要用 `long long` |
| 9 | CDQ 处理动态问题时忘记"只有时间在前的修改才影响询问" | 靠分治保证，别额外排序打乱时间序 |
| 10 | 整体二分中"修改操作"没有跟着分到左右两边 | 修改必须跟着走，否则后续贡献丢失 |

## 5.6 模板汇总

```
分治与离线模板清单

CDQ 分治：
  cmpA / cmpB
  cdq(l, r)                三维偏序（sort 版 O(n log^2 n) / inplace_merge 版 O(n log n)）

整体二分：
  solveAll(ql, qr, vl, vr) 静态区间第 k 小

```
