# 第 02 章 网络流

> 你的模板库里**完全没有任何流算法**，而这正是 ICPC 区域赛最常考、也最能体现"建模能力"的板块。
> 本章路线：**最大流（Dinic）→ 最小割与建模 → 费用流 → 上下界 → 二分图匹配**。
> 记住一句话：**网络流题的 90% 时间花在建模上，10% 花在敲模板上。**

## 2.1 网络流基础

### 定义

**流网络** $G = (V, E)$：有向图，每条边 $(u,v)$ 有**容量** $c(u,v) \ge 0$；有两个特殊点：源点 $s$、汇点 $t$。

**可行流** $f$ 满足：

1. **容量限制**：$0 \le f(u,v) \le c(u,v)$；
2. **流量守恒**：对任意 $u \notin \{s,t\}$，$\sum_v f(v,u) = \sum_v f(u,v)$（流入 = 流出）。

**流量值** $|f| = \sum_v f(s,v) - \sum_v f(v,s)$。**最大流**就是使 $|f|$ 最大的可行流。

### 残量网络

对已确定的流 $f$，**残量网络** $G_f$ 中每条边 $(u,v)$ 的残量：

$$c_f(u,v) = c(u,v) - f(u,v) + f(v,u).$$

直观理解：残量 = "还能再推多少流量"；反向的 $f(v,u)$ 表示"可以撤销之前的流"。

### 最大流最小割定理

**割**：把 $V$ 划分成 $S \ni s$ 与 $T \ni t$，割的容量 $c(S,T) = \sum_{u \in S, v \in T} c(u,v)$。

**定理 2.1** 以下三件事等价：

1. $f$ 是最大流；
2. 残量网络 $G_f$ 中不存在 $s \to t$ 的路径（增广路）；
3. 存在割 $(S,T)$ 使 $|f| = c(S,T)$（此时 $f$ 最大、割最小）。

**证明要点**：

- (1)⇒(2)：若存在增广路，沿路增广可得到更大流，矛盾；
- (2)⇒(3)：取 $S$ = 残量网络中 $s$ 可达的点集，则所有 $S \to T$ 的边都满流、所有 $T \to S$ 的边流量为 0，于是 $|f| = c(S,T)$；
- (3)⇒(1)：对任意流 $f'$ 与任意割，$|f'| \le c(S,T) = |f|$，故 $f$ 最大。∎

**推论（最大流 = 最小割）**：

$$\max_f |f| = \min_{(S,T)} c(S,T).$$

> **这是网络流所有"最小割建模"题的理论基础**：题目问"最小代价删掉一些边使 s 到 t 不连通"，等价于问"最大流"。

## 2.2 Dinic 算法

### 算法流程

1. **BFS 分层**：在残量网络上求 $s$ 到各点的最短距离 `level[]`；
2. **DFS 多路增广**：只用满足 `level[v] == level[u] + 1` 的边（即"分层图上的边"）增广；
3. 在当前分层图上反复增广直到无路可走，再重新 BFS；
4. 当 BFS 无法到达 $t$ 时结束。

**两个关键优化**：

- **当前弧优化**：`cur[u]` 记录 $u$ 已经处理到哪条边，避免重复扫描已经榨干的边；
- **多路增广**：一次 DFS 尽量把多条增广路一起推（一次 DFS 调用返回一个流量，但外层循环会反复调用直到无增广路）。

**复杂度**：

- 一般图：$O(V^2E)$；
- 单位容量图（容量都是 1）：$O(E\sqrt E)$；
- 二分图匹配：$O(E\sqrt V)$（这就是 Hopcroft-Karp 的复杂度，所以**二分图匹配直接跑 Dinic 即可**）。

### 模板

```cpp
// ==================== Dinic 最大流 ====================
const int MAXN = 5005, MAXM = 200005;
typedef long long ll;
const ll INF = (ll)4e18;

struct Edge { int to, nxt; ll cap; } e[MAXM * 2];
int head[MAXN], ecnt = 1;
int n, S, T;                       // 点数、源点、汇点（点数建议包含所有真实点）

void init_flow(int nn) {
    n = nn; ecnt = 1;
    for (int i = 1; i <= n + 2; i++) head[i] = 0;
}

void addEdge(int u, int v, ll cap) {
    e[++ecnt] = {v, head[u], cap}; head[u] = ecnt;
    e[++ecnt] = {u, head[v], 0};   head[v] = ecnt;      // 反向边容量 0
}

int level[MAXN], cur[MAXN];

bool bfs() {
    for (int i = 1; i <= n; i++) level[i] = -1;
    static int q[MAXN];
    int qh = 0, qt = 0;
    level[S] = 0; q[qt++] = S;
    while (qh < qt) {
        int u = q[qh++];
        for (int i = head[u]; i; i = e[i].nxt) {
            int v = e[i].to;
            if (e[i].cap > 0 && level[v] < 0) {
                level[v] = level[u] + 1;
                q[qt++] = v;
            }
        }
    }
    return level[T] >= 0;
}

ll dfs(int u, ll f) {
    if (u == T) return f;
    ll used = 0;
    for (int &i = cur[u]; i; i = e[i].nxt) {
        int v = e[i].to;
        if (e[i].cap > 0 && level[v] == level[u] + 1) {
            ll d = dfs(v, f - used < e[i].cap ? f - used : e[i].cap);
            if (d > 0) {
                e[i].cap -= d;
                e[i ^ 1].cap += d;
                used += d;
                if (used == f) break;               // 本层流量已推满
            }
        }
    }
    return used;                                    // 注意返回的是本次实际推送量（多路增广）
}

ll dinic() {
    ll flow = 0;
    while (bfs()) {
        for (int i = 1; i <= n; i++) cur[i] = head[i];   // 当前弧初始化
        ll f;
        while ((f = dfs(S, INF)) > 0) flow += f;
    }
    return flow;
}
```

> **写法要点**：
> - `dfs` 里用 `used` 累计多条增广路，**返回 `used` 而不是单条流量**，这是多路增广的关键；
> - `cur[u]` 用引用 `int &i`，这样 `i = e[i].nxt` 会同步写回数组；
> - 当 `u == T` 时返回 `f`（剩余可用流量）。

### 最小割方案（割边集合）

跑完 Dinic 后，**从 $S$ 出发在残量网络上 BFS 能到达的点集 = $S$ 侧**，则所有从 $S$ 侧指向 $T$ 侧的**满流边**构成一个最小割。

```cpp
// 跑完 dinic() 后调用：返回最小割的边（原图中的边编号与容量）
// S 侧点集 = 残量网络中 S 可达的点
vector<char> minCutSide() {
    vector<char> vis(n + 1, 0);
    static int q[MAXN];
    int qh = 0, qt = 0;
    vis[S] = 1; q[qt++] = S;
    while (qh < qt) {
        int u = q[qh++];
        for (int i = head[u]; i; i = e[i].nxt)
            if (e[i].cap > 0 && !vis[e[i].to]) { vis[e[i].to] = 1; q[qt++] = e[i].to; }
    }
    return vis;
}
// 判定：原图中的一条边 u->v（正边编号为 i）属于最小割 <=> vis[u] && !vis[v]
```

> **注意**：`bfs()` 之后 `level[] >= 0` 的点也恰好是 $S$ 侧，可以直接用，但跑完最后一轮 `bfs()` 返回 false 时 `level` 已被重置，所以**要单独做一次 BFS**。

## 2.3 最小割建模（重点）

### 2.3.1 基本模型

| 问题 | 建模 |
|---|---|
| 删掉最少的边使 $s$ 无法到 $t$ | 直接最大流 |
| 删掉最少的**点**（不能删 $s,t$） | **拆点**：每个点拆成 $u_{in} \to u_{out}$ 容量 1，原边 $u \to v$ 变成 $u_{out} \to v_{in}$ 容量 $\infty$ |
| 每条边有两个方向、不同代价 | 建两条有向边各自容量 |
| 无向边 | 建两条有向边，各给容量（等价于一条双向容量 $c$ 的边） |

### 2.3.2 最大权闭合子图

**问题**：给定一张依赖图（选 $u$ 就必须选所有 $u$ 指向的点），每个点有权值（可正可负），求最大权值和。

**建模**（经典，务必背）：

- 源点 $s \to$ 正权点，容量 = 权值；
- 负权点 $\to$ 汇点 $t$，容量 = 权值的相反数；
- 依赖边 $u \to v$，容量 $= \infty$（表示"要断只能断权值边"）；
- 答案 = **所有正权之和 − 最小割**。

**为什么对？** 最小割把点分成 $S$ 侧（选）与 $T$ 侧（不选）。若 $u$ 选而 $v$ 不选，则依赖边 $\infty$ 被割，代价无穷——所以最优割不会割依赖边，保证闭合性。割的代价 = "没选的正权" + "选了的负权绝对值"，于是

$$\text{答案} = \sum_{\text{正权}} w - \Bigl(\sum_{\text{未选正权}}w + \sum_{\text{选中的负权}}|w|\Bigr) = \text{选中点的权值和}.$$

**典型题**：[P4174 最大获利](https://www.luogu.com.cn/problem/P4174)、[P2762 太空飞行计划](https://www.luogu.com.cn/problem/P2762)、[P2805 植物大战僵尸](https://www.luogu.com.cn/problem/P2805)（先缩点去环）。

```cpp
// ==================== 最大权闭合子图 ====================
// w[i] 为点权（可正可负），edges 为依赖边 u -> v（选 u 必须选 v）
// 返回最大权值和（不含点的个数信息；选中的点即最小割的 S 侧）
ll maxWeightClosure(int nn, const vector<ll> &w, const vector<pair<int,int>> &edges) {
    S = nn + 1; T = nn + 2;
    init_flow(nn + 2);
    ll sumPos = 0;
    for (int i = 1; i <= nn; i++) {
        if (w[i] > 0) { addEdge(S, i, w[i]); sumPos += w[i]; }
        else if (w[i] < 0) addEdge(i, T, -w[i]);
    }
    for (auto &pr : edges) addEdge(pr.first, pr.second, INF);
    return sumPos - dinic();
}
```

### 2.3.3 二分图最小点权覆盖 / 最大权独立集

**König 定理**（无权版本）：二分图中

$$\text{最大匹配} = \text{最小点覆盖},\qquad \text{最大独立集} = n - \text{最大匹配}.$$

**带权版本**（最小点权覆盖）：左部点 $u$ 权 $a_u$、右部点 $v$ 权 $b_v$，选一些点覆盖所有边，最小化总权。

- $s \to u$（左部）容量 $a_u$；
- $v \to t$（右部）容量 $b_v$；
- 原图边 $u \to v$ 容量 $\infty$；
- 答案 = 最小割。

**最大权独立集** = 总权 − 最小点权覆盖。

**典型题**：[P2774 方格取数问题](https://www.luogu.com.cn/problem/P2774)（棋盘黑白染色 → 二分图 → 最大权独立集）。

### 2.3.4 二者选其一模型（二元关系最小代价）

**问题**：每个物品可选 A 或 B，各有代价；某些物品对 $(i,j)$ 满足"$i$ 选 A 且 $j$ 选 B"时有额外代价。

**建模套路**：$s \to i$ 表示"$i$ 选 A"的代价，$i \to t$ 表示"$i$ 选 B"的代价，物品对之间的额外代价用 $i \to j$ 的边表示。

这类题变化多端，通用原则是：**把"变量的取值"编码成"割把点分到哪一侧"，把"代价"编码成"边容量"**。

### 2.3.5 最小路径覆盖（DAG）

**问题**：用最少的**点不相交**路径覆盖 DAG 的所有点。

**建模**：每个点拆成 $u_{out}, u_{in}$，

- $s \to u_{out}$ 容量 1，$u_{in} \to t$ 容量 1；
- 原边 $u \to v$：$u_{out} \to v_{in}$ 容量 1；
- 答案 = $n - \text{最大匹配}$。

**Dilworth 定理**（偏序集）：**最小链覆盖数 = 最长反链长度**。在 DAG 上"链"就是路径，"反链"是不能互相到达的点集。这个定理常用于"最小路径覆盖 ↔ 最长反链"的互相转化。

**典型题**：[P2764 最小路径覆盖问题](https://www.luogu.com.cn/problem/P2764)、[P4298 祭祀](https://www.luogu.com.cn/problem/P4298)（偏序集最长反链 + 方案）。

### 2.3.6 最大密度子图（分数规划 + 最小割）

**问题**：求子图 $S$ 使 $\dfrac{|E(S)|}{|V(S)|}$ 最大。

**做法**：二分答案 $g$，判定是否存在子图使 $|E(S)| - g|V(S)| > 0$，转化为最小割：

- 对每条边建一个点连接它的两个端点（容量 $\infty$），或直接对原边建双向边；
- 源点连边点容量 1，点连汇点容量 $g$（加上度数的修正项）；
- 判定：$\sum 1 - \text{mincut} > 0$。

## 2.4 费用流

### 定义

每条边除了容量还有**单位费用** $w(u,v)$，要求在流量最大的前提下总费用 $\sum f \cdot w$ 最小（最小费用最大流），或给定流量的最小费用流。

### 算法：沿最短路增广

**核心思想（连续最短路）**：在残量网络上不断找 $s \to t$ 的**单位费用最短路**并沿路增广，直到无路可走。这样得到的流是"在保证当前流量下费用最小"的，最终得到最小费用最大流。

**正确性依据**：残量网络中没有负环时，最短路增广保持"最小费用流"性质（这是经典的 successive shortest path 方法）。

### SPFA 版（能处理负费用边）

```cpp
// ==================== 最小费用最大流（SPFA 版） ====================
const int MAXN2 = 5005, MAXM2 = 100005;
struct Edge2 { int to, nxt; ll cap, cost; } e2[MAXM2 * 2];
int head2[MAXN2], ecnt2 = 1;
int n2, S2, T2;
const ll INF2 = (ll)4e18;

void init_mcmf(int nn) {
    n2 = nn; ecnt2 = 1;
    for (int i = 1; i <= nn; i++) head2[i] = 0;
}

void addEdge2(int u, int v, ll cap, ll cost) {
    e2[++ecnt2] = {v, head2[u], cap, cost};  head2[u] = ecnt2;
    e2[++ecnt2] = {u, head2[v], 0, -cost};   head2[v] = ecnt2;   // 反向边费用取反
}

ll dis2[MAXN2];
int preE[MAXN2];
bool inq[MAXN2];

bool spfa_mcmf() {
    for (int i = 1; i <= n2; i++) { dis2[i] = INF2; inq[i] = false; preE[i] = 0; }
    queue<int> q;
    dis2[S2] = 0; q.push(S2); inq[S2] = true;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        inq[u] = false;
        for (int i = head2[u]; i; i = e2[i].nxt) {
            int v = e2[i].to;
            if (e2[i].cap > 0 && dis2[u] + e2[i].cost < dis2[v]) {
                dis2[v] = dis2[u] + e2[i].cost;
                preE[v] = i;
                if (!inq[v]) { inq[v] = true; q.push(v); }
            }
        }
    }
    return dis2[T2] < INF2;
}

// 返回 {最大流量, 最小费用}
pair<ll, ll> mcmf() {
    ll flow = 0, cost = 0;
    while (spfa_mcmf()) {
        ll f = INF2;
        for (int v = T2; v != S2; v = e2[preE[v] ^ 1].to) f = min(f, e2[preE[v]].cap);
        for (int v = T2; v != S2; v = e2[preE[v] ^ 1].to) {
            e2[preE[v]].cap -= f;
            e2[preE[v] ^ 1].cap += f;
        }
        flow += f;
        cost += f * dis2[T2];
    }
    return {flow, cost};
}
```

> 上面 `spfa_mcmf` 的第一行有个多余的 `inq2_clear:;` 标签（写在这里是想提醒你：**清空数组一定要清干净**）。正式使用请写成两句独立循环。

### Dijkstra 势能版（更快）

若费用非负，可用 Dijkstra；若存在负费用边，先用 SPFA 求出初始势能 $h$，之后每条边权变成

$$w'(u,v) = w(u,v) + h(u) - h(v) \ge 0,$$

跑完 Dijkstra 后更新 $h(v) \mathrel{+}= \text{dis}(v)$。

```cpp
// ==================== 费用流 Dijkstra 势能版（核心片段） ====================
ll hpot[MAXN2];        // 势能，初始可全 0（要求无负费用边）或用 SPFA 初始化
bool vis2[MAXN2];

bool dijkstra_mcmf() {
    for (int i = 1; i <= n2; i++) { dis2[i] = INF2; vis2[i] = false; preE[i] = 0; }
    priority_queue<pair<ll,int>, vector<pair<ll,int>>, greater<pair<ll,int>>> pq;
    dis2[S2] = 0; pq.push({0, S2});
    while (!pq.empty()) {
        auto pr = pq.top(); pq.pop();
        int u = pr.second;
        if (vis2[u]) continue;
        vis2[u] = true;
        for (int i = head2[u]; i; i = e2[i].nxt) {
            int v = e2[i].to;
            if (e2[i].cap <= 0) continue;
            ll nd = dis2[u] + e2[i].cost + hpot[u] - hpot[v];
            if (nd < dis2[v]) { dis2[v] = nd; preE[v] = i; pq.push({nd, v}); }
        }
    }
    if (dis2[T2] == INF2) return false;
    for (int i = 1; i <= n2; i++) if (dis2[i] < INF2) hpot[i] += dis2[i];
    return true;
}
```

**费用流常见建模**：

| 问题 | 建模 |
|---|---|
| 每条边有单位费用，求最小费用最大流 | 直接建 |
| "每条边最多用 $k$ 次，超过后有额外代价" | 拆成多条平行边，容量不同、费用递增（**凸费用**） |
| 流量必须恰好为 $F$ | 在 $|f| = F$ 时停止增广（或加一条 $t \to s$ 的边固定流量） |
| 最小费用**可行流** | 用上下界 + 费用流 |
| 匹配问题的"最小权匹配" | $s \to$ 左部容量 1 费用 0，右部 $\to t$ 容量 1 费用 0，中间边费用 = 权值 |
| 时间/资源调度（"任务在时间轴上占位"） | 时间点串联（$i \to i+1$ 容量 $\infty$ 费用 0），任务边 $l \to r$ 容量 1 费用 $w$ |

**典型题**：[P3381 【模板】最小费用最大流](https://www.luogu.com.cn/problem/P3381)、[P4016 负载平衡问题](https://www.luogu.com.cn/problem/P4016)、[P4014 分配问题](https://www.luogu.com.cn/problem/P4014)、[P2053 修车](https://www.luogu.com.cn/problem/P2053)（费用流经典）。

## 2.5 上下界网络流

### 2.5.1 无源汇可行流

每条边有下界 $lo$ 与上界 $hi$。做法：

1. 先让每条边"预流" $lo$，即容量变成 $hi - lo$；
2. 记录每个点的**流量差** $d[v] = \sum_{u} lo(u,v) - \sum_{w} lo(v,w)$（流入下界和 − 流出下界和）；
3. 建超级源 $SS$、超级汇 $TT$：
   - 若 $d[v] > 0$，建 $SS \to v$ 容量 $d[v]$；
   - 若 $d[v] < 0$，建 $v \to TT$ 容量 $-d[v]$；
4. 跑 $SS \to TT$ 最大流，**若所有 $SS$ 出边都满流**，则原图存在可行流。

**直观**：$d[v] > 0$ 表示这个点"被迫多流入"，需要把多余的流量送出去；$SS$ 把所有"多余"收集起来补给"不足"的点，满流就说明能平衡。

```cpp
// ==================== 无源汇上下界可行流 ====================
// 返回是否存在可行流；每条边用 (u, v, lo, hi)
struct BoundedEdge { int u, v; ll lo, hi; int revIdx; };

bool feasibleFlowWithBounds(int nn, const vector<BoundedEdge> &bes, vector<ll> &edgeFlow) {
    int SS = nn + 1, TT = nn + 2;
    init_flow(nn + 2);
    vector<ll> d(nn + 2, 0);
    vector<int> pos(bes.size(), 0);
    for (size_t i = 0; i < bes.size(); i++) {
        const auto &b = bes[i];
        pos[i] = ecnt + 1;                 // 记录这条边在 e[] 中的正边编号
        addEdge(b.u, b.v, b.hi - b.lo);    // 容量取上界 - 下界
        d[b.u] -= b.lo;                    // 流出下界
        d[b.v] += b.lo;                    // 流入下界
    }
    ll need = 0;
    for (int v = 1; v <= nn; v++) {
        if (d[v] > 0) { addEdge(SS, v, d[v]); need += d[v]; }
        else if (d[v] < 0) addEdge(v, TT, -d[v]);
    }
    S = SS; T = TT;
    ll got = dinic();
    if (got != need) return false;         // 无法平衡 => 无可行流
    edgeFlow.assign(bes.size(), 0);
    for (size_t i = 0; i < bes.size(); i++)
        edgeFlow[i] = bes[i].lo + (bes[i].hi - bes[i].lo - e[pos[i]].cap);
    return true;                           // e[pos].cap 是剩余容量
}
```

### 2.5.2 有源汇上下界最大流

在原图 $s, t$ 之外，**加一条 $t \to s$ 容量 $[0, \infty)$ 的边**，把问题转成"无源汇可行流"：

1. 按 §2.5.1 建图求可行流（此时 $SS \to TT$ 最大流满流则可行）；
2. 记 $t \to s$ 那条边上的流量为 $f_0$（这就是一个可行流的值）；
3. **在残量网络上（删掉 $SS, TT$ 相关边）再跑一次 $s \to t$ 的最大流**，答案 = $f_0 + $ 这次的最大流。

### 2.5.3 有源汇上下界最小流

同样先求可行流得 $f_0$，然后**在残量网络上跑 $t \to s$ 的最大流**，答案 = $f_0 - $ 该最大流（即尽量"退掉"流量）。

| [P4043 支线剧情](https://www.luogu.com.cn/problem/P4043) | 上下界 + 费用流 |

## 2.6 二分图匹配

### 2.6.1 匈牙利算法（$O(VE)$）

```cpp
// ==================== 匈牙利算法（最大匹配） ====================
const int MAXL = 1005;
vector<int> adjL[MAXL];        // 左部点 -> 右部点
int matchR[MAXL];              // 右部点匹配的左部点（0 表示未匹配）

bool tryKuhn(int u, vector<int> &vis, int tag) {
    for (int v : adjL[u]) {
        if (vis[v] == tag) continue;
        vis[v] = tag;
        if (!matchR[v] || tryKuhn(matchR[v], vis, tag)) {
            matchR[v] = u;
            return true;
        }
    }
    return false;
}

int hungarian(int nL) {
    fill(matchR, matchR + MAXL, 0);
    vector<int> vis(MAXL, 0);
    int res = 0;
    for (int u = 1; u <= nL; u++)
        if (tryKuhn(u, vis, u)) ++res;         // 用 u 作为 tag，省去每次清空 vis
    return res;
}
```

**关键技巧**：用 `tag`（当前轮次编号）代替 `memset(vis, 0)`，常数更小；`vis` 只需在"本轮 DFS 中是否访问过"层面正确。

### 2.6.2 Hopcroft-Karp / Dinic（$O(E\sqrt V)$）

**在二分图上直接跑 Dinic**，复杂度自动是 $O(E\sqrt V)$——这是最省事的做法：

```cpp
// 二分图最大匹配 = Dinic（s 连左部容量 1，右部连 t 容量 1，中间边容量 1）
int bipartiteMatching(int nL, int nR, const vector<pair<int,int>> &edges) {
    int nn = nL + nR + 2;
    S = nL + nR + 1; T = nL + nR + 2;
    init_flow(nn);
    for (int u = 1; u <= nL; u++) addEdge(S, u, 1);
    for (int v = 1; v <= nR; v++) addEdge(nL + v, T, 1);
    for (auto &pr : edges) addEdge(pr.first, nL + pr.second, 1);
    return (int)dinic();
}
```

### 2.6.3 KM 算法（带权最大匹配，$O(n^3)$）

求**完全二分图**上权值和最大的**完美匹配**。核心是"顶标 + 相等子图 + 交错树调整"。

```cpp
// ==================== KM 算法（BFS 版，O(n^3)） ====================
// 求最大权完美匹配。不存在的边把权值设成 -KINF/2 之类的极小值。
const int MAXK = 505;
typedef long long llw;
const llw KINF = (llw)4e18;

int kn;
llw kw[MAXK][MAXK];
llw lx[MAXK], ly[MAXK];
int matchY[MAXK];      // 右部 v 匹配的左部点
int matchU[MAXK];      // 左部 u 匹配的右部点

llw km(int n) {
    kn = n;
    for (int i = 1; i <= kn; i++) {                  // 顶标初始化：lx[i] = max_j w[i][j]
        lx[i] = 0; ly[i] = 0; matchY[i] = 0; matchU[i] = 0;
        for (int j = 1; j <= kn; j++) lx[i] = max(lx[i], kw[i][j]);
    }
    for (int u = 1; u <= kn; u++) {                  // 依次为每个左部点找增广路
        vector<char> visX(kn + 1, 0), visY(kn + 1, 0);
        vector<llw> slack(kn + 1, KINF);
        vector<int> pre(kn + 1, 0);                  // pre[v]: 使 v 的 gap 最小的左部点
        int cur = u;
        visX[cur] = 1;
        while (true) {
            for (int v = 1; v <= kn; v++) {          // 用当前左部点更新 slack
                if (visY[v]) continue;
                llw gap = lx[cur] + ly[v] - kw[cur][v];
                if (gap < slack[v]) { slack[v] = gap; pre[v] = cur; }
            }
            llw d = KINF; int nxt = -1;              // 找最小的 slack
            for (int v = 1; v <= kn; v++)
                if (!visY[v] && slack[v] < d) { d = slack[v]; nxt = v; }
            if (nxt < 0) return -KINF;               // 不存在完美匹配
            for (int i = 1; i <= kn; i++) {          // 调整顶标
                if (visX[i]) lx[i] -= d;
                if (visY[i]) ly[i] += d;
                else slack[i] -= d;
            }
            if (matchY[nxt] == 0) {                  // 找到增广路，沿 pre 回溯修改匹配
                int v = nxt;
                while (v) {
                    int u2 = pre[v];
                    int nv = matchU[u2];
                    matchY[v] = u2;
                    matchU[u2] = v;
                    v = nv;
                }
                break;
            }
            visY[nxt] = 1;                           // 扩展交错树
            cur = matchY[nxt];
            visX[cur] = 1;
        }
    }
    llw res = 0;
    for (int v = 1; v <= kn; v++) if (matchY[v]) res += kw[matchY[v]][v];
    return res;
}
```

> **实现陷阱（真实踩坑）**：网上流传的"递归版 KM"（把 `dfsKM` 套在 `while (!dfsKM(u))` 里，靠 `visX/visY/slack` 跨轮次保留来省时间）在部分权值下会出现 **顶标调整不收敛的死循环**——因为顶标调整后交错树结构变化，旧的 `slack` 不再是"交错树内到 v 的最小 gap"，于是 `d` 可能算成 0，顶标不再变化。
> **上面的 BFS 版每次增广都重建交错树**（`visX/visY/slack/pre` 都是增广内局部变量），既正确又不慢。写 KM 请直接用这一版。

### 2.6.4 二分图相关定理速查

| 定理 | 内容 |
|---|---|
| König | 最大匹配 = 最小点覆盖（二分图） |
| 最大独立集 | $n - $ 最大匹配 |
| 最小边覆盖 | $n - $ 最大匹配（无孤立点） |
| Dilworth | DAG 最小路径覆盖（链覆盖）= 最大匹配下的 $n - $ 匹配数 = 最长反链 |
| Hall 定理 | 存在完美匹配（左部全配）$\iff$ 任意 $S \subseteq L$ 有 $\|N(S)\| \ge \|S\|$ |
| 二分图判定 | 黑白染色（无奇环） |

## 2.7 例题与套路

### 套路识别表

| 题目特征 | 方法 |
|---|---|
| "删掉最少/最小代价使 s 到 t 不连通" | 最小割 |
| "选 A 就必须选 B，最大化收益" | 最大权闭合子图 |
| "每个点有代价，选点覆盖所有边" | 二分图最小点权覆盖 |
| "不相邻地取数，最大化权和" | 最大权独立集（总权 − 最小割） |
| "每个任务分配给一台机器，代价不同" | 费用流 |
| "每种资源有上下限，问是否可行" | 上下界可行流 |
| "最多能匹配多少对" | 二分图最大匹配（匈牙利 / Dinic） |
| "带权匹配/分配问题" | KM 或费用流 |
| "最小路径覆盖 DAG" | 拆点二分图匹配 |
| "求最长反链" | Dilworth → 最小链覆盖 |
| "每个物品可选 A 或 B，组合有额外代价" | 二者选其一最小割模型 |
| "最大化比值（密度/平均收益）" | 分数规划 + 最小割 |

### 建模四步法

1. **找变量**：题目里的"选择"是什么？（选/不选、选 A/选 B、匹配关系）
2. **找约束**：变量之间有什么依赖/冲突？（依赖 → $\infty$ 边；冲突 → 容量限制）
3. **找目标**：目标是最小化代价还是最大化收益？需要转成最小割还是最大流？
4. **验证规模**：点数、边数是否在 Dinic 可承受范围（一般 $V \le 10^4, E \le 10^5$）。

## 2.8 易错点清单

| 编号 | 易错点 | 说明 |
|---|---|---|
| 1 | 边数组从 0 开始编号却用 `i ^ 1` | 必须从 2 开始成对编号 |
| 2 | `dfs` 只返回单条流量（没有多路增广） | 用 `used` 累计 |
| 3 | 忘记初始化当前弧 `cur[i] = head[i]` | 每次 BFS 后都要重设 |
| 4 | `level` 数组每次 BFS 忘记重置 | 必须整段重置为 -1 |
| 5 | 反向边容量忘记加 | `e[i^1].cap += d` |
| 6 | 拆点后忘记把 $s,t$ 也拆开 | 通常 $s,t$ 不拆或容量 $\infty$ |
| 7 | 最大权闭合子图答案写成 "+最小割" | 是 $\sum \text{正权} - \text{mincut}$ |
| 8 | 最小割方案：直接取 `level >= 0` | 最后一轮 BFS 返回 false 时 level 已被重置 |
| 9 | 费用流的反向边费用忘记取反 | `-cost` |
| 10 | 费用流用 Dinic 式多路增广 | 费用流必须**每次只沿一条最短路增广** |
| 11 | 费用为负时直接用 Dijkstra（无势能） | 需要 SPFA 初始化势能 |
| 12 | KM 中不存在的边权设成 0 | 会被误当成合法匹配，应设极小值 |
| 13 | 上下界网络中忘记记录"下界已流"的贡献 | $d[v]$ 的符号与方向容易搞反 |
| 14 | 多组数据忘记 `init_flow` | 建议每次重建 |
| 15 | 用 `int` 存容量导致溢出 | 容量之和可能超过 $2^{31}$ |
