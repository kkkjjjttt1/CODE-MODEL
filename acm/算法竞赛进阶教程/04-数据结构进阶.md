## 4.1 线段树合并

### 适用场景

**每个点有一棵动态开点线段树**，需要把子树（或连通块）的信息合并起来。典型：

- 统计每个子树内各颜色的出现次数（合并颜色线段树）；
- 树上逆序对（[P3521 旋转treap](https://www.luogu.com.cn/problem/P3521)）；
- 连通块第 $k$ 小（[P3224 永无乡](https://www.luogu.com.cn/problem/P3224)）。

### 原理

把两棵线段树的对应位置**相加**：

```
merge(a, b):
    if a == 0: return b
    if b == 0: return a
    if 叶子: sum[a] += sum[b]; return a
    ls[a] = merge(ls[a], ls[b])
    rs[a] = merge(rs[a], rs[b])
    pushUp(a)
    return a
```

**复杂度**：看似 $O(\text{节点数})$，但注意每次 `merge` 返回后 $b$ 树被"吃掉"。全局来看，**每合并一次就少一个节点**，总复杂度 $O(\text{总节点数}) = O(n\log n)$。

### 模板

```cpp
// ==================== 线段树合并 ====================
// 动态开点权值线段树，支持合并；这里以"统计子树内各颜色的出现次数"为例
const int MAXN = 100005;
const int LOGV = 18;                 // 值域大小 2^LOGV

int lc[MAXN * 20], rc[MAXN * 20], sum[MAXN * 20];
int root[MAXN], totNode;

int newNode() { ++totNode; lc[totNode] = rc[totNode] = sum[totNode] = 0; return totNode; }

// 单点插入：把值 pos 的计数 +1，返回新的根
int insert(int &node, int l, int r, int pos) {
    if (!node) node = newNode();
    ++sum[node];
    if (l == r) return node;
    int mid = (l + r) >> 1;
    if (pos <= mid) insert(lc[node], l, mid, pos);
    else insert(rc[node], mid + 1, r, pos);
    return node;
}

// 合并 a、b 两棵树，返回合并后的根（b 被并入 a）
int mergeTree(int a, int b, int l, int r) {
    if (!a) return b;
    if (!b) return a;
    if (l == r) { sum[a] += sum[b]; return a; }
    int mid = (l + r) >> 1;
    lc[a] = mergeTree(lc[a], lc[b], l, mid);
    rc[a] = mergeTree(rc[a], rc[b], mid + 1, r);
    sum[a] = sum[lc[a]] + sum[rc[a]];
    return a;
}

// 查询：区间 [ql, qr] 的计数和
int query(int node, int l, int r, int ql, int qr) {
    if (!node || qr < l || r < ql) return 0;
    if (ql <= l && r <= qr) return sum[node];
    int mid = (l + r) >> 1;
    return query(lc[node], l, mid, ql, qr) + query(rc[node], mid + 1, r, ql, qr);
}
```

**使用流程**（以"每个子树内不同颜色数"为例）：

1. 对每个点 $u$ 建一棵只含 `col[u]` 的线段树，`root[u] = insert(...)`；
2. DFS，回溯时 `root[u] = mergeTree(root[u], root[v], 1, V)`；
3. 在 $u$ 处查询 `query(root[u], ...)`。

## 4.2 李超线段树（Li Chao Segment Tree）

### 适用场景

**维护一堆直线（或线段），支持：**

- 插入一条直线 $y = kx + b$；
- 查询某个 $x$ 处所有直线的最小/最大值。

**用途**：斜率优化 DP 的另一种写法（不需要单调队列/凸包，支持任意插入顺序、甚至强制在线）；李超树合并。

### 原理

线段树每个节点存**一条"在该区间中点处最优的直线"**。插入新直线时，与节点存的直线比较：

- 若新直线在区间两端都更优 → 直接替换（旧直线被完全淘汰）；
- 若新直线在两端都不优 → 丢弃；
- 否则（在某端更优）→ 保留中点更优的那条，另一条递归下推到对应的那半边子区间。

**复杂度**：单次插入 $O(\log^2 V)$（若用"全局李超树"是 $O(\log V)$），查询 $O(\log V)$。

### 模板（维护最大值）

```cpp
// ==================== 李超线段树（全局维护最大值，正负无穷用 -INF/INF） ====================
const int MAXN = 100005;
const double INFDBL = 1e18;

struct Line {
    double k, b;                       // y = kx + b
    Line(double k = 0, double b = -INFDBL) : k(k), b(b) {}
    double at(double x) const { return k * x + b; }
};

Line tree[MAXN * 4];
int X0, X1;                            // x 的定义域 [X0, X1]

void insertLine(Line nw, int node, int l, int r) {
    int mid = (l + r) >> 1;
    bool leftBetter = nw.at(l) > tree[node].at(l);
    bool midBetter = nw.at(mid) > tree[node].at(mid);
    if (midBetter) std::swap(nw, tree[node]);       // 中点更优的留在本节点
    if (l == r) return;
    if (leftBetter != midBetter) insertLine(nw, node << 1, l, mid);       // 左半更优 → 递归左
    else insertLine(nw, node << 1 | 1, mid + 1, r);                       // 否则递归右
}

double queryMax(int node, int l, int r, int x) {
    double res = tree[node].at(x);
    if (l == r) return res;
    int mid = (l + r) >> 1;
    if (x <= mid) res = std::max(res, queryMax(node << 1, l, mid, x));
    else res = std::max(res, queryMax(node << 1 | 1, mid + 1, r, x));
    return res;
}
```

> **说明**：定义域是**整数**区间 $[X_0, X_1]$（把 $x$ 坐标离散化或直接取整数范围）。
> 若定义域很大（例如 $x$ 可达 $10^9$）而查询点只有 $O(n)$ 个，应先**离散化**所有查询点，再在离散化后的下标上建树。

**李超树 vs 斜率优化**：

| | 斜率优化（单调队列/凸包） | 李超线段树 |
|---|---|---|
| 前提 | 斜率单调、$x$ 单调 | 无要求 |
| 复杂度 | $O(n)$ | $O(n\log^2 V)$ |
| 代码 | 边界多、易错 | 模板化，不易错 |
| 支持强制在线 | 否（需离线） | 是 |

**结论**：**能写李超树就别写斜率优化**——除非数据规模逼你卡常数。

## 4.3 线段树分治 + 可撤销并查集

### 适用场景

**操作只在某个时间区间内有效**，例如：

- 动态图连通性（加边/删边，查询两点是否连通）；
- 每件物品只在 $[l, r]$ 时间内可用；
- "消失之物"型背包问题。

### 思想

把**时间轴**建成线段树。每个"存在于 $[l, r]$ 的操作"挂到 $O(\log T)$ 个线段树节点上。DFS 这棵线段树：

- 进入节点时，把挂在它上面的所有操作**应用**；
- 到达叶子时，回答该时刻的询问；
- 离开节点时，**撤销**这些操作。

**关键要求**：数据结构必须支持撤销（可持久化或可回滚）。最常用的是**可撤销并查集**（按秩合并 + 栈记录，**不能路径压缩**）。

### 可撤销并查集

```cpp
// ==================== 可撤销并查集（按秩合并，O(log n) 每次操作） ====================
const int MAXN = 100005;
int ufFa[MAXN], ufRk[MAXN];
int histU[MAXN * 40], histV[MAXN * 40], histTop;   // 记录每次合并（用于撤销）

void initUF(int n) {
    for (int i = 1; i <= n; i++) { ufFa[i] = i; ufRk[i] = 1; }
    histTop = 0;
}

int findUF(int x) {                    // 注意：不能路径压缩（否则无法撤销）
    while (ufFa[x] != x) x = ufFa[x];
    return x;
}

// 返回是否真的发生了合并（用于撤销时判断）
bool uniteUF(int a, int b) {
    int ra = findUF(a), rb = findUF(b);
    if (ra == rb) { histU[++histTop] = 0; histV[histTop] = 0; return false; }
    if (ufRk[ra] < ufRk[rb]) std::swap(ra, rb);     // 按秩合并
    ufFa[rb] = ra;
    ufRk[ra] += (ufRk[ra] == ufRk[rb]);
    histU[++histTop] = ra; histV[histTop] = rb;
    return true;
}

void undoUF(int stamp) {               // 撤销到 stamp 层
    while (histTop > stamp) {
        int ra = histU[histTop], rb = histV[histTop];
        --histTop;
        if (ra) { ufFa[rb] = rb; ufRk[ra] -= (ufRk[ra] == ufRk[rb] + 1); }
    }
}
// ==================== 线段树分治框架（配合上面的可撤销并查集使用） ====================
// 每个操作：在时间区间 [l, r] 内生效
struct Operation { int u, v; };        // 以"加边"为例

const int MAXT = 100005;
vector<Operation> segOps[MAXT * 4];
int ans[MAXT];

// 把操作挂到时间线段树上（[l, r] 为闭区间）
void addOp(int node, int nl, int nr, int l, int r, const Operation &op) {
    if (r < nl || nr < l) return;
    if (l <= nl && nr <= r) { segOps[node].push_back(op); return; }
    int mid = (nl + nr) >> 1;
    addOp(node << 1, nl, mid, l, r, op);
    addOp(node << 1 | 1, mid + 1, nr, l, r, op);
}

// 具体问题在这里实现"应用"（进入节点时调用）
void applyOp(const Operation &op) {
    // 例如：加一条边 (u, v)
    uniteUF(op.u, op.v);
}

void dfsSeg(int node, int l, int r) {
    int stamp = histTop;                       // 记录进入时的状态
    for (const auto &op : segOps[node]) applyOp(op);   // 应用本节点所有操作
    if (l == r) {
        // 在 l 时刻回答询问（例如查询两点是否连通）
        ans[l] = (findUF(1) == findUF(l) ? 1 : 0);
    } else {
        int mid = (l + r) >> 1;
        dfsSeg(node << 1, l, mid);
        dfsSeg(node << 1 | 1, mid + 1, r);
    }
    undoUF(stamp);                             // 撤销本节点的操作
}
```

> **注意**：撤销只回滚**并查集的合并**，`segOps[node]` 不必清空（每个节点只会被访问一次）。但多组数据时要在 `initUF` 里把整棵树清空。

## 4.4 吉司机线段树（Segment Tree Beats）

### 适用场景

支持如下操作的数据结构题：

- 区间 $a_i \leftarrow \min(a_i, x)$（区间 chmin）；
- 区间 chmax；
- 区间求和、求最大值、求最小值。

暴力修改每次可能触及 $O(n)$ 个位置，但吉司机线段树用**势能分析**证明总复杂度是 $O((n+q)\log n)$（在只有 chmin 时）。

### 核心思想

每个节点维护：

| 变量 | 含义 |
|---|---|
| `mx` | 区间最大值 |
| `se` | 区间**次大值**（严格小于 `mx` 的最大值，不存在则 $-\infty$） |
| `cnt` | 区间内等于 `mx` 的个数 |
| `sum` | 区间和 |

执行 `chmin(u, x)`：

- 若 $x \ge mx$：无影响，直接返回；
- 若 $se < x < mx$：**只需把 `cnt` 个最大值改成 $x$**，$O(1)$ 完成（`sum -= cnt*(mx-x)`, `mx = x`）；
- 若 $x \le se$：无法偷懒，递归到两个儿子。

**为什么快？** 每次"递归下去"都会让区间的**不同取值个数**减少（势能），总势能有限。

```cpp
// ==================== 吉司机线段树（区间 chmin + 区间求和 + 区间最大值） ====================
const int MAXN = 100005;
typedef long long ll;
const int INFV = 0x3f3f3f3f;

int mx[MAXN * 4], se[MAXN * 4], cnt[MAXN * 4];
ll sum[MAXN * 4];

void pushUp(int node) {
    int l = node << 1, r = node << 1 | 1;
    sum[node] = sum[l] + sum[r];
    if (mx[l] == mx[r]) {
        mx[node] = mx[l];
        cnt[node] = cnt[l] + cnt[r];
        se[node] = std::max(se[l], se[r]);
    } else if (mx[l] > mx[r]) {
        mx[node] = mx[l];
        cnt[node] = cnt[l];
        se[node] = std::max(se[l], mx[r]);
    } else {
        mx[node] = mx[r];
        cnt[node] = cnt[r];
        se[node] = std::max(mx[l], se[r]);
    }
}

void build(int node, int l, int r, const int *a) {
    if (l == r) { mx[node] = sum[node] = a[l]; se[node] = -INFV; cnt[node] = 1; return; }
    int mid = (l + r) >> 1;
    build(node << 1, l, mid, a);
    build(node << 1 | 1, mid + 1, r, a);
    pushUp(node);
}

// 把 node 维护区间内所有 == mx 的值改成 x（要求 se < x < mx）
void updateMin(int node, int x) {
    if (x >= mx[node]) return;
    sum[node] -= (ll)cnt[node] * (mx[node] - x);
    mx[node] = x;
}

void pushDown(int node) {
    updateMin(node << 1, mx[node]);
    updateMin(node << 1 | 1, mx[node]);
}

void chminRange(int node, int l, int r, int ql, int qr, int x) {
    if (qr < l || r < ql || x >= mx[node]) return;      // 无影响
    if (ql <= l && r <= qr && se[node] < x) { updateMin(node, x); return; }   // 可偷懒
    int mid = (l + r) >> 1;
    pushDown(node);
    chminRange(node << 1, l, mid, ql, qr, x);
    chminRange(node << 1 | 1, mid + 1, r, ql, qr, x);
    pushUp(node);
}

ll querySum(int node, int l, int r, int ql, int qr) {
    if (qr < l || r < ql) return 0;
    if (ql <= l && r <= qr) return sum[node];
    int mid = (l + r) >> 1;
    pushDown(node);
    return querySum(node << 1, l, mid, ql, qr) + querySum(node << 1 | 1, mid + 1, r, ql, qr);
}
```

> **注意**：一旦引入"区间加"等操作，吉司机线段树的标记设计会复杂得多（需要同时维护最大值/次大值的加法标记），实现难度陡增。竞赛中建议**只在题目明确需要 chmin/chmax + 求和时**才用它。

## 4.5 可并堆（左偏树）

### 适用场景

- 需要合并两个堆（普通 `priority_queue` 不支持 $O(\log n)$ 合并）；
- 树上"带权最大匹配"/"每次合并子树的最优解"。

### 模板（小根堆）

```cpp
// ==================== 左偏树（可并堆） ====================
const int MAXN = 100005;
int ltL[MAXN], ltR[MAXN], ltDis[MAXN];     // 左儿子、右儿子、零距离（null path length）
int ltVal[MAXN], ltFa[MAXN];

void initLT(int n) {
    for (int i = 1; i <= n; i++) { ltL[i] = ltR[i] = ltFa[i] = 0; ltDis[i] = 1; }
}

int findLTRoot(int x) {                     // 并查集式找根（可加路径压缩）
    while (ltFa[x]) x = ltFa[x];
    return x;
}

// 合并两堆，返回新根（小根）
int mergeLT(int x, int y) {
    if (!x || !y) return x | y;
    if (ltVal[x] > ltVal[y]) std::swap(x, y);       // 保证 x 的根更小
    ltR[x] = mergeLT(ltR[x], y);
    if (ltDis[ltL[x]] < ltDis[ltR[x]]) std::swap(ltL[x], ltR[x]);   // 保持左偏
    ltDis[x] = ltDis[ltR[x]] + 1;
    ltFa[ltL[x]] = ltFa[ltR[x]] = x;
    return x;
}

// 弹出堆顶，返回新的堆根
int popLT(int x) {
    int l = ltL[x], r = ltR[x];
    ltVal[x] = -1;
    ltFa[l] = ltFa[r] = 0;
    ltL[x] = ltR[x] = 0; ltDis[x] = 1;
    return mergeLT(l, r);
}
```

**复杂度**：合并 $O(\log n)$（左偏性质保证右链长度 $O(\log n)$）。

**经典题**：[P3377 【模板】左偏树](https://www.luogu.com.cn/problem/P3377)、[P2713 罗马游戏](https://www.luogu.com.cn/problem/P2713)、[APIO2012 派遣](https://www.luogu.com.cn/problem/P1552)。

## 4.6 笛卡尔树

### 定义

给定序列 $a_{1..n}$，笛卡尔树是一棵二叉树，满足：

1. **中序遍历就是原序列**；
2. **堆性质**：每个节点的权值小于（或大于）其子树中所有节点（小根笛卡尔树对应 RMQ 最小值）。

### 构建（单调栈，$O(n)$）

```cpp
// ==================== 笛卡尔树（小根） ====================
const int MAXN = 100005;
int a[MAXN], lcD[MAXN], rcD[MAXN], stkD[MAXN];

// 返回根节点编号
int buildCartesian(int n) {
    int top = 0;
    for (int i = 1; i <= n; i++) {
        int last = 0;
        while (top && a[stkD[top]] > a[i]) last = stkD[top--];    // 弹出比 a[i] 大的
        lcD[i] = last;                                            // 最后弹出的成为左儿子
        if (top) rcD[stkD[top]] = i;                              // 栈顶的右儿子指向 i
        stkD[++top] = i;
    }
    return stkD[1];                                               // 栈底是根
}
```

**用途**：

| 用途 | 说明 |
|---|---|
| **RMQ → LCA** | 区间最小值位置 = 笛卡尔树上两点的 LCA |
| **区间 DP 优化** | "最小值分治"（按最小值位置划分）正好是笛卡尔树的结构 |
| **直方图最大矩形** | 单调栈问题的树形视角 |
| **树上问题转序列** | 笛卡尔树把序列问题变成树形 DP |

**典型用法：分治最值问题**

求"所有子区间的最小值之和"：建小根笛卡尔树，每个节点 $u$ 的贡献 = $a_u \times \text{size}_L \times \text{size}_R$（跨越 $u$ 的区间以 $u$ 为最小值）。

## 4.7 分块

### 思想

把序列分成 $\sqrt n$ 块，**整块打标记、散块暴力**。

**复杂度**：区间操作 $O(\sqrt n)$，某些问题可以做到 $O(\sqrt n)$ 查询 / $O(1)$ 修改（或反之）。

**适用**：需要"支持修改 + 区间查询"，但线段树难以维护（如区间众数、区间第 $k$ 小、查询值域内某种性质）；或者标记合并不可行。

### 模板（区间加 + 区间求和）

```cpp
// ==================== 分块（区间加 + 区间求和） ====================
const int MAXN = 100005;
typedef long long ll;

int blkSize, blkCnt;
int bel[MAXN], blkL[MAXN], blkR[MAXN];
ll a[MAXN], addTag[MAXN], blkSum[MAXN];

void buildBlock(int n) {
    blkSize = (int)sqrt((double)n) + 1;
    blkCnt = (n + blkSize - 1) / blkSize;
    for (int i = 1; i <= n; i++) bel[i] = (i - 1) / blkSize + 1;
    for (int b = 1; b <= blkCnt; b++) {
        blkL[b] = (b - 1) * blkSize + 1;
        blkR[b] = std::min(n, b * blkSize);
        blkSum[b] = 0; addTag[b] = 0;
        for (int i = blkL[b]; i <= blkR[b]; i++) blkSum[b] += a[i];
    }
}

void rangeAdd(int l, int r, ll v) {
    if (bel[l] == bel[r]) {
        for (int i = l; i <= r; i++) { a[i] += v; blkSum[bel[i]] += v; }
        return;
    }
    for (int i = l; i <= blkR[bel[l]]; i++) { a[i] += v; blkSum[bel[i]] += v; }
    for (int i = blkL[bel[r]]; i <= r; i++) { a[i] += v; blkSum[bel[i]] += v; }
    for (int b = bel[l] + 1; b <= bel[r] - 1; b++) { addTag[b] += v; blkSum[b] += v * (blkR[b] - blkL[b] + 1); }
}

ll rangeSum(int l, int r) {
    ll res = 0;
    if (bel[l] == bel[r]) {
        for (int i = l; i <= r; i++) res += a[i] + addTag[bel[i]];
        return res;
    }
    for (int i = l; i <= blkR[bel[l]]; i++) res += a[i] + addTag[bel[i]];
    for (int i = blkL[bel[r]]; i <= r; i++) res += a[i] + addTag[bel[i]];
    for (int b = bel[l] + 1; b <= bel[r] - 1; b++) res += blkSum[b];
    return res;
}
```

**"数列分块入门九题"** 是公认的分块训练路线（区间加、区间乘、区间开方、区间众数、区间第 $k$ 小、区间前驱……）。

## 4.8 莫队家族

### 4.8.1 普通莫队

**适用**：**离线**区间查询，能够在 $O(1)$ 或 $O(\log n)$ 内"加入/删除一个元素"并维护答案，且**无法用线段树合并**（如区间不同颜色数、区间众数）。

**做法**：把所有询问按 $\left(\lfloor l/B\rfloor,\ r\right)$ 排序（奇偶优化：奇数块按 $r$ 降序），用双指针在区间上"爬"。

**复杂度**：$O\left(n\sqrt q\right)$（块长取 $n/\sqrt q$ 最优）。

```cpp
// ==================== 普通莫队（区间不同颜色数） ====================
const int MAXN = 100005;
int blockSize;

struct Query { int l, r, id; };
bool cmpQuery(const Query &a, const Query &b) {
    int ba = a.l / blockSize, bb = b.l / blockSize;
    if (ba != bb) return ba < bb;
    return (ba & 1) ? a.r > b.r : a.r < b.r;      // 奇偶优化：常数减半
}

int curL = 1, curR = 0;
int cntColM[MAXN], distinctCnt;
int aM[MAXN];
int ansM[MAXN];

void addPos(int p) { if (++cntColM[aM[p]] == 1) ++distinctCnt; }
void delPos(int p) { if (--cntColM[aM[p]] == 0) --distinctCnt; }

void solveMo(const vector<Query> &qs, int n) {
    blockSize = std::max(1, (int)(n / std::sqrt((double)qs.size())));
    vector<Query> order = qs;
    std::sort(order.begin(), order.end(), cmpQuery);
    curL = 1; curR = 0; distinctCnt = 0;
    for (const auto &q : order) {
        while (curL > q.l) addPos(--curL);
        while (curR < q.r) addPos(++curR);
        while (curL < q.l) delPos(curL++);
        while (curR > q.r) delPos(curR--);
        ansM[q.id] = distinctCnt;
    }
}
```

### 4.8.2 带修莫队

**适用**：既有修改又有区间询问。把"修改"也看作一维（时间轴），变成三维莫队：块长取 $n^{2/3}$，复杂度 $O(n^{5/3})$。

排序键：`(l 的块, r 的块, t)`，同样加奇偶优化。

### 4.8.3 回滚莫队（只加不减）

**适用**：加入容易、**删除困难**（如维护最大值）。做法：

- 同一块内的询问：暴力计算 $O(\sqrt n)$；
- 跨块的询问：对右端点单调递增的部分只加不删；左端点部分每次**回滚**（记录状态并撤销）。

复杂度 $O(n\sqrt q)$，但要求操作可回滚。

### 4.8.4 树上莫队

把树转成**欧拉序**（每个点进出各记一次，长度 $2n$），路径 $(u,v)$ 的查询转化为欧拉序上的区间查询（配合 LCA 补充）。出现奇数次的点才计入答案。

### 4.8.5 二次离线莫队

当"移动指针"的单次代价是 $O(\log n)$ 或更高（如查询区间内 $\le x$ 的数的个数），把每次移动贡献拆成"前缀查询"离线下来用其他手段（如 BIT、分块）批量处理，把 $O(n\sqrt q\log n)$ 降到 $O(n\sqrt q + n\log n)$。

**莫队选择速查**：

| 情形 | 选择 |
|---|---|
| 可加可删、$O(1)$ 维护 | 普通莫队 |
| 带修改 | 带修莫队（$n^{2/3}$ 块） |
| 只能加不能删 | 回滚莫队 |
| 树上的路径统计 | 树上莫队 |
| 单次移动 $O(\log n)$ 太慢 | 二次离线莫队 |

## 4.9 根号分治

### 思想

按**某个量的阈值**分类讨论，两类的复杂度互补。经典三种：

| 类型 | 做法 |
|---|---|
| **按出现次数** | 出现次数 $> \sqrt n$ 的"重"元素只有 $O(\sqrt n)$ 个，预处理；其他的暴力 |
| **按度数** | 度数 $> \sqrt m$ 的"大点"只有 $O(\sqrt m)$ 个，预处理；小点暴力 |
| **按值域/模数** | 模数 $> \sqrt n$ 时答案可以直接枚举（层数少）；模数 $\le \sqrt n$ 时预处理 |

**典型应用**：

- 询问"有多少数等于 $x$"且带修改 → 值域分块；
- 图上的"三度点"问题（三元环计数：按度数定向，$O(m\sqrt m)$）；
- "每个模数下的余数统计"（[P3645](https://www.luogu.com.cn/problem/P3645) 类）；
- 序列上的"大段/小段"处理（分块 + 分类讨论）。

### 例：三元环计数（$O(m\sqrt m)$）

把每条边定向为"从度数小的点指向度数大的点"（度数相同按编号），则每个点的出度 $\le \sqrt{2m}$。枚举 $u$，枚举它的出边 $u \to v$，再枚举 $v$ 的出边 $v \to w$，若 $w$ 也与 $u$ 相邻则构成三元环。

```cpp
// ==================== 三元环计数（O(m sqrt m)） ====================
// 返回三元环个数。n 个点、m 条无向边
long long countTriangles(int n, const std::vector<std::pair<int,int>> &edges) {
    std::vector<int> deg(n + 1, 0);
    for (auto &e2 : edges) { ++deg[e2.first]; ++deg[e2.second]; }
    std::vector<std::vector<int>> out(n + 1);
    for (auto &e2 : edges) {
        int u = e2.first, v = e2.second;
        if (deg[u] > deg[v] || (deg[u] == deg[v] && u > v)) std::swap(u, v);
        out[u].push_back(v);                  // 从"小"指向"大"
    }
    std::vector<char> mark(n + 1, 0);
    long long cnt = 0;
    for (int u = 1; u <= n; u++) {
        for (int v : out[u]) mark[v] = 1;
        for (int v : out[u])
            for (int w : out[v]) if (mark[w]) ++cnt;
        for (int v : out[u]) mark[v] = 0;
    }
    return cnt;
}
```

## 4.10 K-D Tree 与珂朵莉树（简介）

### K-D Tree

**用途**：$k$ 维空间的正交范围查询、最近邻搜索、$k$ 维偏序。
**做法**：按维度轮流选"方差最大"的维度作为切分维，取中位数作为根，递归建树（平衡二叉搜索树）。
**复杂度**：随机数据下范围查询 $O(n^{1-1/k})$；最坏 $O(n)$（会被卡）。
**竞赛用法**：常作为"暴力重构 + 剪枝"的手段（如三维偏序、动态最近点对），或用来替代树套树。

### 珂朵莉树（Chtholly Tree / ODT）

**适用**：**区间赋值**（`assign`）操作较多的题目。用 `std::set` 维护若干"值相同的连续区间"，赋值时把区间拆开并合并。

```cpp
// ==================== 珂朵莉树（区间赋值 + 区间求和） ====================
#include <set>
struct OdtNode {
    int l, r;
    mutable long long v;
    bool operator<(const OdtNode &o) const { return l < o.l; }
};
std::set<OdtNode> odt;

// 把 pos 处切开，返回以 pos 为左端点的迭代器
std::set<OdtNode>::iterator splitOdt(int pos) {
    auto it = odt.lower_bound({pos, 0, 0});
    if (it != odt.end() && it->l == pos) return it;
    --it;
    int l = it->l, r = it->r; long long v = it->v;
    odt.erase(it);
    odt.insert({l, pos - 1, v});
    return odt.insert({pos, r, v}).first;
}

void assignOdt(int l, int r, long long v) {
    auto itr = splitOdt(r + 1), itl = splitOdt(l);
    odt.erase(itl, itr);
    odt.insert({l, r, v});
}
```

**复杂度**：单次 `assign` 均摊 $O(\log n)$；总复杂度依赖 `assign` 的次数，数据随机时期望 $O(n\log\log n)$。**可以被构造数据卡掉**，比赛时只作为"能过就行"的兜底手段。

## 4.11 例题与套路

| 题目特征 | 方法 |
|---|---|
| 每个点/子树有"颜色集合"，要合并统计 | 线段树合并 |

## 4.12 易错点清单

| 编号 | 易错点 | 说明 |
|---|---|---|
| 1 | 线段树合并时把 `b` 也保留了 | `merge(a,b)` 后 `b` 已被并入 `a`，不能再单独用 |
| 2 | 线段树合并空间开小 | 每点一棵线段树：$O(n\log V)$，通常需要 `n * 20` 个节点 |
| 3 | 李超树定义域没离散化 | $x$ 值域大时必须先收集所有查询点 |
| 4 | 李超树维护最小值时不等号方向写反 | 统一封装 `better()` 函数 |
| 5 | 可撤销并查集用了路径压缩 | 无法撤销！只能按秩合并 |
| 6 | `undoUF` 中秩的恢复写错 | 需要精确记录"是否增加了秩" |
| 7 | 线段树分治忘记清空节点上的操作列表 | 多组数据会残留 |
| 8 | 吉司机线段树的 `pushDown` 忘记传 `mx` | 下推的是"父节点的最大值"作为 chmin 的上界 |
| 9 | 左偏树的 `fa` 指针没维护 | 找根会错 |
| 10 | 笛卡尔树建树时比较方向搞反 | 小根堆用 `>` 弹出 |
| 11 | 莫队块长取 $\sqrt n$ 而非 $n/\sqrt q$ | 询问少时前者会慢 |
| 12 | 莫队忘记奇偶优化 | 常数约差 2 倍 |
| 13 | 回滚莫队忘记"块内暴力"分支 | 会漏答案 |
| 14 | 根号分治阈值选错 | 一般取 $\sqrt n$ 或 $\sqrt m$，需要按常数调 |
| 15 | 珂朵莉树在无 `assign` 的题上使用 | 会退化为 $O(n)$ 每次 |
