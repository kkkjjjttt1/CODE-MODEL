## 3.1 点分治

### 解决什么问题

**树上路径统计**：统计有多少条路径满足某个性质（长度 $\le k$、边权和 $= k$、颜色数 $\le c$……）。
直接枚举所有路径是 $O(n^2)$，点分治把它降到 $O(n\log n)$（每层统计 $O(n)$，共 $O(\log n)$ 层）。

### 核心思想：按重心分治

**重心**：删掉它之后，剩余各连通块大小的最大值最小的点。性质：**删掉重心后，每个连通块大小 $\le n/2$**。

于是"所有路径"可以按"是否经过重心"分成两类：

1. **经过重心 $c$ 的路径**：在 $c$ 的视角下统计（把每条路径拆成 $c \to u$ 与 $c \to v$ 两段）；
2. **不经过 $c$ 的路径**：完全落在某个连通块内 → 递归处理该连通块。

因为每次规模减半，递归深度是 $O(\log n)$，总复杂度 $O(n \log n)$。

### 关键技巧：容斥去重

统计"经过 $c$ 的路径"时，直接对 $c$ 的所有子树一起统计会把**同一棵子树内**的两点也算进来（它们的路径实际不经过 $c$）。做法是：

$$\text{ans} += \text{calc}(c, 0) - \sum_{\text{子树 } v} \text{calc}(v, w(c,v)).$$

其中 `calc(x, d0)` 统计"以 $x$ 为根、初始距离 $d0$ 的子树内，两点距离满足条件的点对数（含 $x$ 自身）"。

### 模板（以"统计距离 $\le K$ 的点对数"为例）

```cpp
// ==================== 点分治模板 ====================
// 统计树上距离 <= K 的无序点对数（洛谷 P4178 风格）
const int MAXN = 100005;
typedef long long ll;

struct Edge { int to, w, nxt; } e[MAXN * 2];
int head[MAXN], ecnt = 1;
void addEdge(int u, int v, int w) {
    e[++ecnt] = {v, w, head[u]}; head[u] = ecnt;
    e[++ecnt] = {u, w, head[v]}; head[v] = ecnt;
}

bool removed[MAXN];        // 该点是否已作为重心被"删除"
int sz[MAXN];
int K;                     // 距离限制

int getSize(int u, int fa) {
    sz[u] = 1;
    for (int i = head[u]; i; i = e[i].nxt) {
        int v = e[i].to;
        if (v == fa || removed[v]) continue;
        sz[u] += getSize(v, u);
    }
    return sz[u];
}

// 在 u 的连通块（大小 tot）内找重心
int getCentroid(int u, int fa, int tot) {
    for (int i = head[u]; i; i = e[i].nxt) {
        int v = e[i].to;
        if (v == fa || removed[v]) continue;
        if (sz[v] * 2 > tot) return getCentroid(v, u, tot);
    }
    return u;
}

int dis[MAXN], disCnt;

void collectDis(int u, int fa, int d) {
    dis[++disCnt] = d;
    for (int i = head[u]; i; i = e[i].nxt) {
        int v = e[i].to;
        if (v == fa || removed[v]) continue;
        collectDis(v, u, d + e[i].w);
    }
}

// 统计：以 u 为根、初始距离 d0 的子树内，两两距离 <= K 的点对数（含 u 自身）
ll calc(int u, int d0) {
    disCnt = 0;
    collectDis(u, 0, d0);
    sort(dis + 1, dis + disCnt + 1);
    ll res = 0;
    for (int l = 1, r = disCnt; l < r; ) {
        if (dis[l] + dis[r] <= K) { res += r - l; ++l; }    // l 与 (l+1..r) 都合法
        else --r;
    }
    return res;
}

ll ans = 0;

void divide(int u) {
    removed[u] = true;
    ans += calc(u, 0);                                 // 经过 u 的全部点对（含重复）
    for (int i = head[u]; i; i = e[i].nxt) {
        int v = e[i].to;
        if (removed[v]) continue;
        ans -= calc(v, e[i].w);                        // 容斥：减掉同一子树内被多算的
        int tot = getSize(v, u);
        int c = getCentroid(v, u, tot);
        divide(c);
    }
}

// 调用：ans = 0; getSize(1, 0); divide(getCentroid(1, 0, getSize(1, 0)));
```

### 点分治的常见变体

| 题目类型 | 统计方式 |
|---|---|
| 距离 $\le K$ 的点对数 | 双指针（排序后） |
| 距离恰好 $= K$ 的路径是否存在 | 桶数组 / 排序 + 二分 |
| 边权和为 $K$ 的倍数 | 对 $K$ 取模后统计余数 |
| 路径上颜色数 $\le c$ | 双指针 / 树上维护颜色计数 |
| 路径上第 $k$ 大 | 二分答案 + 点分治判定 |
| 带修改的路径统计 | 点分树（见 §3.2） |

### 复杂度与常数

- 理论：$O(n\log n)$（每层 $O(n)$，深度 $O(\log n)$）；
- 实际：每层都要排序 → $O(n\log^2 n)$；常数较大，$n \le 10^5$ 通常能过，$n \le 10^6$ 需要谨慎；
- **优化**：把 `sort` 换成计数排序/桶（值域小时），或用 `k` 短路。

## 3.2 点分树（动态点分治）

**思想**：把点分治的**分治结构本身**建成一棵树（每个重心连向它上一层重心的边），称为**点分树**。

**性质**：

1. 点分树的深度是 $O(\log n)$；
2. 对任意 $u, v$，$\mathrm{LCA}_{\text{点分树}}(u,v)$ 在**原树**上位于 $u \to v$ 的路径上；
3. 每条路径在点分树上恰好被"统计一次"（在该路径的两个端点所在连通块分离的那个重心处）。

**用途**：处理**带修改**的树上路径统计。每次修改 $u$ 的值时，只需沿着点分树向上更新 $O(\log n)$ 个祖先的信息；询问时同样沿链合并。

**实现要点**：

- 预处理 $\text{dist}(u, \text{祖先})$ 的 LCA 距离（用倍增 LCA 或欧拉序 RMQ）；
- 每个点分树节点维护"以它为重心时的子树信息"以及"以它为重心、但它所属的上级重心分支的信息"（用于容斥去重）。

**典型题**：[P6329 震波](https://www.luogu.com.cn/problem/P6329)、[P3241 开店](https://www.luogu.com.cn/problem/P3241)、[CF757G Can Bash Save the Day?](https://codeforces.com/problemset/problem/757/G)。

## 3.3 DSU on tree（树上启发式合并）

### 解决什么问题

**子树统计问题**：对每个点 $u$，求它子树内满足某个性质的值（子树颜色众数、子树内出现次数最多的颜色编号之和……）。
暴力对每个点扫子树是 $O(n^2)$，DSU on tree 把它降到 $O(n\log n)$。

### 算法流程

对每个点，**保留重儿子的答案**（不清理），把轻儿子的子树暴力加进来：

```
dfs(u, keep):
    1. 对所有轻儿子 v: dfs(v, false)        // 处理完不保留
    2. 对重儿子 son[u]: dfs(son[u], true)   // 保留贡献
    3. 把轻儿子子树内的点全部暴力加入       // O(size of light subtrees)
    4. 把 u 自己加入
    5. ans[u] = 当前统计值
    6. if (!keep) 撤销 u 子树的全部贡献
```

**复杂度证明**：一个点被"暴力加入"的次数，等于它到根的路径上**轻边**的条数。每经过一条轻边，子树大小至少减半，所以轻边数 $\le \log n$。故总复杂度 $O(n\log n)$。

> **和点分治的区别**：点分治处理"路径"，DSU on tree 处理"子树"。两者的复杂度都是 $O(n\log n)$，但思路完全相反。

### 模板（以"子树众数颜色编号之和"为例，即 CF600E）

```cpp
// ==================== DSU on tree 模板 ====================
// 对每个点 u，求 u 子树中出现次数最多的颜色编号之和（CF600E Lomsat gelral）
const int MAXN = 100005;
typedef long long ll;

vector<int> g[MAXN];
int col[MAXN];
int sz[MAXN], heavy[MAXN];
int cntCol[MAXN];                 // 颜色计数
int maxCnt;                       // 当前最大出现次数
ll curSum;                        // 当前"出现次数 == maxCnt"的颜色编号之和
ll ansDsu[MAXN];

void dfsSize(int u, int fa) {
    sz[u] = 1; heavy[u] = 0;
    for (int v : g[u]) {
        if (v == fa) continue;
        dfsSize(v, u);
        sz[u] += sz[v];
        if (heavy[u] == 0 || sz[v] > sz[heavy[u]]) heavy[u] = v;
    }
}

// 把 u 子树的贡献整体 +1 或 -1
void addSubtree(int u, int fa, int delta) {
    int c = col[u];
    cntCol[c] += delta;
    if (cntCol[c] > maxCnt) { maxCnt = cntCol[c]; curSum = c; }
    else if (cntCol[c] == maxCnt) { curSum += c; }
    for (int v : g[u]) if (v != fa) addSubtree(v, u, delta);
}

void dfsDsu(int u, int fa, bool keep) {
    for (int v : g[u])                                  // 先处理轻儿子（不保留）
        if (v != fa && v != heavy[u]) dfsDsu(v, u, false);
    if (heavy[u]) dfsDsu(heavy[u], u, true);            // 重儿子保留
    for (int v : g[u])                                  // 轻儿子子树暴力加入
        if (v != fa && v != heavy[u]) addSubtree(v, u, +1);
    // 加入 u 自身
    cntCol[col[u]]++;
    if (cntCol[col[u]] > maxCnt) { maxCnt = cntCol[col[u]]; curSum = col[u]; }
    else if (cntCol[col[u]] == maxCnt) { curSum += col[u]; }

    ansDsu[u] = curSum;
    if (!keep) {
        addSubtree(u, fa, -1);                          // 撤销整棵子树
        maxCnt = 0; curSum = 0;                         // 复位全局统计量
    }
}
```

> **注意撤销**：`addSubtree(u, fa, -1)` 会把 `cntCol` 减回去，但 `maxCnt/curSum` 无法"减回去"，所以直接重置。
> 如果题目要求"撤销后 maxCnt 必须精确"（例如统计量还参与其他计算），就不能这样偷懒，需要写成支持删除的版本（比如用 `set` 或线段树维护）。

| 题目 | 统计量 |
|---|---|
| [CF600E Lomsat gelral](https://codeforces.com/problemset/problem/600/E) | 子树众数颜色编号之和 |
| [P3521 旋转treap](https://www.luogu.com.cn/problem/P3521) | 逆序对（线段树合并也可） |

## 3.4 长链剖分

### 与重链剖分的区别

| | 重链剖分（HLD） | 长链剖分 |
|---|---|---|
| "重儿子"定义 | 子树**大小**最大 | 子树**深度**（最长链长度）最大 |
| 用途 | 路径查询、LCA | 与**深度**相关的 DP 合并 |
| 关键性质 | 每条路径被 $O(\log n)$ 条链覆盖 | 每条长链的长度之和 = $n$（总长 $O(n)$） |

**核心优势**：长链剖分可以做到 $O(n)$ 合并"以深度为下标"的 DP 数组——只要把重儿子的 DP 数组**指针复用**（数组平移一位）。

### 经典应用 1：$O(n\log n)$ 预处理、$O(1)$ 查询的 $k$ 级祖先

预处理出每条长链顶端向上 $2^i$ 级的祖先，利用"长度和 $O(n)$"的性质做到 $O(1)$ 查询。

### 经典应用 2：CF1009F Dominant Indices

**问题**：对每个 $u$，求 $u$ 子树内**距离 $u$ 深度为 $d$ 的点数最多**的最小 $d$。

**DP**：$f[u][d]$ = $u$ 子树中与 $u$ 距离为 $d$ 的点数，转移 $f[u][d] = \sum_{v}f[v][d-1]$。

用长链剖分 + 数组复用：

```cpp
// ==================== 长链剖分：CF1009F Dominant Indices ====================
// f[u][d] = u 子树中与 u 距离为 d 的点数；求使 f[u][d] 最大的最小 d
const int MAXN = 1000005;
vector<int> g[MAXN];
int dep[MAXN], sonLong[MAXN];     // 长儿子（子树深度最大的儿子）
int buf[MAXN];                    // 公用数组，每条长链分配一段
int *f[MAXN];                     // f[u] 指向 buf 中属于 u 的段
int ansLen[MAXN];
int bufPtr;

// 注意：这里的 dep[u] 表示"u 的子树中最深点到 u 的距离 + 1"（即长链长度），不是普通深度！
void dfsDeep(int u, int fa) {
    for (int v : g[u]) {
        if (v == fa) continue;
        dfsDeep(v, u);
        if (dep[v] > dep[sonLong[u]]) sonLong[u] = v;   // dep[v] 已是 v 子树的最深深度
    }
    dep[u] = dep[sonLong[u]] + 1;
}

void solveLong(int u, int fa) {
    f[u][0] = 1;
    if (sonLong[u]) {
        f[sonLong[u]] = f[u] + 1;          // 关键：重儿子复用父数组（平移一位）
        solveLong(sonLong[u], u);
        ansLen[u] = ansLen[sonLong[u]] + 1;
    }
    for (int v : g[u]) {
        if (v == fa || v == sonLong[u]) continue;
        f[v] = buf + bufPtr; bufPtr += dep[v];      // 给轻儿子长链分配新段
        solveLong(v, u);
        for (int d = 1; d <= dep[v]; d++) {         // 暴力合并（总复杂度 O(n)）
            f[u][d] += f[v][d - 1];
            if (f[u][d] > f[u][ansLen[u]] ||
                (f[u][d] == f[u][ansLen[u]] && d < ansLen[u]))
                ansLen[u] = d;
        }
    }
    if (f[u][ansLen[u]] == 1) ansLen[u] = 0;        // 只有自己时答案为 0
}

// ============ 调用顺序（很容易写错！）============
// dfsDeep(1, 0);                 // 1) 先求出每个点的长儿子与长链长度 dep[]
// f[1] = buf;                    // 2) 根的段从 buf 开头开始
// bufPtr = dep[1];               // 3) 关键！分配指针跳过"根的那一段"，否则会与根段重叠
// solveLong(1, 0);
```

> **踩坑提醒**：`bufPtr` 的初值必须是 `dep[1]`（根所在长链的长度），而不是 0。
> 如果写成 0，第一个轻儿子分到的段就和根的段重叠，`f` 数组互相覆盖，答案会莫名其妙地偏大。
> 这个 bug 在随机对拍里表现为"某个点的答案比真值大"，很难靠肉眼发现。
```

> **指针复用是长链剖分的灵魂**：`f[sonLong[u]] = f[u] + 1`，这样重儿子的数组直接"继承"父数组的一段，省掉了所有重儿子的合并开销。总空间 $O(n)$。

## 3.5 虚树

### 解决什么问题

**多组询问 + 每组只涉及少量关键点**：例如"每次给定 $k$ 个点，问删掉最少多少边使这些点都与根断开"。每次询问若在原树上跑 DP 是 $O(n)$，总共 $O(nq)$ 会炸；虚树把每次的规模降到 $O(k\log k)$。

### 构造

1. 把关键点按 **dfn 排序**，并加入**相邻两点的 LCA**（这些 LCA 是虚树的"分叉点"）；
2. 再排序去重；
3. 用**单调栈**按 dfn 顺序建树：栈中维护"当前的一条祖先链"。

```cpp
// ==================== 虚树构建 ====================
const int MAXN = 300005;
vector<int> G[MAXN];              // 原树
int dfn[MAXN], dep2[MAXN], siz2[MAXN], faBin[MAXN][20], timerV;

void dfsInit(int u, int fa) {     // 预处理 dfn / 深度 / 倍增祖先 / 子树大小
    dfn[u] = ++timerV;
    siz2[u] = 1;
    faBin[u][0] = fa;
    dep2[u] = dep2[fa] + 1;
    for (int k = 1; k < 20; k++) faBin[u][k] = faBin[faBin[u][k - 1]][k - 1];
    for (int v : G[u]) {
        if (v == fa) continue;
        dfsInit(v, u);
        siz2[u] += siz2[v];
    }
}

int lcaV(int a, int b) {
    if (dep2[a] < dep2[b]) swap(a, b);
    for (int k = 19; k >= 0; k--) if (dep2[a] - (1 << k) >= dep2[b]) a = faBin[a][k];
    if (a == b) return a;
    for (int k = 19; k >= 0; k--) if (faBin[a][k] != faBin[b][k]) { a = faBin[a][k]; b = faBin[b][k]; }
    return faBin[a][0];
}

// 虚树边集（父 -> 子）
vector<pair<int,int>> vEdges;
int vstk[MAXN], vtop;

// key 为关键点（未排序也可以，函数内排序）；建完后 vEdges 给出虚树的边
void buildVirtualTree(vector<int> key) {
    sort(key.begin(), key.end(), [](int a, int b) { return dfn[a] < dfn[b]; });
    // 加入相邻关键点的 LCA
    int m = (int)key.size();
    for (int i = 1; i < m; i++) key.push_back(lcaV(key[i - 1], key[i]));
    sort(key.begin(), key.end(), [](int a, int b) { return dfn[a] < dfn[b]; });
    key.erase(unique(key.begin(), key.end()), key.end());

    vEdges.clear();
    vtop = 0;
    for (int u : key) {
        if (vtop == 0) { vstk[++vtop] = u; continue; }
        int l = lcaV(u, vstk[vtop]);
        while (vtop >= 2 && dep2[vstk[vtop - 1]] >= dep2[l]) {
            vEdges.push_back({vstk[vtop - 1], vstk[vtop]});
            --vtop;
        }
        if (vstk[vtop] != l) {
            vEdges.push_back({l, vstk[vtop]});
            vstk[vtop] = l;                    // 用 LCA 替换栈顶
        }
        vstk[++vtop] = u;
    }
    while (vtop >= 2) {
        vEdges.push_back({vstk[vtop - 1], vstk[vtop]});
        --vtop;
    }
}
```

**建完之后的处理**：在虚树上做 DP。注意虚树的边需要携带"原树上的信息"（例如两点间最短路/最小边权），这些信息通过 LCA 与原树预处理（倍增最小值等）得到。

| [P4103 大工程](https://www.luogu.com.cn/problem/P4103) | 虚树 + 统计路径长度和/最小值/最大值 |

## 3.6 树哈希与树同构

### 有根树哈希

$$h(u) = 1 + \sum_{v \in \text{son}(u)} \text{shift}\bigl(h(v)\bigr),$$

其中 `shift` 是把子哈希映射成大整数的扰动函数（避免 $\{1,2\}$ 与 $\{3\}$ 之类的冲突）。常用做法：

- 对子哈希排序后拼接成字符串再哈希；
- 或用随机权值：$h(u) = \bigoplus_{v} \text{rand}[h(v)]$（**异或哈希**，天然与顺序无关）。

```cpp
// ==================== 树哈希（异或随机权值版，O(n)） ====================
// 便于判断两棵有根树是否同构；无根树取重心为根做两次比较
const int MAXN = 100005;
vector<int> g[MAXN];
int hval[MAXN];
unsigned long long rndPool[MAXN];        // 预生成的随机权值（按哈希值索引）

unsigned long long splitmix(unsigned long long x) {   // 简单的扰动函数
    x += 0x9e3779b97f4a7c15ULL;
    x = (x ^ (x >> 30)) * 0xbf58476d1ce4e5b9ULL;
    x = (x ^ (x >> 27)) * 0x94d049bb133111ebULL;
    return x ^ (x >> 31);
}

// 计算有根树（根为 rt）的哈希；返回根的哈希值
unsigned long long dfsHash(int u, int fa) {
    unsigned long long h = 1;
    for (int v : g[u]) {
        if (v == fa) continue;
        h += splitmix(dfsHash(v, u));      // 加法 + 扰动（也可用 xor）
    }
    return h;
}
```

### 无根树同构

**做法**：找出树的所有**重心**（1 个或 2 个），分别以它们为根计算哈希，取较小（或排序后比较）作为整棵树的哈希。

$$\text{hash}(T) = \min\bigl(\text{hashRooted}(T, c_1),\ \text{hashRooted}(T, c_2)\bigr).$$

**应用**：判断两棵树是否同构、统计本质不同的树形结构个数、判断某个子树是否与给定树同构（配合括号序列 / AHU 算法）。

**更稳的做法（AHU）**：把有根树转成括号序列，再对这个序列做字符串哈希；这与树的同构判定等价（**AHU 定理**：用"子树括号序列排序后拼接"得到的规范化串，两棵树同构 $\iff$ 规范化串相同）。

## 3.7 Link-Cut Tree（LCT）

### 解决什么问题

**动态树**：支持**任意时刻**的连边/删边/换根，并在路径上做修改与查询。普通树剖做不到（树的形态变了），LCT 用**实链剖分 + Splay** 维护，均摊 $O(\log n)$ 每个操作。

### 核心概念

- **实边/虚边**：每个点最多一个"实儿子"，实边连成"实链"；
- **Splay 维护每条实链**（按深度为关键字），链顶的父亲的指针指向它在原树中的父节点（"路径父亲"，即虚边）；
- **`access(x)`**：把 $x$ 到根的路径变成一条实链（LCT 的核心操作）；
- **`makeRoot(x)`**：把 $x$ 变成整棵树的根（`access(x)` + `splay(x)` + 翻转）；
- **`split(x,y)`**：把 $x \to y$ 路径提取成一条实链（`makeRoot(x); access(y); splay(y)`），然后直接读 `sum[y]`。

### 模板（维护路径异或和，支持连边/删边）

```cpp
// ==================== Link-Cut Tree ====================
// 维护路径异或和：link / cut / query(x,y)（路径异或和）
const int MAXN = 100005;
typedef long long ll;

int ch[MAXN][2], faLCT[MAXN];
int revTag[MAXN];
ll valLCT[MAXN], sumLCT[MAXN];

bool isRoot(int x) { return ch[faLCT[x]][0] != x && ch[faLCT[x]][1] != x; }

void pushUp(int x) { sumLCT[x] = sumLCT[ch[x][0]] ^ sumLCT[ch[x][1]] ^ valLCT[x]; }

void pushRev(int x) { if (!x) return; std::swap(ch[x][0], ch[x][1]); revTag[x] ^= 1; }

void pushDown(int x) {
    if (revTag[x]) { pushRev(ch[x][0]); pushRev(ch[x][1]); revTag[x] = 0; }
}

void rotateLCT(int x) {
    int y = faLCT[x], z = faLCT[y];
    int k = (ch[y][1] == x);
    if (!isRoot(y)) ch[z][ch[z][1] == y] = x;
    faLCT[x] = z;
    ch[y][k] = ch[x][k ^ 1];
    if (ch[x][k ^ 1]) faLCT[ch[x][k ^ 1]] = y;
    ch[x][k ^ 1] = y;
    faLCT[y] = x;
    pushUp(y); pushUp(x);
}

void splayLCT(int x) {
    static int stk[MAXN];
    int top = 0, y = x;
    stk[++top] = y;
    while (!isRoot(y)) { y = faLCT[y]; stk[++top] = y; }
    while (top) pushDown(stk[top--]);                 // 先把整条链的标记下推
    while (!isRoot(x)) {
        int y2 = faLCT[x], z = faLCT[y2];
        if (!isRoot(y2)) rotateLCT(((ch[y2][1] == x) ^ (ch[z][1] == y2)) ? x : y2);
        rotateLCT(x);
    }
}

void access(int x) {                                  // 打通 x 到根的路径
    int last = 0;
    for (int y = x; y; y = faLCT[y]) {
        splayLCT(y);
        ch[y][1] = last;                              // 断掉原来的实儿子，接上新的
        pushUp(y);
        last = y;
    }
    splayLCT(x);
}

void makeRoot(int x) { access(x); pushRev(x); }

int findRoot(int x) {                                 // 找 x 所在树的根（用于判连通）
    access(x);
    while (ch[x][0]) { pushDown(x); x = ch[x][0]; }
    splayLCT(x);
    return x;
}

void split(int x, int y) { makeRoot(x); access(y); }  // 此时 y 的 splay 表示 x->y 的路径

void link(int x, int y) {                             // 连边（要求不连通）
    makeRoot(x);
    if (findRoot(y) != x) faLCT[x] = y;
}

void cut(int x, int y) {                              // 删边（要求直接相连）
    makeRoot(x);
    if (findRoot(y) == x && faLCT[y] == x && !ch[y][0]) {
        faLCT[y] = ch[x][1] = 0;
        pushUp(x);
    }
}
```

**典型题**：[P3690 【模板】动态树](https://www.luogu.com.cn/problem/P3690)、[P3203 弹飞绵羊](https://www.luogu.com.cn/problem/P3203)、[P1501 Tree II](https://www.luogu.com.cn/problem/P1501)、[P2387 魔法森林](https://www.luogu.com.cn/problem/P2387)（LCT 维护最小生成树）。

**LCT 维护动态 MST**（重要套路）：把**边也建成点**（边点权 = 边权），加边时若成环，则删掉环上权值最大的边点。

## 3.8 例题与套路

| 题目特征 | 方法 |
|---|---|
| 统计/查询树上**路径**的信息 | 点分治（静态）／点分树（带修改） |
| 统计每个点的**子树**信息 | DSU on tree |
| DP 下标是**深度** | 长链剖分 |
| 多次询问，每次只给**少量关键点** | 虚树 |
| 判断两棵树是否同构 | 树哈希 / AHU |
| 动态连边删边 + 路径查询 | LCT |
| 树上第 $k$ 大路径 | 二分 + 点分治 或 主席树 |
| 子树内深度为 $d$ 的点数 | 长链剖分 / dsu on tree + 深度桶 |

**选择顺序建议**：

1. 先问"是路径还是子树"；
2. 路径 → 静态用点分治，动态用点分树；
3. 子树 → dsu on tree（最通用）或长链剖分（深度相关）；
4. 多询问 + 少量关键点 → 虚树；
5. 动态树 → LCT（最后考虑，因为代码量大、易错）。

## 3.9 易错点清单

| 编号 | 易错点 | 说明 |
|---|---|---|
| 1 | 点分治忘记把 `removed[u] = true` 提前设置 | 会导致在子树里又走回重心 |
| 2 | 点分治容斥写成 `- calc(v, 0)` | 应是 `- calc(v, w(u,v))`（要带上这条边的权） |
| 3 | 点分治的重心在 `getSize` 之后又变（递归中 `sz` 被覆盖） | 每次进入新的连通块都要重新 `getSize` |
| 4 | 点分治递归时用了旧的 `tot` | 必须用新连通块的大小 |
| 5 | DSU on tree 撤销时忘记重置 `maxCnt/curSum` | 无法"减回去"，直接清零 |
| 6 | DSU on tree 的 `keep` 传反 | 轻儿子 `false`，重儿子 `true` |
| 7 | 长链剖分中 `dep` 含义混用（深度 vs 子树最深深度） | 全篇统一 |
| 8 | 长链剖分的数组复用忘记 `f[son] = f[u] + 1` | 会导致空间/时间爆炸 |
| 9 | 虚树忘记加入相邻关键点的 LCA | 会导致虚树结构错误（漏掉分叉点） |
| 10 | 虚树栈式构建中 `dep[stk[top-1]] >= dep[l]` 的比较写反 | 建议背标准写法 |
| 11 | 虚树上 DP 忘记清空（多组询问） | 用"访问过的点列表"清空，别 memset 整棵树 |
| 12 | 树哈希用加法且不做扰动 | 会被卡（不同子树和相同） |
| 13 | 无根树同构只取一个重心 | 有两个重心时必须都试 |
| 14 | LCT 的 `splay` 前忘记下推整条链的标记 | 会导致 `revTag` 错乱 |
| 15 | LCT 的 `cut` 未检查"是否直接相连" | 会破坏结构 |
