## 6.1 快速沃尔什变换 FWT

### 解决什么问题

普通卷积是"加法卷积"：$c_k = \sum_{i+j=k}a_ib_j$。但在**位运算**场景下，需要的是：

| 类型 | 形式 | 含义 |
|---|---|---|
| 或卷积 | $c_k = \sum_{i \,\|\, j = k} a_ib_j$ | 集合的并 |
| 与卷积 | $c_k = \sum_{i \,\&\, j = k} a_ib_j$ | 集合的交 |
| 异或卷积 | $c_k = \sum_{i \oplus j = k} a_ib_j$ | 对称差（博弈/异或空间常用） |

**FWT 的思想与 FFT 完全一致**：找一个可逆变换 $\mathcal F$，使**位运算卷积变成逐点乘法**：

$$\mathcal F(a * b) = \mathcal F(a)\cdot\mathcal F(b).$$

### 三种变换与逆变换

设数组长度为 $2^k$。每次按最高位把数组分成前后两半 $a_0, a_1$（长度 $2^{k-1}$），递归处理：

| 变换 | 正变换 | 逆变换 |
|---|---|---|
| **OR** | $a_1 \mathrel{+}= a_0$ | $a_1 \mathrel{-}= a_0$ |
| **AND** | $a_0 \mathrel{+}= a_1$ | $a_0 \mathrel{-}= a_1$ |
| **XOR** | $a_0' = a_0+a_1,\ a_1' = a_0-a_1$ | $a_0 = (a_0'+a_1')/2,\ a_1 = (a_0'-a_1')/2$ |

**复杂度**：$O(n\log n)$（$n = 2^k$）。

```cpp
// ==================== FWT：或 / 与 / 异或卷积 ====================
typedef long long ll;

// 或卷积：子集和（zeta 变换）
void fwtOr(std::vector<ll> &a, bool inv) {
    int n = (int)a.size();
    for (int len = 1; len < n; len <<= 1)
        for (int i = 0; i < n; i += (len << 1))
            for (int j = i; j < i + len; j++)
                a[j + len] += inv ? -a[j] : a[j];
}

// 与卷积
void fwtAnd(std::vector<ll> &a, bool inv) {
    int n = (int)a.size();
    for (int len = 1; len < n; len <<= 1)
        for (int i = 0; i < n; i += (len << 1))
            for (int j = i; j < i + len; j++)
                a[j] += inv ? -a[j + len] : a[j + len];
}

// 异或卷积（逆变换需要除以 n）
void fwtXor(std::vector<ll> &a, bool inv) {
    int n = (int)a.size();
    for (int len = 1; len < n; len <<= 1)
        for (int i = 0; i < n; i += (len << 1))
            for (int j = i; j < i + len; j++) {
                ll u = a[j], v = a[j + len];
                a[j] = u + v;
                a[j + len] = u - v;
            }
    if (inv) for (auto &x : a) x /= n;
}

// 用法：位运算卷积 c = a (*) b
std::vector<ll> walshConvolution(std::vector<ll> a, std::vector<ll> b, int type) {
    // type: 0 = OR, 1 = AND, 2 = XOR
    int n = (int)a.size();
    if (type == 0) { fwtOr(a, false); fwtOr(b, false); }
    else if (type == 1) { fwtAnd(a, false); fwtAnd(b, false); }
    else { fwtXor(a, false); fwtXor(b, false); }
    for (int i = 0; i < n; i++) a[i] *= b[i];
    if (type == 0) fwtOr(a, true);
    else if (type == 1) fwtAnd(a, true);
    else fwtXor(a, true);
    return a;
}
```

> **为什么 OR 变换就是子集和？** $\mathcal F_{\text{OR}}(a)_i = \sum_{j \subseteq i} a_j$（$j$ 是 $i$ 的二进制子集）。
> 于是 $\mathcal F(a*b)_i = \sum_{j\subseteq i}\sum_{u|v=j}a_ub_v = \bigl(\sum_{u\subseteq i}a_u\bigr)\bigl(\sum_{v\subseteq i}b_v\bigr)$ ✓ 逐点相乘。

**经典应用**：

| 题目 | 用法 |
|---|---|
| 位运算卷积模板（[P4717](https://www.luogu.com.cn/problem/P4717)） | 三种 FWT |
| 两个集合的"或/与/异或"计数 | FWT + 容斥 |
| 博弈论（SG 值的异或卷积） | XOR 卷积 |
| 高维前缀和 / SOS DP | 就是 FWT_OR（第 DP 教程第 1 章已讲） |

## 6.2 子集卷积

### 问题

$$c_S = \sum_{T \subseteq S} a_T\, b_{S\setminus T}\quad(\text{要求 } T \cap (S \setminus T) = \varnothing).$$

注意：这与"或卷积"不同——或卷积允许 $T \cup U = S$ 但 $T \cap U \ne \varnothing$ 的项。

### 做法：加一维"集合大小"

**关键技巧**：给每个集合加一维"popcount"标签，即把 $a_S$ 放进 $A_{|S|, S}$：

1. 由 $a$ 得到 $\hat a_{k,S} = a_S\,[\,|S| = k\,]$；
2. 对每一层 $k$ 做 FWT_OR；
3. 逐点相乘时**只取"大小恰好相加"的那一项**：$\hat c_{k,S} = \sum_{i+j=k}\hat a_{i,S}\hat b_{j,S}$；
4. 对每一层做 FWT_OR 逆变换，取出 $\hat c_{|S|,S}$ 即为答案。

**复杂度**：$O(2^n n^2)$。

```cpp
// ==================== 子集卷积 ====================
// a[S], b[S] 为集合函数（下标为位掩码），求 c[S] = Σ_{T ⊆ S} a[T] * b[S^T]
std::vector<ll> subsetConvolution(const std::vector<ll> &a, const std::vector<ll> &b) {
    int n = (int)a.size();          // n = 2^k
    int k = 0;
    while ((1 << k) < n) ++k;
    std::vector<std::vector<ll>> A(k + 1, std::vector<ll>(n, 0)), B(k + 1, std::vector<ll>(n, 0));
    for (int S = 0; S < n; S++) {
        int pc = __builtin_popcount((unsigned)S);
        A[pc][S] = a[S];
        B[pc][S] = b[S];
    }
    for (int i = 0; i <= k; i++) { fwtOr(A[i], false); fwtOr(B[i], false); }
    std::vector<std::vector<ll>> C(k + 1, std::vector<ll>(n, 0));
    for (int i = 0; i <= k; i++)
        for (int j = 0; i + j <= k; j++)
            for (int S = 0; S < n; S++)
                C[i + j][S] += A[i][S] * B[j][S];
    for (int i = 0; i <= k; i++) fwtOr(C[i], true);
    std::vector<ll> c(n, 0);
    for (int S = 0; S < n; S++) c[S] = C[__builtin_popcount((unsigned)S)][S];
    return c;
}
```

**应用**：集合划分计数（把集合分成若干非空块）、$k$-染色计数、集合幂级数的 exp/ln。

**集合幂级数的 exp/ln**：有了子集卷积，"集合幂级数"也能像普通多项式一样做 exp/ln（$O(2^n n^2)$），用来解决"由若干互不相交的连通块组成整体"的计数问题。

## 6.3 类欧几里得算法（floor_sum）

### 问题

$$\text{floorSum}(n, m, a, b) = \sum_{i=0}^{n-1}\left\lfloor \frac{a\,i+b}{m}\right\rfloor .$$

朴算是 $O(n)$，**类欧几里得**能在 $O(\log \max(a,m))$ 内求出（与辗转相除同构，故名"类欧几里得"）。

### 算法

记 $f(n,m,a,b) = \sum_{i=0}^{n-1}\lfloor (ai+b)/m\rfloor$。三步化简：

1. **把 $a,b$ 的整数部分提出来**：若 $a \ge m$，则 $f(n,m,a,b) = \frac{n(n-1)}2\lfloor a/m\rfloor + f(n,m,a\bmod m,b)$；若 $b \ge m$，则 $f(n,m,a,b) = n\lfloor b/m\rfloor + f(n,m,a,b\bmod m)$。
2. **若 $a < m$ 且 $b < m$**：利用"数点"的对称性，
   $$f(n,m,a,b) = \sum_{j=0}^{y_{\max}-1}\left(n - \left\lfloor\frac{mj + m - 1 - b}{a}\right\rfloor\right),\quad y_{\max} = \left\lfloor\frac{an+b}{m}\right\rfloor .$$
3. 于是问题转化为 $(n', m', a', b') = (y_{\max},\, a,\, m,\, m-1-b)$ 的**同类型子问题**，且参数规模变小 → 与辗转相除同复杂度。

```cpp
// ==================== 类欧几里得：Σ_{i=0}^{n-1} floor((a*i + b) / m) ====================
typedef long long ll;

ll floorSum(ll n, ll m, ll a, ll b) {
    ll ans = 0;
    while (true) {
        if (a >= m) { ans += (n - 1) * n / 2 * (a / m); a %= m; }
        if (b >= m) { ans += n * (b / m); b %= m; }
        ll yMax = a * n + b;
        if (yMax < m) break;                 // 没有更多可数的点
        n = yMax / m;
        b = yMax % m;
        std::swap(m, a);
    }
    return ans;
}
```

> **验证要点**：`a * n + b` 可能溢出，$n,a \le 10^9$ 时约 $10^{18}$，靠近 `long long` 上限，保守写法用 `__int128`。

**扩展形式**：还可以求 $\sum i\lfloor\cdot\rfloor$、$\sum\lfloor\cdot\rfloor^2$（多返回几个量，一起辗转），用于处理 $ax+b$ 相关的整除求和、以及**直线下方格点数**类几何问题。

**经典应用**：

- $\sum_{i=1}^{n}\lfloor \frac{ai+b}{c}\rfloor$ 型求和；
- 数论函数求和中出现"两个下取整相乘"的化简；
- 某些"格子内整点数"的几何计数（配合 Pick 定理）。

## 6.4 多项式多点求值与快速插值（思路）

### 多点求值

**问题**：给定多项式 $f$（次数 $< n$）与 $m$ 个点 $x_1, \dots, x_m$，求所有 $f(x_i)$。
朴算是 $O(nm)$；**分治 + 多项式取模**可做到 $O((n+m)\log^2(n+m))$。

**思路**：

1. 对求值点建**线段树式的产品树**：节点 $[l,r]$ 维护 $P_{[l,r]}(x) = \prod_{i=l}^{r}(x - x_i)$；
2. 从根往下：设当前节点已有 $g = f \bmod P_{\text{node}}$，则对左儿子更新 $g_L = g \bmod P_{\text{left}}$，右儿子同理（因为 $f(x_i) = g(x_i)$ 对所有叶子 $i$ ✓）；
3. 到叶子时，$g$ 是常数，即 $f(x_i)$。

**为什么可以取模**：若 $P(x_i) = 0$，则 $f(x_i) = (f \bmod P)(x_i)$ ✓。

```cpp
// ==================== 多点求值：产品树构建（核心片段） ====================
// 说明：polyMul 用数学教程第 7 章的 NTT 卷积；这里给一个朴素版保证本模板可独立编译
typedef long long ll;
const int MOD = 998244353;

std::vector<int> polyMul(const std::vector<int> &a, const std::vector<int> &b) {
    if (a.empty() || b.empty()) return {};
    std::vector<int> c(a.size() + b.size() - 1, 0);
    for (size_t i = 0; i < a.size(); i++)
        for (size_t j = 0; j < b.size(); j++)
            c[i + j] = (c[i + j] + (ll)a[i] * b[j]) % MOD;
    return c;                       // 实际使用时换成 NTT 卷积
}

std::vector<std::vector<int>> prodTree;      // prodTree[node] = Π_{i 属于该节点区间}(x - x_i)

// tree[node] = Π_{i 属于该节点区间} (x - x_i)
void buildProductTree(int node, int l, int r, const std::vector<int> &xs) {
    if ((int)prodTree.size() <= node) prodTree.resize(node + 1);
    if (l == r) {
        prodTree[node] = { (int)((MOD - xs[l]) % MOD), 1 };     // (x - xs[l]) 的系数表示
        return;
    }
    int mid = (l + r) >> 1;
    buildProductTree(node << 1, l, mid, xs);
    buildProductTree(node << 1 | 1, mid + 1, r, xs);
    prodTree[node] = polyMul(prodTree[node << 1], prodTree[node << 1 | 1]);
}
```

**注意**：需要多项式**取模**（即多项式除法），这是数学教程 §7.5 提到的"多项式除法与取模"，实现时用反转多项式 + 求逆。

### 快速插值

**问题**：给定 $m$ 个点 $(x_i, y_i)$，求唯一的多项式 $f$（次数 $< m$）。
朴素的拉格朗日插值是 $O(m^2)$（或连续点的 $O(m)$）；**分治 + 多项式乘法**可做到 $O(m\log^2 m)$。

**思路**：拉格朗日公式

$$f(x) = \sum_i \frac{y_i}{\prod_{j\ne i}(x_i - x_j)}\cdot\prod_{j\ne i}(x-x_j).$$

- 分母 $\prod_{j\ne i}(x_i-x_j) = P'(x_i)$，其中 $P = \prod_j (x-x_j)$（用多点求值算 $P'(x_i)$）；
- 分子部分用分治合并：$\text{solve}(l,r)$ 返回 $\sum_{i\in[l,r]} \frac{y_i}{P'(x_i)}\prod_{j\in[l,r], j\ne i}(x-x_j)$，合并时左右两边分别乘上对方的 $P$ 再相加。

**竞赛建议**：多点求值与快速插值代码量都在 200 行左右，属于"区域赛压轴题工具"。**建议先把"连续点拉格朗日 O(n)"（数学教程已讲）用熟**，再考虑实现完整的快速插值。

## 6.5 拉格朗日反演（简介）

**定理 6.1（拉格朗日反演）** 设 $F(x)$ 满足 $F(0) = 0$、$F'(0) \ne 0$（即有复合逆），记其复合逆为 $G(x)$（即 $F(G(x)) = x$），则

$$[x^n]\,G(x) = \frac1n\,[x^{n-1}]\left(\frac{x}{F(x)}\right)^{n}.$$

**用途**：当某个计数问题满足 $A(x) = x\,\phi(A(x))$ 形式的"隐式方程"时，可以直接用反演公式读出系数，而不必显式解方程。

**经典例子**：卡特兰数的生成函数满足 $C(x) = 1 + xC(x)^2$。令 $A = C - 1$，则 $A = x(1+A)^2$，取 $F(t) = t/(1+t)^2$，用拉格朗日反演可直接得到

$$[x^n]A = \frac1n[x^{n-1}](1+x)^{2n} = \frac1n\binom{2n}{n-1} = C_n .$$

**扩展形式（广义反演）**：

$$[x^n]\,H(G(x)) = \frac1n\,[x^{n-1}]\,H'(x)\left(\frac{x}{F(x)}\right)^n .$$

## 6.6 min_25 筛（完整实现）

### 回顾适用条件

1. $f$ 是**积性函数**；
2. $f(p)$ 是关于 $p$ 的**低次多项式**（可拆成若干 $p^k$ 的线性组合）；
3. $f(p^e)$ 能快速计算。

**复杂度**：$O\left(\dfrac{n^{3/4}}{\log n}\right)$，$n \le 10^{11}$ 可过。

### 两段式结构

**第一段（求"质数处的贡献和"）**：

设 $g_k(x) = \sum_{2\le p \le x} p^k$（对素数求和）。先用"把所有数当成素数"的初值

$$g_k(x) \leftarrow \sum_{i=2}^{x} i^k \quad(\text{用 } \sum i^k \text{ 公式})$$

然后**埃氏筛式地**用每个素数 $p$ 去"筛掉"合数的贡献：

$$g_k(x) \leftarrow g_k(x) - p^k\left(g_k(\lfloor x/p\rfloor) - \sum_{q < p} q^k\right).$$

由于所有需要的 $x$ 都是 $\lfloor n/i\rfloor$ 形式（共 $O(\sqrt n)$ 个），用两个数组离散化下标即可。

**第二段（递归统计合数贡献）**：

$$S(x, y) = \Bigl(\sum_{\text{素数 } p \le x} f(p)\Bigr) - \Bigl(\sum_{\text{素数 } p \le \text{第 } y \text{ 个}}\Bigr)
+ \sum_{i > y,\ p_i^2 \le x}\ \sum_{e \ge 1,\ p_i^{e+1}\le x}\Bigl[f(p_i^{e})\,S(\lfloor x/p_i^e\rfloor, i) + f(p_i^{e+1})\Bigr].$$

最终答案 $= S(n, 0) + f(1)$（通常 $f(1) = 1$）。

### 完整模板（以 $f(p^k) = p^k(p^k-1)$ 为例，即 [P5325](https://www.luogu.com.cn/problem/P5325)）

```cpp
// ==================== min_25 筛 ====================
// 求 Σ_{i=1}^{n} f(i) mod MOD，其中 f 积性、f(p) = p^2 - p、f(p^k) = p^k(p^k - 1)
typedef long long ll;
const int MAXM = 200005;
const ll MOD = 1000000007, INV2 = 500000004, INV6 = 166666668;

ll n, sq;
ll w[MAXM];                       // 所有 ⌊n/i⌋ 的取值
int id1[MAXM], id2[MAXM], m;      // 离散化：值 <= sq 用 id1，否则用 id2[n/值]
ll g1[MAXM], g2[MAXM];            // 质数处的 Σp 与 Σp^2
ll pre1[MAXM], pre2[MAXM];        // 素数前缀和
int primes[MAXM], pcnt;
bool vis[MAXM];

inline ll sumPow1(ll x) { return x % MOD * ((x + 1) % MOD) % MOD * INV2 % MOD; }
inline ll sumPow2(ll x) { return x % MOD * ((x + 1) % MOD) % MOD * ((2 * x + 1) % MOD) % MOD * INV6 % MOD; }
inline ll fSingle(ll pk) { ll t = pk % MOD; return t * ((t - 1 + MOD) % MOD) % MOD; }

inline int getId(ll x) { return x <= sq ? id1[x] : id2[n / x]; }

void initMin25() {
    sq = (ll)sqrt((double)n);
    while (sq * sq > n) --sq;
    while ((sq + 1) * (sq + 1) <= n) ++sq;

    // 1) 线性筛出 <= sq 的素数及其前缀和
    pcnt = 0;
    pre1[0] = pre2[0] = 0;
    for (int i = 2; i <= sq; i++) {
        if (!vis[i]) {
            primes[++pcnt] = i;
            pre1[pcnt] = (pre1[pcnt - 1] + i) % MOD;
            pre2[pcnt] = (pre2[pcnt - 1] + (ll)i * i) % MOD;
        }
        for (int j = 1; j <= pcnt && (ll)i * primes[j] <= sq; j++) {
            vis[i * primes[j]] = true;
            if (i % primes[j] == 0) break;
        }
    }

    // 2) 离散化所有 ⌊n/i⌋，并初始化 g1/g2（把 2..w 全部当作素数）
    m = 0;
    for (ll l = 1, r; l <= n; l = r + 1) {
        r = n / (n / l);
        w[++m] = n / l;
        if (w[m] <= sq) id1[w[m]] = m; else id2[n / w[m]] = m;
        g1[m] = (sumPow1(w[m]) - 1 + MOD) % MOD;
        g2[m] = (sumPow2(w[m]) - 1 + MOD) % MOD;
    }

    // 3) 埃氏式筛掉合数贡献
    for (int j = 1; j <= pcnt; j++) {
        ll p = primes[j];
        for (int i = 1; i <= m && p * p <= w[i]; i++) {
            int k = getId(w[i] / p);
            g1[i] = (g1[i] - p % MOD * ((g1[k] - pre1[j - 1] + MOD) % MOD) % MOD + MOD) % MOD;
            g2[i] = (g2[i] - p % MOD * (p % MOD) % MOD * ((g2[k] - pre2[j - 1] + MOD) % MOD) % MOD + MOD) % MOD;
        }
    }
}

// S(x, y): Σ_{2<=i<=x, lpf(i) > primes[y]} f(i)
ll S(ll x, int y) {
    if (primes[y] >= x) return 0;
    int k = getId(x);
    ll ans = ((g2[k] - pre2[y] + MOD) % MOD - (g1[k] - pre1[y] + MOD) % MOD + MOD) % MOD;   // 质数部分
    for (int i = y + 1; i <= pcnt && (ll)primes[i] * primes[i] <= x; i++) {
        ll pe = primes[i];                                  // p^e
        for (int e = 1; pe * primes[i] <= x; e++, pe *= primes[i]) {
            ans = (ans + fSingle(pe) * S(x / pe, i) + fSingle(pe * primes[i])) % MOD;
        }
    }
    return ans;
}

// 最终答案 = S(n, 0) + 1 （f(1) = 1）
```

> **注意**：`pe * primes[i]` 可能接近 $n$（$\le 10^{11}$），`ll` 足够。
> 递归深度是 $O(\log\log n)$，不会爆栈。

| 给定 $n$ 个点求多项式 | 快速插值 |
| $A = x\phi(A)$ 形式的隐式方程 | 拉格朗日反演 |
| 积性函数前缀和，$f(p)$ 是多项式，$n\le10^{11}$ | min_25 筛 |

---

## 6.8 易错点清单

| 编号 | 易错点 | 说明 |
|---|---|---|
| 1 | FWT 逆变换忘记除以 $n$（仅异或需要） | OR/AND 不需要除 |
| 2 | 数组长度不是 $2$ 的幂 | FWT 要求长度为 $2^k$ |
| 3 | 子集卷积忘记"只取大小恰好相加"的那一层 | 否则退化成或卷积 |
| 4 | 类欧中 `a*n+b` 溢出 | 用 `__int128` |
| 5 | 多点求值的产品树节点数开小 | 需要 $4m$ |
| 6 | min_25 筛的 `pre1[0]` 未初始化 | 会导致 `pre1[j-1]` 读到垃圾 |
| 7 | min_25 筛的 `sq` 用 `sqrt` 浮点误差 | 用 while 校正（模板已做） |
| 8 | min_25 筛中 $g$ 的初值忘记减掉 $f(1)$ | 初值是 $\sum_{i=2}^{x}i^k$ |
| 9 | min_25 递归部分漏掉 $f(p^{e+1})$ 项 | 公式里有两项 |

数学补漏模板清单

FWT：
  fwtOr / fwtAnd / fwtXor     位运算卷积的正/逆变换
