# 第 07 章 搜索进阶

> 当状态空间"大到不能 DP、小到不能全枚举"时，靠的就是**启发式搜索 + 剪枝**。
> 本章覆盖：迭代加深与 IDA*、A*、双向 BFS、DLX（精确覆盖）、Alpha-Beta 剪枝。

---

## 7.1 迭代加深搜索与 IDA*

### 迭代加深（IDDFS）

**问题**：DFS 可能一头扎进无穷深的分支；BFS 又要存下整层状态（空间爆炸）。

**做法**：限定搜索深度 $d$，做 DFS；若没找到解，就 $d \leftarrow d+1$ 重来。

**为什么快？** 虽然重复搜索了浅层，但每层节点数通常指数增长，重复的代价只占常数倍（几何级数求和）：

$$\sum_{i=0}^{d} b^i = O(b^d)\quad(\text{与只搜第 } d \text{ 层同阶}).$$

**适用**：需要"最短步数"且状态空间深度不大（$\le 20$ 左右）、每层分支多。

### IDA*：加上启发式评估

**核心**：用估价函数 $h(s)$（从状态 $s$ 到达目标所需步数的**下界**）来剪枝。

若当前深度 $g$ + 估价 $h$ > 限制深度 $d$，直接回溯。

**关键性质**：$h$ 必须是**可采纳的（admissible）**——即 $h(s) \le$ 真实剩余步数。这样才能保证找到最优解。

```text
// ==================== IDA* 框架 ====================
// 目标：在限制深度 limit 内从状态 s 到目标；h(s) 为可达下界
int limitDepth;
bool found;

// 返回是否找到解
bool idaStar(State s, int g, int hVal) {
    if (hVal == 0) { found = true; return true; }        // 到达目标
    if (g + hVal > limitDepth) return false;             // 剪枝（这是 IDA* 的灵魂）
    for (State nxt : expandStates(s)) {
        if (idaStar(nxt, g + 1, heuristic(nxt))) return true;
    }
    return false;
}

// 外层：逐步放宽深度限制
void solveIDA(State start) {
    for (limitDepth = 0; limitDepth <= 60; limitDepth++) {
        found = false;
        if (idaStar(start, 0, heuristic(start))) {
            // limitDepth 就是最短步数
            return;
        }
        if (found) break;
    }
}
```

> 上面 `State` / `expandStates` / `heuristic` 需要按题目替换。竞赛中通常写成**全局数组 + 具体函数**，避免结构体开销。

### 经典题

| 题目 | 估价函数思路 |
|---|---|
| [P1379 八数码难题](https://www.luogu.com.cn/problem/P1379) | 每个数字当前位置到目标位置的曼哈顿距离之和 |
| [P2324 骑士精神](https://www.luogu.com.cn/problem/P2324) | 与目标棋盘的**不同格子数**（下界：每次移动最多修正 1 个） |
| [P2901 Cow Jogging](https://www.luogu.com.cn/problem/P2901) | A* + 第 $k$ 短路 |
| [P2534 铁盘整理](https://www.luogu.com.cn/problem/P2534) | 相邻数字差 > 1 的对数 |

## 7.2 A* 算法

### 思想

在 Dijkstra（按 $g$ 排序）的基础上，按 $f = g + h$ 排序扩展：**优先探索"看起来更接近目标"的状态**。

**性质**：

- 若 $h$ 可采纳（不高估），A* 保证找到最优解；
- 若 $h$ 还满足**一致性** $h(u) \le w(u,v) + h(v)$，则每个状态只需扩展一次（用"关闭表"）。

### 模板（$k$ 短路 / 图上搜索）

```cpp
// ==================== A* 求图上从 s 到 t 的 k 短路 ====================
// 先用反图跑 Dijkstra 求出每个点到 t 的最短路 h[]，作为估价函数
const int MAXN = 100005;
typedef long long ll;
const ll INF = (ll)4e18;

std::vector<std::pair<int,ll>> gA[MAXN], gRev[MAXN];
ll hDist[MAXN];

void dijkstraReverse(int n, int t) {
    for (int i = 1; i <= n; i++) hDist[i] = INF;
    std::priority_queue<std::pair<ll,int>, std::vector<std::pair<ll,int>>, std::greater<std::pair<ll,int>>> pq;
    hDist[t] = 0; pq.push({0, t});
    while (!pq.empty()) {
        auto pr = pq.top(); pq.pop();
        int u = pr.second;
        if (pr.first > hDist[u]) continue;
        for (auto &e2 : gRev[u])
            if (hDist[u] + e2.second < hDist[e2.first]) {
                hDist[e2.first] = hDist[u] + e2.second;
                pq.push({hDist[e2.first], e2.first});
            }
    }
}

// 返回第 k 短路的长度（不存在返回 -1）
ll kthShortestPath(int n, int s, int t, int k) {
    dijkstraReverse(n, t);
    if (hDist[s] >= INF) return -1;
    std::priority_queue<std::pair<ll,int>, std::vector<std::pair<ll,int>>, std::greater<std::pair<ll,int>>> pq;
    std::vector<int> cnt(n + 1, 0);
    pq.push({hDist[s], s});                      // f = g + h，初始 g = 0
    while (!pq.empty()) {
        auto pr = pq.top(); pq.pop();
        ll f = pr.first;
        int u = pr.second;
        ll gNow = f - hDist[u];                  // 反推出 g
        if (++cnt[u] > k) continue;              // 同一个点最多出队 k 次
        if (u == t && cnt[u] == k) return gNow;
        for (auto &e2 : gA[u]) {
            int v = e2.first;
            if (cnt[v] >= k) continue;
            pq.push({gNow + e2.second + hDist[v], v});
        }
    }
    return -1;
}
```

> **注意**：上面的实现用"出队次数"控制，第 $k$ 次从 $t$ 出队时的 $g$ 就是第 $k$ 短路长度。

## 7.3 双向 BFS

### 思想

从起点和终点**同时** BFS，当两边的搜索前沿相遇时，路径长度 = 两边深度之和。

**复杂度**：从 $O(b^d)$ 降到 $O(b^{d/2})$（$b$ 为分支数，$d$ 为最短距离），是**指数级**的优化。

**实现要点**：

- 用两个 `unordered_map<State, int>` 记录两边的距离；
- 每次选**当前层更小**的一侧扩展（保证两边均衡）；
- 相遇条件是"某个状态同时出现在两边"。

```text
// ==================== 双向 BFS 框架 ====================
// State 需可哈希（竞赛中常用整数编码）
int bidirectionalBFS(State start, State goal, int maxStep) {
    if (start == goal) return 0;
    std::unordered_map<State,int> distS, distG;
    std::queue<State> qs, qg;
    distS[start] = 0; qs.push(start);
    distG[goal] = 0;  qg.push(goal);
    while (!qs.empty() && !qg.empty()) {
        // 扩展较小的一侧
        std::queue<State> &cur = (qs.size() <= qg.size()) ? qs : qg;
        std::unordered_map<State,int> &distCur = (qs.size() <= qg.size()) ? distS : distG;
        std::unordered_map<State,int> &distOther = (qs.size() <= qg.size()) ? distG : distS;
        int layerSize = (int)cur.size();
        for (int t = 0; t < layerSize; t++) {
            State s = cur.front(); cur.pop();
            int d = distCur[s];
            if (d >= maxStep) continue;
            for (State nxt : expandStates(s)) {
                if (distCur.count(nxt)) continue;
                if (distOther.count(nxt)) return d + 1 + distOther[nxt];   // 相遇
                distCur[nxt] = d + 1;
                cur.push(nxt);
            }
        }
    }
    return -1;          // 无解
}
```

**适用**：状态可逆、且状态空间巨大（如拼图、字母变换、图上的最短变换序列）。

**经典题**：[P1032 字串变换](https://www.luogu.com.cn/problem/P1032)、[UVA1601](https://onlinejudge.org/index.php?option=com_onlinejudge&Itemid=8&page=show_problem&problem=4476)（三只鬼）、八数码类。

## 7.4 DLX（Dancing Links，精确覆盖）

### 问题：精确覆盖

给定一个 0/1 矩阵，选择若干行，使**每一列恰好被覆盖一次**。

**经典应用**：数独、$N$ 皇后、"拼图覆盖"问题。

### 算法：Algorithm X + 十字交叉链表

**Algorithm X（回溯）**：

1. 若矩阵为空 → 找到解；
2. 选择一列 $c$（**启发式：选择 1 的个数最少的列**，能极大剪枝）；
3. 枚举覆盖列 $c$ 的每一行 $r$：把 $r$ 加入解；删除所有与 $r$ 有交集的列及这些列对应的行；递归；失败则回溯恢复。

**Dancing Links（舞蹈链）**：用双向十字链表表示矩阵，使"删除/恢复"都是 $O(1)$。

```cpp
// ==================== DLX（精确覆盖模板） ====================
// 行列编号从 1 开始；colCnt 为列数
const int MAXNODE = 300005;
int dlxL[MAXNODE], dlxR[MAXNODE], dlxU[MAXNODE], dlxD[MAXNODE];
int dlxRow[MAXNODE], dlxCol[MAXNODE];
int dlxHead[MAXNODE];            // 每行的头结点
int dlxSize[MAXNODE];            // 每列的 1 的个数
int dlxTot, dlxColCnt;
std::vector<int> dlxAns;         // 选中的行
bool dlxFound;

void dlxInit(int colCnt, int rowCnt) {
    dlxColCnt = colCnt;
    dlxTot = colCnt;
    for (int i = 0; i <= colCnt; i++) {
        dlxL[i] = i - 1; dlxR[i] = i + 1;
        dlxU[i] = dlxD[i] = i;
        dlxSize[i] = 0;
        dlxRow[i] = 0; dlxCol[i] = i;
    }
    dlxL[0] = colCnt; dlxR[colCnt] = 0;
    // 注意：head 是按「行」索引的，行数可能大于列数，必须清够 rowCnt 个！
    for (int i = 1; i <= rowCnt; i++) dlxHead[i] = 0;
}

// 在第 r 行的第 c 列插入一个 1
void dlxInsert(int r, int c) {
    ++dlxTot;
    dlxRow[dlxTot] = r; dlxCol[dlxTot] = c;
    dlxU[dlxTot] = dlxU[c]; dlxD[dlxTot] = c;
    dlxD[dlxU[c]] = dlxTot; dlxU[c] = dlxTot;
    if (!dlxHead[r]) { dlxHead[r] = dlxL[dlxTot] = dlxR[dlxTot] = dlxTot; }
    else {
        dlxL[dlxTot] = dlxL[dlxHead[r]];
        dlxR[dlxTot] = dlxHead[r];
        dlxR[dlxL[dlxHead[r]]] = dlxTot;
        dlxL[dlxHead[r]] = dlxTot;
    }
    ++dlxSize[c];
}

void dlxRemoveCol(int c) {                     // 删除列 c（及其覆盖的行）
    dlxR[dlxL[c]] = dlxR[c];
    dlxL[dlxR[c]] = dlxL[c];
    for (int i = dlxD[c]; i != c; i = dlxD[i])
        for (int j = dlxR[i]; j != i; j = dlxR[j]) {
            dlxU[dlxD[j]] = dlxU[j];
            dlxD[dlxU[j]] = dlxD[j];
            --dlxSize[dlxCol[j]];
        }
}

void dlxResumeCol(int c) {                     // 恢复列 c（逆序恢复）
    for (int i = dlxU[c]; i != c; i = dlxU[i])
        for (int j = dlxL[i]; j != i; j = dlxL[j]) {
            ++dlxSize[dlxCol[j]];
            dlxU[dlxD[j]] = j;
            dlxD[dlxU[j]] = j;
        }
    dlxR[dlxL[c]] = c;
    dlxL[dlxR[c]] = c;
}

// 递归求解；depth 为已选行数
void dlxDance(int depth) {
    if (dlxFound) return;
    if (dlxR[0] == 0) { dlxFound = true; return; }         // 所有列已覆盖
    // 启发式：选 1 最少的列
    int c = dlxR[0];
    for (int i = dlxR[0]; i != 0; i = dlxR[i])
        if (dlxSize[i] < dlxSize[c]) c = i;
    dlxRemoveCol(c);
    for (int i = dlxD[c]; i != c; i = dlxD[i]) {
        dlxAns.push_back(dlxRow[i]);
        for (int j = dlxR[i]; j != i; j = dlxR[j]) dlxRemoveCol(dlxCol[j]);
        dlxDance(depth + 1);
        if (dlxFound) return;          // 找到解：一路直接返回，绝不能再做恢复（否则会重复恢复而破坏链表）
        for (int j = dlxL[i]; j != i; j = dlxL[j]) dlxResumeCol(dlxCol[j]);
        dlxAns.pop_back();
    }
    dlxResumeCol(c);
}
```

**数独建模**：$9\times9$ 数独转化为 $9\times9\times9 = 729$ 行（每个格子填每个数字），$4\times81 = 324$ 列（每格填一个数、每行每数字、每列每数字、每宫每数字）→ DLX 秒解。

## 7.5 Alpha-Beta 剪枝与对抗搜索

### Minimax 与 Alpha-Beta

**Minimax**：双方轮流决策，己方最大化、对方最小化，自底向上求值。

**Alpha-Beta 剪枝**：维护

- $\alpha$：己方已能保证的下界；
- $\beta$：对方已能保证的上界；

当 $\alpha \ge \beta$ 时，当前分支不可能影响最终决策，**直接剪掉**。

**复杂度**：最优情况下从 $O(b^d)$ 降到 $O(b^{d/2})$（相当于搜索深度翻倍）。

```text
// ==================== Alpha-Beta 剪枝框架 ====================
const int INFSC = 1000000000;

// depth: 剩余搜索深度；alpha/beta: 剪枝窗口；maximizing: 是否轮到己方
int alphaBeta(State s, int depth, int alpha, int beta, bool maximizing) {
    if (depth == 0 || isTerminal(s)) return evaluate(s);
    if (maximizing) {
        int best = -INFSC;
        for (State nxt : expandStates(s)) {
            best = std::max(best, alphaBeta(nxt, depth - 1, alpha, beta, false));
            alpha = std::max(alpha, best);
            if (alpha >= beta) break;                  // 剪枝
        }
        return best;
    } else {
        int best = INFSC;
        for (State nxt : expandStates(s)) {
            best = std::min(best, alphaBeta(nxt, depth - 1, alpha, beta, true));
            beta = std::min(beta, best);
            if (alpha >= beta) break;                  // 剪枝
        }
        return best;
    }
}
```

**进阶技巧**（竞赛中常见）：

- **迭代加深 + 置换表（TT）**：记忆化已搜索的状态；
- **历史启发 / 杀手启发**：优先搜索"历史上表现好"的走法；
- **静态搜索（quiescence）**：在叶节点继续搜索"吃子"等剧烈变化，避免地平线效应；
- **Monte Carlo Tree Search（MCTS）**：随机模拟 + UCB 选择（适用于围棋类大分支博弈）。

## 7.6 剪枝技巧总表

| 技巧 | 说明 |
|---|---|
| **可行性剪枝** | 当前状态已经违反约束 → 剪 |
| **最优性剪枝** | 当前代价 + 下界 ≥ 已知最优 → 剪 |
| **估价剪枝（IDA*）** | $g + h > $ 限制 → 剪 |
| **搜索顺序优化** | 先搜"更可能成功"的分支（按启发值排序） |
| **记忆化 / 置换表** | 相同状态只算一次 |
| **对称性去重** | 对称状态视为同一状态 |
| **位运算加速** | 用 `bitset`/整数表示状态与可用集合 |
| **迭代加深** | 避免深分支爆炸，同时保证最优性 |
| **双向搜索** | 从两端同时搜 |
| **随机化重启** | 随机初始顺序，多次尝试 |

## 7.7 例题与套路

| 题目特征 | 方法 |
|---|---|
| 求最短步数、深度小、分支多 | IDDFS / IDA* |
| 有明确"离目标还差多少"的下界 | IDA*（估价函数是核心） |
| 图上的 $k$ 短路 | A* + 反向 Dijkstra |
| 起点终点都给定、状态可逆 | 双向 BFS |
| 精确覆盖（数独、拼图、$N$ 皇后变体） | DLX |
| 双方博弈、局面评估可量化 | Alpha-Beta / MCTS |
| 状态空间大但需要最优解 | 启发式搜索 + 剪枝 |

**估价函数设计三原则**：

1. **可采纳**（不能高估，否则丢最优解）；
2. **尽可能紧**（越接近真实值，剪枝越强）；
3. **计算要快**（估价本身的代价不能超过剪枝收益）。

## 7.8 易错点清单

| 编号 | 易错点 | 说明 |
|---|---|---|
| 1 | IDA* 的估价函数高估 | 会丢失最优解（必须可采纳） |
| 2 | 迭代加深忘记"每次重新搜索"要重置状态 | 全局状态未复原会出错 |
| 3 | A* 中 $h$ 未用"到目标的真实下界" | 例如用欧氏距离而非曼哈顿距离（在有障碍时可能高估） |
| 4 | 双向 BFS 相遇判定放在"生成时"还是"出队时"不一致 | 统一在生成时判定最省事 |
| 5 | 双向 BFS 两边扩展不同步（一边跑完才跑另一边） | 会退化成单向 |
| 6 | DLX 忘记启发式选列 | 速度差几十倍 |
| 7 | DLX 恢复列的顺序与删除相反 | 必须逆序恢复 |
| 8 | Alpha-Beta 剪枝窗口更新写反 | `alpha` 给 max 层、`beta` 给 min 层 |
| 9 | 搜到"吃子"层就停（地平线效应） | 需要静态搜索延展 |
| 10 | 状态编码冲突（不同状态映射到同一整数） | 编码要一一对应 |
