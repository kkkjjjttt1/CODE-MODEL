**共 38 项对拍全部通过**。用法见 [`tools/README.md`](tools/README.md)。

> **对拍抓到的真实 bug**（已修正并记录在对应章节）：
> 1. **KM 算法**：流行的"递归版"在某些权值下顶标调整不收敛（死循环）→ 改用 BFS 版；
> 2. **整体二分**：每层都用 `a[i] <= mid` 加入元素，在右半值域递归时会把已排除的元素算进去 → 答案偏小；
> 3. **DLX**：找到解后提前返回前仍做了一次 `resume`，破坏链表（可能死循环）；
> 4. **DLX**：`head` 按行索引却只清了列数个，行数 > 列数时出错；
> 5. **长链剖分**：公用缓冲区分配指针起点必须是 `dep[1]`，写成 0 会与根段重叠。

## 建议用法

1. **先读第 00 章**核对差距（如果你已掌握某项，跳过对应章节）；
2. **按 01 → 09 顺序学**（有依赖：网络流建模依赖 SCC，虚树依赖 LCA+dfs 序）；
3. **每个模板亲手敲一遍**，再用 `tools/` 里的对拍程序验证你的实现；
4. **做题单**（第 09 章），做完用自测表评分；
5. 卡题时查 `09` 的题单与 `08` 的策略清单。
