## 15.2 例题精讲（一）：[P2178 [NOI2015] 品酒大会](https://www.luogu.com.cn/problem/P2178)（SA + 并查集）

**题意**（浓缩）：长为 n 的串 s，每个位置有美味度 a[i]（可为负）。两杯酒 i、j（i<j）相似度为 `LCP(suffix i, suffix j)`。对每个 r = 0..n−1，求：①相似度 ≥ r 的（无序）对数；②这些对中 a[i]·a[j] 的最大值。

**思路拆解**：

1. 求 SA + height。`LCP(i, j) = min height in (rk[i], rk[j]]`——两后缀 LCP ≥ r 当且仅当它们在"以 height ≥ r 为桥"的同一个连通块内。
2. 把相邻后缀看作点之间的边：点 i 与点 i+1（在 sa 序中相邻）之间边权 = `height[i+1]`。一个连通块（用并查集维护）里的任意两个后缀的 LCP ≥ 该块合并时用到的阈值。
3. **按边权从大到小合并**：把边按 height 降序排序，逐条把两侧集合合并。合并两个集合（大小 s1、s2）时，产生了 s1×s2 对"LCP ≥ 当前边权 w"的新对数——它们对**所有 r ≤ w** 都有贡献，用差分 `diff[1] += s1*s2; diff[w+1] -= s1*s2;` 最后从大到小做后缀和得到每档答案 ①。
4. ②最大乘积：每个集合维护该集合内后缀起点位置美味度的 **max1、max2、min1、min2**（负负得正！）。合并时用 `max(max1*max2, min1*min2)` 更新该档的最大值数组 `best[w]`；最后同样做"≥r 前缀取最大"。

```cpp
// 伪代码框架（并查集版）
sort(edges by w desc);                 // edges: (w=height[i+1], sa序相邻的两点)
for e : edges:
    u = find(x), v = find(y); if (u == v) continue;
    cnt[w] += 1LL * sz[u] * sz[v];     // 累加到“恰为阈值 w”的对数
    best[w] = max(best[w], max( mx[u]*mx2[u], mn[u]*mn2[u], 合并后的候选… ));
    merge(u, v);                        // 维护 sz/mx/mn
// 输出：对 r 从 n-1 到 0：total[r] = total[r+1] + cnt[r]（前缀累加）；maxAns[r] = max(maxAns[r+1], best[r])
```

**易错点**：美味度可能是负数 → 最值要同时维护最小两个；答案 ② 无解输出 0 需特判；用 `long long`。

**复杂度**：O(n log n)（SA）+ O(n log n)（排序边）+ O(n·α(n))。

## 15.3 例题精讲（二）：SPOJ LCS2 多串最长公共子串（SAM + link 树上推）

**题意**：给 k（≤10）个串，求最长公共子串长度。k·总长 ≤ 1e5 级别。

**思路拆解**（对应 10 章④ 的解法二）：

1. 选**最短**的串 S₁ 建 SAM（减少后续遍历成本）。
2. 对其余每个串 T，在 SAM 上"尽力匹配"：维护 (v, l)，像单串 LCS 一样前进/沿 link 回退；每走一步更新 `curMatch[v] = max(curMatch[v], l)`——表示 T 能在状态 v 匹配到长度为 l 的串。
3. **沿 link 树上推**（关键）：T 在状态 v 匹配到 l，那么 v 在 link 树上的祖先（= v 的串的后缀）**至少**也能匹配 min(l, len[ancestor])。所以按 len 从大到小扫所有状态：`curMatch[link[v]] = max(curMatch[link[v]], min(curMatch[v], len[link[v]]))`。
4. 对每个串都做完后，取每个状态在**所有串**下匹配长度的最小值 `mn[v]`，答案 = max mn[v]。

```cpp
// 框架
sam.build(S1);
vector<int> mn(sz, INF);
for (string& T : 其余串) {
    vector<int> cur(sz, 0);
    int v = 0, l = 0;
    for (char ch : T) {
        int c = ch - 'a';
        while (v && !sam.next(v, c)) { v = link[v]; l = len[v]; }
        if (sam.next(v, c)) { v = next(v, c); ++l; cur[v] = max(cur[v], l); }
    }
    for (v 按 len 降序) cur[link[v]] = max(cur[link[v]], min(cur[v], len[link[v]]));
    for (v) mn[v] = min(mn[v], cur[v]);
}
ans = max(mn);   // 注意答案 ≤ len[v] 已在第 3 步 cap
```

**易错点**：上推时要 `min(cur, len[ancestor])`（祖先最长串有限长）；只更新 cur 不更新祖先会漏掉"较长的串失配后其短后缀仍匹配"的情况；答案对每个状态取所有串的最小值再取最大。

**复杂度**：O(Σ|Tᵢ| + k·|S₁|)，几乎是线性。

## 15.6 结语

字符串算法是一个"工具多、套路固定、上手快、精通难"的领域：

1. **先背熟 8 个模板**：哈希、KMP、Z/exKMP、Trie、AC、Manacher、SA、SAM；
2. **做题先定性**：匹配？回文？计数？字典序？子串还是子序列？动态还是静态？——每个问题都有对应的首选工具；
3. **每道题想三件事**：能 O(n) 吗（哈希/自动机）？能离线吗（SA/SAM/排序）？需要数据结构吗（线段树/并查集/BIT）？
4. 遇到不会的题，回来翻本册对应章节的总表与例题——祝你早日 **AK 字符串**！🚀
