# 第 11 章 Lyndon 分解与最小表示法

> **一句话**：本章解决**循环同构（旋转）**家族问题：找字典序最小的旋转、判断两个串是否互为旋转，
> 以及理解串的一种漂亮分解——**Lyndon 分解**。
> 复杂度均为 **O(n)**，代码短小。前置：字典序（01 章）、KMP border 思想（03 章，可选项）。

---

## 11.1 问题：最小表示（最小旋转）

**旋转**：把串 `s` 从某处切开并交换两段，得到 `s[i..n-1] + s[0..i-1]`（0 ≤ i < n）。

**最小表示问题**：n 个旋转里字典序最小的那个，返回它的起始下标。

例：`s = "cab"` 的旋转是 `cab(0), abc(1), bca(2)`，最小的是 `abc`，起始下标 **1**。

朴素：枚举起点逐一比较 O(n²)。需要 O(n)。

---

## 11.2 最小表示法：双指针 O(n)（最实用模板）

维护两个候选起点 `i, j` 和一个"已确认相等长度" `k`。若 `s[i+k] == s[j+k]` 就 k++；否则字典序较大的一方整体跳过 `k+1` 个位置（那些位置开头的旋转都不可能最小，因为与对手相比在位置 k 处分出了胜负且对方更小）：

```cpp
// 返回 s 的最小旋转的起始下标（0 基）；若题目要输出串，取 s.substr(ans) + s.substr(0, ans)
int minRotation(const string& s) {
    int n = (int)s.size();
    string t = s + s;                // 所有旋转都出现在 t 的长度 n 的子串里
    int i = 0, j = 1, k = 0;
    while (i < n && j < n && k < n) {
        char a = t[i + k], b = t[j + k];
        if (a == b) {
            ++k;
        } else if (a > b) {
            i = i + k + 1;           // i 开头的旋转比 j 的大，整段跳过
            if (i == j) ++i;         // 避免两个候选重合（重合后永远相等）
            k = 0;
        } else {
            j = j + k + 1;
            if (i == j) ++j;
            k = 0;
        }
    }
    return min(i, j);
}
```

**正确性直觉**（为什么可以把 i 跳到 `i+k+1`）：比较 `t[i..i+n-1]` 与 `t[j..j+n-1]` 时前 k 个字符相同、第 k+1 个字符 i 侧更大。则对任意 `0 ≤ d ≤ k`，以 `i+d` 开头的旋转一定**大于**以 `j+d` 开头的旋转（前 k−d 个字符相同后仍是 i 侧字符更大），所以 `i..i+k` 这些起点全部可以淘汰，直接跳 `i+k+1`。

**验证小例**：`s="cab"` → 过程：i=0,j=1 比较 'c'>'a' → i 跳为 1，与 j 重合再跳为 2 → i=2,j=1 比较 'b'>'a' → i 跳为 3 ≥ n 退出 → 返回 min(3,1)=1 ✓。

复杂度 O(n)（i、j 各自单调，每个字符最多被比较常数次）。

> 其它等价做法：对 `s+s` 求后缀数组，取起点 ≤ n 的最小者（09 章②，O(n log n)）；或 Lyndon 分解（11.4）。

## 11.3 Lyndon 词与 Lyndon 分解

### 11.3.1 定义与性质

- **Lyndon 词**：串 w 是 Lyndon 词，如果 w **严格小于**它的所有非平凡旋转（循环移位）。等价定义：w 严格小于自己的所有非平凡真后缀。
- 例：`"a"`、`"ab"`、`"aab"`、`"abab"`?（`"abab"`：后缀 `"ab"`、`"b"`，比较 `"abab"<"ab"`? "abab" vs "ab": "ab" 是 "abab" 前缀 → "ab" 更小 → "abab" 不是 Lyndon）→ Lyndon 词都是**本原串**（不是某个更短串的整数次重复），且开头字符是全局最小字符。
- 两条关键性质：
  1. 若 u、v 是 Lyndon 词且 `u < v`，则 `uv` 也是 Lyndon 词；
  2. （本原性）Lyndon 词没有真 border（或说它不能写成 `x^k`，k≥2）。

### 11.3.2 唯一分解定理

> 任意串 s 都能**唯一**分解成若干 Lyndon 词首尾相接：`s = w1 w2 … wk`，且满足 **w1 ≥ w2 ≥ … ≥ wk**（字典序非递增）。

这个分解存在且唯一，是 Lyndon 系列应用的基石。

### 11.3.3 Duval 算法（O(n)）

用三个指针扫描并贪心切分（`i`：当前段起点；`j`：探针；`k`：与段首比较的位置）：

```cpp
// Duval 算法：求 s 的 Lyndon 分解
// 返回每个 Lyndon 段的【起点】下标；段长 = 相邻起点差（最后一个段的终点是 n）
vector<int> lyndonDecomposition(const string& s) {
    int n = (int)s.size();
    vector<int> res;
    for (int i = 0; i < n; ) {
        int j = i + 1, k = i;
        while (j < n && s[k] <= s[j]) {      // 维持“循环候选词”的 Lyndon 性
            if (s[k] < s[j]) k = i;          // 出现更大字符：候选词重新开始
            else ++k;                        // 相等：比较位置后移
            ++j;
        }
        // 此刻段长 = j - k，从 i 开始整段重复取 (j-k) 的长度切分
        while (i <= k) {
            res.push_back(i);
            i += j - k;
        }
    }
    return res;
}
```

例：`s = "aabaaaab"` 的 Lyndon 分解（可自行跑一遍对拍）：`"aab" "aaab"`? 实际分解为 `aab | aaab`? 手算：用 O(n²) 验证太费；建议在 OJ 上用模板题确认。

> 记忆：内层 while 语义 = 在 `s[i..]` 上扩展"字典序最小的周期性候选"，`j-k` 是候选 Lyndon 段的长度；外层把候选整段切下来。

## 11.4 应用

### ① 判断两个串是否循环同构

方法 1：分别求最小表示起点，再比较对应旋转是否相等（哈希或直接比较）。方法 2：`t 在 s+s 中出现` ⇔ t 是 s 的旋转（KMP/AC/哈希）。两者皆 O(n)。

### ② 求最小旋转（三条路）

1. **双指针最小表示**（11.2，推荐，最好写）；
2. **后缀数组**：`s+s` 排序取起点 ≤ n 的最小者（09 章）；
3. **Lyndon 分解**（理论优美）：`s+s` 的 Lyndon 分解中第一个**长度 ≥ n** 的 Lyndon 段的起点即最小旋转起点——具体实现与证明可见 CP-Algorithms《Lyndon factorization》与《Finding the lexicographically minimal string rotation》，竞赛里了解即可，主推方法 1。

### ③ 本质不同旋转计数 / Necklace 计数（组合方向）

- 一个 Lyndon 词的长度 n 段代表**一个项链等价类**的最小旋转；
- **长度 n、字符集大小 |Σ|=q 的 Lyndon 词个数**：
  ```
  L(n) = (1/n) · Σ_{d|n} μ(d) · q^(n/d)      （μ 为莫比乌斯函数）
  ```
  这是 "本质不同项链数/旋转去重计数" 类题的核心公式（另一条路是 Burnside 引理）。例题方向：SPOJ "Necklaces"、各类 Polya 计数题。

### ④ 其它小巧思

- "能否由某个串重复得到"与 Lyndon 词的本原性相通；
- 某些**字典序构造贪心**题（每次取剩余串最小旋转位置）背后就是 Lyndon 分解。

## 11.6 小结

```
循环同构家族：
  最小旋转 ── 双指针 O(n)（首选）
          └─ SA on s+s：O(n log n)
          └─ Lyndon 分解：理论优美
  互为旋转 ── 最小表示相等 / t ∈ s+s
  Lyndon 分解（Duval O(n)）─ 唯一分解 w1 ≥ w2 ≥ … ≥ wk
       └─ 项链计数 L(n) = (1/n)Σ μ(d) q^(n/d)
```
