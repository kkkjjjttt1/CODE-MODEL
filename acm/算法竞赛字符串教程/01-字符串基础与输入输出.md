## 1.1 基本术语（本册统一使用）

设字符集为 `Σ`（如小写字母 `a..z`，`|Σ|=26`），串 `s` 的长度为 `n`。

- **子串 substring**：`s[l..r]`（`0≤l≤r<n`），**连续**的一段；
- **子序列 subsequence**：删去若干字符后得到，**不要求连续**；
- **前缀 prefix**：`s[0..k]`；**后缀 suffix**：`s[k..n-1]`；相应地有**真前缀/真后缀**（不等于整个串）；
- **border**：`s` 的一个**真前缀**同时又是它的**真后缀**，即 `s[0..t-1] = s[n-t..n-1]`，长度记作 `t`。例：`"abacaba"` 的 border 有 `"aba"` 与 `"a"`；
- **周期 period / 循环节**：若对所有 `i` 有 `s[i]=s[i+p]`（`0≤i<n-p`），则 `p` 是一个周期，`s[0..p-1]` 称为循环节。**注意**：`p` 是周期不一定要求 `p | n`（整除时才叫"整周期"）。例：`"abcab"` 有周期 3；
- **回文 palindrome**：`s = reverse(s)`；
- **循环同构 / 旋转 rotation**：把 `s` 从某处切开并交换两部分得到的新串。例：`"bcab"` 是 `"abbc"` 的一个旋转；
- **LCP(l,r)**：两个后缀/两段串的**最长公共前缀长度**；
- **本质不同子串**：按内容计数的不同子串（`"aaa"` 的子串只有 `"a","aa","aaa"` 三种本质不同的）。

> 记忆口诀：**border 是"又当前缀又当后缀"；周期是"平移相等"**。

## 1.2 字符与编码

### 1.2.1 ASCII 与竞赛现实

- ASCII 用 7 bit 表示 `0..127`（`'0'..'9'`、`'A'..'Z'`、`'a'..'z'`、控制字符）。扩展 ASCII 到 255。
- 绝大多数竞赛字符串题只处理**小写/大写字母与数字**（ASCII 字符），因此：
  - 下标偏移：`int c = s[i] - 'a';`（0..25）或 `s[i] - 'A'`、`s[i] - '0'`；
  - Trie/自动机的转移数组开 `[26]` 即可，字符集更大时改用 `map`/`unordered_map` 或排序离散化。
- **中文是多字节**（UTF-8 下一个汉字通常 3 字节）。除非题目明说处理 UTF-8（几乎不会），否则不要对汉字做逐字节字符串算法。读入含中文的行用 `getline` 整行读入、整体比较即可。

### 1.2.2 char 的符号性陷阱

C++ 中 `char` 是否带符号由平台决定。当字符值 `≥128`（如扩展 ASCII 或读字节流）时：

```cpp
char c = ...;
// 若想得到 0..255 的无符号值：
int v = (unsigned char)c;      // 安全
// int v = c;                   // 不安全：可能变成负数
```

处理任意字节时建议直接 `vector<unsigned char>` 或用 `string` 但读取时转 `unsigned char`。

## 1.3 C 风格字符串 vs `std::string`

### 1.3.1 C 风格（`char s[]`）

```cpp
char s[100005];
scanf("%s", s);            // 读到空白停止，自动补 '\0'
strlen(s);                 // O(n) 扫描
strcmp(a, b);              // <0 / 0 / >0，按字典序
strcpy(d, s); strcat(d, s);// 危险：不检查缓冲区
strstr(hay, needle);       // 朴素匹配，可能 O(nm)
```

**坑**：
1. `strlen` 依赖 `'\0'` 结尾，忘记留 `'\0'` 会读到野内存；
2. `scanf("%s")` / `cin >> s` 都**读到空白即停**，读不了含空格的串；
3. C 风格字符串在 `std::map` 等容器里很难用，传参容易退化。

### 1.3.2 `std::string` 常用操作（重点）

```cpp
string s = "hello", t = "world";
s.size(); s.length();           // 都是长度，O(1)
s.empty();                      // 判空
s[i];                           // O(1) 访问，不检查越界（快）
s.at(i);                        // 越界抛异常（慢，调试用）

s.substr(l, len);               // 返回 [l, l+len)，O(len)
s.substr(l);                    // 返回 [l, end)
s.find(t);                      // 返回首次出现位置或 string::npos，朴素实现最坏 O(nm)
s.rfind(t);
s.compare(t);                   // 字典序比较
s < t;                          // 与字典序一致，常用
s += c;  s.append(t);  s = s + t;
// 注意：s = s + t 每次都会复制整个 s，连续拼接是 O(n^2)；
// 正确姿势：s += t（摊还 O(1)），或先 s.reserve(总长)。

s.insert(pos, t);  s.erase(l, len);
s.replace(l, len, t);
s.push_back(c); s.pop_back();   // 尾部操作，摊还 O(1)
s.back();                       // 最后一个字符（别对空串用！）

s.c_str();                      // 转 const char*（以 '\0' 结尾）
s.data();                       // C++17 起与 c_str 等价

// 数字转换
int x = stoi(s);                // stol / stoll / stoull / stod / stof
string y = to_string(123);

// 字符判断（<cctype>）
isalpha(c); isdigit(c); islower(c); isupper(c); isspace(c);
tolower(c); toupper(c);
```

**性能红线**：
- `s.substr(...)` 会**复制**，循环里用要小心（总复杂度可能 O(n²)）；
- `s.find(...)`、`replace`、`insert`、`erase` 大多为 O(len)；
- 大量拼接请 `reserve` 后用 `+=`；需要"只读视图"用下面的 `string_view`。

### 1.3.3 `std::string_view`（C++17，进阶友好）

```cpp
string s = "abcdef";
string_view sv(s.data() + 1, 3);   // "bcd"，不拷贝
// 注意：sv 不拥有内存，原 string 析构/修改后 sv 悬垂，只能当临时参数用。
```

适合在函数参数、切分（split）时避免拷贝，**不要长期保存**。

## 1.4 输入输出技巧（竞赛生存法则）

### 1.4.1 关闭同步 + 解绑

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    // 之后 cin/cout 速度接近 scanf/printf
    // 代价：不能再混用 scanf/printf 与 cin/cout（顺序会乱）
    int n; cin >> n;
    string s; cin >> s;
    cout << s << '\n';       // 用 '\n' 而不是 endl（endl 会刷新缓冲，慢）
    return 0;
}
```

### 1.4.2 读一整行（含空格）

```cpp
string line;
// 坑：前面若用过 cin >> x，行缓冲里可能残留 '\n'
cin.ignore(numeric_limits<streamsize>::max(), '\n');   // 清掉残留换行
getline(cin, line);          // 读入一整行（不含末尾 '\n'）
```

**经典场景**：先读 `n`，随后有 n 行可能含空格的字符串。

### 1.4.3 快读 / 快写模板（数据量 ≥ 1e6 时）

```cpp
// 整数快读（比 cin 快很多，尤其大量数字+字符串混合时）
int readInt() {
    int x = 0; char c = getchar(); bool neg = false;
    while (c < '0' || c > '9') { if (c == '-') neg = true; c = getchar(); }
    while (c >= '0' && c <= '9') { x = x * 10 + (c - '0'); c = getchar(); }
    return neg ? -x : x;
}
// 或者用 getchar_unlocked（Linux OJ）；Windows 本地无此函数，交题慎用。
```

**读字符序列模板**（字符串题常用，跳过空白、保留其余字符到数组）：

```cpp
static char buf[1000005];
int readString() {           // 返回长度
    int p = 0; char c;
    c = getchar();
    while (c != '\n' && c != ' ' && c != EOF) { buf[p++] = c; c = getchar(); }
    buf[p] = '\0';
    return p;
}
```

### 1.4.5 IO 常见坑清单

| 坑 | 说明 | 对策 |
|----|------|------|
| 行尾 `\r` | Windows 造的测试数据行尾是 `\r\n`，`getline` 会留下 `\r` | 读完后若 `s.back()=='\r'` 就 `pop_back()` |
| 数据以空行分隔 | `getline` 读到的是空串 | `while(line.empty()) getline(...)` |
| 多组数据无组数 | 读到 EOF 结束 | `while (getline(cin, s)) { ... }` |
| `cin` 读数字后紧跟 `getline` | 残留换行 | `cin.ignore(...)` |
| 题目说"长度未知，以 EOF 结束" | | 同上循环读 |

## 1.5 字典序（lexicographical order）

- 逐个字符比较，第一个不同的字符决定大小；
- 若一个是另一个的前缀，则**短的更小**（C++ `string` 的 `<` 正是如此）；
- 空串是任何串的前缀，字典序最小。

```cpp
// "ab" < "aba" < "abb" < "b"
// 有时题目要求"后缀排序"，就是按后缀字典序排序 -> 见第 09 章后缀数组
```

## 1.7 本章自测小思考

1. `"aaaa"` 的所有 border 长度分别是多少？（答案：3、2、1）
2. `"ababa"` 有哪些周期？（答案：2、3、4——注意周期不要求整除）
