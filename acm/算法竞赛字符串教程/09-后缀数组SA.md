# 第 09 章 后缀数组（Suffix Array, SA）

> **一句话**：把字符串的 **n 个后缀按字典序排序**，再配上 height 数组（相邻后缀的 LCP），
> 几乎所有"子串"问题都能转化成"后缀区间"问题，用 SA 统一解决。
> 复杂度 O(n log n)（倍增+基数排序）；n ≤ 1e6 无压力。本章采用 **1 基下标**（与 OI-wiki 一致）。

---

## 9.1 定义与核心直觉

设串 `s` 长 `n`（1 基，`s[1..n]`）。

- **后缀 i**：`s[i..n]`（以 i 开头的后缀）；
- **sa[i]**：所有后缀**按字典序升序**排列后，第 i 名的后缀编号（起始位置）——后缀数组本体；
- **rk[i]**：后缀 i 的排名。有 `sa[rk[i]] = rk[sa[i]] = i`。

例：`s = "banana"`（先不管 0/1 基差异）：
```
后缀：1 banana, 2 anana, 3 nana, 4 ana, 5 na, 6 a
排序：a < ana < anana < banana < na < nana
sa = [6, 4, 2, 1, 5, 3]
rk = [4, 3, 6, 2, 5, 1]
```

**为什么子串问题都能用它**：任意子串 `s[l..r]` = 后缀 l 的**前缀**。所以"数不同子串""找出现次数""查 LCP"就变成对**排序好的后缀序列**做区间处理——一个后缀区间里的共同前缀就是"一段连续出现的相同子串"。

## 9.2 倍增法求 SA（O(n log n)，计数排序版）

**思想**：先按每个后缀的长度 1、2、4、8 … 的前缀排序。若已知所有"长度 w/2 前缀"的排名，则"长度 w 前缀"的排名可由二元组 `(rk[i], rk[i+w])` 决定——双关键字排序。倍增到 w ≥ n 时前缀就是整个后缀。

**实现要点**：
1. 用 `rk[i]` 表示"长度 w/2 的前缀"的排名，越界（`i+w>n`）视为最小的 0；
2. 每轮用**基数排序**（两趟计数排序）O(n) 完成双关键字排序；
3. 排名从 1 开始（0 留给"越界哨兵"），若一轮后排名互不相同即可提前结束。

```cpp
#include <bits/stdc++.h>
using namespace std;

// 输入普通字符串 s（0 基）；返回 sa[1..n]：第 i 小后缀的起始位置（1 基，对应 s[sa[i]-1..]）
vector<int> buildSuffixArray(const string& s) {
    int n = (int)s.size();
    vector<int> a(n + 2, 0);                    // 1 基整型串，末尾留 0 哨兵
    for (int i = 1; i <= n; ++i) a[i] = (unsigned char)s[i - 1];

    vector<int> sa(n + 1, 0), rk(2 * n + 2, 0), oldrk(2 * n + 2, 0), id(n + 1);
    int m = 256;                                // 初始值域：字节 1..255（0 留给哨兵）
    vector<int> cnt(m + 1, 0);

    // —— 第一轮：按单个字符基数排序 ——
    for (int i = 1; i <= n; ++i) ++cnt[rk[i] = a[i]];
    for (int i = 1; i <= m; ++i) cnt[i] += cnt[i - 1];
    for (int i = n; i >= 1; --i) sa[cnt[rk[i]]--] = i;

    // 压缩排名到 1..p（p = 当前不同前缀个数）。sa[0]=0, oldrk[0]=0（哨兵）保证第一个元素得 1
    for (int i = 1; i <= n; ++i) oldrk[i] = rk[i];
    int p = 0;
    for (int i = 1; i <= n; ++i)
        rk[sa[i]] = (oldrk[sa[i]] == oldrk[sa[i - 1]]) ? p : ++p;
    // 注意：oldrk[sa[i-1]] 在 i=1 时是 oldrk[0]=0，真实排名 ≥ 1，故第一项必然 ++p，排名从 1 起

    // —— 倍增 ——
    for (int w = 1; w < n; w <<= 1) {
        // 1) 构造按“第二关键字”排好序的序列 id：
        //    越界（rk 视为 0，最小）的后缀排最前，其余按上一轮 sa 顺序平移
        int cur = 0;
        for (int i = n - w + 1; i <= n; ++i) id[++cur] = i;   // 第二关键字为空
        for (int i = 1; i <= n; ++i)
            if (sa[i] > w) id[++cur] = sa[i] - w;             // 上一轮第 i 名的后缀 - w

        // 2) 按第一关键字做稳定计数排序（值域 m = p）
        cnt.assign(p + 1, 0);
        for (int i = 1; i <= n; ++i) ++cnt[rk[i]];
        for (int i = 1; i <= p; ++i) cnt[i] += cnt[i - 1];
        for (int i = n; i >= 1; --i) sa[cnt[rk[id[i]]]--] = id[i];

        // 3) 压缩排名
        for (int i = 1; i <= n; ++i) oldrk[i] = rk[i];
        p = 0;
        for (int i = 1; i <= n; ++i) {
            if (oldrk[sa[i]] == oldrk[sa[i - 1]] &&
                oldrk[sa[i] + w] == oldrk[sa[i - 1] + w])
                rk[sa[i]] = p;
            else
                rk[sa[i]] = ++p;
        }
        if (p == n) break;                      // 所有排名互异，已经得到最终 SA
    }
    return sa;
}
```

**复杂度**：O(n log n) 时间，O(n) 额外空间（rk 开 2n 是为了 `rk[i+w]` 越界访问返回哨兵 0）。

### 9.2.1 简易版（std::sort，O(n log²n)，好写、可用来对拍/小数据）

```cpp
vector<int> buildSA_simple(const string& s) {
    int n = (int)s.size();
    vector<int> sa(n), rk(n + 1);
    for (int i = 0; i < n; ++i) sa[i] = i, rk[i] = (unsigned char)s[i];
    for (int w = 1; w < n; w <<= 1) {
        auto cmp = [&](int x, int y) {
            if (rk[x] != rk[y]) return rk[x] < rk[y];
            int a = x + w < n ? rk[x + w] : -1;
            int b = y + w < n ? rk[y + w] : -1;
            return a < b;
        };
        sort(sa.begin(), sa.end(), cmp);
        vector<int> nrk(n);
        nrk[sa[0]] = 0;
        for (int i = 1; i < n; ++i)
            nrk[sa[i]] = nrk[sa[i - 1]] + (cmp(sa[i - 1], sa[i]) ? 1 : 0);
        rk = nrk;
        if (rk[sa[n - 1]] == n - 1) break;
    }
    return sa;   // 0 基
}
```

> 若追求极致（n ≈ 1e6 且时限紧），可学 **DC3 / SA-IS**（O(n)）。竞赛中倍增已足够。

## 9.3 height 数组（LCP 的钥匙）

### 9.3.1 定义

```
height[i] = LCP(后缀 sa[i], 后缀 sa[i-1])    （i ≥ 2）
height[1] = 0
```

即排序后**相邻**两个后缀的最长公共前缀。

### 9.3.2 求两后缀 LCP 的关键定理

> **定理**：`LCP(后缀 sa[i], 后缀 sa[j]) = min{ height[i+1], …, height[j] }`（i<j）。
> 也就是排好序的后缀里，两后缀的 LCP 等于它们之间所有相邻 height 的最小值（RMQ）。

### 9.3.3 O(n) 求 height

利用引理 **height[rk[i]] ≥ height[rk[i-1]] − 1**（前一个后缀的 height 减 1 可以继承），暴力比较的指针 k 至多回退 n 次：

```cpp
// 需要 rk 与 sa（1 基）以及整型串 a（a[n+1] = 0 哨兵）
vector<int> buildHeight(const vector<int>& a, const vector<int>& sa, const vector<int>& rk) {
    int n = (int)sa.size() - 1;
    vector<int> height(n + 1, 0);
    for (int i = 1, k = 0; i <= n; ++i) {
        if (rk[i] == 1) continue;              // 排名第 1，无前驱
        if (k) --k;
        while (a[i + k] == a[sa[rk[i] - 1] + k]) ++k;   // a[n+1]=0 哨兵自然停止
        height[rk[i]] = k;
    }
    return height;   // height[1..n]
}
```

> 验证小例：`s = "banana"` 的 height = [0, 1(ana|a), 3(anana|ana), 0(banana|anana), 0(na|banana), 2(nana|na)]。

**把 height 建成 ST 表**（RMQ）后，任何两个位置的后缀 LCP 都是 O(1)：

```cpp
// lcp 任意两后缀（1 基位置 i, j）：L = min(height[rk[i]+1 .. rk[j]]) 的 RMQ
```

## 9.4 应用大全（SA 的"十般武艺"）

### ① 模式串出现次数 / 出现位置（在线二分）

模式 P 若出现，必是若干**连续相邻**后缀的公共前缀 → 在 sa 上二分出 P 能匹配的后缀区间 `[L, R]`：

```cpp
// 找 P 匹配的 sa 区间 [L,R]（都出现该模式），返回出现次数 = R-L+1
// 每次二分比较 P 与 后缀 sa[mid] 的字典序 O(|P| log n)
```

### ② 最小循环移位（旋转串字典序最小）

`s + s` 的所有长度 n 的子串 = 所有旋转。对 `s + s` 求 SA，取**前 n 个后缀中起始位置 ≤ n** 的最小者。例题：[P4051 [JSOI2007] 字符加密](https://www.luogu.com.cn/problem/P4051)（注意该题输出每行一个字符，读清题意）。

### ③ 本质不同子串个数

每个子串 = 某个后缀的前缀。按 sa 顺序枚举后缀 i：它与前一名的公共前缀 `height[i]` 已经在前面算过，新增的不同子串 = `(n - sa[i] + 1) - height[i]`：

```cpp
long long distinctSubstrings(const vector<int>& sa, const vector<int>& height) {
    int n = (int)sa.size() - 1;
    long long ans = 1LL * n * (n + 1) / 2;      // 全部子串数
    for (int i = 2; i <= n; ++i) ans -= height[i];   // 减去与前一名的重复前缀
    return ans;
}
```

### ④ 最长重复子串

- **可重叠**：答案 = `max(height[2..n])`；
- **不可重叠**：二分长度 L，把 height 按 `≥ L` 分成若干段，每段内后缀的 LCP 都 ≥ L；若某段内最大最小 sa 下标差 ≥ L 则可行（两个该长度的相同子串不重叠）。

### ⑤ 最长公共子串（两串 / 多串）

两串：拼成 `A + '#' + B`（分隔符小于所有字符或至少不在字符集中），求 SA+height；答案是**跨过分隔符两侧**的相邻后缀的 height 最大值。
多串：把所有串用不同分隔符拼接，二分答案 L，检查是否存在一段连续后缀（height ≥ L）覆盖了**每个串**至少一个后缀。

### ⑥ 出现至少 k 次的最长子串

height 连续段内若有 ≥ k 个后缀（LCP ≥ L），则长度为 L 的子串出现 ≥ k 次。二分 L，滑动窗口维护"每 k−1 个相邻 height 的最小值"取最大。
例题：[P2852 [USACO06DEC] Milk Patterns](https://www.luogu.com.cn/problem/P2852)。

### ⑦ 字典序第 k 小子串（本质不同计数版）

沿用 ③ 的"增量"思路：按 sa 顺序累加每个后缀贡献的新子串数 `(n - sa[i] + 1) - height[i]`，累计 ≥ k 时定位到后缀 i 与内部偏移。O(n)。（若题目按"位置不同也算不同"计数，则是可重复子串计数，另用 SAM 处理。）

### ⑧ height 的区间最小值贡献（单调栈）

`Σ_{i<j} LCP(i,j)` 类问题：每个 height 值作为**区间最小**的左右延伸范围决定它被多少对后缀当 LCP 用——单调栈求左右边界 O(n)。例题：[P4248 [AHOI2013] 差异](https://www.luogu.com.cn/problem/P4248)。

### ⑨ height 按值合并（并查集 / 品酒大会）

把后缀看作点、height 看作相邻两点之间的边权。按 height 从大到小合并相邻点，合并时用两集合的大小等信息统计"LCP ≥ 当前值"的答案。经典题：[P2178 [NOI2015] 品酒大会](https://www.luogu.com.cn/problem/P2178)。

### ⑩ 与数据结构结合

- 线段树/ST 表维护区间 min(height) → 区间内 LCP；
- SA + 莫队 / 分块处理区间查询；
- SA 排序 + RMQ 支持任意两子串字典序比较（见 OI-wiki）：子串 A = s[a..b]、B = s[c..d]，先比 LCP 再比下一字符。

## 9.6 小结

```
SA 全家桶：
  sa[]  rk[]  height[]
    │
    ├─ LCP(i,j) = RMQ(height)          → 判子串相等/比较子串/找公共部分
    ├─ 本质不同子串数 = n(n+1)/2 − Σheight
    ├─ 出现次数 ≥ k 的子串（二分 + 分段）
    ├─ 最长公共子串（拼接分隔符 + 跨段 height）
    ├─ 两两 LCP 统计（单调栈 / 并查集）
    └─ 循环移位/第 k 小/优秀拆分……
```

> SA 是"离线、好写、常数小"的通用武器；但**不能增量**。下一章（10）的后缀自动机 SAM 以 O(n) 状态在线构建，擅长"增量 + 出现次数 + 本质不同"类问题——两者互补，是字符串题的两大支柱。
