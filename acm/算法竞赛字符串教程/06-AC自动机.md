# 第 06 章 AC 自动机（Aho–Corasick Automaton）

> **一句话**：AC 自动机 = **Trie + KMP 的 fail 思想**，让"一堆模式串 + 一段文本"的多模式匹配一次扫描完成：
> 预处理 O(模式总长)，匹配 O(文本长 + 输出)。
> 前置：第 03 章（KMP/border 直觉）、第 05 章（Trie）。本章 0 基下标，小写字母集（大字符集换 `map`）。

---

## 6.1 问题与动机

给定 `k` 个模式串 `p_1..p_k` 和长文本 `s`，问：
1. 每个模式串在 s 中出现了多少次？（P3796 / P5357）
2. s 中有多少个**不同**模式串出现过？（P3808）
3. 以及各种"AC 自动机 + DP"计数问题。

朴素做法：对每个模式串跑一次 KMP → O(k·n) 或做 k 次拼接，总 O(n·Σ|p|)，文本被扫了 k 遍。

**AC 自动机的关键**：把 k 个模式串建成 **Trie**（一次性收纳所有模式），匹配时文本指针像 KMP 一样**从不回退**，失配时沿 **fail 指针**跳到"当前已匹配文本的最长后缀（且是某模式前缀）"对应的节点。

---

## 6.2 数据结构定义

```cpp
struct AhoCorasick {
    struct Node {
        int ch[26];      // 孩子（build 后未补全→补全后变为转移表）
        int fail;        // 失配指针
        int cnt;         // 以该节点为结尾的模式串个数（insert 时累加）
        Node() { memset(ch, 0, sizeof ch); fail = cnt = 0; }
    };
    vector<Node> tr;
    vector<int> order;          // BFS 顺序（后续 fail 树上推用）
    AhoCorasick() { tr.emplace_back(); }

    void insert(const string& p) {
        int u = 0;
        for (char c : p) {
            int x = c - 'a';
            if (!tr[u].ch[x]) { tr[u].ch[x] = (int)tr.size(); tr.emplace_back(); }
            u = tr[u].ch[x];
        }
        tr[u].cnt++;
    }
    // ... build() 见 6.3
};
```

## 6.3 构建 fail 指针（BFS + 补全转移 = "Trie 图"）

**fail[u] 的定义**：节点 u 代表的串的最长**真后缀**，且该后缀是**某个模式串的前缀**（即 Trie 中存在的节点）。失配时从 u 跳到 fail[u] 继续尝试。

KMP 里 border 是"一条链"；Trie 里每个节点只有一个 fail，且 `fail[u]` 的深度严格小于 u，因此 **fail 指针构成一棵以根为根的树（fail 树）**。

**BFS 构建**：深度从小到大。节点 u 的孩子 `v = u + c`，其 fail 就是"u 的 fail 链上第一个存在字符 c 孩子"的节点的 c 孩子。用**补全转移**写法（把不存在的孩子直接补成 fail 的转移），代码最简洁、匹配时零回退：

```cpp
    void build() {
        queue<int> q;
        for (int c = 0; c < 26; ++c)          // 第一层：fail 直接指向根
            if (tr[0].ch[c]) q.push(tr[0].ch[c]);
        while (!q.empty()) {
            int u = q.front(); q.pop();
            order.push_back(u);
            for (int c = 0; c < 26; ++c) {
                int v = tr[u].ch[c];
                if (v) {                       // 真实存在的孩子
                    tr[v].fail = tr[tr[u].fail].ch[c];
                    q.push(v);
                } else {                       // 补全：孩子不存在 → 指向 fail 的转移
                    tr[u].ch[c] = tr[tr[u].fail].ch[c];
                }
            }
        }
    }
```

> 补全之后，"沿着 ch 走"永远不会失败：**自动机在任何状态读入任何字符都有确定的下一状态**，这正是 DP（6.5 节）能做的原因。
> 注意根的自身补全：`tr[0].ch[c]` 若不存在会补成 `tr[0].ch[c]=tr[tr[0].fail].ch[c]=tr[0].ch[c]=0`，即"停在根"，行为正确。

## 6.4 匹配与计数

### 6.4.1 模式串种类计数（P3808 简单版）

逐字符走自动机，把沿途节点（以及它们 fail 链上的祖先）里"是模式结尾"的计数收走一次。经典写法用 `cnt=-1` 标记防重复：

```cpp
    // 返回文本 s 中出现了多少种不同的模式串
    int queryKind(const string& s) {
        int u = 0, res = 0;
        for (char c : s) {
            u = tr[u].ch[c - 'a'];
            for (int t = u; t && tr[t].cnt != -1; t = tr[t].fail) {
                res += tr[t].cnt;
                tr[t].cnt = -1;               // 每个模式只算一次
            }
        }
        return res;
    }
```

最坏情况下每个字符都要跳整条 fail 链（如全 a 的模式），因此数据较大时用 6.4.2 的 fail 树上推法。

### 6.4.2 每个模式串出现次数（P3796 / P5357 加强版）

**方法（fail 树差分）**：匹配时只给"当前状态"打点，最后在 fail 树上做子树和。

```
cnt[w] += 1   （对文本每个位置的状态 w）
之后按深度从大到小：cnt[fail[u]] += cnt[u]
则 cnt[ 模式串 i 的结尾节点 ] = 模式 i 的出现次数
```

```cpp
    // 返回每个模式串的出现次数；endNode[i] 为第 i 个模式的结尾节点
    vector<int> countOccurrences(const string& s, const vector<int>& endNode) {
        int u = 0;
        for (char c : s) {                    // 打点
            u = tr[u].ch[c - 'a'];
            tr[u].cnt++;
        }
        for (int i = (int)order.size() - 1; i >= 0; --i) {   // 逆 BFS 序 = 深度降序
            int v = order[i];
            tr[tr[v].fail].cnt += tr[v].cnt;  // 沿 fail 树累加给父
        }
        vector<int> res(endNode.size());
        for (size_t i = 0; i < endNode.size(); ++i)
            res[i] = tr[endNode[i]].cnt;
        return res;
    }
```

> 注意：如果多个模式串**完全相同**，它们共用同一个结尾节点，出现次数相同——这正是想要的答案，但若题目要求分别输出，需要按"哪些模式共用一个节点"分发。若文本中出现模式后又要求"模式作为文本子串继续向后匹配"，本方法天然支持（叠加式），与简单版"防重复清零"不同，**先想清楚题目统计口径再用**。

### 6.4.3 复杂度

- 构建：O(模式总长 × |Σ| 的补全均摊) ≈ O(总长 · 26)；
- 匹配+计数：O(文本长 + Trie 节点数)，输出 O(Σ出现次数)。
- 空间：约 总长 × 26 个 int（1e6 总长 ≈ 100+ MB 用 int[26]，注意内存；可用 `array<int,26>` 或改 vector 边）。

## 6.5 AC 自动机上的 DP（重点进阶）

补全后的自动机是一个**确定的 DFA**：状态 = 当前匹配位置在自动机上的节点。于是"构造/修改一个串，使其（不）包含某些模式"都能 DP：

### 6.5.1 危险（终止）状态标记

模式串结尾节点以及 **fail 树上它的所有子孙** 都"沾了毒"（走到这些状态说明文本后缀已含某个模式）。BFS 时可顺带传播：

```cpp
    // 在 build 的 BFS 中加一行（pop 出 u 之后）：
    //   if (tr[tr[u].fail].cnt_bad) tr[u].bad = true;   // cnt_bad: 该节点是否模式结尾/被传染
    // 更稳妥：先把“模式结尾”标记 bad，再用一次逆 BFS 序：bad[fail[u]] ||= bad[u]
```

### 6.5.2 例：长度为 n、不含任何模式的串的个数

`dp[i][u]` = 长度为 i、当前在节点 u 且从未进入 bad 状态的串数：

```cpp
// 模板化思路（mod = 题目模数）
vector<vector<int>> dp(n + 1, vector<int>(sz));
dp[0][0] = 1;
for (int i = 0; i < n; ++i)
    for (int u = 0; u < sz; ++u)
        if (dp[i][u])
            for (int c = 0; c < 26; ++c) {
                int v = tr[u].ch[c];          // 补全后的确定性转移
                if (!bad[v]) dp[i + 1][v] = (dp[i + 1][v] + dp[i][u]) % MOD;
            }
答案 = Σ_u dp[n][u]
```

> [洛谷 P4052 [JSOI2007] 文本生成器](https://www.luogu.com.cn/problem/P4052)：答案 = 所有串数 − 不含任何模式的串数（即上面的 DP）。若模式很短、n 很大，可用**矩阵快速幂**优化（转移矩阵是自动机的邻接转移）。

### 6.5.3 更多 AC+DP 题型

- **最少修改**：给定文本，最少改几个字符使其不含模式（POJ 3691 / HDU 2457 DNA repair）：`dp[i][u]` 上做"改/不改"的 min 转移；
- **病毒 / 无限串**：[洛谷 P2444 [POI2000] 病毒](https://www.luogu.com.cn/problem/P2444)：不含模式、可无限延伸的串是否存在 ⇔ 在"去掉 bad 状态"的自动机上是否存在**环**（DFS 三色标记）；
- **AC 自动机 + 概率/期望 + 高斯消元**（进阶）：随机串首次命中某模式的期望长度；
- **fail 树 + DFS 序 + 树状数组**：[洛谷 P2414 [NOI2011] 阿狸的打字机](https://www.luogu.com.cn/problem/P2414)：模式串本身就是 Trie 中一条路径（含退格操作），询问"x 在 y 中出现几次" ⇔ fail 树上"x 结尾节点的子树里有多少个 y 路径上的点"，用 DFS 序 + BIT 离线回答，经典中的经典。

## 6.6 完整模板（计数 + fail 树，可直接抄）

```cpp
#include <bits/stdc++.h>
using namespace std;

struct AhoCorasick {
    struct Node {
        int ch[26], fail, cnt;
        Node() { memset(ch, 0, sizeof ch); fail = cnt = 0; }
    };
    vector<Node> tr;
    vector<int> order;
    AhoCorasick() { tr.emplace_back(); }

    void insert(const string& p) {
        int u = 0;
        for (char c : p) {
            int x = c - 'a';
            if (!tr[u].ch[x]) { tr[u].ch[x] = (int)tr.size(); tr.emplace_back(); }
            u = tr[u].ch[x];
        }
        tr[u].cnt++;
    }
    void build() {
        queue<int> q;
        for (int c = 0; c < 26; ++c) if (tr[0].ch[c]) q.push(tr[0].ch[c]);
        while (!q.empty()) {
            int u = q.front(); q.pop();
            order.push_back(u);
            for (int c = 0; c < 26; ++c) {
                int v = tr[u].ch[c];
                if (v) { tr[v].fail = tr[tr[u].fail].ch[c]; q.push(v); }
                else   tr[u].ch[c] = tr[tr[u].fail].ch[c];
            }
        }
    }
    // 统计文本中出现了多少种模式
    int queryKind(const string& s) {
        int u = 0, res = 0;
        for (char c : s) {
            u = tr[u].ch[c - 'a'];
            for (int t = u; t && tr[t].cnt != -1; t = tr[t].fail) {
                res += tr[t].cnt;
                tr[t].cnt = -1;
            }
        }
        return res;
    }
    // 统计每个模式出现次数：调用前需 build()，传入各模式结尾节点
    vector<int> countAll(const string& s, const vector<int>& endNode) {
        int u = 0;
        for (char c : s) { u = tr[u].ch[c - 'a']; tr[u].cnt++; }
        for (int i = (int)order.size() - 1; i >= 0; --i) {
            int v = order[i];
            tr[tr[v].fail].cnt += tr[v].cnt;
        }
        vector<int> res(endNode.size());
        for (size_t i = 0; i < endNode.size(); ++i) res[i] = tr[endNode[i]].cnt;
        return res;
    }
};
```

## 6.8 小结

```
k 个模式 → Trie（收纳全部前缀）
         → BFS 求 fail（补全转移 → 确定性 DFA "Trie 图"）
         → 匹配文本 O(n)，文本指针永不回退
         → 计数口径：
             种类计数：cnt=-1 防重复
             次数统计：打点 + fail 树逆拓扑累加
         → 进阶：bad 状态 + 自动机 DP / 判环 / 矩阵加速 / fail 树+BIT
```
