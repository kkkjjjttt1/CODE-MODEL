# 第 3 章 积性函数与狄利克雷卷积

> 本章是数论题从"会写板子"到"会做题"的分水岭。
> 核心只有两个工具：**狄利克雷卷积**（把求和式代数化）与**整除分块**（把 $O(n)$ 的求和降到 $O(\sqrt n)$）。
> 掌握之后，形如 $\sum\sum f(\gcd(i,j))$ 的一整类题都能用固定套路秒掉。

---

## 3.1 数论函数与积性

**定义 3.1** 定义域为正整数、值域为复数（竞赛中通常是整数）的函数称为**数论函数**。

**定义 3.2（积性）** 若对任意 $\gcd(a,b)=1$ 都有 $f(ab) = f(a)f(b)$，称 $f$ 为**积性函数**。若对**任意** $a, b$（不要求互素）都有 $f(ab)=f(a)f(b)$，称 $f$ 为**完全积性函数**。约定非恒零的积性函数满足 $f(1) = 1$。

**积性函数的关键性质**：若 $n = \prod p_i^{\alpha_i}$，则

$$f(n) = \prod_i f(p_i^{\alpha_i}).$$

因此只要知道 $f$ 在每个素数幂处的取值，就唯一确定了 $f$。**这正是线性筛能筛一切积性函数的原因。**

### 常用数论函数表

| 记号 | 名称 | 定义 | 是否积性 |
|---|---|---|---|
| $\varepsilon$ | 单位函数 | $\varepsilon(n) = [n = 1]$ | 完全积性 |
| $\mathbf{1}$ | 常函数 | $\mathbf{1}(n) = 1$ | 完全积性 |
| $\mathrm{id}$ | 恒等函数 | $\mathrm{id}(n) = n$ | 完全积性 |
| $\mathrm{id}_k$ | 幂函数 | $\mathrm{id}_k(n) = n^k$ | 完全积性 |
| $\varphi$ | 欧拉函数 | $1\sim n$ 中与 $n$ 互素的个数 | 积性 |
| $\mu$ | 莫比乌斯函数 | 见 §3.2 | 积性 |
| $d$ | 约数个数 | $d(n)=\sum_{d\mid n}1$ | 积性 |
| $\sigma$ | 约数和 | $\sigma(n) = \sum_{d \mid n} d$ | 积性 |
| $\sigma_k$ | 约数 $k$ 次幂和 | $\sigma_k(n)=\sum_{d\mid n}d^k$ | 积性 |
| $\lambda$ | 刘维尔函数 | $\lambda(n) = (-1)^{\Omega(n)}$，$\Omega$ 为带重数质因子个数 | 完全积性 |

> **判断积性的通用手法**：写出素数幂处的值。例如 $d(p^\alpha) = \alpha+1$，只与指数有关，故 $d$ 积性。

### 线性筛积性函数的模板化步骤

给定积性函数 $f$，要做到 $O(n)$ 筛出所有 $f(1..n)$，只需回答两个问题：

1. $f(p)$ 等于什么？（$p$ 为素数）
2. 已知 $f(i)$ 且 $p \mid i$（$p$ 是 $i$ 的最小质因子）时，$f(ip)$ 等于什么？通常需要额外维护一个"最小质因子幂"的辅助数组。

以 $\mu$ 和 $\varphi$ 为例：

```cpp
const int MAXN = 1e7 + 5;
int primes[MAXN / 10], pcnt;
bool comp[MAXN];
int mu[MAXN], phi[MAXN];

void sieve_mu_phi(int n) {
    comp[0] = comp[1] = true;
    mu[1] = 1; phi[1] = 1;
    for (int i = 2; i <= n; i++) {
        if (!comp[i]) { primes[pcnt++] = i; mu[i] = -1; phi[i] = i - 1; }
        for (int j = 0; j < pcnt; j++) {
            ll v = (ll)i * primes[j];
            if (v > n) break;
            comp[v] = true;
            if (i % primes[j] == 0) {
                // p 已是 i 的因子：v 含平方因子 => μ(v) = 0
                mu[v] = 0;
                phi[v] = phi[i] * primes[j];
                break;
            }
            mu[v] = -mu[i];
            phi[v] = phi[i] * (primes[j] - 1);
        }
    }
}
```

## 3.2 狄利克雷卷积与莫比乌斯函数

### 定义与基本性质

**定义 3.3（狄利克雷卷积）**

$$(f * g)(n) = \sum_{d \mid n} f(d)\, g\!\left(\frac{n}{d}\right).$$

**性质**（证明都很直接，建议自己写一遍）：

| 性质 | 内容 |
|---|---|
| 交换律 | $f * g = g * f$ |
| 结合律 | $(f*g)*h = f*(g*h)$ |
| 分配律 | $f*(g+h) = f*g + f*h$ |
| 单位元 | $f * \varepsilon = f$ |
| 积性封闭 | $f, g$ 积性 $\Rightarrow f*g$ 积性 |

**积性封闭的证明**：设 $\gcd(m,n)=1$。$mn$ 的每个约数 $d$ 唯一写成 $d = d_1 d_2$（$d_1 \mid m$，$d_2 \mid n$，$\gcd(d_1,d_2)=1$），故

$$(f*g)(mn) = \sum_{d_1\mid m}\sum_{d_2 \mid n} f(d_1d_2)g\!\left(\tfrac{m}{d_1}\tfrac{n}{d_2}\right) = \Big(\sum_{d_1\mid m}f(d_1)g(\tfrac m{d_1})\Big)\Big(\sum_{d_2 \mid n}f(d_2)g(\tfrac n{d_2})\Big). \blacksquare$$

### 莫比乌斯函数

**定义 3.4**

$$\mu(n) = \begin{cases}
1, & n = 1,\\
(-1)^k, & n = p_1p_2\cdots p_k\ (\text{不同素数之积}),\\
0, & n \text{ 含平方因子}.
\end{cases}$$

$\mu$ 是积性函数，且 $\mu(p) = -1$，$\mu(p^k) = 0\ (k \ge 2)$。

**定理 3.4（核心恒等式）**

$$\mu * \mathbf{1} = \varepsilon, \qquad \text{即} \quad \sum_{d \mid n} \mu(d) = [n = 1].$$

**证明**：$n=1$ 时显然。$n > 1$ 时，设 $n$ 有 $k$ 个不同素因子，含平方因子的 $d$ 贡献 $0$，故

$$\sum_{d \mid n}\mu(d) = \sum_{S \subseteq \{1,\dots,k\}} (-1)^{|S|} = (1-1)^k = 0. \blacksquare$$

这个恒等式是"把 $[\,\gcd=1\,]$ 展开成 $\mu$ 求和"的全部依据：

$$[\gcd(i,j) = 1] = \sum_{d \mid \gcd(i,j)} \mu(d) = \sum_{d \mid i,\ d \mid j}\mu(d).$$

### 重要卷积恒等式表

| 恒等式 | 展开形式 | 用途 |
|---|---|---|
| $\mu * \mathbf{1} = \varepsilon$ | $\sum_{d\mid n}\mu(d) = [n=1]$ | 莫反、互素指示 |
| $\varphi * \mathbf{1} = \mathrm{id}$ | $\sum_{d \mid n}\varphi(d) = n$ | 求 $\varphi$ 前缀和（杜教筛） |
| $\mathbf{1} * \mathbf{1} = d$ | $d(n) = \sum_{d\mid n}1$ | 约数个数 |
| $\mathrm{id} * \mathbf{1} = \sigma$ | $\sigma(n) = \sum_{d\mid n} d$ | 约数和 |
| $\mu * \mathrm{id} = \varphi$ | $\varphi(n)=\sum_{d\mid n}\mu(d)\frac{n}{d}$ | 反演求 $\varphi$ |
| $\mathrm{id}_k * \mathbf{1} = \sigma_k$ | $\sigma_k(n)=\sum_{d\mid n}d^k$ | —— |

**证明 $\varphi * \mathbf{1} = \mathrm{id}$**：由 $\sum_{d\mid n}\varphi(d) = n$（第 2 章 §2.6 已证）。
**证明 $\mu * \mathrm{id} = \varphi$**：$\mu * \mathrm{id} = \mu * (\varphi * \mathbf{1}) = \varphi * (\mu * \mathbf{1}) = \varphi * \varepsilon = \varphi$。

### 计算两个函数的卷积

直接按定义枚举倍数，复杂度 $O(n \log n)$：

```cpp
// 计算 h = f * g（f, g 定义在 1..n 上），h 的下标范围也是 1..n
vector<ll> convolution(const vector<ll> &f, const vector<ll> &g, int n) {
    vector<ll> h(n + 1, 0);
    for (int d = 1; d <= n; d++) {
        if (!f[d]) continue;
        for (int m = 1; (ll)d * m <= n; m++)
            h[d * m] += f[d] * g[m];
    }
    return h;
}
```

## 3.3 莫比乌斯反演

### 两种等价形式

**形式一（约数形式）**：若

$$F(n) = \sum_{d \mid n} f(d),$$

则

$$f(n) = \sum_{d \mid n}\mu(d)\,F\!\left(\frac{n}{d}\right) = \sum_{d\mid n}\mu\!\left(\frac n d\right)F(d).$$

**形式二（倍数形式）**：若

$$F(n) = \sum_{n \mid d} f(d),$$

则

$$f(n) = \sum_{n \mid d}\mu\!\left(\frac{d}{n}\right) F(d).$$

### 证明（形式一）

把 $F = f * \mathbf{1}$ 两边同时卷积 $\mu$：

$$\mu * F = \mu * (f * \mathbf{1}) = f * (\mu * \mathbf{1}) = f * \varepsilon = f. \blacksquare$$

**形式二的证明**：令 $d = nk$，则 $F(n) = \sum_{k\ge1} f(nk)$。于是

$$\sum_{n \mid d}\mu\!\left(\frac d n\right)F(d) = \sum_{k \ge 1}\mu(k)\sum_{j\ge1}f(kj) = \sum_{m \ge 1} f(m)\sum_{k \mid m}\mu(k) = \sum_{m\ge1}f(m)[m=n] = f(n). \blacksquare$$

（第三步把 $m = kj$ 重新按 $m$ 归类，因为 $n \mid kj$ 要求 $n \mid m$；这里 $d = nk$，$f(d) = f(nk)$，令 $m = nkj$。）

> **实战中最常用的其实是"直接展开"而不是套反演公式**：
> $$[\gcd(i,j)=1] = \sum_{d \mid \gcd(i,j)}\mu(d)$$
> 把"互素"这个条件变成一层求和，然后交换求和顺序，这是 90% 莫反题的第一步。

### 交换求和顺序的标准手法

$$\sum_{i=1}^{n}\sum_{j=1}^{m}\sum_{d \mid i,\ d\mid j} \mu(d)\, w(i,j)
= \sum_{d=1}^{\min(n,m)}\mu(d)\sum_{i'=1}^{\lfloor n/d\rfloor}\sum_{j'=1}^{\lfloor m/d\rfloor} w(di', dj').$$

只要内层能写成 $g(\lfloor n/d\rfloor)\cdot h(\lfloor m/d\rfloor)$ 的形式，外层就能用整除分块 $O(\sqrt n)$ 计算。

## 3.4 整除分块（数论分块）

### 结论

**定理 3.5** 对固定 $n$，$\left\lfloor \dfrac{n}{i}\right\rfloor$ 在 $i = 1, 2, \dots, n$ 上只取 $O(\sqrt n)$ 个不同值。

**证明**：当 $i \le \sqrt n$ 时只有 $\sqrt n$ 种可能；当 $i > \sqrt n$ 时 $\lfloor n/i\rfloor < \sqrt n$，也只有 $\sqrt n$ 种可能。$\blacksquare$

**关键公式**：使 $\left\lfloor \dfrac{n}{r}\right\rfloor = \left\lfloor \dfrac{n}{l}\right\rfloor$ 成立的**最大** $r$ 为

$$r = \left\lfloor \frac{n}{\lfloor n/l \rfloor} \right\rfloor .$$

**证明**：令 $v = \lfloor n/l\rfloor$。$\lfloor n/i \rfloor = v \iff v \le n/i < v+1 \iff \frac{n}{v+1} < i \le \frac{n}{v}$，故最大整数 $i$ 是 $\lfloor n/v\rfloor$。$\blacksquare$

### 基础模板

```cpp
// 计算 Σ_{i=1}^{n} f(i) * g(⌊n/i⌋) 的通用框架
// 其中 f 的前缀和 pre 已知（pre[i] = Σ_{j=1}^{i} f(j)），g 为任意可调用对象
template <class F>
ll block_sum(ll n, const vector<ll> &pre, F g) {
    ll res = 0;
    for (ll l = 1, r; l <= n; l = r + 1) {
        ll q = n / l;
        r = n / q;                       // 最大的使 ⌊n/r⌋ = q 的 r
        res += (pre[r] - pre[l - 1]) * g(q);
    }
    return res;
}
```

### 二维整除分块

区间端点取两者较小者：

```cpp
// Σ_{i=1}^{min(n,m)} f(i) * ⌊n/i⌋ * ⌊m/i⌋
ll block_sum2(ll n, ll m, const vector<ll> &pre) {
    ll res = 0, lim = min(n, m);
    for (ll l = 1, r; l <= lim; l = r + 1) {
        r = min(n / (n / l), m / (m / l));
        res += (pre[r] - pre[l - 1]) * (n / l) * (m / l);
    }
    return res;
}
```

### 常见应用

| 式子 | 化简结果 | 说明 |
|---|---|---|
| $\sum_{i=1}^n \lfloor n/i \rfloor$ | $\sum_l (r-l+1)\lfloor n/l\rfloor$ | $O(\sqrt n)$ 求约数个数前缀和 |
| $\sum_{i=1}^n d(i)$ | 上式 | 因为 $d(i)$ 的和就是格子数 |
| $\sum_{i=1}^{n}\sum_{j=1}^{m}[\gcd=1]$ | $\sum_d \mu(d)\lfloor n/d\rfloor\lfloor m/d\rfloor$ | 杜教筛/线性筛求 $\mu$ 前缀和 |

**多重分块**：遇到 $\lfloor n/i\rfloor\lfloor m/i\rfloor\lfloor k/i\rfloor$ 时，右端点取三者最小值即可，块数仍是 $O(\sqrt n)$ 级别。

## 3.5 莫比乌斯反演经典套路

### 套路 A：$\sum\sum[\gcd(i,j)=1]$

$$\sum_{i=1}^{n}\sum_{j=1}^{m}[\gcd(i,j)=1] = \sum_{d=1}^{\min(n,m)}\mu(d)\left\lfloor\frac n d\right\rfloor\left\lfloor\frac m d\right\rfloor .$$

```cpp
// muPre 为 μ 的前缀和数组（线性筛或杜教筛得到）
ll count_coprime(ll n, ll m, const vector<int> &muPre) {
    ll res = 0, lim = min(n, m);
    for (ll l = 1, r; l <= lim; l = r + 1) {
        r = min(n / (n / l), m / (m / l));
        res += (ll)(muPre[r] - muPre[l - 1]) * (n / l) * (m / l);
    }
    return res;
}
```

### 套路 B：$\sum\sum \gcd(i,j)$

利用 $\mathrm{id} = \varphi * \mathbf{1}$，即 $k = \sum_{d\mid k}\varphi(d)$：

$$\sum_{i\le n}\sum_{j\le m}\gcd(i,j) = \sum_{d=1}^{\min(n,m)}\varphi(d)\left\lfloor\frac n d\right\rfloor\left\lfloor\frac m d\right\rfloor .$$

**推导**：$\gcd(i,j) = \sum_{d \mid \gcd(i,j)}\varphi(d)$，交换求和得 $\sum_d \varphi(d)\cdot\#\{(i,j): d\mid i, d\mid j\}$。

### 套路 C：$\sum\sum [\gcd(i,j)\in S]$（$S$ 为素数集等）

$$\sum_{i\le n}\sum_{j\le m}[\gcd(i,j)\in S] = \sum_{p \in S}\sum_{d}\mu(d)\left\lfloor\frac{n}{pd}\right\rfloor\left\lfloor\frac{m}{pd}\right\rfloor = \sum_{T=1}^{\min(n,m)}\left(\sum_{p\mid T, p\in S}\mu(T/p)\right)\left\lfloor\frac n T\right\rfloor\left\lfloor\frac m T\right\rfloor .$$

内层 $g(T) = \sum_{p \mid T, p \in S}\mu(T/p)$ 可以用**埃氏筛** $O(n\log\log n)$ 预处理（枚举素数 $p$，对 $p$ 的倍数累加 $\mu(T/p)$），再做整除分块。这就是 [P2257 YY 的 GCD](https://www.luogu.com.cn/problem/P2257) 的标准解法。

```cpp
// 预处理 g(T) = Σ_{p | T, p 为素数} μ(T / p)
vector<ll> precompute_g(int n, const vector<int> &mu, const vector<int> &primes) {
    vector<ll> g(n + 1, 0);
    for (int p : primes)
        for (int t = p; t <= n; t += p) g[t] += mu[t / p];
    for (int i = 1; i <= n; i++) g[i] += g[i - 1];       // 前缀和
    return g;
}
```

### 套路 D：约数个数 $d(ij)$ 的展开

$$d(ij) = \sum_{x \mid i}\sum_{y\mid j}[\gcd(x,y)=1].$$

这一恒等式把 $d(ij)$ 的乘积结构变成互素条件，从而可以套莫反。典型题：[P3327 [SDOI2015] 约数个数和](https://www.luogu.com.cn/problem/P3327)。

**证明思路**：设 $i = \prod p^{\alpha_p}$，$j=\prod p^{\beta_p}$。$d(ij) = \prod(\alpha_p+\beta_p+1)$。对每个 $p$，从 $x \mid i$、$y\mid j$、$\gcd(x,y)=1$ 可唯一表示出 $ij$ 的一个约数：$p$ 的指数为 $x$ 中 $p$ 的指数（取 $0..\alpha_p$）或 $\alpha_p + y$ 中 $p$ 的指数（取 $\alpha_p+1..\alpha_p+\beta_p$），共 $\alpha_p+\beta_p+1$ 种。∎

### 套路 E：$\mathrm{lcm}$ 的转化

$$\operatorname{lcm}(i,j) = \frac{ij}{\gcd(i,j)}.$$

把 $\gcd$ 拆出来后再用套路 B。注意除以 $\gcd$ 在模意义下要用逆元，或者通过变量替换 $i = di'$、$j= dj'$（$\gcd(i',j')=1$）来避免除法。

## 3.6 杜教筛

### 问题与推导

**问题**：求积性函数 $f$ 的前缀和 $S(n) = \sum_{i=1}^{n}f(i)$，其中 $n \le 10^{10}$，无法线性筛。

**推导**：取任意数论函数 $g$（通常取 $g = \mathbf{1}$ 或 $g = \mathrm{id}$），考虑

$$\sum_{i=1}^{n}(f*g)(i) = \sum_{i=1}^{n}\sum_{d\mid i}f(d)g\!\left(\frac i d\right)
= \sum_{d=1}^{n}g(d)\sum_{k=1}^{\lfloor n/d\rfloor}f(k) = \sum_{d=1}^{n}g(d)\,S\!\left(\left\lfloor \frac n d\right\rfloor\right).$$

把 $d=1$ 这一项单独拿出来：

$$g(1)\,S(n) = \sum_{i=1}^{n}(f*g)(i) - \sum_{d=2}^{n}g(d)\,S\!\left(\left\lfloor\frac n d\right\rfloor\right).$$

若 $g(1) = 1$ 且 $f*g$ 的前缀和容易计算（例如 $f*g = \mathrm{id}$ 时前缀和为 $\frac{n(n+1)}2$），右侧就只有 $S$ 在 $\lfloor n/d\rfloor$ 处的值。后者只有 $O(\sqrt n)$ 种取值，递归求解并记忆化即可。

### 复杂度

- 只用记忆化 + 整除分块：$O(n^{3/4})$；
- 线性筛预处理前 $k = n^{2/3}$ 项：$O(n^{2/3})$，这是标准做法；
- 记忆化用 `unordered_map`（会被卡时用手写哈希表）。

**直觉**：低于阈值直接查表；高于阈值的不同 $\lfloor n/d \rfloor$ 只有 $O(\sqrt n)$ 个，每个又要 $O(\sqrt{n})$ 枚举块……但递归层数分摊后总复杂度显著低于朴素估计。

### 常用配对

| 求 $S_f$ | 取 $g$ | $f*g$ | 得到 |
|---|---|---|---|
| $\varphi$ | $\mathbf{1}$ | $\mathrm{id}$ | $S_\varphi(n) = \frac{n(n+1)}{2} - \sum_{d=2}^{n}S_\varphi(\lfloor n/d\rfloor)$ |
| $\mu$ | $\mathbf{1}$ | $\varepsilon$ | $S_\mu(n) = 1 - \sum_{d=2}^{n}S_\mu(\lfloor n/d\rfloor)$ |
| $\mathrm{id}\cdot\varphi$ | $\mathrm{id}$ | $\mathrm{id}_2$ | 见例题 |
| $d$ | $\mu$? 不易 | —— | $d$ 通常用整除分块直接算 |

### 模板：$\varphi$ 与 $\mu$ 的前缀和

```cpp
const int LIM = 5000000;                 // 预处理阈值 n^(2/3)
const ll MOD = 1000000007;

int primes[LIM / 10], pcnt;
bool comp[LIM];
int mu[LIM], phi[LIM];
ll  phiPre[LIM];                          // Σφ mod MOD
int muPre[LIM];                           // Σμ（原始整数）

void init_dusieve(int n = LIM - 1) {
    comp[0] = comp[1] = true;
    mu[1] = 1; phi[1] = 1;
    for (int i = 2; i <= n; i++) {
        if (!comp[i]) { primes[pcnt++] = i; mu[i] = -1; phi[i] = i - 1; }
        for (int j = 0; j < pcnt; j++) {
            ll v = (ll)i * primes[j];
            if (v > n) break;
            comp[v] = true;
            if (i % primes[j] == 0) { mu[v] = 0; phi[v] = phi[i] * primes[j]; break; }
            mu[v] = -mu[i]; phi[v] = phi[i] * (primes[j] - 1);
        }
    }
    for (int i = 1; i <= n; i++) {
        phiPre[i] = (phiPre[i - 1] + phi[i]) % MOD;
        muPre[i] = muPre[i - 1] + mu[i];
    }
}

unordered_map<ll, ll> memPhi;
unordered_map<ll, int> memMu;

// Σ_{i=1}^{n} φ(i) mod MOD
ll S_phi(ll n) {
    if (n < LIM) return phiPre[n];
    auto it = memPhi.find(n);
    if (it != memPhi.end()) return it->second;
    ll res = (ll)((i128)(n % MOD) * ((n + 1) % MOD) % MOD) * ((MOD + 1) / 2) % MOD;
    for (ll l = 2, r; l <= n; l = r + 1) {
        r = n / (n / l);
        res -= (ll)((r - l + 1) % MOD) * S_phi(n / l) % MOD;
        res %= MOD;
    }
    res = (res % MOD + MOD) % MOD;
    return memPhi[n] = res;
}

// Σ_{i=1}^{n} μ(i)
int S_mu(ll n) {
    if (n < LIM) return muPre[n];
    auto it = memMu.find(n);
    if (it != memMu.end()) return it->second;
    ll res = 1;                                     // Σ ε(i) = 1
    for (ll l = 2, r; l <= n; l = r + 1) {
        r = n / (n / l);
        res -= (r - l + 1) * S_mu(n / l);
    }
    return memMu[n] = (int)res;
}
```

> **`n(n+1)/2` 的溢出**：$n \le 10^{11}$ 时 $n(n+1) \approx 10^{22}$ 超出 64 位，必须先取模或用 `__int128`。上面代码先取模再乘 $2^{-1}$（即 `(MOD+1)/2`）。

### 通用杜教筛思路

若要求 $S_f$，只需找到 $g$ 使 $h = f*g$ 的前缀和 $S_h$ 可 $O(1)$ 或 $O(\sqrt n)$ 计算，然后套同一个递推式：

```cpp
// 通用杜教筛框架：把「h = f * g 的前缀和」与「g 的前缀和」作为回调传入
using SumFunc = function<ll(ll)>;

ll du_sieve(ll n, ll LIM, const vector<ll> &pre, const SumFunc &Sh, const SumFunc &Sg,
            unordered_map<ll, ll> &memo) {
    if (n < LIM) return pre[n];                    // 低于阈值查预处理表
    auto it = memo.find(n);
    if (it != memo.end()) return it->second;
    ll res = Sh(n);                                // Σ_{i<=n} (f*g)(i)
    for (ll l = 2, r; l <= n; l = r + 1) {
        r = n / (n / l);
        res -= (Sg(r) - Sg(l - 1)) * du_sieve(n / l, LIM, pre, Sh, Sg, memo);
    }
    return memo[n] = res;
}
```

## 3.7 进阶：min_25 筛的思想

当 $f$ 的前缀和无法用杜教筛处理（例如 $f$ 在素数处取值是 $p$ 的多项式、但 $f * g$ 不好找）时，用 **min_25 筛**。它能在 $O\!\left(\frac{n^{3/4}}{\log n}\right)$ 或 $O(n^{1-\varepsilon})$ 时间内求 $\sum_{i\le n}f(i)$，前提是：

1. $f$ 是积性函数；
2. $f(p)$ 是关于 $p$ 的**低次多项式**（可拆成若干个 $p^k$ 的线性组合）；
3. $f(p^e)$ 能在 $O(1)$ 或 $O(\log n)$ 内计算。

**核心思想（两段式）**：

- **第一段**：把所有"素数处的贡献"按 $\lfloor n/i \rfloor$ 的 $O(\sqrt n)$ 个值分块，用**埃氏筛式的 DP** 求出每个块中"素数的 $f$ 值之和"。
  这等价于计算 $\sum_{p \le x}p^k$（$x$ 取那些块端点），用完全积性函数在素数处取值的 DP 完成；
- **第二段**：递归枚举"最小质因子"并利用积性把合数贡献乘起来，得到 $\sum_{i \le n,\ \mathrm{lpf}(i) > p_j} f(i)$。

**学习建议**：先把杜教筛打熟，再做 [P5325 【模板】Min_25 筛](https://www.luogu.com.cn/problem/P5325) 和 [P4213](https://www.luogu.com.cn/problem/P4213)。min_25 筛的实现细节多、常数不小，属于"性价比不高但必须会"的工具（区域赛中出现频率低于杜教筛与莫反）。

### 通用解题流程

1. **看清是"约数型"还是"倍数型"**。$\sum_{d\mid n}$ 用第一种反演；$\sum_{n \mid d}$ 用第二种。
2. **把条件写成指示函数**，$[\gcd=1]$ 一定展开成 $\sum_{d\mid\gcd}\mu(d)$。
3. **交换求和顺序**，让 $d$ 提到最外层。
4. **化简内层**成 $\lfloor n/d\rfloor$ 的多项式形式。
5. **整除分块**（+ 杜教筛 / 线性筛预处理前缀和）。

## 3.9 易错点清单

| 编号 | 易错点 | 说明 |
|---|---|---|
| 1 | 忘记 $O(\sqrt n)$ 分块的右端点公式 | 必须写 `r = n / (n / l)` |
| 2 | 二维分块用错端点 | `r = min(n/(n/l), m/(m/l))` |
| 3 | 多重分块漏掉某个维度 | 有几个 $\lfloor \cdot /l\rfloor$ 就取几次 min |
| 4 | 杜教筛阈值太小导致超时 | 一般取 $\max(n^{2/3}, 10^6)$，并权衡内存 |
| 5 | `n(n+1)/2` 溢出 | 先取模或用 `__int128` |
| 6 | 杜教筛记忆化用 `map` 太慢 | 用 `unordered_map` 并 `reserve`，或手写哈希 |
| 7 | $\mu$ 前缀和用 `int` 但中途乘法溢出 | 乘法时转 `ll` |
| 8 | 莫反后忘记处理 $\min(n,m)$ 的边界 | 分块上限是 $\min(n,m)$ |
| 9 | 线性筛 $g(T)$ 时枚举方式错 | 枚举素数 $p$，对 $p$ 的倍数累加 |
| 10 | 把 $\sigma$（约数和）与 $d$（约数个数）搞混 | 记牢定义 |
