# 第 4 章 组合数学

> 组合数学是竞赛里"看起来最简单、做起来最容易错"的板块。
> 本章覆盖：二项式系数及其计算（含 Lucas / exLucas）、容斥与反演、经典数列（Catalan / Stirling / Bell / 拆分数）、以及生成函数入门。
> **心法**：把"条件"翻译成"指示函数 / 系数"，剩下的交给代数运算。

## 4.1 计数基础与二项式系数

### 加法原理与乘法原理

- **加法原理**：若方案可分成互不重叠的若干类，总方案数为各类之和；
- **乘法原理**：若方案由若干**独立**步骤组成，总方案数为各步方案数之积。

一切计数都是这两条的组合。**关键在于判断"是否重复计数"**——这是 90% 计数错误（算重/算漏）的根源。

### 排列与组合

从 $n$ 个不同元素中取 $k$ 个：

| 名称 | 公式 | 含义 |
|---|---|---|
| 排列数 $A_n^k$（或 $P(n,k)$） | $\dfrac{n!}{(n-k)!}$ | 取 $k$ 个并**排序** |
| 组合数 $\binom{n}{k}$（或 $C_n^k$） | $\dfrac{n!}{k!(n-k)!}$ | 取 $k$ 个**不排序** |
| 可重排列 | $\dfrac{k!}{c_1!c_2!\cdots c_m!}$ | 多重集的全排列（$c_i$ 为第 $i$ 种元素的重复次数） |
| 可重组合 | $\dbinom{n+k-1}{k}$ | $n$ 种元素取 $k$ 个（隔板法） |

**隔板法**：方程 $x_1 + x_2 + \cdots + x_m = n$（$x_i \ge 1$）的**正整数解**个数为 $\binom{n-1}{m-1}$；非负整数解个数为 $\binom{n+m-1}{m-1}$。

推导：正整数解等价于在 $n$ 个"1"之间的 $n-1$ 个空隙放 $m-1$ 个隔板；非负解令 $y_i = x_i + 1$，则 $y$ 的和为 $n+m$ 且均为正。

### 二项式定理

$$(x+y)^n = \sum_{k=0}^{n}\binom{n}{k}x^k y^{n-k}, \qquad (1+x)^n = \sum_{k=0}^n \binom n k x^k .$$

**多项式定理**：

$$(x_1 + \cdots + x_m)^n = \sum_{k_1 + \cdots + k_m = n}\frac{n!}{k_1!k_2!\cdots k_m!}\,x_1^{k_1}\cdots x_m^{k_m}.$$

### 必须背下来的恒等式

| 恒等式 | 说明 |
|---|---|
| $\binom n k = \binom n {n-k}$ | 对称性 |
| $\binom n k = \binom{n-1}k + \binom{n-1}{k-1}$ | 帕斯卡递推（杨辉三角） |
| $\binom n k = \dfrac n k \binom{n-1}{k-1}$ | 吸收恒等式 |
| $\sum_{k=0}^n \binom n k = 2^n$ | 所有子集 |
| $\sum_{k=0}^n (-1)^k\binom nk = [n=0]$ | 奇偶相消 |
| $\sum_{k} k\binom nk = n2^{n-1}$ | 求导法 |
| $\sum_{k} \binom nk^2 = \binom{2n}{n}$ | 范德蒙德特例 |
| $\sum_{k}\binom mk \binom{n}{r-k} = \binom{m+n}{r}$ | 范德蒙德卷积 |
| $\sum_{i=r}^{n}\binom i r = \binom{n+1}{r+1}$ | 曲棍球棒 |
| $\sum_{k}\binom{r}{k}\binom{s}{n-k}[-1]^k = (-1)^n\binom{s-r}{n}$ | 带符号范德蒙德，非常有用 |

**证明技巧**（比记公式更重要）：

1. **组合意义**：如 $\sum_k \binom nk = 2^n$ 表示"数子集个数"；
2. **生成函数/系数比较**：如范德蒙德卷积来自 $(1+x)^m(1+x)^n = (1+x)^{m+n}$ 两边比较 $x^r$ 系数；
3. **求导/积分**：如 $\sum k\binom nk$ 来自对 $(1+x)^n$ 求导后令 $x=1$；
4. **二项式反演**：见 §4.3。

## 4.2 组合数的计算

### 情形一：$n$ 较小，模数为素数

预处理阶乘与阶乘逆元，$O(1)$ 查询：

```cpp
const int MAXN = 1000005;
ll fac[MAXN], ifac[MAXN], MOD;      // MOD 须为素数，且使用前赋好值

void init_comb(int n) {
    fac[0] = 1;
    for (int i = 1; i <= n; i++) fac[i] = fac[i - 1] * i % MOD;
    ifac[n] = qpow(fac[n], MOD - 2, MOD);
    for (int i = n; i >= 1; i--) ifac[i - 1] = ifac[i] * i % MOD;
}
ll C(int n, int k) {
    if (k < 0 || k > n) return 0;
    return fac[n] * ifac[k] % MOD * ifac[n - k] % MOD;
}
```

**前提**：$\text{MOD}$ 为素数且 $n < \text{MOD}$（否则 $n! \equiv 0$，公式失效）。

### 情形二：模数为素数 $p$，但 $n$ 很大 —— Lucas 定理

**定理 4.1（Lucas）** 设 $p$ 为素数，把 $n, k$ 写成 $p$ 进制

$$n = n_0 + n_1 p + n_2 p^2 + \cdots, \qquad k = k_0 + k_1 p + \cdots,$$

则

$$\binom n k \equiv \prod_i \binom{n_i}{k_i} \pmod p .$$

（约定若某个 $k_i > n_i$，则 $\binom{n_i}{k_i} = 0$，整个乘积为 $0$。）

**证明**：在 $\mathbb{F}_p[x]$ 中，由费马小定理 $(1+x)^p \equiv 1 + x^p$，故

$$(1+x)^n = \prod_i \left((1+x)^{p^i}\right)^{n_i} \equiv \prod_i (1 + x^{p^i})^{n_i} \pmod p .$$

左边 $x^k$ 的系数是 $\binom nk$；右边展开后 $x^k$ 的系数（由 $k$ 的 $p$ 进制展开唯一性）恰为 $\prod_i \binom{n_i}{k_i}$。∎

```cpp
ll C_small(ll n, ll k, ll p);      // 组合数，要求 n, k < p 且 p 为素数（用上面的阶乘法）

// Lucas 定理：C(n, k) mod p，p 为素数（一般 p <= 1e5 才能预处理阶乘）
ll lucas(ll n, ll k, ll p) {
    if (k == 0) return 1 % p;
    return C_small(n % p, k % p, p) * lucas(n / p, k / p, p) % p;
}
```

> 若 $p$ 较大（如 $10^9$）但 $n$ 也很大，$O(p)$ 预处理不可行。此时注意：Lucas 的递归深度是 $O(\log_p n)$，每层只需要算 $\binom{n_i}{k_i}$，其中 $n_i < p$。若 $n_i$ 不大，可以**直接用 $O(n_i)$ 的公式** $\binom{n_i}{k_i} = \prod_{j=1}^{k_i}\frac{n_i-k_i+j}{j}$ 边乘边求逆。

**Kummer 定理**（Lucas 的进位形式）：$\binom n k$ 中素数 $p$ 的指数等于 $n-k$ 与 $k$ 相加时在 $p$ 进制下的**进位次数**。用于判断 $\binom nk$ 是否为 $p$ 的倍数。

### 情形三：模数任意 —— 扩展 Lucas（exLucas）

模数 $m$ 不一定是素数、甚至可能不是素数幂。做法是**拆成素数幂再 CRT 合并**：

1. 分解 $m = \prod p_i^{e_i}$，对每个 $p^k$ 求 $\binom nk \bmod p^k$；
2. 用中国剩余定理合并。

求 $\binom nk \bmod p^k$ 的关键是处理 $p$ 因子：把 $\binom nk = \frac{n!}{k!(n-k)!}$ 中所有的 $p$ 单独提取出来。

设 $n!_p$ 表示 $n!$ 去掉所有因子 $p$ 后的部分，则

$$\binom nk = \frac{n!_p}{k!_p\,(n-k)!_p}\cdot p^{\,c}, \qquad c = v_p(n!) - v_p(k!) - v_p((n-k)!),$$

其中 $v_p(n!) = \sum_{i\ge1}\left\lfloor n/p^i\right\rfloor$（勒让德公式）。

计算 $n!_p \bmod p^k$ 利用**周期性**：在 $1 \sim p^k$ 中，与 $p$ 互素的数的乘积有循环结构，可以整块用快速幂，再递归处理 $\lfloor n/p\rfloor!$。

```cpp
// ============ exLucas：求 C(n, k) mod m，m 任意 ============

// 计算 n! 去掉所有 p 因子后 mod p^k 的值
ll fac_mod(ll n, ll p, ll pk) {
    if (n == 0) return 1 % pk;
    ll res = 1;
    for (ll i = 2; i <= pk; i++)            // 一个完整周期内的乘积
        if (i % p) res = (ll)((i128)res * i % pk);
    res = qpow(res, n / pk, pk);            // 完整周期数
    for (ll i = 2; i <= n % pk; i++)        // 剩余部分
        if (i % p) res = (ll)((i128)res * i % pk);
    return (ll)((i128)res * fac_mod(n / p, p, pk) % pk);
}

// 计算 C(n, m) mod p^k（p 为素数）
ll C_mod_pk(ll n, ll m, ll p, ll pk) {
    if (m < 0 || m > n) return 0;
    ll a = fac_mod(n, p, pk), b = fac_mod(m, p, pk), c = fac_mod(n - m, p, pk);
    ll k = 0;                                // p 的指数（勒让德公式）
    for (ll i = n; i; i /= p) k += i / p;
    for (ll i = m; i; i /= p) k -= i / p;
    for (ll i = n - m; i; i /= p) k -= i / p;
    // a / (b*c) 在模 p^k 下，b、c 均与 p 互素，可用 exgcd 求逆
    ll res = a * inv_exgcd(b % pk, pk) % pk * inv_exgcd(c % pk, pk) % pk;
    res = (ll)((i128)res * qpow(p, k, pk) % pk);
    return res;
}

// 求 C(n, m) mod mod，mod 任意
ll exlucas(ll n, ll m, ll mod) {
    if (m < 0 || m > n) return 0;
    ll res = 0, M = 1, tmp = mod;
    for (ll p = 2; p * p <= tmp; p++) {
        if (tmp % p) continue;
        ll pk = 1;
        while (tmp % p == 0) { tmp /= p; pk *= p; }
        ll r = C_mod_pk(n, m, p, pk);
        // CRT 合并：M 与 pk 互素
        ll inv = inv_exgcd(M % pk, pk);
        ll t = (ll)((i128)((r - res) % pk + pk) % pk * inv % pk);
        res = (ll)(((i128)res + (i128)t * M) % (M * pk));
        M *= pk;
    }
    if (tmp > 1) {                            // 剩下一个大于 sqrt(mod) 的素数因子
        ll p = tmp, pk = tmp;
        ll r = C_mod_pk(n, m, p, pk);
        ll inv = inv_exgcd(M % pk, pk);
        ll t = (ll)((i128)((r - res) % pk + pk) % pk * inv % pk);
        res = (ll)(((i128)res + (i128)t * M) % (M * pk));
        M *= pk;
    }
    return (res % M + M) % M;
}
```

**复杂度**：$O\!\left(p^k \log n\right)$ 级别的预处理（每个周期 $p^k$ 要枚举一遍），适合 $m \le 10^6$ 左右的情形。

> **注意**：$k$ 可能为负吗？不会——$v_p\binom nk \ge 0$ 恒成立，且用勒让德公式计算出来的 $k \ge 0$。

## 4.3 容斥原理与反演

### 容斥原理

**定理 4.2** 设 $A_1, \dots, A_n$ 是有限集合，则

$$\left|\bigcup_{i=1}^n A_i\right| = \sum_{\varnothing \ne S \subseteq [n]} (-1)^{|S|+1}\left|\bigcap_{i \in S} A_i\right| .$$

**证明**：设元素 $x$ 属于其中恰好 $r$ 个集合。右侧对 $x$ 的贡献为

$$\sum_{j=1}^{r}(-1)^{j+1}\binom rj = 1 - (1-1)^r = 1 \quad (r \ge 1),$$

当 $r = 0$ 时贡献为 $0$。故右侧恰好统计了并集中的每个元素一次。∎

**常用形式（"至少一个"→"一个都没有"）**：

$$\#\{\text{至少满足一个性质}\} = \sum_{\varnothing\ne S}(-1)^{|S|+1}\#\{S \text{ 中性质同时满足}\}.$$

**枚举子集的代码框架**：

```cpp
// 容斥枚举：对 n 个条件的所有非空子集，按 |S| 的奇偶加权
template <class F>
ll inclusion_exclusion(int n, F count_satisfying) {
    ll res = 0;
    for (int S = 1; S < (1 << n); S++) {
        int bits = __builtin_popcount(S);
        ll c = count_satisfying(S);          // 同时满足 S 中所有条件的方案数
        res += (bits & 1) ? c : -c;
    }
    return res;
}
```

### 错排问题（容斥的经典应用）

$n$ 个元素的排列中，没有元素在原来位置的排列数：

$$D_n = n!\sum_{k=0}^{n}\frac{(-1)^k}{k!} = \sum_{k=0}^n (-1)^k\binom nk (n-k)! .$$

**推导**：设 $A_i$ 为"第 $i$ 个元素在原位"的排列集合，$|A_{i_1}\cap\cdots\cap A_{i_k}| = (n-k)!$。由容斥

$$D_n = \sum_{k=0}^{n}(-1)^k\binom nk (n-k)! .$$

**递推**：$D_n = (n-1)(D_{n-1} + D_{n-2})$，$D_0 = 1,\ D_1 = 0$。

```cpp
// 错排数（可用递推，O(n)）
vector<ll> derangement(int n, ll MOD) {
    vector<ll> D(n + 1);
    D[0] = 1 % MOD;
    if (n >= 1) D[1] = 0;
    for (int i = 2; i <= n; i++) D[i] = (i - 1) % MOD * ((D[i - 1] + D[i - 2]) % MOD) % MOD;
    return D;
}
```

### 二项式反演

**形式一（"至少/恰好"型）**

$$f(n) = \sum_{k=0}^{n}\binom nk g(k) \iff g(n) = \sum_{k=0}^{n}(-1)^{n-k}\binom nk f(k).$$

**形式二（"恰好 $k$ 个"型，最常用）**

$$f(k) = \sum_{i=k}^{n}\binom i k g(i) \iff g(k) = \sum_{i=k}^{n}(-1)^{i-k}\binom i k f(i).$$

其中通常 $f(k)$ 表示"钦定 $k$ 个位置满足条件"的方案数（便于计算），$g(k)$ 表示"恰好 $k$ 个满足"的方案数。

**证明（形式二）**：把 $f(k) = \sum_i \binom ik g(i)$ 代入右侧：

$$\sum_{i\ge k}(-1)^{i-k}\binom ik \sum_{j \ge i}\binom ji g(j) = \sum_{j\ge k}g(j)\sum_{i=k}^{j}(-1)^{i-k}\binom ik\binom ji .$$

用 $\binom ik \binom ji = \binom jk\binom{j-k}{i-k}$，内层变成 $\binom jk \sum_{i}(-1)^{i-k}\binom{j-k}{i-k} = \binom jk [j = k]$，故结果 $= g(k)$。∎

```cpp
// 二项式反演（形式二）：已知 f[0..n]，求 g[0..n]
vector<ll> binomial_inversion(const vector<ll> &f, int n, ll MOD) {
    vector<ll> g(n + 1, 0);
    for (int k = 0; k <= n; k++) {
        ll s = 0;
        for (int i = k; i <= n; i++) {
            ll term = C(i, k) * f[i] % MOD;
            s = ((i - k) & 1) ? (s - term + MOD) % MOD : (s + term) % MOD;
        }
        g[k] = s;
    }
    return g;
}
```

### 子集反演（集合幂级数视角）

$$F(S) = \sum_{T \subseteq S} f(T) \iff f(S) = \sum_{T\subseteq S}(-1)^{|S|-|T|}F(T).$$

这是"按位"版本的莫比乌斯反演，与第 3 章的约数形式完全平行。**FWT（快速沃尔什变换）**就是它的 $O(n2^n)$ 快速实现。

### min-max 容斥

$$\max(S) = \sum_{\varnothing \ne T \subseteq S}(-1)^{|T|-1}\min(T), \qquad
k\text{-th}\max(S) = \sum_{\substack{T\subseteq S\\|T|\ge k}}(-1)^{|T|-k}\binom{|T|-1}{k-1}\min(T).$$

**用途**：当"最小值"比"最大值"好求时（例如"至少有一个元素满足条件"很容易算，"全部满足"很难算），用 min-max 容斥把 max 换成 min。典型场景：状压 DP + 期望（"集齐所有元素所需时间的期望"）。

## 4.4 经典数列

### 卡特兰数（Catalan）

$$C_n = \frac{1}{n+1}\binom{2n}{n} = \binom{2n}{n} - \binom{2n}{n+1}, \qquad C_0 = 1.$$

**递推**：$C_n = \sum_{i=0}^{n-1}C_iC_{n-1-i}$。

**生成函数**：$C(x) = \dfrac{1-\sqrt{1-4x}}{2x}$（推导见 §4.5）。

**典型计数对象**（都等于 $C_n$）：

- $n$ 对括号的合法括号序列数；
- $n$ 个节点的不同形态二叉树个数；
- $n+1$ 边形的三角剖分数；
- $n$ 个元素的出栈序列数（栈的合法出入栈序列）；
- 从 $(0,0)$ 走到 $(n,n)$ 且不越过对角线 $y=x$ 的路径数；
- 不含 $231$ 模式的排列数。

**记忆法**：看到"某种结构递归地分成左右两部分"+"不能越过边界"，基本就是卡特兰。

```cpp
// 卡特兰数 C[0..n]
vector<ll> catalan(int n, ll MOD) {
    vector<ll> C(n + 1), fac(2 * n + 2), ifac(2 * n + 2);
    fac[0] = 1;
    for (int i = 1; i <= 2 * n + 1; i++) fac[i] = fac[i - 1] * i % MOD;
    ifac[2 * n + 1] = qpow(fac[2 * n + 1], MOD - 2, MOD);
    for (int i = 2 * n + 1; i >= 1; i--) ifac[i - 1] = ifac[i] * i % MOD;
    auto comb = [&](int a, int b) -> ll {
        if (b < 0 || b > a) return 0;
        return fac[a] * ifac[b] % MOD * ifac[a - b] % MOD;
    };
    for (int i = 0; i <= n; i++) C[i] = comb(2 * i, i) * qpow(i + 1, MOD - 2, MOD) % MOD;
    return C;
}
```

### 第二类斯特林数

**定义**：$S(n,k) = \begin{Bmatrix} n \\ k \end{Bmatrix}$ 表示把 $n$ 个**不同**元素分成 $k$ 个**非空无序**集合的方案数。

**递推**（考虑第 $n$ 个元素的归属）：

$$S(n,k) = S(n-1,k-1) + k\,S(n-1,k).$$

**显式公式**（容斥：先允许空盒）：

$$S(n,k) = \frac{1}{k!}\sum_{i=0}^{k}(-1)^i\binom ki (k-i)^n .$$

**与幂的关系**（下降幂展开）：

$$x^n = \sum_{k=0}^{n}S(n,k)\,x^{\underline{k}}, \qquad x^{\underline{k}} = x(x-1)\cdots(x-k+1).$$

**EGF**：$\sum_{n \ge k}S(n,k)\dfrac{x^n}{n!} = \dfrac{(e^x-1)^k}{k!}$。

```cpp
// 第二类斯特林数表 O(nk) 递推
vector<vector<ll>> stirling2(int n, ll MOD) {
    vector<vector<ll>> S(n + 1, vector<ll>(n + 1, 0));
    S[0][0] = 1 % MOD;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= i; j++)
            S[i][j] = (S[i - 1][j - 1] + j % MOD * S[i - 1][j]) % MOD;
    return S;
}

// 某一行（固定 n，所有 k）的 O(n log n) 卷积做法：
// S(n, k) = Σ_i [(-1)^i / i!] * [(k-i)^n / (k-i)!]
// 令 A[i] = (-1)^i * ifac[i]，B[i] = i^n * ifac[i]，则 S(n,k) = (A * B)[k]
// 具体实现：用第 7 章的 NTT 做一次长度为 n+1 的卷积即可
```

### 第一类斯特林数

**定义**：$\begin{bmatrix} n \\ k \end{bmatrix}$ 表示把 $n$ 个不同元素排成 $k$ 个**环**（循环排列）的方案数。

**递推**：$\begin{bmatrix} n \\ k\end{bmatrix} = \begin{bmatrix} n-1 \\ k-1\end{bmatrix} + (n-1)\begin{bmatrix} n-1 \\ k\end{bmatrix}$。

**生成函数（上升幂）**：$x^{\overline n} = x(x+1)\cdots(x+n-1) = \sum_k \begin{bmatrix} n \\ k\end{bmatrix}x^k$。

> **记忆**：第二类用**下降幂**展开普通幂，第一类用**上升幂**；两者的递推系数分别是 $k$ 和 $n-1$。

### 贝尔数（Bell）

$B_n = \sum_{k=0}^{n}S(n,k)$，即 $n$ 个元素的划分方案总数。递推 $B_{n+1} = \sum_{k}\binom nk B_k$。EGF：$e^{e^x-1}$。

### 整数拆分（划分数）

**定义**：$p(n,k)$ 表示把 $n$ 拆成 $k$ 个正整数之和的方案数（顺序不计）；$p(n) = \sum_k p(n,k)$。

- 递推：$p(n,k) = p(n-1,k-1) + p(n-k,k)$（是否含 1）；
- 五边形数定理：$p(n) = \sum_{k\ge1}(-1)^{k-1}\left[p\!\left(n - \tfrac{k(3k-1)}2\right) + p\!\left(n-\tfrac{k(3k+1)}2\right)\right]$，可 $O(n\sqrt n)$ 求全部 $p(0..n)$；
- $O(n\sqrt n)$ 的另一做法：完全背包（物品为 $1,2,\dots,n$，每个可用无限次，且**按物品从小到大枚举**以避免重复计数）。

```cpp
// 整数拆分数 p[0..n]，O(n sqrt n)：五边形数定理
vector<ll> partition_numbers(int n, ll MOD) {
    vector<ll> p(n + 1, 0);
    p[0] = 1 % MOD;
    for (int i = 1; i <= n; i++) {
        ll s = 0;
        for (int k = 1; ; k++) {
            ll g1 = (ll)k * (3 * k - 1) / 2;
            ll g2 = (ll)k * (3 * k + 1) / 2;
            if (g1 > i && g2 > i) break;
            ll sign = (k & 1) ? 1 : -1;
            if (g1 <= i) s += sign * p[i - g1];
            if (g2 <= i) s += sign * p[i - g2];
        }
        p[i] = ((s % MOD) + MOD) % MOD;
    }
    return p;
}
```

| 数列 | 公式 | 场景 |
|---|---|---|
| 错排 $D_n$ | $n!\sum_{k\le n}(-1)^k/k!$ | 全错位排列 |
| 贝尔 $B_n$ | $\sum_k S(n,k)$ | 集合划分 |

## 4.5 生成函数入门

### 普通生成函数（OGF）

**定义**：序列 $a_0, a_1, a_2, \dots$ 的 OGF 为 $A(x) = \sum_{n\ge0}a_nx^n$。

**核心规则**：

| 运算 | 对应 |
|---|---|
| $A(x) + B(x)$ | 序列逐项相加 |
| $A(x)\cdot B(x)$ | 卷积 $c_n = \sum_{i+j=n}a_ib_j$ —— **这就是"组合"** |
| $x^k A(x)$ | 序列右移 $k$ 位 |
| $A(x)/(1-x)$ | 前缀和 |

**常用封闭形式**：

$$\sum_{n\ge0}x^n = \frac1{1-x}, \qquad \sum_{n\ge0}a^nx^n = \frac1{1-ax}, \qquad \sum_{n\ge0}\binom{n+k-1}{k-1}x^n = \frac1{(1-x)^k}.$$

**关键思想**：把"每种选择的方案数"写成 $x^{\text{权值}}$ 的幂级数，则**乘法**自动完成"各种选择之间的组合"。

**例（隔板法）**：$x_1 + \cdots + x_m = n$ 的非负解数，等于 $\left(\frac1{1-x}\right)^m = \frac1{(1-x)^m}$ 中 $x^n$ 的系数，即 $\binom{n+m-1}{m-1}$。

### 用 OGF 解递推

**例：斐波那契** $f_0=0, f_1=1, f_n = f_{n-1}+f_{n-2}$。

设 $F(x) = \sum f_nx^n$，则

$$F(x) = x + xF(x) + x^2F(x) \implies F(x) = \frac{x}{1-x-x^2}.$$

**一般方法**：把递推式两边乘 $x^n$ 求和，把 $F(x)$ 解出来，再部分分式展开求出通项（斐波那契通项即 Binet 公式）。

### 卡特兰数的 OGF 推导

设 $C(x) = \sum C_nx^n$。由递推 $C_n = \sum_{i+j=n-1}C_iC_j$ 得

$$C(x) = 1 + xC(x)^2 \implies xC^2 - C + 1 = 0 \implies C(x) = \frac{1-\sqrt{1-4x}}{2x}.$$

（取减号是为了让 $x\to0$ 时极限为 $1$。）再用广义二项式定理展开 $\sqrt{1-4x}$ 即得 $C_n = \frac{1}{n+1}\binom{2n}n$。

### 指数生成函数（EGF）

**定义**：$\hat A(x) = \sum_{n\ge0}a_n\dfrac{x^n}{n!}$。

**为什么需要它？** OGF 的乘法处理"无标号"的组合（元素不可区分时直接相加），而 EGF 的乘法处理**有标号**的组合：若 $A$ 描述"一个集合结构"，$B$ 描述"另一个集合结构"，则 $\hat A\hat B$ 描述"把标号分成两部分分别放置"。

$$\left(\hat A \hat B\right)_n = \sum_{k}\binom nk a_k b_{n-k} \quad\Longleftrightarrow\quad \text{EGF 乘积系数} = \sum_k \frac{a_k}{k!}\cdot\frac{b_{n-k}}{(n-k)!}.$$

**常用 EGF**：

| 序列 | EGF |
|---|---|
| $a_n = 1$ | $e^x$ |
| $a_n = c^n$ | $e^{cx}$ |
| 排列数 $n!$ | $\dfrac1{1-x}$ |
| 第二类斯特林（固定 $k$） | $\dfrac{(e^x-1)^k}{k!}$ |
| 贝尔数 | $e^{e^x-1}$ |
| $\dfrac{1}{n}$（$n\ge1$） | $-\ln(1-x)$ |

**exp 组合定理**：若 $\hat A$ 描述"连通（不可分）结构"，则 $e^{\hat A}$ 描述"由若干连通结构组成的集合（集合的集合）"。这是 EGF 最有力的工具。

例：$\hat A = e^x - 1$ 描述"非空集合"，则 $e^{e^x-1}$ 描述"集合的集合"，即贝尔数。

## 4.7 例题与套路

### 套路 1："恰好" → "至少" → 二项式反演

> **题目特征**：求"恰好 $k$ 个满足条件"的方案数。

**方法**：先算 $f(k) = $ "钦定 $k$ 个满足（其余任意）"，它通常容易算；再反演出 $g(k) = $ "恰好 $k$ 个满足"：

$$g(k) = \sum_{i=k}^{n}(-1)^{i-k}\binom ik f(i).$$

### 套路 2：容斥处理"都不发生"

> **题目特征**：求满足若干限制且"每个限制都不能违反"的方案数。

**方法**：总方案数减去"至少违反一个"的方案数，用容斥枚举违反集合。

### 套路 3：整除/LCM 类组合计数

> **题目特征**：计数与 $\gcd$、$\mathrm{lcm}$、整除有关。

**方法**：先做莫比乌斯反演（第 3 章），再套组合数。

### 套路 4：生成函数建模

> **题目特征**：给定每种元素的选取规则（个数限制/奇偶限制），求总量为 $n$ 的方案数。

**方法**：每种元素写出 $x^{k}$ 的和式（有限和或等比级数），相乘得到 $\prod$，提取 $x^n$ 系数。若乘积形式复杂，用 EGF + 多项式 exp（第 7 章）加速。

### 套路 5：Catalan 型识别

> **题目特征**：递归结构 + 边界不能越过 + 分成左右两部分。

**方法**：写出 $C_n = \sum C_iC_{n-i-1}$，直接套卡特兰公式；若带参数则可能需要广义 Catalan 或 DP。

### 套路 6：斯特林数拆幂

> **题目特征**：出现 $i^k$（$k$ 小 $n$ 大）的求和。

**方法**：$i^k = \sum_j S(k,j)\,i^{\underline j}$，把幂变成下降幂，可与组合数结合化简（例如 $\sum_i \binom ni i^k$）。

## 4.8 易错点清单

| 编号 | 易错点 | 说明 |
|---|---|---|
| 1 | `C(n,k)` 中 `k > n` 未返回 0 | 必须判 |
| 2 | 模数非素数却用费马小定理求阶乘逆元 | 用 exLucas 或分解模数 |
| 3 | $n \ge$ MOD 时仍用阶乘法 | $n! \equiv 0$，必须用 Lucas |
| 4 | Lucas 中 $k_i > n_i$ 时忘记返回 0 | 组合数定义为 0 |
| 5 | exLucas 忘记处理 $\sqrt{\text{mod}}$ 之后的剩余素因子 | 循环结束后要补一次 |
| 6 | 二项式反演符号写反 | 记住 $(-1)^{i-k}$ 的指数是**下标差** |
| 7 | 容斥枚举从 $S=0$ 开始 | 应从 $S=1$ 开始，且注意符号 |
| 8 | 卡特兰数忘了 $\div(n+1)$，或在模数下写成整除 | 用逆元 |
| 9 | 整数拆分用背包时物品循环顺序错 | 完全背包按物品递增，保证不重复计数 |
| 10 | 第一类/第二类斯特林数混淆 | 第二类：$S(n-1,k-1) + kS(n-1,k)$；第一类：$c(n-1,k-1)+(n-1)c(n-1,k)$ |
| 11 | EGF 与 OGF 混用 | 有标号对象用 EGF，无标号用 OGF |
| 12 | 组合数溢出 | $10^9 \times 10^9$ 用 `__int128` |
