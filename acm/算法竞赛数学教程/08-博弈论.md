# 第 8 章 博弈论

> 算法竞赛里的博弈论 90% 是**公平组合游戏（ICG）**，而 ICG 的核心只有一个定理：**SG 定理**。
> 它把"两个玩家轮流操作"的游戏化归为"一堆数的异或和"，于是博弈问题变成了位运算问题。

---

## 8.1 基本概念

### 公平组合游戏（Impartial Combinatorial Game, ICG）

满足以下条件的游戏：

1. 两名玩家轮流行动；
2. 双方**可用的操作集合完全相同**（与是谁的回合无关）；
3. 游戏状态有限，且不存在无限循环（或规定循环为平局）；
4. **无法行动者判负**（normal play convention）。

### 必胜态与必败态

- **P 态（Previous player wins / 必败态）**：轮到当前玩家时，无论怎么走都会输；
- **N 态（Next player wins / 必胜态）**：轮到当前玩家时存在一步走到 P 态。

**判定规则**（递归定义）：

- 终止状态（无法移动）是 **P 态**；
- 若某状态存在后继是 P 态，则它是 **N 态**；
- 若某状态的所有后继都是 N 态，则它是 **P 态**。

**这一定义是全部博弈论题的基础**。任何 ICG 题都可以先尝试"找出 P 态的规律"。

## 8.2 几个经典小博弈

### 巴什博弈（Bash）

**规则**：$n$ 个石子，每次取 $1 \sim m$ 个，取走最后一个者胜。

**结论**：先手必败 $\iff n \equiv 0 \pmod{m+1}$。

**证明**：若 $n \equiv 0 \pmod{m+1}$，无论先手取 $k$ 个（$1\le k\le m$），后手取 $m+1-k$ 个，两人一轮共取 $m+1$ 个，$n$ 始终是 $m+1$ 的倍数，最终后手取走最后一个。反之若 $n \not\equiv 0$，先手先取 $n \bmod (m+1)$ 个，把局面变成 $m+1$ 的倍数，此后镜像对手即可。∎

```cpp
// 巴什博弈：n 个石子每次取 1..m 个，取完者胜。返回 true 表示先手必胜
bool bash(ll n, ll m) { return n % (m + 1) != 0; }
```

### 威佐夫博弈（Wythoff）

**规则**：两堆石子 $(a, b)$，每次可以：从一堆中取任意多个，或从两堆中取相同多个。取完最后一个者胜。

**结论**：先手必败 $\iff a = \lfloor k\varphi \rfloor$ 且 $b = \lfloor k\varphi^2\rfloor = a + k$，其中 $k = b - a \ge 0$，$\varphi = \frac{1+\sqrt5}{2}$。

**这些 P 态**（"奇异局势"）是：$(0,0), (1,2), (3,5), (4,7), (6,10), (8,13), (9,15),\dots$ —— 恰好是 Beatty 序列对。

```cpp
// 威佐夫博弈：判断 (a, b) 是否先手必败
bool wythoff_lose(ll a, ll b) {
    if (a > b) swap(a, b);
    ll k = b - a;
    ll t = (ll)(k * (1.0 + sqrt(5.0)) / 2.0);        // 浮点算 ⌊kφ⌋，k 很大时需高精度
    return a == t;
}
```

> **精度提醒**：$k$ 很大（$\ge 10^{15}$）时浮点算 $\lfloor k\varphi\rfloor$ 会出错。稳妥做法是用整数迭代或二分高精度计算 $\lfloor k\varphi\rfloor$：
> 因为 $\lfloor k\varphi\rfloor = \lfloor k\cdot\frac{1+\sqrt5}{2}\rfloor$，可以用 `sqrtl`（`long double`）并做一次校正：
> `if (t * t <= k * k + ... )` 之类的校验，或直接用 `(ll)((k * (1.0L + sqrtl(5.0L)) / 2.0L))` 再微调。

### 斐波那契博弈

**规则**：$n$ 个石子，先手第一次可取任意多个（至少 1 个），此后每次最多取上一次取的石子数的两倍，取完者胜。

**结论**：先手必败 $\iff n$ 是斐波那契数（$1, 2, 3, 5, 8, 13, \dots$）。

### 对称策略

当局面关于某条对称轴/中心对称时，后手可以"镜像"先手的操作。**这是许多博弈题的关键，也是 P 态分析的有力工具。**

## 8.3 Nim 游戏与 SG 定理

### Nim 游戏

**规则**：$n$ 堆石子，每堆 $a_i$ 个；每次可以选一堆取走任意正数目的石子；取走最后一个者胜。

**定理 8.1（Nim）** 先手必败 $\iff a_1 \oplus a_2 \oplus \cdots \oplus a_n = 0$。

**证明**：

- 若异或和 $S = 0$：任意操作把某堆从 $a$ 变成 $a' < a$，则新的异或和 $S' = S \oplus a \oplus a' = a\oplus a' \ne 0$（因为 $a \ne a'$）。所以从 $S=0$ 只能走到 $S\ne0$；
- 若 $S \ne 0$：取 $S$ 的最高位 $k$，必有某堆 $a_i$ 的第 $k$ 位为 $1$。令 $a_i' = a_i \oplus S < a_i$，把第 $i$ 堆减到 $a_i'$，则新异或和为 $0$。故从 $S\ne0$ 总能走到 $S=0$；
- 终止状态（全 $0$）满足 $S=0$。

综合三条即得：$S=0$ 是 P 态。∎

```cpp
// Nim：返回 true 表示先手必胜
bool nim(const vector<ll> &a) {
    ll x = 0;
    for (ll v : a) x ^= v;
    return x != 0;
}
```

### SG 函数（Sprague-Grundy）

**定义 8.2（mex）** $\operatorname{mex}(S) = \min\{x \ge 0: x \notin S\}$（不在集合中的最小非负整数）。

**定义 8.3（SG 值）** 对一个 ICG 的状态 $x$：

$$\operatorname{SG}(x) = \operatorname{mex}\bigl\{\operatorname{SG}(y) : y \text{ 是 } x \text{ 的后继}\bigr\}.$$

终止状态的 SG 值为 $0$。

**定理 8.4（SG 定理）** 若游戏 $G$ 由若干**独立子游戏** $G_1,\dots,G_k$ 组成（"分裂和"，每回合只能在一个子游戏里操作），则

$$\operatorname{SG}(G) = \operatorname{SG}(G_1)\oplus\operatorname{SG}(G_2)\oplus\cdots\oplus\operatorname{SG}(G_k).$$

且**当前局面先手必胜 $\iff$ 总 SG 值 $\ne 0$**。

**证明要点**：

1. 先证单个游戏：状态 $x$ 是 P 态 $\iff \operatorname{SG}(x) = 0$。
   - 若 $\operatorname{SG}(x)=0$，则没有后继的 SG 为 $0$（mex 不含 $0$），即所有后继都是 N 态，故 $x$ 是 P 态；
   - 若 $\operatorname{SG}(x)=g\ne0$，由 mex 定义存在后继的 SG 为 $0$，故 $x$ 是 N 态。
2. 再证分裂和：设 $S = \bigoplus_i \operatorname{SG}(G_i)$。
   - 若 $S = 0$，任取一个子游戏操作，其 SG 由 $g$ 变为 $g'\ne g$（因为后继 SG 不等于自身），于是 $S' \ne 0$；
   - 若 $S \ne 0$，取 $S$ 的最高位 $k$，找到某个 $g_i$ 第 $k$ 位为 $1$，令 $g_i' = g_i\oplus S < g_i$。由 mex 定义，$g_i'<g_i$ 意味着子游戏 $i$ 存在 SG 值为 $g_i'$ 的后继（因为 $g_i$ 是后继 SG 集合的 mex，小于 $g_i$ 的值都必须在集合中）。走到该后继后 $S'=0$；
   - 终止局面 $S = 0$。

   与 Nim 的证明完全同构。∎

**Nim 与 SG 的关系**：Nim 的每个堆（大小 $a$）就是一个子游戏，其 SG 值恰为 $a$（因为可以走到任意更小的值，mex 为 $a$）。所以 SG 定理是 Nim 定理的推广。

### SG 的计算

```cpp
// 通用 SG 计算（记忆化 + 时间戳数组避免清空）
// nxt[x] 为状态 x 的所有后继状态，状态编号 0..N-1
vector<int> sg_val, seen_stamp;
int stamp = 0;

int sg(int x, const vector<vector<int>> &nxt) {
    if (sg_val[x] >= 0) return sg_val[x];
    for (int y : nxt[x]) sg(x, nxt);              // 先算后继
    ++stamp;
    for (int y : nxt[x])
        if (sg_val[y] < (int)seen_stamp.size()) seen_stamp[sg_val[y]] = stamp;
    int g = 0;
    while (g < (int)seen_stamp.size() && seen_stamp[g] == stamp) ++g;
    return sg_val[x] = g;
}

// 例：一堆石子 n，每次可取 a_1..a_k 个（取完者胜）—— SG(n) = mex{SG(n-a_i)}
int sg_take(int n, const vector<int> &take) {
    vector<int> g(n + 1, 0);
    for (int i = 1; i <= n; i++) {
        vector<char> mark(n + 2, 0);
        for (int t : take) if (i - t >= 0) mark[g[i - t]] = 1;
        int m = 0;
        while (mark[m]) ++m;
        g[i] = m;
    }
    return g[n];
}
```

> **状态数很大的时候**：SG 值往往呈周期性。**打表找规律**是竞赛中处理 SG 的常规操作（例如"每次可取 $a_1..a_k$ 个"的 SG 值序列通常是周期序列，周期与 $a$ 有关）。

## 8.4 Nim 的常见变形

### 反 Nim（Anti-Nim）

**规则**：与 Nim 相同，但**取走最后一个石子的人输**。

**定理 8.5（SJ 定理）** 先手必胜当且仅当：

- 所有堆的大小都 $\le 1$ 且异或和为 $0$（即 1 的个数为偶数）；**或**
- 存在堆大小 $> 1$ 且异或和不为 $0$。

```cpp
// 反 Nim：返回 true 表示先手必胜
bool anti_nim(const vector<ll> &a) {
    ll x = 0, cnt1 = 0, big = 0;
    for (ll v : a) {
        x ^= v;
        if (v == 1) ++cnt1;
        if (v > 1) ++big;
    }
    if (big == 0) return (cnt1 % 2 == 0);      // 全是 0/1：偶数个 1 时先手胜
    return x != 0;
}
```

**直觉**：全是 $1$ 时每人只能取一个，"取最后一个者输"意味着谁面对最后一个谁输，所以奇偶性决定胜负。存在 $>1$ 的堆时，玩家有足够自由度调整奇偶，结论与普通 Nim 相同。

### 阶梯博弈（Staircase Nim）

**规则**：石子放在若干级台阶上（第 $0$ 级为地面），每次从某一级（$i \ge 1$）取任意多个石子放到第 $i-1$ 级。取走最后一个石子者胜（石子落到地面即视为离开游戏）。

**结论**：只看**奇数级**台阶上石子数的异或和，非 $0$ 则先手胜。

**为什么？** 偶数级的石子是"废子"：若对手移动偶数级的石子到奇数级，你可以把同样数量的石子从该奇数级再移到偶数级，形成配对。因此胜负由奇数级决定，而奇数级的操作等价于普通 Nim。

```cpp
// 阶梯 Nim：stair[i] 为第 i 级台阶上的石子数（i >= 1，第 0 级为地面）
bool staircase_nim(const vector<ll> &stair) {
    ll x = 0;
    for (size_t i = 1; i <= stair.size(); i += 2) x ^= stair[i - 1];  // 奇数级
    return x != 0;
}
```

### 翻硬币游戏（Turning Turtles 类）

**规则**：一排硬币，有的正面朝上。每次操作按规则翻转若干枚硬币（通常要求被翻的硬币中**最右边**的那枚从正面翻到反面）。翻不了者输。

**关键结论**：整个游戏的 SG 值 = **每个正面朝上的硬币单独作为一个游戏时的 SG 值的异或**。

也就是说，设 $g(i)$ 为"只有第 $i$ 枚硬币是正面"时的 SG 值，则

$$\operatorname{SG}(\text{局面}) = \bigoplus_{i \in \text{正面集合}} g(i).$$

**证明思路**：一次操作等价于"选择最右的正面硬币 $i$ 变为反面，并任意翻转其左边的若干硬币"，这在分裂和意义下正好是把 $g(i)$ 换成若干个 $g(j)$（$j<i$）的异或。∎

$g(i)$ 由具体规则递推（往往有简洁形式，例如"每次可翻任意连续三枚且最右为正面"对应 $g(i) = i$）。

**实现**：按规则对每个位置 $i$ 递推 $g(i) = \operatorname{mex}\{\text{一次操作可达状态的 SG}\}$，再用上面的异或公式。

### Moore's Nimₖ

**规则**：$n$ 堆石子，每次可以同时从**至多 $k$ 堆**中各取任意多个（至少取 1 个）。

**结论**：把每堆石子数写成二进制，逐位统计 1 的个数，全部模 $(k+1)$ 后都为 $0$ 则先手必败（即"$k+1$ 进制下的错位 Nim"）。$k=1$ 时退化为普通 Nim。

### 其他经典模型

| 模型 | 结论 |
|---|---|
| **Green Hackenbush**（删边游戏） | 树上/图上的删边游戏，SG 值有 Colon Principle 等规则 |
| **树上删边** | 每条边的 SG 值递归计算：$g(\text{节点}) = \bigoplus_{\text{子边}}(\text{子边 SG}+1)$ |
| **二分图博弈** | 棋子在二分图上移动且不能重复经过点，先手必胜 $\iff$ 起点被**每个**最大匹配覆盖 |
| **有向图游戏** | 直接按定义算 SG |

## 8.5 二分图博弈（最大匹配判定）

**规则**：给定二分图 $G=(X,Y,E)$ 与起点 $s$，两人轮流把棋子沿边移动，不能移动到访问过的点，无法移动者输。

**结论**：先手必胜 $\iff$ 起点 $s$ 属于**所有**最大匹配（即删除 $s$ 后最大匹配大小会减小）。

**做法**：

1. 求一个最大匹配 $M$；
2. 若 $s$ 未被 $M$ 匹配 → 先手必败；
3. 否则，判断是否存在一个最大匹配不覆盖 $s$：从 $s$ 沿"非匹配边 → 匹配边 → 非匹配边 → …"的交替路走，若能达到某个未匹配点，则存在不覆盖 $s$ 的最大匹配 $\Longrightarrow$ 先手必败；否则先手必胜。

## 8.6 例题与套路

### 套路 1：直接套 Nim

> **特征**：多个独立的"堆"，每步操作减少某个堆的值。

**方法**：异或和判零。注意"堆"未必是石子——可以是任意可减少的量（如字符串长度、坐标差值）。

### 套路 2：分裂游戏 → SG

> **特征**：一次操作会把一个游戏拆成若干个更小的游戏（如"把一堆石子分成两堆"）。

**方法**：设 $\operatorname{SG}(n) = \operatorname{mex}\{\operatorname{SG}(a)\oplus\operatorname{SG}(n-a)\}$，打表找规律（这类题往往规律很漂亮，如 $\operatorname{SG}(n)$ 与 $n$ 的奇偶或二进制有关）。

### 套路 3：SG 打表找规律

> **特征**：状态转移复杂但一维（如"每次可取若干种数量"）。

**方法**：写暴力算前 $200\sim1000$ 项 SG 值，找周期，再对大范围套用。**这是最实用的技巧**。

### 套路 4：反 Nim / 阶梯 Nim 识别

> **特征**："取最后一个输" → 反 Nim；"石子从高往低移动，最后落到地面" → 阶梯 Nim。

**方法**：先判断能否归约成标准 Nim。**问自己：这个游戏等价于哪一堆的 Nim？**

### 套路 5：对称策略

> **特征**：局面有对称性（序列回文、图对称、两堆相等）。

**方法**：后手镜像。常用于证明某个局面是 P 态。

### 套路 6：非公平 / 有向图博弈

> **特征**：双方操作集合不同（partizan game）。

**方法**：不能用 SG（SG 只适用于 ICG）。改用"必胜/必败态 DP"或超现实数理论（竞赛中极少见），或者把它转成 ICG。

## 8.7 易错点清单

| 编号 | 易错点 | 说明 |
|---|---|---|
| 1 | 把"取最后一个输"当普通 Nim | 反 Nim 结论完全不同 |
| 2 | 阶梯 Nim 搞错级数编号 | 只看**奇数级**（从地面往上数第 1、3、5… 级） |
| 3 | SG 用 `set` 导致常数过大 | 用时间戳数组 |
| 4 | SG 状态数太大 | 打表找周期 |
| 5 | 分裂游戏忘记把两个子游戏 SG 异或 | $\operatorname{SG}(n) = \operatorname{mex}\{\operatorname{SG}(a)\oplus\operatorname{SG}(n-a)\}$ |
| 6 | 威佐夫博弈浮点精度不足 | $k$ 大时用 `long double` 并校正 |
| 7 | 忘记检查终止状态 | 终止态 SG = 0 |
| 8 | 对 partizan game 用 SG 定理 | SG 只适用于双方操作集合相同的游戏 |
| 9 | 二分图博弈忘记"属于所有最大匹配"的条件 | 不是"被最大匹配覆盖" |
| 10 | 平局（循环）未处理 | ICG 要求无环；有环时需专门分析 |
