# 第 2 章 同余理论

> 本章是数论题的"主战场"。逆元、CRT、欧拉定理、原根、BSGS、二次剩余，是竞赛中出现频率最高的一批工具。
> 学习顺序建议：逆元 → exCRT → 欧拉定理/降幂 → BSGS → 原根 → 二次剩余（Cipolla）。

---

## 2.1 同余的定义与基本性质

**定义 2.1** 设 $m \in \mathbb{Z}_{>0}$。若 $m \mid (a - b)$，则称 $a$ 与 $b$ 关于模 $m$ 同余，记作

$$a \equiv b \pmod m .$$

同余是 $\mathbb{Z}$ 上的等价关系（自反、对称、传递），把整数分成 $m$ 个**同余类** $\overline{0}, \overline{1}, \dots, \overline{m-1}$，记作 $\mathbb{Z}_m$。

### 基本运算律

若 $a \equiv b$、$c \equiv d \pmod m$，则

$$a + c \equiv b + d, \qquad a - c \equiv b - d, \qquad ac \equiv bd \pmod m .$$

**但除法不成立**：$6 \equiv 2 \pmod 4$ 不能说 $3 \equiv 1 \pmod 4$（这里确实成立，但 $2 \equiv 6 \pmod 4 \Rightarrow 1 \equiv 3$? 反例：$2 \cdot 3 \equiv 2 \cdot 1 \pmod 4$，但 $3 \not\equiv 1$）。

**正确的"约分"法则**：

$$ac \equiv bc \pmod m \iff a \equiv b \pmod{\frac{m}{\gcd(c, m)}} .$$

这条非常有用：**当 $\gcd(c,m)=1$ 时可以直接约分**，也就是"除以 $c$"="乘以 $c$ 的逆元"。

### 幂的周期性

若 $a \equiv b \pmod m$，则 $a^k \equiv b^k \pmod m$ 对一切 $k \ge 0$ 成立。但**注意**：不能由 $a \equiv b$ 推出 $a^k \equiv b^k$ 时把指数也模掉——指数的模需要欧拉定理（§2.6）。

## 2.2 完全剩余系与简化剩余系

- **完全剩余系**：$m$ 个整数，两两不同余，即 $\mathbb{Z}_m$ 的一个代表元集合；
- **简化剩余系（缩系）**：与 $m$ 互素的那些同余类的代表元集合，共 $\varphi(m)$ 个。

**关键性质**：若 $a_1, \dots, a_{\varphi(m)}$ 是模 $m$ 的缩系，且 $\gcd(c, m) = 1$，则 $ca_1, \dots, ca_{\varphi(m)}$ **仍是缩系**。

证明：映射 $x \mapsto cx$ 是缩系到自身的双射（$\gcd(cx,m)=1$；且 $cx \equiv cy \Rightarrow c(x-y)\equiv 0 \Rightarrow m \mid (x-y)$，因为 $\gcd(c,m)=1$）。这是欧拉定理证明的核心。

## 2.3 乘法逆元

**定义 2.3** 若 $ax \equiv 1 \pmod m$，则称 $x$ 为 $a$ 模 $m$ 的**逆元**，记作 $a^{-1}$。

**定理 2.3** $a$ 模 $m$ 的逆元存在 $\iff \gcd(a, m) = 1$；存在时在 $\mathbb{Z}_m$ 中唯一。

证明：$ax \equiv 1 \pmod m \iff \exists y,\ ax + my = 1$，由裴蜀定理即得充要条件。唯一性：若 $x, x'$ 都是逆元，则 $a(x - x') \equiv 0$，由 $\gcd(a,m)=1$ 得 $m \mid (x-x')$。

### 三种求法

```cpp
// 法一：费马小定理 a^(p-2) ≡ a^{-1} (mod p)。仅当 mod 为素数（更一般地 gcd(a,mod)=1 且已知 ord）
ll inv_fermat(ll a, ll mod) { return qpow(a, mod - 2, mod); }

// 法二：exgcd，适用于任意 mod，只要 gcd(a, mod) = 1
ll inv_exgcd(ll a, ll mod) {
    ll x, y;
    ll d = exgcd(a, mod, x, y);
    if (d != 1) return -1;                  // 逆元不存在
    return (x % mod + mod) % mod;
}

// 法三：线性递推求出 1..n 的所有逆元，O(n)。要求 mod 为素数且 n < mod
vector<ll> inv_table(int n, ll mod) {
    vector<ll> inv(n + 1);
    inv[1] = 1;
    for (int i = 2; i <= n; i++)
        inv[i] = (mod - mod / i) * inv[mod % i] % mod;
    return inv;
}
```

**法三的推导**：设 $m = qi + r$（$q = \lfloor m/i \rfloor$，$r = m \bmod i$），则 $qi + r \equiv 0 \pmod m$。两边乘 $i^{-1} r^{-1}$：

$$q \cdot r^{-1} + i^{-1} \equiv 0 \implies i^{-1} \equiv -q \cdot (m \bmod i)^{-1} \pmod m .$$

因为 $r = m \bmod i < i$，可以递推。代码里写 `(mod - mod / i)` 是为了避免负数取模。

### 阶乘逆元的批量递推

求组合数时常需要 $1!, 2!, \dots, n!$ 的逆元。用**倒推法**只需一次快速幂：

```cpp
vector<ll> fac, ifac;

// 预处理阶乘与阶乘逆元，要求 mod 为素数且 n < mod
void init_fact(int n, ll mod) {
    fac.assign(n + 1, 1); ifac.assign(n + 1, 1);
    for (int i = 1; i <= n; i++) fac[i] = fac[i - 1] * i % mod;
    ifac[n] = qpow(fac[n], mod - 2, mod);
    for (int i = n; i >= 1; i--) ifac[i - 1] = ifac[i] * i % mod;
}

ll comb(int a, int b, ll mod) {         // C(a, b) mod prime
    if (b < 0 || b > a) return 0;
    return fac[a] * ifac[b] % mod * ifac[a - b] % mod;
}
```

> **竞赛常识**：写组合数预处理时一律用 `long long` 存数组，乘法前不需要额外转型（因为 `ll * ll` 不会溢出，值都 $< 2^{31}$）。但如果模数 $\ge 2^{31}$，必须用 `__int128`。

### 逆元的常见用途

- 模意义下的**除法**：$\dfrac{a}{b} \equiv a \cdot b^{-1}$；
- 概率期望题中求 $\frac{p}{q}$ 的模值；
- 公式里的分数（如 $\dfrac{n(n+1)}{2}$）在模意义下的计算；
- 线性递推中消去系数。

## 2.4 线性同余方程

**问题**：解 $ax \equiv c \pmod m$。

**定理 2.4** 令 $d = \gcd(a, m)$。方程有解 $\iff d \mid c$；有解时在 $\mathbb{Z}_m$ 中恰有 $d$ 个解，它们构成模 $\frac{m}{d}$ 的一个同余类：

$$x \equiv x_0 + k \cdot \frac{m}{d} \pmod m, \qquad k = 0, 1, \dots, d-1 .$$

**推导**：$ax \equiv c \pmod m \iff \exists y,\ ax + my = c$。由裴蜀定理，有解 $\iff d \mid c$。此时两边同除 $d$：$\frac{a}{d}x + \frac{m}{d}y = \frac{c}{d}$，且 $\gcd(\frac a d, \frac m d) = 1$，故 $x \equiv x_0 \pmod{m/d}$，在模 $m$ 下有 $d$ 个解。

```cpp
// 解 ax ≡ c (mod m)。返回最小非负解；无解返回 -1。
// 通解为 x0 + k * (m / d)，k ∈ Z
ll solve_linear_congruence(ll a, ll c, ll m) {
    a = ((a % m) + m) % m;
    c = ((c % m) + m) % m;
    ll x, y;
    ll d = exgcd(a, m, x, y);
    if (c % d) return -1;                   // 无解
    ll step = m / d;
    x = (ll)((i128)(x % step + step) % step * ((c / d) % step) % step);
    return x;                               // 最小非负解
}
```

> **应用**：解 $ax \equiv c$ 等价于求 $\frac{c}{a}$ 在模 $m$ 下的值（当 $\gcd(a,m) \nmid c$ 时"分数"无意义）。
> 这在"要给 $\frac{a}{b}$ 取模但 $b$ 与模数不互素"的题目里是关键：可能需要把模数拆成 $p^k$ 分别解，再用 CRT 合并。

## 2.5 中国剩余定理与扩展中国剩余定理

### CRT（模数两两互素）

**定理 2.5** 设 $m_1, \dots, m_k$ 两两互素，则同余方程组

$$x \equiv r_1 \pmod{m_1},\quad \dots,\quad x \equiv r_k \pmod{m_k}$$

在模 $M = \prod m_i$ 下**有唯一解**。

**构造性证明**：令 $M_i = M / m_i$，因 $m_i$ 两两互素，$\gcd(M_i, m_i) = 1$，故 $M_i$ 在模 $m_i$ 下有逆元 $t_i$。取

$$x = \sum_{i=1}^{k} r_i M_i t_i \pmod M .$$

验证：对任意 $j$，当 $i \ne j$ 时 $m_j \mid M_i$，故求和式中除第 $j$ 项外全部 $\equiv 0 \pmod{m_j}$；而第 $j$ 项 $r_j M_j t_j \equiv r_j \cdot 1 = r_j \pmod{m_j}$。∎

```cpp
// CRT：要求 m 两两互素。返回最小非负解，结果模 M = prod(m)
ll crt(const vector<ll> &r, const vector<ll> &m) {
    ll M = 1;
    for (ll x : m) M *= x;
    ll ans = 0;
    for (size_t i = 0; i < r.size(); i++) {
        ll Mi = M / m[i];
        ll inv = inv_exgcd(Mi % m[i], m[i]);
        ll t = (ll)((i128)(((r[i] % m[i]) + m[i]) % m[i]) * Mi % M * inv % M);
        ans = (ans + t) % M;
    }
    return ans;
}
```

### exCRT（模数不必互素）

竞赛中**更常用**的是"逐个合并"的版本，不需要互素条件。核心是合并两个方程：

$$\begin{cases} x \equiv r_1 \pmod{m_1} \\ x \equiv r_2 \pmod{m_2} \end{cases}
\iff x = r_1 + m_1 t,\quad m_1 t \equiv r_2 - r_1 \pmod{m_2}$$

这是一个形如 $at \equiv c \pmod{m_2}$ 的线性同余方程（其中 $a = m_1$，$c = r_2 - r_1$）。有解条件是

$$d = \gcd(m_1, m_2) \mid (r_2 - r_1),$$

此时解为 $t \equiv t_0 \pmod{m_2/d}$，代回得

$$x \equiv r_1 + m_1 t_0 \pmod{\operatorname{lcm}(m_1, m_2)} .$$

于是两个方程合并成一个，模数变成 $\operatorname{lcm}$。

```cpp
// 合并 x ≡ r1 (mod m1) 与 x ≡ r2 (mod m2)，成功返回 true 并更新 (r1, m1)
bool merge(ll &r1, ll &m1, ll r2, ll m2) {
    ll x, y;
    ll d = exgcd(m1, m2, x, y);
    ll diff = r2 - r1;
    if (diff % d) return false;
    ll step = m2 / d;
    ll t = (ll)((i128)((x % step + step) % step) * (((diff / d) % step + step) % step) % step);
    ll lcm = m1 / d * m2;                       // 新的模数
    r1 = (ll)(((i128)r1 + (i128)t * m1) % lcm);
    m1 = lcm;
    r1 = (r1 % m1 + m1) % m1;
    return true;
}

// 解一般方程组；无解返回 false
bool excrt(vector<ll> r, vector<ll> m, ll &x, ll &mod) {
    ll R = r[0], M = m[0];
    for (size_t i = 1; i < r.size(); i++)
        if (!merge(R, M, ((r[i] % m[i]) + m[i]) % m[i], m[i])) return false;
    x = (R % M + M) % M; mod = M;
    return true;
}
```

**溢出安全**：`t < step = m2/d`，故 `t * m1 < m2 * m1 / d = lcm`，加上 $r_1 < m_1$ 后仍在 $[0, \text{lcm} + m_1)$ 内。只要 $\text{lcm} \le 9\times10^{18}$ 就不会溢出——但如果题目给的模数乘积可达 $10^{36}$，就必须用 `__int128` 甚至手写高精度。

> **实战提示**：`__int128` 能表示约 $1.7 \times 10^{38}$，处理 $\text{lcm} \le 10^{36}$ 的 exCRT 是够用的。

## 2.6 欧拉函数与欧拉定理

### 欧拉函数

**定义 2.6** $\varphi(n)$ 为 $1 \sim n$ 中与 $n$ 互素的整数个数（约定 $\varphi(1) = 1$）。

**计算公式**：由唯一分解 $n = \prod p_i^{\alpha_i}$，

$$\varphi(n) = n \prod_{i=1}^{k}\left(1 - \frac{1}{p_i}\right) = \prod_i p_i^{\alpha_i - 1}(p_i - 1).$$

**证明**：用容斥。先减去所有被某个 $p_i$ 整除的数的个数，再加回被两个整除的……等价地，也可以直接用中国剩余定理：$\mathbb{Z}_n \cong \prod \mathbb{Z}_{p_i^{\alpha_i}}$（环同构），故 $\varphi(n) = \prod \varphi(p_i^{\alpha_i})$。而 $\varphi(p^\alpha) = p^\alpha - p^{\alpha-1}$（$1 \sim p^\alpha$ 中与 $p$ 不互素的恰是 $p$ 的倍数，共 $p^{\alpha-1}$ 个）。∎

**常用性质**：

| 性质 | 说明 |
|---|---|
| $\sum_{d \mid n} \varphi(d) = n$ | 极为常用，等价于 $\varphi = \mu * \mathrm{id}$ |
| $\varphi(p) = p - 1$ | $p$ 为素数 |
| $\varphi(p^k) = p^{k-1}(p-1)$ | 素数幂 |
| $\gcd(a,b)=1 \Rightarrow \varphi(ab) = \varphi(a)\varphi(b)$ | 积性 |
| $n \ge 3 \Rightarrow \varphi(n)$ 为偶数 | 逆元成对出现 |
| $a \mid b \Rightarrow \varphi(a) \mid \varphi(b)$ | 由公式直接看出 |

**$\sum_{d\mid n}\varphi(d) = n$ 的证明**：按 $\gcd(i, n)$ 对 $1 \le i \le n$ 分类。$\gcd(i,n) = d$ 的 $i$ 有 $\varphi(n/d)$ 个，于是 $n = \sum_{d \mid n}\varphi(n/d) = \sum_{d\mid n}\varphi(d)$。∎

### 单点求 $\varphi$

```cpp
ll euler_phi(ll n) {
    ll res = n;
    for (ll i = 2; i <= n / i; i++) {
        if (n % i == 0) {
            res = res / i * (i - 1);          // 先除后乘，避免溢出
            while (n % i == 0) n /= i;
        }
    }
    if (n > 1) res = res / n * (n - 1);
    return res;
}
```

复杂度 $O(\sqrt n)$。批量求 $\varphi(1..n)$ 用第 1 章的线性筛。

### 欧拉定理

**定理 2.6（Euler）** 若 $\gcd(a, m) = 1$，则

$$a^{\varphi(m)} \equiv 1 \pmod m .$$

**证明**：设 $a_1, \dots, a_{\varphi(m)}$ 是模 $m$ 的缩系。因 $\gcd(a,m)=1$，$aa_1, \dots, aa_{\varphi(m)}$ 也是缩系，故两组乘积同余：

$$\prod_{i}(a a_i) \equiv \prod_i a_i \pmod m \implies a^{\varphi(m)} \prod_i a_i \equiv \prod_i a_i \pmod m .$$

由于 $\gcd(\prod a_i, m) = 1$，两边约分得 $a^{\varphi(m)} \equiv 1 \pmod m$。∎

**推论（费马小定理）**：$p$ 为素数、$p \nmid a$ 时，$a^{p-1} \equiv 1 \pmod p$，即 $a^p \equiv a \pmod p$（后者对一切 $a$ 成立，包括 $p \mid a$）。

## 2.7 欧拉降幂（指数循环节）

当指数 $b$ 巨大（$10^{100}$ 甚至更高）时，用**广义欧拉定理**降幂：

$$a^b \bmod m = \begin{cases}
a^{b \bmod \varphi(m)}, & \gcd(a, m) = 1,\\[4pt]
a^{b}, & b < \varphi(m),\\[4pt]
a^{\,b \bmod \varphi(m) \,+\, \varphi(m)}, & b \ge \varphi(m).
\end{cases}$$

**说明**：

- 第二条是针对 $\gcd(a,m) \ne 1$ 的情况。此时 $b$ 一旦 $\ge \varphi(m)$，就进入循环节，可以直接加 $\varphi(m)$ 补偿；
- 为什么加一个 $\varphi(m)$ 就够？直观理解：$\gcd(a,m)>1$ 时 $a^b$ 中多余的质因子会被"吸收"进 $m$，一旦 $b \ge \log_2 m$（远小于 $\varphi(m)$），幂的模值就只剩下"指数模 $\varphi$"的部分。加 $\varphi(m)$ 的作用是保证指数不小于那个阈值；
- **竞赛中的实用结论**：若你能保证 $b \ge \varphi(m)$，就用 $b \bmod \varphi(m) + \varphi(m)$；否则老老实实直接求 $a^b$。

```cpp
// 求 a^b mod m，其中 b 以十进制字符串给出（可以巨大）
ll power_big(ll a, const string &b, ll m) {
    ll phi = euler_phi(m);
    ll e = 0; bool big = false;
    for (char c : b) {
        e = e * 10 + (c - '0');
        if (e >= phi) { big = true; e %= phi; }
    }
    if (big) e += phi;                  // 补偿 φ(m)
    return qpow(a, e, m);
}
```

> **注意**：这里 if $b < \varphi(m)$ 就不补偿，对应公式第二、三条。`big` 标记必须"一旦超过就置位"，因为后续取模会丢失信息。

**递归指数**（如 $a^{a^{a^{\cdots}}}$）的做法：从最内层开始，每一层都用上式。

## 2.8 阶与原根

### 阶

**定义 2.8** 设 $\gcd(a, m) = 1$，称使 $a^k \equiv 1 \pmod m$ 成立的**最小正整数** $k$ 为 $a$ 模 $m$ 的**阶**，记作 $\operatorname{ord}_m(a)$。

**定理 2.8** 记 $d = \operatorname{ord}_m(a)$。则

$$a^k \equiv 1 \pmod m \iff d \mid k .$$

特别地 $d \mid \varphi(m)$（因为 $a^{\varphi(m)} \equiv 1$）。

**证明**：设 $k = qd + r$（$0 \le r < d$），则 $a^k = (a^d)^q a^r \equiv a^r$，故 $a^k \equiv 1 \iff a^r \equiv 1$。由 $d$ 的最小性，只能 $r = 0$，即 $d \mid k$。∎

**常用推论**：$a^u \equiv a^v \pmod m \iff u \equiv v \pmod{\operatorname{ord}_m(a)}$。

### 原根

**定义** 若 $\operatorname{ord}_m(g) = \varphi(m)$，则称 $g$ 是模 $m$ 的**原根**（primitive root）。

**定理 2.9（原根存在性）** 模 $m$ 的原根存在 $\iff m \in \{1, 2, 4, p^k, 2p^k\}$，其中 $p$ 是奇素数、$k \ge 1$。

**原根个数**：若存在原根，则原根共有 $\varphi(\varphi(m))$ 个。所有原根为 $g^t$，其中 $\gcd(t, \varphi(m)) = 1$。

**判定定理**：设 $\varphi(m) = \prod q_i^{e_i}$，则 $g$ 是原根 $\iff$ 对每个 $q_i$ 都有

$$g^{\varphi(m)/q_i} \not\equiv 1 \pmod m .$$

**证明思路**：若 $g$ 不是原根，设 $d = \operatorname{ord}(g) \mid \varphi(m)$ 且 $d < \varphi(m)$，则 $\varphi(m)/d$ 有某个质因子 $q$，于是 $\frac{\varphi(m)}{q}$ 是 $d$ 的倍数，从而 $g^{\varphi(m)/q} \equiv 1$，即判定条件失败。反之显然。∎

```cpp
// 求模素数 p 的最小原根（p 为素数）
ll primitive_root(ll p) {
    if (p == 2) return 1;
    ll phi = p - 1, t = phi;
    vector<ll> fac;
    for (ll i = 2; i <= t / i; i++)
        if (t % i == 0) { fac.push_back(i); while (t % i == 0) t /= i; }
    if (t > 1) fac.push_back(t);
    for (ll g = 2; g < p; g++) {
        bool ok = true;
        for (ll q : fac) if (qpow(g, phi / q, p) == 1) { ok = false; break; }
        if (ok) return g;
    }
    return -1;
}
```

**为什么原根重要？** 它把模 $p$ 的**乘法群**变成了**加法群**：$\mathbb{Z}_p^* = \{g^0, g^1, \dots, g^{p-2}\}$，于是幂运算变成指数加法、乘法变成指数相加。这正是：

- **离散对数（BSGS）**的理论基础；
- **NTT 的原理**：$998244353 = 119 \cdot 2^{23} + 1$ 的原根为 $3$；
- 一些计数题中"把乘法条件转成加法条件"的技巧。

**最小原根的量级**：可以证明最小原根是 $O(p^{1/4+\varepsilon})$ 的，实际枚举很快（对 $10^{18}$ 内的素数，最小原根通常小于 $1000$）。

## 2.9 离散对数：BSGS 与 exBSGS

**问题（Discrete Logarithm）**：给定 $\gcd(a, p) = 1$，求最小的 $x \ge 0$ 使

$$a^x \equiv b \pmod p .$$

### Baby-Step Giant-Step

把 $x$ 写成 $x = im - j$（$0 \le j < m$，$1 \le i \le m$，$m = \lceil \sqrt p \rceil$），则

$$a^{im - j} \equiv b \iff a^{im} \equiv b\, a^{j} \pmod p .$$

于是：

1. **Baby step**：枚举 $j = 0 \dots m-1$，把 $b a^j$ 存入哈希表（值 → 最小的 $j$）；
2. **Giant step**：枚举 $i = 1 \dots m$，计算 $a^{im}$，查表；若有匹配的 $j$，则 $x = im - j$。

复杂度 $O(\sqrt p)$ 时间、$O(\sqrt p)$ 空间（用哈希表）。**注意**：$i$ 从小到大枚举保证首次找到的 $x$ 最小——但更严格地说，先更新哈希表让 $j$ 取最小值，再让 $i$ 递增，得到的 $im - j$ 随着 $i$ 递增而增大（因为 $j$ 固定），所以第一个匹配就是最小解。

```cpp
ll rng_seed();   // 见第 1 章 mt19937_64

// 求 a^x ≡ b (mod p) 的最小非负解；无解返回 -1。要求 gcd(a, p) = 1
ll bsgs(ll a, ll b, ll p) {
    a %= p; b %= p;
    if (b == 1 % p) return 0;                 // a^0 = 1
    ll m = (ll)sqrt((long double)p);
    while (m * m < p) m++;                    // 防止 sqrt 下取整误差
    unordered_map<ll, ll> mp;
    mp.reserve(m * 2);
    ll cur = b;
    for (ll j = 0; j < m; j++) {
        if (!mp.count(cur)) mp[cur] = j;      // 保留最小的 j
        cur = (ll)((i128)cur * a % p);
    }
    ll am = qpow(a, m, p), now = 1;
    for (ll i = 1; i <= m; i++) {
        now = (ll)((i128)now * am % p);
        auto it = mp.find(now);
        if (it != mp.end()) {
            ll x = i * m - it->second;
            if (x >= 0) return x;
        }
    }
    return -1;
}
```

> **被卡常数的风险**：`unordered_map` 可能被精心构造的数据卡成 $O(n)$。稳妥做法是手写哈希表（开放寻址 + 固定容量），见 §2.12 的模板。
> 另一种优化：把 $a$ 换成 $a^{-1}$，做成 $a^{-im} \cdot b = a^j$ 的形式，避免求逆元（当 $p$ 不是素数时更友好）。

### 扩展 BSGS（$a$ 与 $p$ 不互素）

当 $\gcd(a, p) \ne 1$ 时，可以不断提取公因子把问题化归为互素情形。

设要求 $a^x \equiv b \pmod p$。每次令 $g = \gcd(a, p)$：

- 若 $g \nmid b$，则无解（因为 $a^x$ 与 $p$ 的公因子必为 $g$ 的幂，$b$ 必须能被整除）；
- 否则把方程两边同除以 $g$，并记录累积的系数 $d$，重复直到 $\gcd(a, p) = 1$。

设做了 $k$ 次，得到 $a^{x-k} \cdot d \equiv b' \pmod{p'}$，其中 $\gcd(a, p') = 1$，于是化为 BSGS 求解 $a^{y} \equiv b' \cdot d^{-1} \pmod{p'}$，答案 $x = y + k$。

```cpp
// 求 a^x ≡ b (mod p) 的最小非负解；无解返回 -1。p 任意
ll exbsgs(ll a, ll b, ll p) {
    a %= p; b %= p;
    if (p == 1) return 0;
    if (b == 1 % p) return 0;
    ll k = 0, d = 1;
    while (true) {
        ll g = gcd(a, p);
        if (g == 1) break;
        if (b % g) return -1;
        b /= g; p /= g; ++k;
        d = (ll)((i128)d * (a / g) % p);
        if (d == b) return k;                 // 提前命中
    }
    // 解 a^y ≡ b * d^{-1} (mod p)
    ll invd = inv_exgcd(d % p, p);
    if (invd < 0) return -1;
    ll y = bsgs(a, (ll)((i128)b * invd % p), p);
    return y < 0 ? -1 : y + k;
}
```

> 注意 `bsgs` 中要求 $\gcd(a, p) = 1$，而这里已经保证；`a` 在循环中保持不变，`p` 被缩小。

## 2.10 二次剩余与 Cipolla 算法

**问题**：给定奇素数 $p$ 与 $n \not\equiv 0$，求 $x$ 使 $x^2 \equiv n \pmod p$。

### 勒让德符号与欧拉判别法

**定义**（勒让德符号）

$$\left(\frac{n}{p}\right) = \begin{cases} 0, & p \mid n,\\ 1, & n \text{ 是模 } p \text{ 的二次剩余},\\ -1, & n \text{ 是非二次剩余}. \end{cases}$$

**定理 2.10（欧拉判别法）** 对奇素数 $p$ 与 $p \nmid n$，

$$\left(\frac{n}{p}\right) \equiv n^{\frac{p-1}{2}} \pmod p .$$

**证明**：若 $n \equiv x^2$，则 $n^{(p-1)/2} \equiv x^{p-1} \equiv 1$。反之设 $n^{(p-1)/2} \equiv 1$，取原根 $g$ 使 $n = g^t$，则 $g^{t(p-1)/2} \equiv 1$，由阶的性质 $(p-1) \mid \frac{t(p-1)}{2}$，即 $t$ 为偶数，于是 $x = g^{t/2}$ 就是平方根。若 $n$ 是非剩余，则 $n^{(p-1)/2}$ 是 $x^2 \equiv 1$ 的非 $1$ 解，只能 $\equiv -1$。∎

**结论**：模奇素数 $p$ 下，二次剩余恰有 $\frac{p-1}{2}$ 个，与 $\frac{p-1}{2}$ 个非剩余各占一半。

### Cipolla 算法

**核心想法**：在 $\mathbb{F}_p$ 中 $n$ 可能没有平方根，但我们可以在**二次扩域** $\mathbb{F}_{p^2} = \mathbb{F}_p[\omega]/(\omega^2 - w)$ 中找。取 $a$ 使 $w = a^2 - n$ 是**非二次剩余**（随机试，期望 2 次即可），则

$$(a + \omega)^{p+1} = (a+\omega)^p (a+\omega) = (a - \omega)(a+\omega) = a^2 - \omega^2 = a^2 - w = n .$$

其中用到 $(a+\omega)^p = a^p + \omega^p = a + \omega^p$（Frobenius 自同构）以及 $\omega^p = \omega \cdot (\omega^2)^{(p-1)/2} = \omega \cdot w^{(p-1)/2} = -\omega$（因为 $w$ 是非剩余）。

因此

$$x = (a + \omega)^{\frac{p+1}{2}}$$

就是解，且其 $\omega$ 分量必为 $0$（因为 $x^2 = n \in \mathbb{F}_p$）。

```cpp
mt19937_64 rng(chrono::steady_clock::now().time_since_epoch().count());

namespace cipolla {
    ll p, w;                                  // 扩域元素 a + b*ω，其中 ω^2 ≡ w
    struct Fp2 { ll a, b; };
    Fp2 mul(Fp2 x, Fp2 y) {
        return { (ll)(((i128)x.a * y.a + (i128)x.b * y.b % p * w) % p),
                 (ll)(((i128)x.a * y.b + (i128)x.b * y.a) % p) };
    }
    Fp2 pw(Fp2 x, ll e) {
        Fp2 r{1, 0};
        for (; e; e >>= 1, x = mul(x, x)) if (e & 1) r = mul(r, x);
        return r;
    }
    // 求 x^2 ≡ n (mod P) 的一个解（另一个解为 P - x）；无解返回 -1。要求 P 为奇素数
    ll solve(ll n, ll P) {
        p = P; n = ((n % p) + p) % p;
        if (n == 0) return 0;
        if (qpow(n, (p - 1) / 2, p) != 1) return -1;      // 欧拉判别法：非剩余
        ll a;
        do {
            a = (ll)(rng() % p);
            w = (ll)((((i128)a * a - n) % p + p) % p);
        } while (w == 0 || qpow(w, (p - 1) / 2, p) != p - 1);   // 要求 w 为非剩余
        return pw(Fp2{a % p, 1}, (p + 1) / 2).a;
    }
}
```

**复杂度**：期望 $O(\log^2 p)$（几次快速幂）。

**应用**：

- 求解二次同余方程 $x^2 \equiv n \pmod p$；
- 求解 $ax^2 + bx + c \equiv 0$ 时先配方（需 $2$ 可逆，即 $p$ 为奇素数）；
- 某些"二次扩域"构造（如计算 $i = \sqrt{-1}$）配合原根使用。

## 2.11 其他常用定理

### 威尔逊定理

**定理 2.11** $p$ 为素数 $\iff (p-1)! \equiv -1 \pmod p$。

**证明**（必要性）：$p = 2$ 显然。对奇素数 $p$，$\mathbb{F}_p^*$ 中的元素两两配对成逆元对 $\{x, x^{-1}\}$，只有 $x = \pm 1$ 时 $x = x^{-1}$。故 $(p-1)!$ 中除 $1$ 与 $-1$ 外所有元素成对消去，得 $(p-1)! \equiv -1$。∎

**应用**：把 $(p-1)! \bmod p$ 化成 $-1$，用于处理"阶乘模素数"的题目（例如求 $\binom{n}{k} \bmod p$ 的 Lucas 反用）。

### 二次剩余的补充结论

- $-1$ 是模 $p$ 的二次剩余 $\iff p \equiv 1 \pmod 4$；
- $2$ 是模 $p$ 的二次剩余 $\iff p \equiv \pm 1 \pmod 8$；
- 高斯二次互反律：$p \ne q$ 为奇素数时 $\left(\frac{p}{q}\right)\left(\frac{q}{p}\right) = (-1)^{\frac{p-1}{2}\frac{q-1}{2}}$。

### 拉格朗日定理

**定理**：模素数 $p$ 下，$n$ 次多项式方程 $f(x) \equiv 0 \pmod p$（$f$ 不恒为 $0$，$\deg f = n < p$）至多有 $n$ 个解。

**用途**：证明某些方程解的唯一性；分析插值多项式的性质。

## 2.12 例题与套路

### 套路 1：看到"指数爆炸"就降幂

> **题目特征**：求 $a^{b^{c}} \bmod m$，或指数以字符串/高精度形式给出，或递归定义指数。

**方法**：逐层欧拉降幂。注意 $m$ 变为 $\varphi(m)$ 后继续递归，$\varphi$ 迭代 $O(\log m)$ 次就会变成 $1$，所以递归层数是 $O(\log m)$。

```cpp
// 计算 b^c mod m 形式的塔，例如 https://www.luogu.com.cn/problem/P4139 风格
ll tower(ll b, ll c, ll m) {          // 求 b^c mod m，允许未降幂的 c 很大
    if (m == 1) return 0;
    ll phi = euler_phi(m);
    ll e = c >= phi ? c % phi + phi : c;
    ll r = qpow(b, e, m);
    return r ? r : r + m;             // 返回 "r 或 r+m" 用于上一层判断是否 >= φ
}
```

### 套路 2：同余方程组一次 exCRT 搞定

> **题目特征**："士兵排队"型问题；给出若干取模条件；要求最小的正整数解。

**方法**：逐个 `merge`。**注意判无解**（$d \nmid (r_2-r_1)$）；注意输入可能 $r_i > m_i$，先规范。

### 套路 3：离散对数转 BSGS

> **题目特征**：求 $a^x \equiv b \pmod p$；密码学背景；"最少多少次操作达到目标状态"且每次操作是乘一个常数。

**方法**：BSGS。若 $a$ 与 $p$ 不互素，用 exBSGS。若 $p$ 很大（$10^{18}$）则 BSGS 是 $O(\sqrt p)$，可能太慢，考虑其他性质。

### 套路 4：二次剩余转 Cipolla

> **题目特征**：需要求 $x^2 \equiv a \pmod p$；或在 $\mathbb{F}_p$ 上做矩阵开方/求特征值。

**方法**：欧拉判别法判有无解，Cipolla 求一个解。

### 套路 5：原根把乘法变加法

> **题目特征**：涉及 $g^{x_1} \cdot g^{x_2} \equiv g^{x_3}$ 形式；或"所有元素都是某个数的幂"；或 NTT 需要找原根。

**方法**：求原根后对每个元素取离散对数，问题转化为加法/线性问题。

### 套路 6：逆元处理"分数取模"

> **题目特征**：答案形如 $\frac{a}{b} \bmod p$；概率期望；组合数。

**方法**：$ab^{-1}$。若 $b$ 与 $p$ 不互素，必须用 §2.4 的手法（拆模数 / 维护素因子指数）。

## 2.13 易错点清单

| 编号 | 易错点 | 正确做法 |
|---|---|---|
| 1 | 用费马小定理求逆元但模数不是素数 | 模数非素数时用 exgcd |
| 2 | `inv[i] = (mod - mod / i) * inv[mod % i] % mod` 中 `mod % i` 越界 | 递推前保证 `n < mod`，且从 `i = 2` 开始 |
| 3 | 线性同余 `c % d != 0` 时忘记返回无解 | 必须判 |
| 4 | exCRT 中 `diff = r2 - r1` 为负 | `diff % d` 在 C++ 中负数取模仍能正确判整除，但计算 `t` 时要规范到非负 |
| 5 | exCRT 溢出 | `t * m1` 需用 `__int128`，或保证 `lcm` 不超过 $9\times10^{18}$ |
| 6 | 降幂时忘记判断 $b \ge \varphi(m)$ | 用 `big` 标记，一旦超过就置位 |
| 7 | 降幂时 `a` 与 `m` 不互素仍直接用 $b \bmod \varphi(m)$ | 必须用广义形式（+$\varphi(m)$ 补偿） |
| 8 | BSGS 的 `sqrt` 取下整导致覆盖不全 | `while (m * m < p) m++;` |
| 9 | BSGS 中 `b == 0` 的情况 | 单独特判（通常 $x$ 需满足 $a^x = 0$，即 $x \ge 1$ 且 $p \mid a$） |
| 10 | Cipolla 中 `w == 0` 时进入死循环 | 循环条件里排除 `w == 0` |
| 11 | Cipolla 用于 $p = 2$ | $p = 2$ 时特判返回 $n$ |
| 12 | 原根判定漏掉质因子 | 枚举 $\varphi(m)$ 的**所有不同质因子** $q$ |
| 13 | `unordered_map` 被卡 | 手写哈希表或加随机扰动 |
