# 第 7 章 多项式与快速变换

> 多项式是现代竞赛数学题的"重武器"。核心只有一条：**把卷积从 $O(n^2)$ 做到 $O(n\log n)$**（FFT / NTT）。
> 一旦有了它，多项式求逆、取对数、取指数（"多项式全家桶"）就都是模板，能解决一大类生成函数计数问题。

---

## 7.1 多项式与卷积

### 表示方式

- **系数表示**：$A(x) = \sum_{i=0}^{n-1}a_ix^i$，用数组 `a[0..n-1]` 存储；
- **点值表示**：$n$ 个点 $(x_i, A(x_i))$ 唯一确定一个次数 $< n$ 的多项式（当 $x_i$ 互异时）。

**关键洞察**：

| 运算 | 系数表示 | 点值表示 |
|---|---|---|
| 加法 | $O(n)$ | $O(n)$ |
| **乘法** | $O(n^2)$（卷积） | **$O(n)$**（逐点相乘） |

于是策略是：**系数 → 点值 → 乘 → 系数**。若"系数 ↔ 点值"的转换能 $O(n\log n)$ 完成，整体就是 $O(n\log n)$。FFT/NTT 正是这个转换。

### 卷积

$$C(x) = A(x)B(x) \iff c_k = \sum_{i+j=k}a_ib_j .$$

朴素算法 $O(nm)$：

```cpp
// 朴素卷积，小规模（n*m 较小）时反而比 NTT 快
vector<ll> convolution_naive(const vector<ll> &a, const vector<ll> &b, ll MOD) {
    if (a.empty() || b.empty()) return {};
    vector<ll> c(a.size() + b.size() - 1, 0);
    for (size_t i = 0; i < a.size(); i++)
        for (size_t j = 0; j < b.size(); j++)
            c[i + j] = (c[i + j] + a[i] * b[j]) % MOD;
    return c;
}
```

## 7.2 单位根与 DFT

### 复数单位根

记 $\omega_n = e^{2\pi i/n}$（$n$ 次单位根）。性质：

1. $\omega_n^n = 1$；
2. $\omega_n^0, \omega_n^1, \dots, \omega_n^{n-1}$ 两两不同；
3. **消去引理**：$\omega_{2n}^{2k} = \omega_n^k$；
4. **折半引理**：$\{(\omega_n^k)^2\} = \{\omega_{n/2}^k\}$（平方后只剩 $n/2$ 个不同值）；
5. **求和引理**：$\sum_{k=0}^{n-1}(\omega_n^j)^k = n[j\equiv0]$。

### DFT 与 IDFT

$$A_k = \sum_{j=0}^{n-1}a_j\omega_n^{jk},\qquad a_j = \frac1n\sum_{k=0}^{n-1}A_k\omega_n^{-jk}.$$

这就是"系数 ↔ 点值"的变换（在 $x=\omega_n^0,\dots,\omega_n^{n-1}$ 处求值）。直接算是 $O(n^2)$，FFT 用分治把它降到 $O(n\log n)$。

### FFT 的分治推导

按下标奇偶拆成两个多项式（设 $n$ 为偶数）：

$$A(x) = A_0(x^2) + xA_1(x^2),$$

其中 $A_0$ 取偶数下标的系数，$A_1$ 取奇数下标的系数，各有 $n/2$ 项。于是对 $k = 0,\dots,n/2-1$：

$$A(\omega_n^k) = A_0(\omega_{n/2}^k) + \omega_n^k A_1(\omega_{n/2}^k),$$
$$A(\omega_n^{k+n/2}) = A_0(\omega_{n/2}^k) - \omega_n^k A_1(\omega_{n/2}^k).$$

这就是**蝶形运算**：递归求两个 $n/2$ 规模的问题，然后 $O(n)$ 合并。复杂度 $T(n) = 2T(n/2)+O(n) = O(n\log n)$。

**迭代实现**：把递归改成自底向上，需要先做**位反转置换**（把下标按二进制位翻转），然后从长度 $2$ 开始逐层合并。

**FFT 的精度问题**：复数运算会积累浮点误差。系数很大（$\ge 10^5$）时必须用 `long double` 或改用 NTT。

## 7.3 NTT（数论变换）

**思想**：把 $\omega_n$ 换成模 $p$ 下的**原根幂** $g^{(p-1)/n}$。这样所有运算在 $\mathbb{Z}_p$ 中进行，**完全精确**。

**要求**：$n \mid (p-1)$，其中 $n$ 是变换长度（$2$ 的幂）。

### 常用 NTT 模数

| 模数 $p$ | 分解 | 原根 | 最大长度 |
|---|---|---|---|
| $998244353$ | $119\cdot2^{23}+1$ | $3$ | $2^{23}$ |
| $1004535809$ | $479\cdot2^{21}+1$ | $3$ | $2^{21}$ |
| $469762049$ | $7\cdot2^{26}+1$ | $3$ | $2^{26}$ |
| $167772161$ | $5\cdot2^{25}+1$ | $3$ | $2^{25}$ |

> **为什么是 $998244353$？** 它是"$p-1$ 含大因子 $2^{23}$ + 数值在 `int` 范围内便于优化 + 是素数"的最佳折中，几乎所有国内比赛都用它。

### 模板

```cpp
namespace NTT {
    const int MOD = 998244353;      // 常用 NTT 模数
    const int G   = 3;              // 原根

    ll qpow(ll a, ll e) {
        ll r = 1 % MOD;
        for (a %= MOD; e; e >>= 1, a = a * a % MOD) if (e & 1) r = r * a % MOD;
        return r;
    }

    // 原地 NTT；inv = true 时做逆变换
    void ntt(vector<int> &a, bool inv) {
        int n = (int)a.size();
        // 1) 位反转置换
        for (int i = 1, j = 0; i < n; i++) {
            int bit = n >> 1;
            for (; j & bit; bit >>= 1) j ^= bit;
            j ^= bit;
            if (i < j) swap(a[i], a[j]);
        }
        // 2) 蝶形合并
        for (int len = 2; len <= n; len <<= 1) {
            int w = (int)qpow(G, (MOD - 1) / len);
            if (inv) w = (int)qpow(w, MOD - 2);
            for (int i = 0; i < n; i += len) {
                ll wn = 1;
                for (int j = 0; j < len / 2; j++) {
                    int u = a[i + j];
                    int v = (int)(wn * a[i + j + len / 2] % MOD);
                    int x = u + v; if (x >= MOD) x -= MOD;
                    int y = u - v; if (y < 0) y += MOD;
                    a[i + j] = x;
                    a[i + j + len / 2] = y;
                    wn = wn * w % MOD;
                }
            }
        }
        // 3) 逆变换需要除以 n
        if (inv) {
            ll inv_n = qpow(n, MOD - 2);
            for (int &x : a) x = (int)(x * inv_n % MOD);
        }
    }

    // 多项式乘法
    vector<int> convolution(vector<int> a, vector<int> b) {
        int n = (int)a.size(), m = (int)b.size();
        if (!n || !m) return {};
        if (min(n, m) <= 60) {                    // 小规模暴力更快
            vector<int> c(n + m - 1, 0);
            for (int i = 0; i < n; i++)
                for (int j = 0; j < m; j++)
                    c[i + j] = (c[i + j] + (ll)a[i] * b[j]) % MOD;
            return c;
        }
        int sz = 1;
        while (sz < n + m - 1) sz <<= 1;
        a.resize(sz); b.resize(sz);
        ntt(a, false); ntt(b, false);
        for (int i = 0; i < sz; i++) a[i] = (int)((ll)a[i] * b[i] % MOD);
        ntt(a, true);
        a.resize(n + m - 1);
        return a;
    }
}
```

### 通用（模板化）NTT

换模数时不必重写代码：

```cpp
template <int MOD, int G>
struct NTTImpl {
    static ll qpow(ll a, ll e) {
        ll r = 1 % MOD;
        for (a %= MOD; e; e >>= 1, a = a * a % MOD) if (e & 1) r = r * a % MOD;
        return r;
    }
    static void ntt(vector<int> &a, bool inv) {
        int n = (int)a.size();
        for (int i = 1, j = 0; i < n; i++) {
            int bit = n >> 1;
            for (; j & bit; bit >>= 1) j ^= bit;
            j ^= bit;
            if (i < j) swap(a[i], a[j]);
        }
        for (int len = 2; len <= n; len <<= 1) {
            int w = (int)qpow(G, (MOD - 1) / len);
            if (inv) w = (int)qpow(w, MOD - 2);
            for (int i = 0; i < n; i += len) {
                ll wn = 1;
                for (int j = 0; j < len / 2; j++) {
                    int u = a[i + j];
                    int v = (int)(wn * a[i + j + len / 2] % MOD);
                    a[i + j] = u + v >= MOD ? u + v - MOD : u + v;
                    a[i + j + len / 2] = u - v < 0 ? u - v + MOD : u - v;
                    wn = wn * w % MOD;
                }
            }
        }
        if (inv) {
            ll inv_n = qpow(n, MOD - 2);
            for (int &x : a) x = (int)(x * inv_n % MOD);
        }
    }
    static vector<int> convolution(vector<int> a, vector<int> b) {
        int n = (int)a.size(), m = (int)b.size();
        if (!n || !m) return {};
        int sz = 1;
        while (sz < n + m - 1) sz <<= 1;
        a.resize(sz); b.resize(sz);
        ntt(a, false); ntt(b, false);
        for (int i = 0; i < sz; i++) a[i] = (int)((ll)a[i] * b[i] % MOD);
        ntt(a, true);
        a.resize(n + m - 1);
        return a;
    }
};
```

## 7.4 任意模数卷积（MTT）

当答案模数不是 NTT 友好的素数（例如 $10^9+7$、$1$ 亿以内任意数）时，有三种做法：

### 方法一：拆系数 FFT（经典 MTT）

把每个系数拆成 $a = a_0 + 2^{15}a_1$，用 4 次 FFT（或 3 次）分别卷积再合并。

### 方法二：三模 NTT + CRT（推荐，精度无损失）

在三个 NTT 模数下分别卷积，再用中国剩余定理合并。因为真实系数 $< 10^9\times10^9\times n \le 10^{23}$ 而 $M_1M_2M_3 \approx 4.7\times10^{26}$，所以能**精确还原**真实值再取模。

```cpp
namespace MTT {
    const int M1 = 998244353, M2 = 1004535809, M3 = 469762049;

    // 用 __int128 计算 a * b % m
    static inline ll mul_mod(ll a, ll b, ll m) { return (ll)((i128)a * b % m); }

    // 合并三个同余式，返回真实值 mod mod（真实值 < M1*M2*M3 ≈ 4.7e26）
    ll crt3(ll r1, ll r2, ll r3, ll mod) {
        ll x, y;
        // 第一步：合并 (r1, M1) 与 (r2, M2)
        exgcd(M1 % M2, M2, x, y);
        ll inv1 = (x % M2 + M2) % M2;
        ll t1 = mul_mod(((r2 - r1) % M2 + M2) % M2, inv1, M2);
        i128 x12 = (i128)r1 + (i128)t1 * M1;               // < M1*M2 ≈ 1e18
        ll m12 = M1 * M2;                                  // ≈ 1.0e18，long long 可存
        // 第二步：与 (r3, M3) 合并
        exgcd((ll)(x12 % M3), M3, x, y);
        ll inv2 = (x % M3 + M3) % M3;
        ll t2 = mul_mod(((r3 - (ll)(x12 % M3)) % M3 + M3) % M3, inv2, M3);
        i128 real = x12 + (i128)t2 * m12;                  // 真实值 < 4.7e26
        return (ll)((real % mod + mod) % mod);
    }
}
```

> 上面为了可读性做了化简。**注意 `m12 = M1 * M2` 约 $10^{18}$，没有溢出**；`real` 用 `__int128`，最大约 $4.7\times10^{26}$，也没有溢出。
> 若你的编译器不支持 `__int128`（如 MSVC），改用拆系数 FFT。

## 7.5 多项式全家桶

以下所有操作默认在模 $998244353$ 下、以 `vector<int>` 表示系数（`a[i]` 是 $x^i$ 的系数）。

### 求导与积分

```cpp
vector<int> poly_derivative(const vector<int> &f) {          // f'(x)
    int n = (int)f.size();
    vector<int> d(n > 0 ? n - 1 : 0, 0);
    for (int i = 1; i < n; i++) d[i - 1] = (ll)f[i] * i % NTT::MOD;
    return d;
}

// 积分需要 1..n 的逆元
vector<int> invs;                                            // invs[i] = i^{-1} mod MOD
void init_invs(int n) {
    invs.assign(n + 1, 0);
    if (n >= 1) invs[1] = 1;
    for (int i = 2; i <= n; i++)
        invs[i] = (ll)(NTT::MOD - NTT::MOD / i) * invs[NTT::MOD % i] % NTT::MOD;
}

vector<int> poly_integral(const vector<int> &f) {            // ∫f，常数项取 0
    int n = (int)f.size();
    vector<int> g(n + 1, 0);
    for (int i = 0; i < n; i++) g[i + 1] = (ll)f[i] * invs[i + 1] % NTT::MOD;
    return g;
}
```

### 多项式求逆

**目标**：求 $g$ 使 $f\cdot g \equiv 1 \pmod{x^n}$（要求 $f_0 \ne 0$）。

**牛顿迭代**：若已有 $g \equiv f^{-1} \pmod{x^{n}}$，则

$$g' \equiv g\,(2 - fg) \pmod{x^{2n}} .$$

**推导**：设 $h = g' - g$。要求 $f(g+h)\equiv1$，即 $fg + fh \equiv 1$。由 $fg \equiv 1 \pmod{x^n}$ 知 $fg = 1 + x^n\varepsilon$。取 $h = -g\cdot x^n\varepsilon$ 可得 $fg + fh = (1+x^n\varepsilon)(1 - x^n\varepsilon\cdot?) $…… 标准推导是把 $g'$ 看作 $\frac{1}{f}$ 的牛顿迭代：$g' = g - \frac{fg-1}{f}$，用 $g$ 近似 $1/f$ 得 $g' = g - g(fg-1) = 2g - fg^2 = g(2-fg)$。由于 $fg - 1$ 有因子 $x^n$，误差被平方，故精度翻倍。∎

```cpp
// 多项式求逆：返回 f^{-1} mod x^n，要求 f[0] != 0
vector<int> poly_inv(const vector<int> &f, int n) {
    vector<int> g(1, (int)NTT::qpow(f[0], NTT::MOD - 2));
    int cur = 1;
    while (cur < n) {
        int nxt = min(cur << 1, n);
        int sz = 1;
        while (sz < 2 * nxt) sz <<= 1;                 // 需要 2*nxt 才有足够精度
        vector<int> a(f.begin(), f.begin() + min((int)f.size(), nxt));
        a.resize(sz);
        vector<int> b(g);
        b.resize(sz);
        NTT::ntt(a, false); NTT::ntt(b, false);
        for (int i = 0; i < sz; i++) {
            ll fg = (ll)a[i] * b[i] % NTT::MOD;
            a[i] = (int)((2 - fg + NTT::MOD) % NTT::MOD * b[i] % NTT::MOD);
        }
        NTT::ntt(a, true);
        g.assign(a.begin(), a.begin() + nxt);
        cur = nxt;
    }
    return g;
}
```

### 多项式 ln

$$\ln f = \int \frac{f'}{f}, \qquad (\ln f)' = \frac{f'}{f}.$$

要求 $f_0 = 1$（否则 $\ln f_0$ 在模意义下无定义）。

```cpp
// 多项式 ln：返回 ln(f) mod x^n，要求 f[0] == 1
vector<int> poly_ln(const vector<int> &f, int n) {
    vector<int> d = poly_derivative(f);
    vector<int> invf = poly_inv(f, n);
    vector<int> q = NTT::convolution(d, invf);
    q.resize(n > 0 ? n - 1 : 0);
    vector<int> res = poly_integral(q);
    res.resize(n);
    return res;
}
```

### 多项式 exp

$$\exp f = g,\qquad g' = f'g \quad\Longrightarrow\quad g = 1 + \int f'g .$$

牛顿迭代形式（要求 $f_0 = 0$）：若 $g \equiv e^f \pmod{x^n}$，则

$$g' \equiv g\left(1 - \ln g + f\right) \pmod{x^{2n}} .$$

```cpp
// 多项式 exp：返回 exp(f) mod x^n，要求 f[0] == 0
vector<int> poly_exp(const vector<int> &f, int n) {
    vector<int> g(1, 1);
    int cur = 1;
    while (cur < n) {
        int nxt = min(cur << 1, n);
        vector<int> lg = poly_ln(g, nxt);
        vector<int> t(nxt, 0);
        for (int i = 0; i < nxt; i++) {
            int fi = (i < (int)f.size()) ? f[i] : 0;
            t[i] = ((fi - lg[i]) % NTT::MOD + NTT::MOD) % NTT::MOD;
        }
        t[0] = (t[0] + 1) % NTT::MOD;                 // 1 - ln g + f
        g = NTT::convolution(g, t);
        g.resize(nxt);
        cur = nxt;
    }
    return g;
}
```

> **实现要点**：exp 内部会递归调用 `poly_ln`，而 `poly_ln` 又调用 `poly_inv`。每层都是 NTT，总复杂度是 $O(n\log n)$（常数较大，约 20~30 次 NTT）。

### 多项式 sqrt

牛顿迭代：$g' = \dfrac{1}{2}\left(g + \dfrac{f}{g}\right)$。

```cpp
// 多项式开方：返回 sqrt(f) mod x^n，要求 f[0] == 1（或已知 f[0] 的平方根）
vector<int> poly_sqrt(const vector<int> &f, int n, int g0 = 1) {
    vector<int> g(1, g0);
    int cur = 1;
    while (cur < n) {
        int nxt = min(cur << 1, n);
        vector<int> invg = poly_inv(g, nxt);
        vector<int> t = NTT::convolution(f, invg);
        t.resize(nxt);
        g.resize(nxt);
        const int INV2 = (NTT::MOD + 1) / 2;
        for (int i = 0; i < nxt; i++)
            g[i] = (ll)(g[i] + t[i]) % NTT::MOD * INV2 % NTT::MOD;
        cur = nxt;
    }
    return g;
}
```

### 多项式快速幂

$$f^k = \exp(k\ln f) \quad (\text{要求 } f_0 = 1).$$

若 $f_0 \ne 1$，先提取最低次项：设 $f = x^t\cdot h$（$h_0 \ne 0$），则 $f^k = x^{tk}h^k$，再对 $h$ 用上式。

```cpp
// 多项式快速幂：f^k mod x^n，要求 f[0] == 1
vector<int> poly_pow(const vector<int> &f, ll k, int n) {
    vector<int> lg = poly_ln(f, n);
    for (int &x : lg) x = (int)((ll)x * (k % NTT::MOD) % NTT::MOD);
    return poly_exp(lg, n);
}
```

### 多项式除法与取模（简述）

给定 $f$（$n$ 次）、$g$（$m$ 次），求 $q, r$ 使 $f = qg + r$（$\deg r < m$）。

利用**反转多项式** $f^R(x) = x^{n}f(1/x)$：

$$q^R \equiv f^R \cdot (g^R)^{-1} \pmod{x^{n-m+1}} ,$$

求出 $q$ 后 $r = f - qg$。复杂度 $O(n\log n)$。

## 7.6 分治 FFT（CDQ 分治 + 卷积）

**问题**：求 $f$ 使

$$f_i = \sum_{j=1}^{i} g_j f_{i-j} \quad (i \ge 1),\qquad f_0 = 1,$$

即 $f = 1 + g*f$ 的"半在线卷积"（$f$ 的每一项依赖前面的项，不能直接一次卷积）。

**做法**：CDQ 分治。递归处理 $[l,r)$：

1. 递归 $[l, mid)$，得到 $f[l..mid)$；
2. 用 $f[l..mid)$ 与 $g[1..r-l)$ 卷积，把贡献加到 $f[mid..r)$；
3. 递归 $[mid, r)$。

总复杂度 $O(n\log^2 n)$。

```cpp
// 分治 FFT：f[i] = Σ_{j=1}^{i} g[j] * f[i-j]（f[0] 已给定）
vector<int> f, g;

void cdq(int l, int r) {
    if (r - l == 1) return;
    int mid = (l + r) >> 1;
    cdq(l, mid);
    // 用 f[l..mid) 去更新 f[mid..r)
    vector<int> a(f.begin() + l, f.begin() + mid);
    vector<int> b(g.begin(), g.begin() + min((int)g.size(), r - l));
    vector<int> c = NTT::convolution(a, b);
    for (int i = mid; i < r; i++) {
        int idx = i - l;                              // 对应的卷积下标
        if (idx < (int)c.size())
            f[i] = (f[i] + c[idx]) % NTT::MOD;
    }
    cdq(mid, r);
}
```

**调用**：`f.assign(n, 0); f[0] = 1; cdq(0, n);`

## 7.7 拉格朗日插值

**定理 7.1** 给定 $n+1$ 个互不相同的点 $(x_i, y_i)$，存在唯一的多项式 $f$（$\deg f \le n$）满足 $f(x_i)=y_i$，且

$$f(x) = \sum_{i=0}^{n}y_i\prod_{j\ne i}\frac{x - x_j}{x_i - x_j} .$$

**竞赛用途**：

1. 已知序列前 $n+1$ 项，求第 $k$ 项（$k$ 极大）；
2. 证明"某个 $\sum$ 是关于 $n$ 的 $k$ 次多项式"，然后插值求值。

```cpp
// 一般情形：O(n^2) 插值求 f(k)
ll lagrange(const vector<ll> &x, const vector<ll> &y, ll k, ll MOD) {
    int n = (int)x.size();
    ll res = 0;
    for (int i = 0; i < n; i++) {
        ll num = 1, den = 1;
        for (int j = 0; j < n; j++) {
            if (i == j) continue;
            num = num * ((k - x[j]) % MOD + MOD) % MOD;
            den = den * ((x[i] - x[j]) % MOD + MOD) % MOD;
        }
        res = (res + y[i] % MOD * num % MOD * qpow(den, MOD - 2, MOD)) % MOD;
    }
    return res;
}

// 连续点版本：x_i = i（i = 0..n），O(n) 求 f(k)
ll lagrange_consecutive(const vector<ll> &y, ll k, ll MOD) {
    int n = (int)y.size() - 1;                 // 共 n+1 个点
    if (k >= 0 && k <= n) return y[(int)k] % MOD;
    vector<ll> pre(n + 2, 1), suf(n + 2, 1), fac(n + 2, 1), ifac(n + 2, 1);
    for (int i = 0; i <= n; i++) pre[i + 1] = pre[i] * ((k - i) % MOD + MOD) % MOD;
    for (int i = n; i >= 0; i--) suf[i] = suf[i + 1] * ((k - i) % MOD + MOD) % MOD;
    for (int i = 1; i <= n + 1; i++) fac[i] = fac[i - 1] * i % MOD;
    ifac[n + 1] = qpow(fac[n + 1], MOD - 2, MOD);
    for (int i = n + 1; i >= 1; i--) ifac[i - 1] = ifac[i] * i % MOD;
    ll res = 0;
    for (int i = 0; i <= n; i++) {
        ll num = pre[i] * suf[i + 1] % MOD;                  // Π_{j≠i}(k-j)
        ll den = ifac[i] * ifac[n - i] % MOD;                // 1 / (i! (n-i)!)
        ll term = y[i] % MOD * num % MOD * den % MOD;
        if ((n - i) & 1) res = (res - term + MOD) % MOD;     // 分母符号 (-1)^{n-i}
        else res = (res + term) % MOD;
    }
    return res;
}
```

**关键技巧**：如果数据范围是 $n \le 10^{18}$ 但答案是关于 $n$ 的低次多项式，就取前 $k+1$ 项暴力算出来，再插值求 $n$。

## 7.8 线性递推：Kitamasa 与 Berlekamp-Massey

### Kitamasa：$O(k^2\log n)$ 求递推第 $n$ 项

已知 $k$ 阶常系数线性递推

$$a_n = c_1a_{n-1} + c_2a_{n-2} + \cdots + c_ka_{n-k},$$

把它写成多项式取模：令 $P(x) = x^k - c_1x^{k-1} - \cdots - c_k$（**特征多项式**），则

$$a_n = \sum_{i=0}^{k-1}\left[x^i\right]\big(x^n \bmod P(x)\big)\cdot a_i .$$

**证明思路**：可以验证对一切 $n$，$x^n \equiv \sum_i b_i x^i \pmod{P}$ 的系数 $b_i$ 给出的组合 $\sum b_ia_i$ 满足同一递推且初始值正确。∎

```text
// Kitamasa：a[i] = Σ_{j=0}^{k-1} c[j] * a[i-1-j]，求 a[n]
ll kitamasa(vector<ll> a, vector<ll> c, ll n, ll MOD) {
    int k = (int)c.size();
    if (n < k) return a[(int)n] % MOD;
    for (ll &v : a) v = (v % MOD + MOD) % MOD;
    for (ll &v : c) v = (v % MOD + MOD) % MOD;

    auto mul = [&](const vector<ll> &u, const vector<ll> &v) {
        vector<ll> t(2 * k, 0);
        for (int i = 0; i < k; i++) {
            if (!u[i]) continue;
            for (int j = 0; j < k; j++)
                t[i + j] = (t[i + j] + u[i] * v[j]) % MOD;
        }
        // 用 x^k = c[0]x^{k-1} + ... + c[k-1] 把高次项降次
        for (int i = 2 * k - 2; i >= k; i--) {
            if (!t[i]) continue;
            for (int j = 1; j <= k; j++)
                t[i - j] = (t[i - j] + t[i] * c[j - 1]) % MOD;
        }
        t.resize(k);
        return t;
    };

    vector<ll> res(k, 0), base(k, 0);
    res[0] = 1;                                  // 多项式 1
    if (k == 1) base[0] = c[0] % MOD;            // x ≡ c[0] (mod x - c[0])
    else base[1] = 1;                            // 多项式 x
    for (ll e = n; e; e >>= 1, base = mul(base, base))
        if (e & 1) res = mul(res, base);

    ll ans = 0;
    for (int i = 0; i < k; i++) ans = (ans + res[i] * a[i]) % MOD;
    return ans;
}
```

> **为什么比矩阵快速幂好？** 矩阵快速幂是 $O(k^3\log n)$；Kitamasa 是 $O(k^2\log n)$；用多项式乘法（NTT）加速可得 $O(k\log k\log n)$。

### Berlekamp-Massey：从序列反推最短递推

给定序列的前若干项，求出它的**最短线性递推式**。常用于"打表找规律"。

```cpp
// BM：给定序列 s[0..n-1]，返回最短递推系数 c（a[i] = Σ_{j=0}^{k-1} c[j] a[i-1-j]）
vector<ll> berlekamp_massey(const vector<ll> &s, ll MOD) {
    vector<ll> C(1, 1), B(1, 1);
    int L = 0, m = 1;
    ll b = 1;
    for (int n = 0; n < (int)s.size(); n++) {
        ll d = 0;
        for (int i = 0; i <= L && i < (int)C.size(); i++)
            d = (d + C[i] * s[n - i]) % MOD;
        d = (d % MOD + MOD) % MOD;
        if (d == 0) { ++m; continue; }
        vector<ll> T = C;
        ll coef = d * qpow(b, MOD - 2, MOD) % MOD;
        if ((int)C.size() < (int)B.size() + m) C.resize(B.size() + m, 0);
        for (int i = 0; i < (int)B.size(); i++)
            C[i + m] = ((C[i + m] - coef * B[i]) % MOD + MOD) % MOD;
        if (2 * L <= n) { L = n + 1 - L; B = T; b = d; m = 1; }
        else ++m;
    }
    vector<ll> res(L, 0);
    for (int i = 0; i < L; i++) res[i] = (MOD - C[i + 1] % MOD) % MOD;
    return res;
}
```

**使用流程**：暴力算出前若干项（一般取 $2k+10$ 项，$k$ 为递推阶数的估计）→ BM 求递推 → Kitamasa 求第 $n$ 项。

## 7.9 生成函数题目的实现流程

1. **写出 OGF/EGF**：把每种元素的选取规则写成 $x^k$ 的和式；
2. **相乘**：用多项式乘法；
3. **遇到 $\exp / \ln / \sqrt{}$**：直接套全家桶；
4. **遇到"半在线"递推**（$f_i$ 依赖前面的 $f_j$）：分治 FFT；
5. **遇到"已知前几项求第 $n$ 项"**：BM + Kitamasa 或拉格朗日插值。

**典型例子：整数拆分**

$p(n)$ 的 OGF 是 $\prod_{i\ge1}\frac{1}{1-x^i}$。求前 $n$ 项：用 $\ln$ 转成加法

$$\ln\prod_i\frac1{1-x^i} = \sum_i -\ln(1-x^i) = \sum_i\sum_{k\ge1}\frac{x^{ik}}{k},$$

于是 $p = \exp\left(\sum_{i,k}\frac{x^{ik}}{k}\right)$，可以 $O(n\log n)$ 求出。

## 7.10 易错点清单

| 编号 | 易错点 | 说明 |
|---|---|---|
| 1 | NTT 长度不足 | 需 $\ge n+m-1$ 且为 $2$ 的幂 |
| 2 | 长度超过模数支持的 $2^{23}$ | 998244353 只能到 $2^{23}$ |
| 3 | 逆变换忘记除以 $n$ | `inv_n` 必须乘 |
| 4 | 位反转置换写错 | 用标准写法，注意 `bit` 的循环 |
| 5 | 求逆迭代时 NTT 长度用错 | 需要 `sz >= 2*nxt` |
| 6 | `poly_ln` 要求 `f[0] == 1`，忘记检查 | 否则无定义 |
| 7 | `poly_exp` 要求 `f[0] == 0` | 否则 $e^{f_0}$ 未计入 |
| 8 | 分治 FFT 的下标换算错 | 贡献到 `f[i]` 的卷积项下标是 `i - l` |
| 9 | 拉格朗日插值分母符号错 | 连续点版本需乘 $(-1)^{n-i}$ |
| 10 | Kitamasa 中系数顺序搞反 | `c[0]` 对应 $a_{n-1}$ |
| 11 | BM 输出的递推符号错 | 输出的是 $-C[i+1]$ |
| 12 | 用 `int` 存中间乘法结果 | 必须转 `ll` 或 `i128` |
