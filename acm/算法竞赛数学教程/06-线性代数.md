# 第 6 章 线性代数

> 算法竞赛里的"线性代数"其实只有四件事：**矩阵快速幂**（加速线性递推）、**高斯消元**（解线性方程组）、**行列式**（计数工具）、**线性基**（异或空间）。
> 看到 $n \le 10^{18}$ 且递推线性 → 矩阵快速幂；看到"等概率随机游走" → 高斯消元；看到"异或最大值" → 线性基。

---

## 6.1 矩阵基础

### 定义与运算

$n \times m$ 矩阵 $A = (a_{ij})$。矩阵乘法 $C = AB$：

$$c_{ij} = \sum_{k=1}^{m}a_{ik}b_{kj},$$

要求 $A$ 的列数等于 $B$ 的行数。

**性质**：

| 性质 | 说明 |
|---|---|
| 结合律 | $(AB)C = A(BC)$ —— 这是快速幂的基础 |
| **不满足交换律** | $AB \ne BA$（一般情况） |
| 分配律 | $A(B+C) = AB + AC$ |
| 单位矩阵 | $AI = IA = A$ |
| 转置 | $(AB)^T = B^TA^T$ |

**复杂度**：$n\times m$ 乘 $m \times p$ 是 $O(nmp)$。竞赛中常用的方阵乘法是 $O(n^3)$。

### 矩阵模板

```cpp
template <int MOD>
struct Matrix {
    int n, m;
    vector<vector<ll>> a;
    Matrix(int n = 0, int m = 0) : n(n), m(m), a(n, vector<ll>(m, 0)) {}

    static Matrix identity(int n) {
        Matrix I(n, n);
        for (int i = 0; i < n; i++) I.a[i][i] = 1;
        return I;
    }
    Matrix operator*(const Matrix &o) const {
        Matrix r(n, o.m);
        for (int i = 0; i < n; i++)
            for (int k = 0; k < m; k++) {
                if (!a[i][k]) continue;                 // 稀疏优化
                ll v = a[i][k];
                for (int j = 0; j < o.m; j++)
                    r.a[i][j] = (r.a[i][j] + v * o.a[k][j]) % MOD;
            }
        return r;
    }
    // 方阵快速幂
    Matrix pow(ll e) const {
        Matrix r = identity(n), b = *this;
        for (; e; e >>= 1, b = b * b) if (e & 1) r = r * b;
        return r;
    }
};
```

> **溢出提醒**：`v * o.a[k][j]` 要求 $\text{MOD} \le 10^9$ 量级的平方不溢出 `long long`。
> 若模数达到 $10^{18}$，需改用 `__int128` 或龟速乘。

## 6.2 矩阵快速幂

### 核心思想

若转移可以写成"线性"的形式

$$\vec{v}_{k+1} = T\,\vec{v}_k,$$

则 $\vec v_n = T^n \vec v_0$，用快速幂在 $O(k^3\log n)$ 内解决（$k$ 为状态维数）。

### 例 1：斐波那契

$$\begin{pmatrix}F_{n+1}\\F_n\end{pmatrix} = \begin{pmatrix}1&1\\1&0\end{pmatrix}\begin{pmatrix}F_n\\F_{n-1}\end{pmatrix}
\implies \begin{pmatrix}F_{n+1}\\F_n\end{pmatrix} = \begin{pmatrix}1&1\\1&0\end{pmatrix}^{n}\begin{pmatrix}F_1\\F_0\end{pmatrix}.$$

```cpp
// 斐波那契数 F(n) mod MOD（F(0)=0, F(1)=1）
template <int MOD>
ll fib(ll n) {
    if (n <= 0) return 0;
    Matrix<MOD> T(2, 2);
    T.a[0][0] = 1; T.a[0][1] = 1;
    T.a[1][0] = 1; T.a[1][1] = 0;
    Matrix<MOD> R = T.pow(n);        // T^n，其 (0,1) 元即 F(n)
    return R.a[0][1];
}
```

### 例 2：带常数项的递推

$f(n) = a\,f(n-1) + b\,f(n-2) + c$。把常数 $1$ 也作为一个状态：

$$\begin{pmatrix}f(n)\\f(n-1)\\1\end{pmatrix}
= \begin{pmatrix}a&b&c\\1&0&0\\0&0&1\end{pmatrix}
\begin{pmatrix}f(n-1)\\f(n-2)\\1\end{pmatrix}.$$

### 例 3：带"求和"的递推

若要同时求 $S(n) = \sum_{i=1}^{n}f(i)$，把 $S$ 也加进状态向量：

$$\begin{pmatrix}f(n)\\f(n-1)\\S(n)\end{pmatrix}
= \begin{pmatrix}a&b&0\\1&0&0\\a&b&1\end{pmatrix}
\begin{pmatrix}f(n-1)\\f(n-2)\\S(n-1)\end{pmatrix}.$$

（因为 $S(n) = S(n-1) + f(n) = S(n-1) + a f(n-1) + b f(n-2)$。）

### 例 4：带多项式系数

若要 $f(n) = a\,f(n-1) + n^2$，把 $n^2, n, 1$ 都作为状态：

$$\begin{pmatrix}f(n)\\n^2\\n\\1\end{pmatrix}
= \begin{pmatrix}a&1&1&0\\0&1&2&1\\0&0&1&1\\0&0&0&1\end{pmatrix}
\begin{pmatrix}f(n-1)\\(n-1)^2\\n-1\\1\end{pmatrix}.$$

**构造要点**：$(n)^2 = (n-1)^2 + 2(n-1) + 1$，所以第二行是 $[0,1,2,1]$；$n = (n-1)+1$ 是第三行。

### 例 5：图上路径计数

设 $A$ 为图的邻接矩阵（$a_{ij}$ = 从 $i$ 到 $j$ 的边数），则

$$(A^k)_{ij} = \text{从 } i \text{ 到 } j \text{ 长度恰为 } k \text{ 的路径（walks）条数}.$$

**证明**：对 $k$ 归纳，$A^{k+1} = A^kA$ 的 $(i,j)$ 元为 $\sum_t (A^k)_{it}a_{tj}$，即"先走 $k$ 步到 $t$，再走一步边 $t\to j$"。∎

### 模板化构造步骤

1. **写出状态向量**：包含所有"下一步需要知道的历史信息"（通常是前 $k$ 项 + 常数项 + 求和项 + 多项式项）；
2. **写出每个状态在下一步的表达式**，把系数填进转移矩阵；
3. **确定初始向量**，答案取 $T^{n - n_0}\vec v_{n_0}$ 中的对应分量。

## 6.3 高斯消元

### 线性方程组解的结构

对 $A\vec x = \vec b$（$A$ 为 $n\times m$）：

- 设 $r = \operatorname{rank}(A)$，$r' = \operatorname{rank}([A|\vec b])$；
- 若 $r < r'$：**无解**；
- 若 $r = r' = m$：**唯一解**；
- 若 $r = r' < m$：**无穷多解**，自由变量个数为 $m - r$。

### 算法

用初等行变换（交换两行、某行乘非零常数、某行加上另一行的倍数）把矩阵化成行简化阶梯形（RREF），再读出解。**高斯-约当消元法**在消元过程中同时把主元列的其他元素也消成 $0$，省去回代。

### 模意义下的高斯消元（数论题常用）

竞赛中大多数"解方程"题要求答案模 $10^9+7$，此时用模逆元代替除法：

```cpp
// 解 A x = b（mod P，P 为素数）。返回自由变量个数；无解返回 -1。x 存一组解
int gauss_mod(vector<vector<ll>> a, vector<ll> b, vector<ll> &x, ll P) {
    int n = (int)a.size(), m = (int)a[0].size();
    vector<int> where(m, -1);
    int row = 0;
    for (int col = 0; col < m && row < n; col++) {
        int piv = -1;
        for (int i = row; i < n; i++) if (a[i][col] % P) { piv = i; break; }
        if (piv < 0) continue;                    // 该列无主元 => 自由变量
        swap(a[piv], a[row]); swap(b[piv], b[row]);
        ll inv = qpow(a[row][col], P - 2, P);
        for (int j = col; j < m; j++) a[row][j] = a[row][j] % P * inv % P;
        b[row] = b[row] % P * inv % P;
        for (int i = 0; i < n; i++) {             // 消去该列的其他所有行
            if (i == row || a[i][col] % P == 0) continue;
            ll f = a[i][col] % P;
            for (int j = col; j < m; j++)
                a[i][j] = ((a[i][j] - f * a[row][j]) % P + P) % P;
            b[i] = ((b[i] - f * b[row]) % P + P) % P;
        }
        where[col] = row++;
    }
    for (int i = row; i < n; i++) if (b[i] % P) return -1;      // 0 = 非零，无解
    x.assign(m, 0);
    for (int col = 0; col < m; col++)
        if (where[col] != -1) x[col] = b[where[col]] % P;
    return m - row;                                // 自由变量个数
}
```

### 异或方程组

若方程组形如 $a_{i1}x_1 \oplus \cdots \oplus a_{im}x_m = b_i$（系数与解都在 $\{0,1\}$ 中），用位运算批量处理，复杂度 $O(nm/64)$：

```cpp
// 异或方程组：m 个未知数（m <= 64），coef[i] 的第 j 位是 x_j 的系数
// 返回自由变量个数；无解返回 -1。（m 更大时把 ull 换成 bitset）
int gauss_xor(vector<ull> coef, vector<ull> rhs, int m) {
    int n = (int)coef.size(), rank = 0;
    for (int col = 0; col < m && rank < n; col++) {
        int piv = -1;
        for (int i = rank; i < n; i++) if ((coef[i] >> col) & 1) { piv = i; break; }
        if (piv < 0) continue;
        swap(coef[piv], coef[rank]); swap(rhs[piv], rhs[rank]);
        for (int i = 0; i < n; i++) {
            if (i == rank || !((coef[i] >> col) & 1)) continue;
            coef[i] ^= coef[rank]; rhs[i] ^= rhs[rank];
        }
        rank++;
    }
    for (int i = rank; i < n; i++) if (rhs[i]) return -1;      // 0 = 1，无解
    return m - rank;
}
```

**典型应用**：图上的"灯泡开关"问题（每个开关翻转一定集合的灯，问能否全灭）。

### 其他应用

- **求矩阵的逆**：对 $[A \mid I]$ 做行变换化成 $[I \mid A^{-1}]$；
- **求行列式**：见 §6.4；
- **解期望方程**：见第 5 章。

## 6.4 行列式

### 定义与性质

$n$ 阶行列式

$$\det A = \sum_{\sigma \in S_n}\operatorname{sgn}(\sigma)\prod_{i=1}^{n}a_{i\sigma(i)} .$$

直接按定义算是 $O(n!)$，实践中用高斯消元 $O(n^3)$。

**性质**：

| 性质 | 说明 |
|---|---|
| 交换两行 | 行列式**变号** |
| 某行乘 $c$ | 行列式乘 $c$ |
| 某行加上另一行的 $k$ 倍 | 行列式**不变**（消元的依据） |
| 两行相同（或成比例） | 行列式为 $0$ |
| $\det(AB) = \det A\cdot\det B$ | 乘法性 |
| $\det A^T = \det A$ | 转置不变 |
| 上/下三角 | 等于对角线元素之积 |

**范德蒙德行列式**：

$$\begin{vmatrix}1&x_1&\cdots&x_1^{n-1}\\ \vdots&&&\vdots\\ 1&x_n&\cdots&x_n^{n-1}\end{vmatrix} = \prod_{1\le i<j\le n}(x_j - x_i).$$

**求法**：从第 $n$ 行开始，每行减去上一行的 $x_1$ 倍，然后按第一列展开。

### 代码（模素数）

```cpp
// 模素数 P 下的行列式，O(n^3)
ll det_mod(vector<vector<ll>> a, ll P) {
    int n = (int)a.size();
    ll res = 1;
    for (int i = 0; i < n; i++) {
        int piv = -1;
        for (int j = i; j < n; j++) if (a[j][i] % P) { piv = j; break; }
        if (piv < 0) return 0;                       // 该列全 0，行列式为 0
        if (piv != i) { swap(a[piv], a[i]); res = (P - res) % P; }   // 换行变号
        res = res * a[i][i] % P;
        ll inv = qpow(a[i][i], P - 2, P);
        for (int j = i + 1; j < n; j++) {
            if (a[j][i] % P == 0) continue;
            ll f = a[j][i] % P * inv % P;
            for (int k = i; k < n; k++)
                a[j][k] = ((a[j][k] - f * a[i][k]) % P + P) % P;
        }
    }
    return res;
}
```

> **模数非素数**时不能用逆元，改用**辗转相除法**消元：

```cpp
// 模任意数 M 下的行列式，用辗转相除消元（不需求逆）
ll det_general(vector<vector<ll>> a, ll M) {
    int n = (int)a.size();
    ll res = 1;
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
            while (a[j][i]) {                        // 用 a[i][i] 与 a[j][i] 做辗转相除
                ll t = a[i][i] / a[j][i];
                for (int k = i; k < n; k++)
                    a[i][k] = ((a[i][k] - t * a[j][k]) % M + M) % M;
                swap(a[i], a[j]);
                res = (M - res) % M;                 // 每次交换变号
            }
        }
        if (!a[i][i]) return 0;
        res = res * a[i][i] % M;
    }
    return res;
}
```

### 矩阵树定理（Kirchhoff）

**无向图**：设 $L = D - A$（$D$ 为度数对角阵，$A$ 为邻接矩阵，重边/自环需注意），则**生成树个数**等于 $L$ 的任意 $(n-1)$ 阶主子式的行列式。

**有向图**（以 $1$ 为根）：

- **外向树**（所有边指向远离根的方向）：用**入度**矩阵减去邻接矩阵，取去掉第 $1$ 行第 $1$ 列的余子式；
- **内向树**：用**出度**矩阵。

```cpp
// 无向图生成树计数（模素数 P）
ll count_spanning_trees(int n, const vector<pair<int,int>> &edges, ll P) {
    if (n == 1) return 1 % P;
    vector<vector<ll>> L(n, vector<ll>(n, 0));
    for (auto &e : edges) {
        int u = e.first, v = e.second;
        if (u == v) continue;                        // 自环不影响生成树
        L[u][u]++; L[v][v]++;
        L[u][v] = (L[u][v] - 1 + P) % P;
        L[v][u] = (L[v][u] - 1 + P) % P;
    }
    vector<vector<ll>> a(n - 1, vector<ll>(n - 1));
    for (int i = 0; i + 1 < n; i++)
        for (int j = 0; j + 1 < n; j++) a[i][j] = L[i][j] % P;
    return det_mod(a, P);
}
```

**经典应用**：

- 完全图 $K_n$ 的生成树个数 = $n^{n-2}$（Cayley 公式）；
- 带权生成树计数（每条边权为 $w$，求 $\sum_{\text{树}}\prod_{e\in T}w_e$）：把 $L$ 中的 $1$ 换成 $w_e$。

## 6.5 线性基

### 定义

给定一组数（把每个数看作 $\mathbb{F}_2$ 上的向量），**线性基**是这组向量的一个极大线性无关组，且通常整理成"每个基底元素的最高位互不相同"的阶梯形。

**性质**：原集合中任意若干数的异或和都可以由线性基表示；线性基的大小 = 原集合张成的异或空间的维数（秩）。

**复杂度**：单个插入 $O(\log V)$（$V$ 为值域），空间 $O(\log V)$。

### 模板

```cpp
struct LinearBasis {
    static const int LOG = 62;         // 值域 < 2^63
    ll b[LOG + 1];
    bool hasZero;                      // 原集合能否异或出 0（即是否线性相关）

    LinearBasis() { memset(b, 0, sizeof(b)); hasZero = false; }

    // 插入 x；返回 true 表示 x 与已有基底线性无关
    bool insert(ll x) {
        for (int i = LOG; i >= 0; i--) {
            if (!((x >> i) & 1)) continue;
            if (!b[i]) { b[i] = x; return true; }
            x ^= b[i];
        }
        hasZero = true;                // x 能被已有基底表出
        return false;
    }

    // 最大异或和
    ll max_xor() const {
        ll res = 0;
        for (int i = LOG; i >= 0; i--) res = max(res, res ^ b[i]);
        return res;
    }

    // 非空子集所能得到的最小异或和
    ll min_xor() const {
        if (hasZero) return 0;                         // 存在非空子集异或为 0
        for (int i = 0; i <= LOG; i++) if (b[i]) return b[i];
        return 0;
    }

    // 判断 x 能否被表出
    bool can(ll x) const {
        for (int i = LOG; i >= 0; i--)
            if ((x >> i) & 1) { if (!b[i]) return false; x ^= b[i]; }
        return true;
    }

    int rank() const {
        int c = 0;
        for (int i = 0; i <= LOG; i++) if (b[i]) c++;
        return c;
    }

    // 化为简化阶梯形：保证每个基底的最高位在其他基底中为 0（第 k 小查询需要）
    void normalize() {
        for (int i = LOG; i >= 0; i--) {
            if (!b[i]) continue;
            for (int j = i - 1; j >= 0; j--)
                if ((b[i] >> j) & 1) b[i] ^= b[j];
        }
    }

    // 第 k 小的异或和（k 从 1 开始）。需先调用 normalize()。不存在返回 -1
    // 无论 hasZero 与否，可取的「值集合」都是基底张成的 2^rank 个元素（含 0），
    // 因此第 k 小恰好是「取 (k-1) 的二进制位所对应的那些基底进行异或」
    ll kth(ll k) const {
        vector<ll> v;
        for (int i = 0; i <= LOG; i++) if (b[i]) v.push_back(b[i]);
        int m = (int)v.size();
        if (m < 62 && k > (1LL << m)) return -1;       // 超出值集合的大小
        --k;
        ll res = 0;
        for (int i = 0; i < m; i++) if ((k >> i) & 1) res ^= v[i];
        return res;
    }
};
```

**关于 `kth` 的说明**：`normalize()` 之后，基底按最高位从小到大排列为 $v_0, v_1, \dots, v_{m-1}$，而"用基底组合出的数"与"选择的基底子集"一一对应。若不含 $0$，第 $k$ 小就是"取 $k-1$ 的二进制位对应的基底异或"；若含 $0$，则 $0$ 是最小值，第 $k$ 小（$k \ge 2$）对应 $k-1$ 的二进制。

### 应用

| 问题 | 做法 |
|---|---|
| 最大子集异或和 | `max_xor()` |
| 第 $k$ 小子集异或和 | `normalize()` + `kth(k)` |
| 判断某数能否被表出 | `can(x)` |
| 异或空间大小 | $2^{\text{rank}}$（可含 0 时也计入） |
| 两个线性基合并 | 把其中一个的所有基底插入另一个 |
| 区间线性基（每次询问 $[l,r]$ 的最大异或和） | "前缀线性基"：插入时保留**位置更靠右**的基底，贪心替换 |

**前缀线性基（区间最大异或和）的要点**：维护 $b[i]$ 与 $pos[i]$（该基底最后出现的位置）。插入 $x$（位置 $p$）时，若 $x$ 在第 $i$ 位有值而 $pos[i] < p$，则交换 $x$ 与 $b[i]$、交换 $p$ 与 $pos[i]$，然后继续往下消。查询 $[l,r]$ 时只使用 $pos[i] \ge l$ 的基底。

```cpp
// 前缀线性基：支持查询 [l, r] 内元素的最大异或和
struct PrefixBasis {
    static const int LOG = 30;
    ll b[LOG + 1];
    int pos[LOG + 1];                  // 基底来源的下标
    PrefixBasis() { memset(b, 0, sizeof(b)); memset(pos, 0, sizeof(pos)); }

    void insert(ll x, int p) {
        for (int i = LOG; i >= 0; i--) {
            if (!((x >> i) & 1)) continue;
            if (!b[i]) { b[i] = x; pos[i] = p; return; }
            if (pos[i] < p) { swap(b[i], x); swap(pos[i], p); }   // 保留更靠右的
            x ^= b[i];
        }
    }
    ll query(int l) const {            // 只用 pos >= l 的基底
        ll res = 0;
        for (int i = LOG; i >= 0; i--)
            if (pos[i] >= l && (res ^ b[i]) > res) res ^= b[i];
        return res;
    }
};
```

## 6.6 例题与套路

### 套路 1：递推 + 巨大 $n$ → 矩阵快速幂

> **特征**：$n \le 10^{18}$，且 $f(n)$ 由前若干项线性表示。

**步骤**：确定状态向量 → 填转移矩阵 → 快速幂 → 取对应分量。
**注意**：$k$ 阶递推的复杂度是 $O(k^3\log n)$，$k$ 大时（$k \ge 100$）要谨慎；此时可用第 7 章的线性递推（Kitamasa，$O(k^2\log n)$ 或 $O(k\log k\log n)$）。

### 套路 2：图上路径计数 → 邻接矩阵幂

> **特征**：求"走恰好 $k$ 步的方案数"。

**方法**：$A^k$ 的元素即为答案。带限制（如"不能连续两次走同一条边"）时把边作为状态（转移矩阵大小变成边数 × 2）。

### 套路 3：解方程 → 高斯消元

> **特征**：期望/概率 DP 有环；开关灯问题；线性约束求解。

**方法**：设未知数 → 列方程 → 高斯消元。模意义下用逆元版；异或方程用 bitset 版。

### 套路 4：异或最值 → 线性基

> **特征**："选一些数使异或和最大"、"第 $k$ 大异或和"、"某个数能否被表示"。

**方法**：线性基。区间询问用前缀线性基。

### 套路 5：生成树计数 → 矩阵树定理

> **特征**：统计生成树个数；"所有生成树的权值积之和"。

**方法**：拉普拉斯矩阵 + 行列式。若需要"权值积之和"，把邻接矩阵换成权值矩阵。

## 6.7 易错点清单

| 编号 | 易错点 | 说明 |
|---|---|---|
| 1 | 矩阵相乘顺序颠倒 | $T^n\vec v$ 与 $\vec v\,T^n$ 不同，注意行列约定 |
| 2 | 矩阵快速幂中单位矩阵尺寸错 | 必须是 $n\times n$ |
| 3 | 状态向量遗漏历史项 | 转移矩阵必须是常数矩阵 |
| 4 | 矩阵乘法中 `int` 溢出 | 模数 $\ge 2^{15}$ 就该用 `ll` |
| 5 | 高斯消元未判无解 | 检查"系数全 0 但常数非 0"的行 |
| 6 | 模意义消元中负数未规范 | 用 `(x % P + P) % P` |
| 7 | 行列式换行忘记变号 | `res = (P - res) % P` |
| 8 | 模数非素数时用逆元求行列式 | 用辗转相除版本 |
| 9 | 线性基 `LOG` 开小了 | 值域 $\le 10^{18}$ 需要 `LOG = 62`（含符号位要到 63） |
| 10 | 第 $k$ 小查询前忘记 `normalize()` | 必须先化简 |
| 11 | 矩阵树定理中自环未排除 | 自环对生成树无贡献，但会影响度数 |
| 12 | 异或方程组自由变量个数算错 | 是 $m - \text{rank}$，不是 $n - \text{rank}$ |
