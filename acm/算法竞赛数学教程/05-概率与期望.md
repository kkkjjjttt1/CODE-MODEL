# 第 5 章 概率与期望

> 概率期望题在竞赛里几乎全靠两个武器：**期望的线性性**（不需要独立性！）和**全期望公式**（把问题按情况分解）。
> 一旦你养成"把随机变量拆成指示函数之和"的习惯，很多看起来无从下手的题会瞬间变成简单的计数。

---

## 5.1 概率论基础

### 基本概念

- **样本空间** $\Omega$：所有可能结果的集合；
- **事件**：$\Omega$ 的子集；
- **概率** $P$：满足 $P(\Omega)=1$、$P(A)\ge0$、可列可加性的函数。

**古典概型**：若所有基本结果等可能，则

$$P(A) = \frac{|A|}{|\Omega|}.$$

**竞赛含义**：绝大多数"等概率"题本质上是**计数题**，概率就是两个组合数之比，最后用逆元取模。

### 条件概率与三大公式

**定义 5.1** $P(A \mid B) = \dfrac{P(A \cap B)}{P(B)}$（$P(B) > 0$）。

**乘法定理**：$P(A\cap B) = P(A\mid B)P(B) = P(B\mid A)P(A)$。

**全概率公式**：若 $\{B_i\}$ 是 $\Omega$ 的一个划分，则

$$P(A) = \sum_i P(A \mid B_i)P(B_i).$$

**贝叶斯公式**：

$$P(B_i \mid A) = \frac{P(A\mid B_i)P(B_i)}{\sum_j P(A\mid B_j)P(B_j)}.$$

**容斥（概率版）**：$P(A\cup B) = P(A)+P(B)-P(A\cap B)$，可推广到多个事件。

### 独立性与互斥（易混！）

| 概念 | 定义 | 直觉 |
|---|---|---|
| **独立** | $P(A\cap B) = P(A)P(B)$ | 一个发生不影响另一个的概率 |
| **互斥** | $A \cap B = \varnothing$ | 两者不可能同时发生 |

**互斥**且 $P(A), P(B) > 0$ 的事件**一定不独立**（因为 $P(A\cap B)=0 \ne P(A)P(B)$）。考场上这点经常被搞错。

## 5.2 期望与方差

### 定义

对离散随机变量 $X$：

$$E[X] = \sum_{x}x\,P(X = x).$$

**期望的三大性质**：

1. **线性性**：$E[aX + bY + c] = aE[X] + bE[Y] + c$，**对任意 $X, Y$ 成立，不需要独立！**（这是全部期望题的基础）
2. **独立可乘**：若 $X, Y$ 独立，则 $E[XY] = E[X]E[Y]$；
3. **单调性**：$X \le Y$ 处处成立 $\Rightarrow E[X] \le E[Y]$。

**推论（最常用）**：对任意一组随机变量 $X_1, \dots, X_n$（无论是否独立），

$$E\!\left[\sum_i X_i\right] = \sum_i E[X_i].$$

### 方差

$$\operatorname{Var}(X) = E\left[(X - E[X])^2\right] = E[X^2] - E[X]^2 .$$

- $\operatorname{Var}(aX + b) = a^2\operatorname{Var}(X)$；
- 独立时 $\operatorname{Var}(X+Y) = \operatorname{Var}(X)+\operatorname{Var}(Y)$；
- 一般地 $\operatorname{Var}(X+Y) = \operatorname{Var}(X)+\operatorname{Var}(Y)+2\operatorname{Cov}(X,Y)$。

**竞赛提示**：需要"平方的期望"时，通常先算 $E[X]$ 与 $E[X^2]$ 两个 DP。

### 非负整数随机变量的期望公式

若 $X$ 只取非负整数值，则

$$E[X] = \sum_{i\ge 1}P(X \ge i).$$

**证明**：$\sum_{i\ge1}P(X\ge i) = \sum_{i\ge1}\sum_{k\ge i}P(X=k) = \sum_k k\,P(X=k) = E[X]$。∎

**用途**：当"$X \ge i$"比"$X = i$"容易算时（例如"存活 $i$ 步的概率"），直接套这个公式。

## 5.3 指示函数法：把期望拆成概率之和

这是**竞赛中最重要的期望技巧**。

**方法**：把要求的随机变量写成 $X = \sum_{i} X_i$，其中 $X_i$ 是"事件 $A_i$ 是否发生"的指示变量（发生为 $1$，否则为 $0$）。于是

$$E[X] = \sum_i E[X_i] = \sum_i P(A_i).$$

**关键**：$A_i$ 之间**不需要独立**！每个 $P(A_i)$ 单独算即可。

### 例 1：随机排列的逆序对期望

$n$ 个元素的随机排列中，逆序对数 $X$ 的期望。

对每对 $(i,j)$（$i<j$），令 $X_{ij}$ 表示"$i$ 排在 $j$ 后面"。由对称性 $P = \frac12$，共 $\binom n2$ 对，故

$$E[X] = \binom n2\cdot\frac12 = \frac{n(n-1)}4 .$$

### 例 2：$n$ 个球随机放入 $n$ 个盒子，期望非空盒数

设 $X_i$ 表示第 $i$ 个盒子非空：$P = 1 - \left(1-\frac1n\right)^n$，故

$$E[X] = n\left[1-\left(1-\frac1n\right)^n\right] \xrightarrow{n\to\infty} n\left(1-\frac1e\right).$$

### 例 3：收集卡片（Coupon Collector）

$n$ 种卡片，每次等概率抽到一种，求集齐所有种类的期望次数。

设 $X_i$ 表示"已经集齐 $i-1$ 种，到集齐第 $i$ 种所需次数"。此时每抽一次，抽到新种类的概率是 $p_i = \frac{n-i+1}{n}$，故 $X_i$ 服从参数 $p_i$ 的几何分布，$E[X_i] = \frac1{p_i} = \frac{n}{n-i+1}$。于是

$$E[X] = \sum_{i=1}^{n}\frac{n}{n-i+1} = n\sum_{k=1}^{n}\frac1k = nH_n .$$

**注意这里用了期望的线性性把"顺序抽取"的复杂依赖化掉了**——这正是指示函数法/分解法的威力。

## 5.4 常见分布

| 分布 | 记号 | 概率质量函数 | 期望 | 方差 |
|---|---|---|---|---|
| 伯努利 | $B(1,p)$ | $P(1)=p,\ P(0)=1-p$ | $p$ | $p(1-p)$ |
| 二项 | $B(n,p)$ | $\binom nk p^k(1-p)^{n-k}$ | $np$ | $np(1-p)$ |
| 几何 | $G(p)$ | $(1-p)^{k-1}p$ | $\frac1p$ | $\frac{1-p}{p^2}$ |
| 负二项 | $NB(r,p)$ | $\binom{k-1}{r-1}p^r(1-p)^{k-r}$ | $\frac rp$ | $\frac{r(1-p)}{p^2}$ |
| 均匀（离散） | $U\{a..b\}$ | $\frac{1}{b-a+1}$ | $\frac{a+b}2$ | $\frac{(b-a)(b-a+2)}{12}$ |
| 泊松 | $P(\lambda)$ | $\frac{\lambda^k}{k!}e^{-\lambda}$ | $\lambda$ | $\lambda$ |

**几何分布期望的两种推导**：

方法一（递推）：$E = 1 + (1-p)E \Rightarrow E = 1/p$。

方法二（尾和）：$E = \sum_{i\ge1}P(X\ge i) = \sum_{i\ge1}(1-p)^{i-1} = \frac{1}{p}$。

**二项分布期望**：$X = \sum_{i=1}^n X_i$（第 $i$ 次是否成功），由线性性 $E[X] = np$。**注意这里不需要独立性**。

## 5.5 全期望公式与条件期望

**全期望公式**：若 $\{B_i\}$ 是划分，则

$$E[X] = \sum_i E[X \mid B_i]\,P(B_i).$$

或更一般地 $E[X] = E\big[E[X \mid Y]\big]$。

**用途**：把问题按"第一步的结果"分类，得到关于 $E$ 的方程或递推。

**例**：$X$ 为抛一枚不均匀硬币直到出现正面的次数（正面的概率 $p$）。按第一次结果分类：

$$E[X] = p\cdot 1 + (1-p)\cdot(1 + E[X]) \implies E[X] = \frac1p .$$

## 5.6 期望 DP

### 状态定义的原则

**核心原则**：期望 DP 的状态通常定义为「**从当前状态出发，到达目标所需的期望代价**」，这样全期望公式才能自然使用：

$$E[s] = \sum_{s\to t}p_{s\to t}\big(E[t] + w(s\to t)\big).$$

**顺推还是逆推？**

| 情形 | 做法 |
|---|---|
| 状态转移构成 **DAG**，求"从起点到终点"的期望 | 按拓扑序**顺推**：`E[t] += p * (E[s] + w)` |
| 求"从状态 $s$ 出发还需多少步" | **逆推**（从终点向回推） |
| 转移**有环**（可以回到自己） | 列方程 + **高斯消元**（§5.7） |

> **最常见的错误**：在有环的问题里硬用 DP 递推。只要存在"从 $s$ 可以回到 $s$"的路径，就必须解方程。

### 例 1：掷骰子前进

在数轴上从 $0$ 出发，每次等概率前进 $1\sim 6$ 步，超过 $n$ 就停在 $n$，求到达 $n$ 的期望次数。

设 $E[i]$ 为从 $i$ 到 $n$ 的期望次数，$E[n] = 0$，则

$$E[i] = 1 + \frac16\sum_{k=1}^{6}E[\min(i+k, n)] .$$

从 $i=n-1$ 往回算即可（**逆推**）。

```cpp
// 掷骰子：从 0 到 n 的期望步数（每次等概率走 1..m 步，超出则停）
double dice_walk(int n, int m) {
    vector<double> E(n + 1, 0.0);
    for (int i = n - 1; i >= 0; i--) {
        double s = 0;
        for (int k = 1; k <= m; k++) s += E[min(i + k, n)];
        E[i] = 1.0 + s / m;
    }
    return E[0];
}
```

### 例 2：收集卡片（DP 写法）

设 $E[i]$ 为"已收集 $i$ 种，集齐 $n$ 种所需期望次数"，则

$$E[i] = 1 + \frac{i}{n}E[i] + \frac{n-i}{n}E[i+1] \implies E[i] = E[i+1] + \frac{n}{n-i}.$$

这里出现了 $E[i]$ 依赖自身的情况——移项即可（等价于几何分布的期望）。**这就是"有环但可解析移项"的典型情形：先移项，再决定是否需要高斯消元。**

### 例 3：连续正面的期望（带上限）

抛硬币，求连续出现 $k$ 次正面所需次数的期望（可以用 KMP 式的状态转移 + 高斯消元，也可以用经典结论 $E = 2^{k+1}-2$）。

### 例 4：树上随机游走

树上等概率走向相邻点，求从 $u$ 到 $v$ 的期望步数。**利用树的期望距离结论**：

$$E[\text{dist}(u,v)] = 2\sum_{\text{边}} \text{(子树大小相关项)} - \text{depth}(u)-\text{depth}(v),$$

其中每条边的贡献是 $2\,\mathrm{size}(v)\,(n-\mathrm{size}(v))$。这类"按边拆贡献 + 期望线性性"的套路在树上期望距离题中非常常见。

## 5.7 高斯消元解期望方程

当状态转移有环、无法解析移项时，把每个状态写成一个未知数，得到线性方程组

$$E[s] - \sum_{s\to t}p_{s\to t}E[t] = \text{常数项},$$

然后用高斯消元求解。**注意：方程组规模通常是状态数**，所以只有在状态数较小（$\le$ 几百）时才可行。

**例**：$n$ 个点的图，从 $1$ 号点出发随机游走（每次等概率走向相邻点），求到达 $n$ 的期望步数。

$$E[i] = 1 + \frac{1}{\deg(i)}\sum_{j \sim i}E[j]\quad (i \ne n), \qquad E[n] = 0 .$$

移项整理成 $a_{ii}E[i] - \sum_j a_{ij}E[j] = 1$ 的形式后求解。

```cpp
// 高斯-约当消元（实系数）：解 A x = b，A 为 n×n。有唯一解返回 true
bool gauss_solve(vector<vector<double>> A, vector<double> b, vector<double> &x) {
    int n = (int)A.size();
    for (int col = 0; col < n; col++) {
        int piv = col;
        for (int i = col; i < n; i++)
            if (fabs(A[i][col]) > fabs(A[piv][col])) piv = i;
        if (fabs(A[piv][col]) < 1e-9) return false;        // 奇异或主元过小
        swap(A[piv], A[col]); swap(b[piv], b[col]);
        double d = A[col][col];
        for (int j = col; j < n; j++) A[col][j] /= d;
        b[col] /= d;
        for (int i = 0; i < n; i++) {
            if (i == col) continue;
            double f = A[i][col];
            if (fabs(f) < 1e-12) continue;
            for (int j = col; j < n; j++) A[i][j] -= f * A[col][j];
            b[i] -= f * b[col];
        }
    }
    x = b;
    return true;
}

// 图上随机游走：求从 s 到 t 的期望步数（n 为点数，adj 为邻接表）
double expected_walk_steps(const vector<vector<int>> &adj, int s, int t) {
    int n = (int)adj.size();
    vector<vector<double>> A(n, vector<double>(n, 0.0));
    vector<double> b(n, 0.0);
    for (int i = 0; i < n; i++) {
        if (i == t) { A[i][i] = 1; b[i] = 0; continue; }   // 终点：E = 0
        int d = (int)adj[i].size();
        A[i][i] = 1;
        for (int j : adj[i]) A[i][j] -= 1.0 / d;
        b[i] = 1;
    }
    vector<double> x;
    if (!gauss_solve(A, b, x)) return -1;
    return x[s];
}
```

> **分数答案怎么办？** 竞赛中答案常要求"模 $10^9+7$ 下的分数"，此时应把高斯消元改成**模意义**版本（把除法换成乘逆元），见第 6 章。

## 5.8 进阶技巧

### 技巧 1：期望的对称性

若结构在某些变换下对称，则相关随机变量的期望相等，可以直接替换。

**例**：$n$ 个点随机连成一棵树的期望直径（对称性 + 期望线性性）。

### 技巧 2：把概率题转成计数题

所有结果是等概率时，$E[X] = \frac{\text{所有情况下 }X\text{ 的总和}}{\text{情况总数}}$。于是问题变成"求所有情况下的总和"，可以用计数 DP 解决，最后乘总方案数的逆元。

### 技巧 3：$E[X] = \sum P(X \ge i)$

见 §5.2。典型用法：$X$ 是"操作次数"，$P(X \ge i)$ 是"操作 $i$ 次后仍未结束的概率"，后者往往是简单的 DP。

### 技巧 4：min-max 容斥 + 期望

$$E[\max(S)] = \sum_{\varnothing\ne T\subseteq S}(-1)^{|T|-1}E[\min(T)].$$

若 $E[\min(T)]$（"$T$ 中至少一个出现"的期望时间）容易算，就能求出"全部出现"的期望时间。典型题：每个操作以一定概率获得某些物品，求收集齐所有物品的期望步数。

### 技巧 5：停时定理与鞅（选讲）

若 $X_n$ 是鞅（$E[X_{n+1}\mid \mathcal F_n] = X_n$）且满足可积与有界条件，则 $E[X_\tau] = E[X_0]$。用法：构造一个"势能函数"使每步期望变化为 $0$，从而直接解出期望停时。

**典型构造**：随机游走中，令势能为 $f(\text{位置})$ 满足 $f(x) = \frac{f(x-1)+f(x+1)}2$（即 $f$ 线性），则 $E[\text{停时}]$ 可由边界条件解出。

### 技巧 6：期望的可加性在数据结构题中

例如"随机排列中，参与归并排序的交换次数的期望"——把总代价拆成每一对元素的贡献。

## 5.9 例题与套路

| 题目特征 | 方法 |
|---|---|
| 求"集齐/达到某状态"的期望次数 | 指示函数分解 or 期望 DP 逆推 |
| 每次操作有多个后继状态 | 逆推 DP（DAG）或高斯消元（有环） |
| 求"每个元素是否满足条件"的计数期望 | 指示函数法（线性性） |
| 求"最大值的期望" | min-max 容斥 |
| 给定"存活概率"求步数期望 | $E = \sum P(X \ge i)$ |
| 随机排列中某种结构 | 对称性 + 线性性 |

### 完整示例：抛硬币直到出现 $k$ 次连续正面

设状态 $i$ = "当前已经连续 $i$ 次正面"，$E[i]$ 为从状态 $i$ 出发到结束的期望次数。

$$E[i] = 1 + \tfrac12 E[i+1] + \tfrac12 E[0], \qquad E[k] = 0 .$$

这是一个线性方程组（因为 $E[i]$ 依赖 $E[0]$），可以手推：设 $E[i] = a_iE[0] + b_i$，回代即可得到 $E[0] = 2^{k+1}-2$。

> 教训：**先尝试解析移项/递推，实在不行才上高斯消元。**

## 5.10 易错点清单

| 编号 | 易错点 | 说明 |
|---|---|---|
| 1 | 用 $E[XY]=E[X]E[Y]$ 时未验证独立 | 只有独立才成立 |
| 2 | 期望 DP 忘记把"当前概率"乘进去 | 全期望公式每项都要乘 $p$ |
| 3 | 有环还用 DP 递推 | 必须移项或高斯消元 |
| 4 | 高斯消元主元阈值太小 | 实数用 `1e-9`，模数版用"是否为 0" |
| 5 | 高斯的浮点误差累积 | 必要时用 `long double`，或改成模意义 |
| 6 | 概率取模时忘记逆元 | 分数一律乘逆元 |
| 7 | 把"互斥"当"独立" | 二者完全不同 |
| 8 | 期望 DP 状态定义与转移方向不一致 | 统一为"从当前点到目标" |
| 9 | 忘了处理"超过终点的部分"（如掷骰子越界） | 用 `min(i+k, n)` |
| 10 | 逆序/对称性用错（把无放回当有放回） | 看清题目是否放回 |
