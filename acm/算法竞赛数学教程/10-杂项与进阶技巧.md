## 10.1 Burnside 引理与 Pólya 定理

### 群作用下的计数问题

**典型问题**：用 $k$ 种颜色给 $n$ 个珠子染色，若两个染色方案可以通过**旋转/翻转**互相得到则视为同一种，问本质不同的方案数。

直接枚举会重复计数，需要"在群作用下数轨道"的工具。

### 基本概念

设有限群 $G$ 作用在集合 $X$ 上（$g\cdot x$ 表示把 $x$ 通过变换 $g$ 变成另一个方案）：

- **轨道** $Gx = \{g\cdot x: g\in G\}$：与 $x$ 等价的所有方案；
- **稳定化子** $\operatorname{Stab}(x) = \{g: g\cdot x = x\}$；
- **不动点集** $\operatorname{Fix}(g) = \{x : g\cdot x = x\}$。

**轨道-稳定化子定理**：$|Gx|\cdot|\operatorname{Stab}(x)| = |G|$。

### Burnside 引理

**定理 10.1（Burnside）** 轨道的个数（即本质不同的方案数）为

$$\#\text{轨道} = \frac{1}{|G|}\sum_{g\in G}\left|\operatorname{Fix}(g)\right| .$$

**证明**：考虑集合 $S = \{(g,x) : g\cdot x = x\}$，用两种方式计数：

- 按 $g$ 数：$|S| = \sum_{g\in G}|\operatorname{Fix}(g)|$；
- 按 $x$ 数：$|S| = \sum_{x\in X}|\operatorname{Stab}(x)| = \sum_{x\in X}\frac{|G|}{|Gx|} = |G|\sum_{\text{轨道}}\sum_{x\in\text{轨道}}\frac1{|\text{轨道}|} = |G|\cdot\#\text{轨道}$。

两式相等即得结论。∎

### Pólya 定理

若 $X$ 是"用 $k$ 种颜色给 $n$ 个位置染色"得到的集合，置换群 $G$ 作用在位置上，则

$$\left|\operatorname{Fix}(g)\right| = k^{c(g)},$$

其中 $c(g)$ 是置换 $g$ 的**循环个数**（因为同一循环内的位置必须同色）。

于是

$$\#\text{轨道} = \frac1{|G|}\sum_{g\in G}k^{c(g)} .$$

### 例：项链计数

$n$ 个珠子的项链用 $k$ 种颜色染色，群为二面体群 $D_n$（$n$ 个旋转 + $n$ 个翻转，共 $2n$ 个元素）：

| 变换 | 个数 | 循环数 $c(g)$ |
|---|---|---|
| 旋转 $i$ 格 | 1（每个 $i$） | $\gcd(i, n)$ |
| 翻转（$n$ 为奇数） | $n$ | $\frac{n+1}{2}$ |
| 翻转，轴过两珠（$n$ 为偶数） | $\frac n2$ | $\frac n2+1$ |
| 翻转，轴过两边中点（$n$ 为偶数） | $\frac n2$ | $\frac n2$ |

所以

$$\#\text{项链} = \frac1{2n}\begin{cases}
\sum_{i=0}^{n-1}k^{\gcd(i,n)} + n\,k^{(n+1)/2}, & n \text{ 为奇数},\\[6pt]
\sum_{i=0}^{n-1}k^{\gcd(i,n)} + \frac n2 k^{n/2+1} + \frac n2 k^{n/2}, & n \text{ 为偶数}.
\end{cases}$$

（若只考虑旋转（循环群 $C_n$），则只保留求和部分并除以 $n$，此时称为"bracelet/necklace"的区别。）

```cpp
// 项链计数：n 个珠子，k 种颜色
// rotationOnly = true 时只考虑旋转（循环群），否则考虑旋转+翻转（二面体群）
ll necklace_count(ll n, ll k, ll MOD, bool rotationOnly = false) {
    ll sum = 0;
    for (ll i = 0; i < n; i++)
        sum = (sum + qpow(k % MOD, std::gcd(i, n), MOD)) % MOD;
    if (rotationOnly) return sum % MOD * qpow(n % MOD, MOD - 2, MOD) % MOD;

    ll inv2 = (MOD + 1) / 2;
    if (n & 1) {
        sum = (sum + (n % MOD) * qpow(k % MOD, (n + 1) / 2, MOD)) % MOD;
    } else {
        ll half = n / 2 % MOD;
        sum = (sum + half * qpow(k % MOD, n / 2 + 1, MOD)) % MOD;
        sum = (sum + half * qpow(k % MOD, n / 2, MOD)) % MOD;
    }
    (void)inv2;
    return sum % MOD * qpow(2 * n % MOD, MOD - 2, MOD) % MOD;
}

// 例：正方体 6 个面用 k 种颜色染色，本质不同方案数 = (k^6 + 3k^4 + 12k^3 + 8k^2) / 24
ll cube_faces(ll k, ll MOD) {
    ll inv24 = qpow(24 % MOD, MOD - 2, MOD);
    ll s = qpow(k % MOD, 6, MOD);
    s = (s + 3 * qpow(k % MOD, 4, MOD)) % MOD;
    s = (s + 12 * qpow(k % MOD, 3, MOD)) % MOD;
    s = (s + 8 * qpow(k % MOD, 2, MOD)) % MOD;
    return s * inv24 % MOD;
}
```

> **正方体公式验证**：$k=2$ 时 $(64+48+96+32)/24 = 240/24 = 10$，正是"用两色给正方体染色"的经典答案。

### 模式化的解题步骤

1. **确定群 $G$**：题目允许的操作构成什么置换群（旋转、翻转、置换）；
2. **对每个 $g\in G$ 数不动点**：通常是 $k^{c(g)}$（Pólya）或更复杂的组合量；
3. **Burnside 求和除以 $|G|$**（模意义下乘 $|G|^{-1}$）。

## 10.2 线性规划与单纯形法

### 标准型

**原始问题（P）**：

$$\max\ c^Tx \quad \text{s.t.}\quad Ax \le b,\ x \ge 0 .$$

**对偶问题（D）**：

$$\min\ b^Ty \quad \text{s.t.}\quad A^Ty \ge c,\ y \ge 0 .$$

**强对偶定理**：若 (P) 与 (D) 都有可行解，则两者最优值相等。

**竞赛提示**：很多"最大化某线性目标"的题可以用对偶转成更好处理的形式（例如把"选物品"转成"覆盖约束"）。

### 单纯形法

加入松弛变量 $s \ge 0$ 把不等式变成等式：$Ax + s = b$。**当 $b \ge 0$ 时**，以 $s$ 为初始基就得到一个可行基，可以直接迭代：

1. 在当前单纯形表里找一个**能使目标增大**的变量（进入变量）；
2. 用**最小比值检验**确定离开变量（保证可行性）；
3. 做一次**转轴（pivot）**；
4. 重复直到没有可改进的变量（最优）或某进入变量没有正系数（**无界**）。

**Bland 规则**（选下标最小的候选）可以避免循环。

```cpp
// ============ 单纯形法 ============
// 求解 max c^T x，约束 A x <= b，x >= 0（要求 b >= 0）
// 若 b 中有负数，需要两阶段法（见文末说明）
struct Simplex {
    static constexpr double EPS = 1e-9;
    int m, n, tot;                       // m 个约束、n 个决策变量、tot = n + m 个变量
    vector<vector<double>> a;            // (m+1) x (tot+1)：前 tot 列是变量，最后一列是 RHS
    vector<int> basic;                   // 每行的基变量编号（0..n-1 决策变量，n..n+m-1 松弛变量）

    Simplex(const vector<vector<double>> &A, const vector<double> &b, const vector<double> &c) {
        m = (int)b.size();
        n = (int)c.size();
        tot = n + m;
        a.assign(m + 1, vector<double>(tot + 1, 0.0));
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) a[i][j] = A[i][j];
            a[i][n + i] = 1.0;                       // 松弛变量列（必须显式保存！）
            a[i][tot] = b[i];
        }
        for (int j = 0; j < n; j++) a[m][j] = -c[j]; // 目标行：z - c^T x = 0
        basic.resize(m);
        for (int i = 0; i < m; i++) basic[i] = n + i;   // 初始基为松弛变量
    }

    void pivot(int r, int c) {
        double k = a[r][c];
        for (int j = 0; j <= tot; j++) a[r][j] /= k;
        for (int i = 0; i <= m; i++) {
            if (i == r || fabs(a[i][c]) < EPS) continue;
            double f = a[i][c];
            for (int j = 0; j <= tot; j++) a[i][j] -= f * a[r][j];
        }
        basic[r] = c;
    }

    // 返回 false 表示问题无界；最优值写入 best
    bool solve(double &best) {
        while (true) {
            int c = -1;
            for (int j = 0; j < tot; j++)
                if (a[m][j] < -EPS) { c = j; break; }              // Bland 规则
            if (c < 0) break;                                      // 已最优
            int r = -1;
            for (int i = 0; i < m; i++) {
                if (a[i][c] <= EPS) continue;
                if (r < 0 || a[i][tot] / a[i][c] < a[r][tot] / a[r][c] - EPS) r = i;
            }
            if (r < 0) return false;                               // 无界
            pivot(r, c);
        }
        best = a[m][tot];
        return true;
    }

    // 读出最优解（非基变量为 0）
    vector<double> solution() const {
        vector<double> x(n, 0.0);
        for (int i = 0; i < m; i++)
            if (basic[i] < n) x[basic[i]] = a[i][tot];
        return x;
    }
};
```

> **实现陷阱（真实踩坑）**：不要把松弛变量的列"压缩掉"。松弛变量在初始基中是单位列，但经过转轴后它们也会有非零的检验数，**可能重新进入基**。如果表里不保存这些列，就会误判"已最优"而提前终止。
> 例如 `max x1 + 2x2, s.t. x1+x2 <= 3, x1 <= 2, x2 <= 2`，漏掉松弛列时程序会停在目标值 4（而不是正确的 5）。

> **关于 $b < 0$**：此时松弛基不可行，需要**两阶段法**（先以最小化"人工变量之和"为目标找可行基）。竞赛中更常见的做法是：**把问题转成对偶**，或用"初始化时把每个 $b_i<0$ 的约束整体取负"再引入人工变量。
> **整数约束**：单纯形只解**线性规划**，不能保证整数解。需要整数规划时，通常要利用问题结构（如全幺模矩阵 → 单纯形得到的解自动是整数）。

## 10.3 数值方法

### 三分法（Ternary Search）

**适用**：函数在区间上**单峰**（先增后减或先减后增）。每次取两个三等分点，比较函数值后舍去 $1/3$ 区间。

```cpp
// 三分法求单峰函数在 [l, r] 上的极大值点（求极小值把比较反过来）
double ternary_search(double l, double r, const function<double(double)> &f) {
    for (int it = 0; it < 200; it++) {
        double m1 = l + (r - l) / 3.0;
        double m2 = r - (r - l) / 3.0;
        if (f(m1) < f(m2)) l = m1; else r = m2;
    }
    return (l + r) / 2;
}

// 整数三分：因为整数域上可能出现"平台"，最后再暴力检查剩余 3~4 个点
ll ternary_search_int(ll l, ll r, const function<ll(ll)> &f) {
    while (r - l > 3) {
        ll m1 = l + (r - l) / 3, m2 = r - (r - l) / 3;
        if (f(m1) < f(m2)) l = m1; else r = m2;
    }
    ll best = l;
    for (ll i = l + 1; i <= r; i++) if (f(i) > f(best)) best = i;
    return best;
}
```

**常见用途**：凸函数的最值、几何最优化（如"到所有点距离和最小"的三分套三分）、带参数的二分答案。

### 模拟退火（Simulated Annealing）

**思想**：从当前解随机跳到邻近解，若更优则接受，若更差则以 $e^{-\Delta/T}$ 的概率接受（$T$ 为"温度"，逐渐降低）。这样可以跳出局部最优。

```cpp
// 模拟退火：在矩形区域中求 f(x, y) 的最小值
double simulated_annealing(double xlo, double xhi, double ylo, double yhi,
                           const function<double(double,double)> &f) {
    mt19937_64 rng(chrono::steady_clock::now().time_since_epoch().count());
    auto rnd = [&](double lo, double hi) {
        return lo + (hi - lo) * (double)(rng() >> 11) * (1.0 / 9007199254740992.0);
    };
    double cx = rnd(xlo, xhi), cy = rnd(ylo, yhi), cf = f(cx, cy);
    double bx = cx, by = cy, bf = cf;
    double T = max(xhi - xlo, yhi - ylo);
    for (int iter = 0; iter < 200000; iter++) {
        T *= 0.9995;                                        // 降温
        if (T < 1e-10) break;
        double nx = min(xhi, max(xlo, cx + rnd(-T, T)));
        double ny = min(yhi, max(ylo, cy + rnd(-T, T)));
        double nf = f(nx, ny);
        double d = nf - cf;
        if (d < 0 || exp(-d / T) > rnd(0, 1)) {              // 更优或按概率接受
            cx = nx; cy = ny; cf = nf;
            if (cf < bf) { bf = cf; bx = cx; by = cy; }
        }
    }
    (void)bx; (void)by;
    return bf;
}
```

**调参经验**：

- 初温 $T_0$ 取"目标函数值域的一个代表尺度"；
- 降温系数 $0.99 \sim 0.9995$；
- 每个温度迭代若干次（内循环）；
- **多跑几遍取最优**（比赛时按时间预算决定次数）。

### 自适应辛普森积分

**Simpson 公式**（用抛物线近似）：

$$\int_l^r f \approx \frac{r-l}{6}\Bigl(f(l) + 4f\!\left(\tfrac{l+r}2\right) + f(r)\Bigr).$$

**自适应**：若把区间二分后两段的 Simpson 值之和与整段相差在允许范围内，就采用；否则递归细分。

```cpp
// 自适应辛普森积分：计算 ∫_l^r f(x) dx
double simpson(double l, double r, const function<double(double)> &f) {
    double m = (l + r) / 2;
    return (f(l) + 4 * f(m) + f(r)) * (r - l) / 6;
}

double adaptive_simpson(double l, double r, double eps, double whole,
                        const function<double(double)> &f) {
    double m = (l + r) / 2;
    double ls = simpson(l, m, f), rs = simpson(m, r, f);
    if (fabs(ls + rs - whole) <= 15 * eps)
        return ls + rs + (ls + rs - whole) / 15;             // 误差补偿
    return adaptive_simpson(l, m, eps / 2, ls, f) +
           adaptive_simpson(m, r, eps / 2, rs, f);
}

// 调用方式：
// double ans = adaptive_simpson(l, r, 1e-9, simpson(l, r, f), f);
```

### 牛顿迭代（求方程根 / 多项式求逆的理论基础）

$$x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)} .$$

**在竞赛中的两种用法**：

1. **数值求根**（如求 $\sqrt[3]{n}$ 的高精度值）；
2. **多项式运算中求逆/开方/exp**：把"求多项式 $g$"看成求函数零点，用牛顿迭代构造精度倍增的公式（第 7 章的多项式全家桶全部基于此）。

## 10.4 递推与特征方程

### 常系数线性齐次递推

$$a_n = c_1a_{n-1} + c_2a_{n-2} + \cdots + c_ka_{n-k}.$$

**特征方程**：

$$x^k = c_1x^{k-1} + c_2x^{k-2} + \cdots + c_k \quad\Longleftrightarrow\quad x^k - c_1x^{k-1} - \cdots - c_k = 0 .$$

**通解结构**：设特征方程的根为 $r_1, \dots, r_s$，重数分别为 $m_1, \dots, m_s$，则

$$a_n = \sum_{i=1}^{s}\left(\sum_{j=0}^{m_i-1}A_{ij}\,n^j\right)r_i^{\,n}.$$

其中系数 $A_{ij}$ 由初始条件确定。

**例：斐波那契** $a_n = a_{n-1}+a_{n-2}$，特征方程 $x^2 - x - 1 = 0$，根 $\varphi = \frac{1+\sqrt5}2$、$\hat\varphi = \frac{1-\sqrt5}2$。由 $a_0=0,a_1=1$ 解得

$$a_n = \frac{\varphi^n - \hat\varphi^{\,n}}{\sqrt5}\quad(\text{Binet 公式}).$$

**例：重根** $a_n = 4a_{n-1} - 4a_{n-2}$，特征方程 $(x-2)^2=0$，通解 $a_n = (A + Bn)2^n$。

### 非齐次递推

$a_n = c_1a_{n-1} + \cdots + c_ka_{n-k} + f(n)$ 的通解 = 齐次通解 + 一个特解。

**猜特解的经验**：

| $f(n)$ 形式 | 猜特解形式 |
|---|---|
| 常数 $c$ | 常数 $A$（若 1 是特征根，则乘 $n$） |
| 多项式 $P(n)$ | 同次多项式（若 1 是特征根，乘 $n^{m}$） |
| $c^n$ | $A c^n$（若 $c$ 是特征根，乘 $n^m$） |
| $c^nP(n)$ | $c^n\cdot$ 多项式 |

### 生成函数法（更通用）

把递推式两边乘 $x^n$ 求和，解出 $F(x)$，再用部分分式或有理函数展开求通项。第 4 章 §4.5 已给示例。

### 竞赛中的三种实现选择

| 方法 | 复杂度 | 适用 |
|---|---|---|
| 矩阵快速幂 | $O(k^3\log n)$ | $k$ 小（$\le 50$），实现简单 |
| Kitamasa（多项式取模） | $O(k^2\log n)$ | $k$ 中等（$\le 1000$） |
| 生成函数 + NTT | $O(k\log k\log n)$ | $k$ 大 |

若只是"求第 $n$ 项"，直接上 Kitamasa；若是"维护多个量的转移"，用矩阵。

## 10.5 其他常用技巧

### 差分与前缀和

**一维差分**：区间加、单点查询。

```cpp
// 区间加、单点查询：先记录差分，最后做前缀和
vector<ll> range_add_single_query(const vector<array<ll,3>> &ops, int n) {
    // ops[i] = {l, r, v} 表示对 [l, r] 加 v
    vector<ll> diff(n + 2, 0), res(n + 1, 0);
    for (auto &op : ops) {
        ll l = op[0], r = op[1], v = op[2];
        diff[l] += v;
        diff[r + 1] -= v;
    }
    for (int i = 1; i <= n; i++) res[i] = res[i - 1] + diff[i];
    return res;
}
```

**二维差分**：`d[x1][y1] += v, d[x2+1][y1] -= v, d[x1][y2+1] -= v, d[x2+1][y2+1] += v`，最后二维前缀和。

**高阶差分**：$(1-x)^k$ 对应 $k$ 次差分，用于"把多项式次数降到 0"再找规律。

### 离散化

把大值域压缩到 $O(n)$：

```cpp
// 离散化：返回压缩后的编号（从 1 开始），同时可用 id 查回原值
vector<int> discretize(const vector<ll> &v, vector<ll> &sorted_unique) {
    sorted_unique = v;
    sort(sorted_unique.begin(), sorted_unique.end());
    sorted_unique.erase(unique(sorted_unique.begin(), sorted_unique.end()), sorted_unique.end());
    vector<int> id(v.size());
    for (size_t i = 0; i < v.size(); i++)
        id[i] = (int)(lower_bound(sorted_unique.begin(), sorted_unique.end(), v[i])
                      - sorted_unique.begin()) + 1;
    return id;
}
```

### 随机化技巧

1. **字符串哈希**：把字符串映射成数字，用随机底数与随机模数避免被卡；
2. **随机权值哈希**：给集合中每个元素赋随机权值，用权值异或/和判"两个集合是否相同"（例如判断两棵子树是否同构）；
3. **随机化判定**：对"是否存在满足条件的解"这类问题，随机采样若干次提高正确率；
4. **Pollard-Rho / 生日悖论**：见第 1 章。

### 鸽巢原理

$n+1$ 个物体放入 $n$ 个盒子，必有一个盒子含 $\ge 2$ 个物体。常用于：

- 证明"必然存在重复"（如长度 $\ge 2^n$ 的序列必有相同的子段异或和）；
- 说明"暴力枚举一定能在某个小范围内找到答案"。

### 数学归纳法与构造

构造题的常见套路：先猜结论，再对 $n$ 归纳构造（"从 $n$ 到 $n+1$"或"从 $n$ 到 $2n$"）。

### 常见"数学建模"步骤

遇到新题时，按这个顺序自查：

1. 能否写出**计数公式**（组合数、容斥）？
2. 能否写出**递推式**（DP/生成函数）？
3. 能否写出**闭式**（特征方程、生成函数展开）？
4. 是否存在**对称性/不变量**（守恒量、单调量）？
5. 数据范围是否暗示了**更快的算法**（$10^{18}$ → 矩阵/插值；$10^{10}$ → 杜教筛；$10^5$ → NTT）？

## 10.6 易错点清单

| 编号 | 易错点 | 说明 |
|---|---|---|
| 1 | Burnside 分母忘记取逆元 | 模意义下乘 $\|G\|^{-1}$ |
| 2 | Pólya 中循环数算错 | 旋转 $i$ 格的循环数为 $\gcd(i,n)$ |
| 3 | 翻转的两种情形（过点/过边）混淆 | 偶数 $n$ 时各占 $n/2$ |
| 4 | 单纯形前提 $b\ge0$ 未满足 | 需要两阶段法 |
| 5 | 单纯形未使用 Bland 规则导致死循环 | 退化时可能循环 |
| 6 | 三分用于非单峰函数 | 先证明单峰性，或改用模拟退火 |
| 7 | 整数三分忽略平台 | 最后暴力检查剩余点 |
| 8 | 辛普森积分在奇点处发散 | 避开奇点或做变量替换 |
| 9 | 模拟退火参数不当 | 多跑几遍、控制温度范围 |
| 10 | 特征方程重根忘记乘 $n^j$ | 通解中要有多项式因子 |
| 11 | 随机化哈希被卡 | 用 `chrono` 种子 + 双模数 |

## 10.8 结语：数学板块的训练方法

1. **建立自己的板子库**：把前 10 章的模板整理成一个 `math.cpp`，用宏开关控制编译，比赛时直接复制；
2. **每个板子都要"对拍"过**：写暴力版本，随机数据对比（本教程 `tools/` 目录下的 `verify_nt.cpp`、`verify_more.cpp`、`verify_misc.cpp` 提供了 71 项参考对拍，可直接运行）；
3. **总结题目特征 → 方法**的映射表（见附录 A 末节），比赛中先匹配特征再动手；
4. **不要过度依赖模板**：能推的公式尽量推，模板只用来省时间，不用来替代思考；
5. **限时训练**：数学题容易陷入"想太久"，建议给自己设定 20 分钟阈值，超时就先看题解归纳套路。
