## 0. 总览：进阶 DP 的知识地图与学习路线

你已经会的三类 DP 是"地基"，进阶专题本质上是三种升级：

| 你已有的能力 | 升级方向 | 对应本章 |
| --- | --- | --- |
| 线性 DP：状态是一维/二维下标 | 状态变成"一个集合/一个排列" | 第 1 章 状压 DP |
| 背包 DP：状态是容量 | 容量维度变成子树大小 / 层数 / 恰好 k 个 | 第 3 章 树上背包；第 8 章 WQS |
| 区间 DP：状态是 [l,r] | 转移代价函数更复杂，决策有单调性 | 第 7 章 决策单调性与四边形不等式 |
| 线性 DP：n 很大时 O(n²) 转移扛不住 | 观察转移式结构，砍掉一维 | 第 5/6/7 章 三大优化 |
| 状态里有"数位/树/图/概率" | 给 DP 加上专门的处理框架 | 第 2/3/4 章 |

### 0.1 推荐学习顺序（两阶段）

- **阶段 A（状态建模的扩展）**：第 1 章 状压 → 第 2 章 数位 → 第 3 章 树形 → 第 4 章 概率期望。
- **阶段 B（转移的优化）**：第 5 章 单调队列 → 第 6 章 斜率优化 → 第 7 章 决策单调性 → 第 8 章 WQS。
- 第 9 章计数 DP 是"工具章"，建议配合前八章穿插学习；第 10 章是扩展方向速览。

阶段 B 内部有依赖关系：第 5 章的"单调队列思想"是第 6 章的基础；第 7 章的决策单调性往往和第 8 章一起出现（先学会观察、用暴力打表验证单调性，比背模板更重要）。

### 0.2 贯穿全文的"方法论"（每次做 DP 题都过一遍）

1. **先问自己三个问题再写代码**：
   - 最终答案长什么样？(一个数 / 方案数 / 最小值…)
   - 什么信息在转移中"必须记住"？→ 这就是状态维度。
   - 这个信息能不能**压缩**？（只记末尾 / 只记差值 / 只记集合 / 只记数量而不是具体是谁）
2. **"刷表"与"填表"都要会**：填表是 `dp[i] = f(dp[j])`，刷表是 `dp[i] 更新 dp[k]`；数位 DP、期望 DP 用记忆化搜索写往往更不容易错。
3. **复杂度先粗估再细想**：`2^n`、`n·m`、`O(n²)` 各自能扛多大 n？心里有数再定状态。
4. **边界三件套**：`dp[0]` 初始值、`-inf/+inf` 与 `0` 的选择、下标从 0 还是 1。
5. **写对拍**：DP 题最容易"样例过、大数据 WA"。拿一个 O(n²) 暴力或朴素写法做对拍器，随机小数据跑几百组，是省选题手的日常。
6. **常见坑清单**：
   - 忘记 `long long`；`-inf` 设得不够小导致加值后溢出；
   - 位运算优先级：`mask >> i & 1` 要加括号（`>>` 高于 `&`，实际是 `(mask>>i)&1` 才对）；
   - 记忆化数组初值 -1，但合法答案也可能是 -1（换成 `-2e18` 或加 `vis` 数组）；
   - 滚动数组没有"清零/拷贝"干净，残留上一层的值；
   - 数位 DP 的 `tight` 和 `前导零` 两个维度漏掉任意一个。

## 1. 状态压缩 DP（状压 DP）与子集技巧（SOS DP）

### 1.1 触发信号与核心思想

**触发信号**：题目里出现"每个元素只用一次 / 某些物品不能共存 / 要记录哪些已经用过"这类**集合信息**，并且元素个数 **n ≤ 20 左右**（2^n 能放进数组）。

线性 DP 的状态是"处理到前 i 个"，它丢掉了"具体哪几个已选"的信息——当转移规则和"已选集合"有关（而不是只和数量有关）时，就必须把整个集合记进状态。**状压 DP 就是用二进制整数表示集合**：

```
mask 的第 i 位 = 1   ⇔   元素 i 已被选/已被占用
```

常用位运算（背熟）：

| 操作 | 写法 |
| --- | --- |
| 判断 i 是否在集合中 | `(mask >> i) & 1` |
| 加入 i | `mask \| (1 << i)` |
| 删除 i | `mask ^ (1 << i)` 或 `mask & ~(1 << i)` |
| 集合大小 | `__builtin_popcount(mask)` |
| 枚举 mask 的真子集 | `for (int s = mask; s; s = (s-1) & mask)` |
| 只保留最低位 1 | `mask & (-mask)` |
| 全集 | `(1 << n) - 1` |

**状态设计套路**：`dp[mask][额外维度]`，`mask` 表示集合，额外维度一般放"最后用到的是谁 / 当前阶段"。

### 1.2 例 1：最短 Hamilton 路径（模板题，O(2^n · n²) 可优化到 O(2^n · n)）

> 题意：n ≤ 20 个点，边权 w[i][j]，求从 0 出发**恰好经过每个点一次**、到达 n−1 的最短路径。

若只记"走过前 k 个点"是不够的——下一步能走哪取决于**上一个点是谁**，所以状态要带"最后在哪"：

```
dp[mask][i] = 已经访问过集合 mask 中的点，当前停在 i（i ∈ mask）的最短长度
转移：        dp[mask | (1<<j)][j] = min( dp[mask][i] + w[i][j] )   // j ∉ mask
答案：        dp[(1<<n)-1][n-1]
```

用"刷表法"写（外层 mask 递增即可，因为加入一个点后数值必然变大）：

```cpp
#include <bits/stdc++.h>
using namespace std;
const int INF = 0x3f3f3f3f;
int w[20][20];
int dp[1 << 20][20];            // n ≤ 20：2^20 * 20 * 4B ≈ 80MB，注意内存

int main() {
    ios::sync_with_stdio(false); cin.tie(nullptr);
    int n; cin >> n;
    for (int i = 0; i < n; ++i)
        for (int j = 0; j < n; ++j) cin >> w[i][j];

    memset(dp, 0x3f, sizeof(dp));
    dp[1][0] = 0;                                    // 起点 0，集合 {0}
    for (int mask = 1; mask < (1 << n); ++mask) {
        for (int i = 0; i < n; ++i) if ((mask >> i) & 1) {
            if (dp[mask][i] >= INF) continue;
            for (int j = 0; j < n; ++j)
                if (!((mask >> j) & 1))
                    dp[mask | (1 << j)][j] =
                        min(dp[mask | (1 << j)][j], dp[mask][i] + w[i][j]);
        }
    }
    cout << dp[(1 << n) - 1][n - 1] << '\n';         // 从 0 到 n-1 的开放路径

    // 若题目是"从 1 出发最后回到 1"的闭合环（如洛谷 P1171）：
    // int ans = INF;
    // for (int i = 1; i < n; ++i) ans = min(ans, dp[(1 << n) - 1][i] + w[i][0]);
    // cout << ans << '\n';
    return 0;
}
```

**为什么不能只用一维 `dp[mask]`？** 走到同一集合 `mask` 的不同终点 i，会带来不同的"未来成本"，所以终点必须入状态。这一条思考路径会反复出现：**状态要存"对未来的决策有影响的最小信息"**。

### 1.3 例 2（思考题，不贴全代码）：[NOI2001] 炮兵阵地（洛谷 P2704）

> 100 行 × 10 列的棋盘，格子有平原 / 山地（H 不能放炮）；每门炮的攻击范围是"上下左右两格"（同行隔 1 格、隔 2 格都不能有炮，相邻行同列也不能有）。求最多放几门炮。

- 每行 10 个格子 → 每行用一个 10 位 mask 表示"这行哪些列放炮"；
- 一行内合法的 mask 要满足 `(m & (m<<1)) == 0 && (m & (m<<2)) == 0`（横向不互相打），宽度 10 时这样的合法 mask 只有 **60 个**；
- 因为炮能打到**上两行**，所以状态要记住**连续两行**的摆放：

```
dp[row][a][b] = 处理完前 row 行，第 row 行放 a、第 row-1 行放 b 的最大数量
转移：枚举第 row-2 行的放法 c，要求 a&b==0、a&c==0、b&c==0 且与山地地形不冲突
```

复杂度 O(行数 × 60³)（实际剪枝后远小于），配合滚动数组只留两行。做完这题你就掌握了"状压 + 行与行之间的兼容性"这类题。

### 1.4 枚举子集：O(3^n) 技巧

形如 `dp[mask] = min over 子集s (dp[s] + dp[mask^s] + f(s, mask))` 的**集合划分型 DP**，需要枚举 mask 的子集：

```cpp
for (int mask = 0; mask < (1 << n); ++mask)
    for (int s = mask; s; s = (s - 1) & mask) {   // 枚举 mask 的非空真子集 s
        int other = mask ^ s;
        // ... 用 dp[s] 和 dp[other] 转移 dp[mask]
    }
```

总复杂度 Σ C(n,k)·2^k = **O(3^n)**：每个元素在 `s` 中 / 在 `other` 中 / 不在 `mask` 中，共三种状态。经典题：[NOIP2017 提高] 宝藏（P3959，O(3^n·n) 可过）、CF 或 ICPC 里的集合划分问题。

### 1.5 SOS DP：高维前缀和（把 O(3^n) 降成 O(n·2^n)）

很多状压题需要"对每个 mask，快速知道所有**子集**的信息"，例如：

```
对每个 mask：g[mask] = Σ 或 max 或 OR  over s⊆mask 的 f[s]
```

朴素枚举每个 mask 的子集是 O(3^n)。用**按位递推**（每个二进制位做一次"前缀和"）：

```cpp
// f[mask] 已填好初始值，然后：
for (int b = 0; b < n; ++b)
    for (int mask = 0; mask < (1 << n); ++mask)
        if ((mask >> b) & 1)
            f[mask] = combine(f[mask], f[mask ^ (1 << b)]);
// 结束后 f[mask] 就聚合了所有子集的信息
```

`combine` 可以是求和、取 max、取 min、按位或等任何**可交换可结合**的运算。复杂度 O(n·2^n)。

### 1.6 例 3：CF 165E Compatible Numbers（SOS DP 应用）

> 给 m 个互不相同的数 a[i]，对每个 a[i] 找一个 a[j] 使 `a[i] & a[j] == 0`，找不到输出 -1。

`a[i] & a[j] == 0` 等价于 `a[j]` 的每一位都是 `a[i]` 的补集里的 1，即 **a[j] ⊆ (~a[i])**（按题目数值的二进制位数取补）。于是问题变成：对每个 mask 求"是否存在某个 a[j] 是 mask 的子集"——正好是 SOS DP。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int B = 22, FULL = (1 << B) - 1;   // 按题目数值的最大二进制位数调 B
int dp[1 << B];                          // dp[mask] = 一个下标 j 满足 a[j] ⊆ mask，-1 表示无
int a[1 << 20];

int main() {
    ios::sync_with_stdio(false); cin.tie(nullptr);
    int m; cin >> m;
    memset(dp, -1, sizeof(dp));
    for (int i = 0; i < m; ++i) {
        cin >> a[i];
        dp[a[i]] = i;                    // a[i] 是它自己的子集
    }
    for (int b = 0; b < B; ++b)
        for (int mask = 0; mask <= FULL; ++mask)
            if (((mask >> b) & 1) && dp[mask] == -1)
                dp[mask] = dp[mask ^ (1 << b)];   // 从"去掉一位"的子集继承

    for (int i = 0; i < m; ++i) {
        int want = FULL ^ a[i];          // 需要 a[j] ⊆ want
        if (dp[want] == -1) cout << -1;
        else cout << a[dp[want]];
        cout << (i == m - 1 ? '\n' : ' ');
    }
    return 0;
}
```

## 2. 数位 DP

### 2.1 触发信号与核心思想

**触发信号**：题目要求统计区间 [L, R]（R 可能高达 10^9 ~ 10^18）内满足"关于数字位"的条件（某数字出现次数、相邻位大小关系、不含某子串、各位和是…、各位互不相同……）的数字个数、和或乘积。

**核心思想**：把"x 从高位到低位"看成一个填数过程，用带记忆化的搜索解决：

```
dfs(pos, 状态, tight, started)
  pos     ：当前填到第几位（从最高位开始）
  状态    ：题目要求记住的"已填部分的信息"（上一个数字、已出现的数字集合、数字和、余数……）
  tight   ：前面填的位是否与 x 完全相等（=1 时当前位最多只能填 x 的这一位）
  started ：是否已经开始填非零数字（处理"前导零"）
```

- **为什么 tight 要进状态**：如果前面某位已经填得比 x 小，后面随便填都不会超过 x，此时所有后缀的答案只取决于"状态"，可以记忆化；否则受 x 限制。
- **为什么有 started**：形如 `05` 和 `5` 是同一个数，且"相邻位差 ≥ 2"这类条件不应该把前导零算进去。
- 记忆化数组只对 `tight == 0` 有意义，但直接把 tight 也放进下标更不容易错（本教程写法）。
- 回答区间询问统一用 `solve(R) - solve(L-1)`，`solve(x)` 统计 [1, x]（或 [0, x]）。

### 2.2 例：[SCOI2009] windy 数（洛谷 P2657）

> 定义 windy 数为"不含前导零且相邻两个数字之差至少为 2"的正整数。求 [L, R] 内 windy 数个数（L, R ≤ 2×10^9）。

状态只需记住**上一位数字 last**。搜索时分类：还没开始 → 这一位填 0（继续没开始）或填 d 开始；已经开始 → 只有 |d − last| ≥ 2 才能填。

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

// 统计 [1, x] 中的 windy 数个数
ll windyCnt(ll x) {
    if (x <= 0) return 0;
    string s = to_string(x);
    int n = (int)s.size();
    ll memo[20][11][2][2];              // [位数][last+1(0..10, -1用0表示)][tight][started]
    memset(memo, -1, sizeof(memo));

    function<ll(int, int, int, int)> dfs = [&](int pos, int last, int tight, int started) -> ll {
        if (pos == n) return started;   // 数 "0" 不算 windy 数
        ll &res = memo[pos][last + 1][tight][started];
        if (res != -1) return res;
        int lim = tight ? s[pos] - '0' : 9;
        ll ans = 0;
        for (int d = 0; d <= lim; ++d) {
            if (!started) {             // 还没开始填有效数字（前面都是前导零）
                if (d == 0) ans += dfs(pos + 1, -1, tight && d == lim, 0);
                else        ans += dfs(pos + 1, d,  tight && d == lim, 1);
            } else {                    // 已开始：必须满足相邻差 >= 2
                if (abs(d - last) >= 2) ans += dfs(pos + 1, d, tight && d == lim, 1);
            }
        }
        return res = ans;
    };
    return dfs(0, -1, 1, 0);
}

int main() {
    ll L, R;
    cin >> L >> R;
    cout << windyCnt(R) - windyCnt(L - 1) << '\n';
    return 0;
}
```

**这个模板怎么改造成其他题？**

| 条件类型 | 状态里加什么 |
| --- | --- |
| 某数字不能出现 / 相邻两位不能组成 XX（如不要 62、不能有 4） | `last`（上一数字），判断时跳过非法位 |
| 各位数字和是 m 的倍数 | `sum`（数字和）+ `mod` |
| 数本身能被各位数字整除（CF 55D） | 记录数值模 lcm(1..9)=2520 的余数 + 已出现数字集合的 lcm（2520 的因子，可离散化，只有 48 种） |
| 二进制中 1 的个数相关（如洛谷 P4317） | 按 2 进制做同样模板，状态记已出现的 1 的个数 |
| 含有长度 ≥ 2 的回文子串（如洛谷 P3413 萌数） | `last` 与 `last2`：任何回文串都源于"相邻相等"或"隔一个相等" |
| 统计"和"而不是"个数" | 让 dfs 返回 pair<个数, 总和>，或在状态里多记一个维度 |

## 3. 树形 DP：树上背包、换根、基环树

### 3.1 定位与总套路

树给 DP 带来了天然的顺序：**自底向上（后序遍历）**。要点是把"子树"当作子问题——`dp[u][…]` 通常描述"以 u 为根的子树里的最优值"，转移时依次"合并"每个孩子 v 的答案。

```
dfs(u):
    dp[u] = 只考虑 u 自己的初值
    for v in children(u):
        dfs(v)                          // 先算好孩子
        把 dp[v] 的结果“合并”进 dp[u]    // 逐个孩子做一遍背包/取 max/取 min
```

最常见的基础题（P1352 没有上司的舞会，选/不选两状态）你大概率见过，下面直接上进阶三连：**树上背包、换根 DP、基环树**。

### 3.2 树上背包（分组背包在树上）：[CTSC1997] 选课（洛谷 P2014）

> n ≤ 300 门课，每门课至多一个先修课（组成森林）。选恰好 m 门课（选了先修才能选后继），求最大总学分。

把森林加一个**虚拟根 0**（学分为 0），问题变成"在 0 为根的树上选恰好 m+1 个点（0 必选），选儿子必须选父亲"。

定义：

```
dp[u][j] = 在 u 的子树内，u 必选，一共选了 j 个点（j ≥ 1）的最大学分；dp[u][0] = 0 表示这棵子树一个都不选
```

孩子子树是一个**分组**：要么整组不选（k=0），要么从孩子 v 里选 k ≥ 1 个（dp[v][k]，含 v 自己）。合并时枚举 a（当前已有）+ k（从 v 选），这就是标准分组背包，只是"组"是子树。

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
const ll NEG = -(1LL << 60);
const int MAXN = 305;

int n, m, CAP;
int val[MAXN];
vector<int> ch[MAXN];
ll dp[MAXN][MAXN];
int sz[MAXN];

void dfs(int u) {
    for (int j = 0; j <= CAP; ++j) dp[u][j] = NEG;
    dp[u][0] = 0;          // u 子树一个不选（作为孩子时被父节点"跳过"）
    dp[u][1] = val[u];     // 只选 u
    sz[u] = 1;
    for (int v : ch[u]) {
        dfs(v);
        // 把 v 的子树作为一个分组合并进来；a 从大到小避免同一孩子被用两次
        for (int a = sz[u]; a >= 1; --a) {
            if (dp[u][a] <= NEG / 2) continue;
            for (int k = 0; k <= sz[v] && a + k <= CAP; ++k) {
                if (dp[v][k] <= NEG / 2) continue;
                dp[u][a + k] = max(dp[u][a + k], dp[u][a] + dp[v][k]);
            }
        }
        sz[u] += sz[v];
    }
}

int main() {
    ios::sync_with_stdio(false); cin.tie(nullptr);
    cin >> n >> m;
    CAP = m + 1;                         // 虚拟根 0 占一个名额
    for (int i = 1; i <= n; ++i) {
        int s, c;                        // s: 先修课编号（0 表示无先修），c: 学分
        cin >> s >> c;
        ch[s].push_back(i);
        val[i] = c;
    }
    dfs(0);
    cout << dp[0][CAP] << '\n';          // 虚拟根 + 恰好 m 门真实课
    return 0;
}
```

**复杂度**：合并两棵子树各枚举一次，朴素最坏 O(n·m²)，用子树大小 `sz` 裁剪后本题 n, m ≤ 300 轻松通过；更精细的分析（每对点在"它们的 LCA 处"只贡献一次）可知裁剪后接近 O(n·m)。

**该模型的变体**：
- 容量不是"点数"而是"边数/叶数/重量"：改容量维度即可，如 **P1273 有线电视网**（dp[u][j] = u 子树内服务 j 个用户的最大收益）。
- **按"边对答案的贡献"转化**：[HAOI2015] 树上染色（洛谷 P3177）：把"黑点两两距离"改成枚举每条边，边权 ×（子树内黑点 × 子树外黑点 + 子树内白点 × 子树外白点），然后做树上背包——这是"贡献拆分"思想的代表题。

### 3.3 换根 DP（reroot）：[POI2008] STA-Station（洛谷 P3478）

**触发信号**："以每个点为根/中心都问一次答案，n 到 1e6"——每个点跑一遍 dfs 是 O(n²)，必须换根。

思路分两步：
1. 以 1 为根做一次树形 DP，得到 `sz[u]`（子树大小）和 `down[u]`（u 子树内所有点到 u 的距离和）；
2. 从根向儿子"换根"：当根从 u 换到儿子 v 时，v 子树里的点（共 sz[v] 个）距离都 −1，其余 n − sz[v] 个点距离都 +1：

```
ans[v] = ans[u] - sz[v] + (n - sz[v]) = ans[u] + n - 2·sz[v]
```

n 可能到 1e6，递归会爆栈，用**队列 + 逆序**实现自底向上：

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
const int N = 1000005;

int head[N], to[N << 1], nxt[N << 1], tot;
void add(int u, int v) { to[++tot] = v; nxt[tot] = head[u]; head[u] = tot; }

int parent[N], que[N];
int sz[N];
ll down[N], ans[N];              // down: 子树内距离和；ans: 换根后的总距离和

int main() {
    ios::sync_with_stdio(false); cin.tie(nullptr);
    int n; cin >> n;
    for (int i = 1; i < n; ++i) { int u, v; cin >> u >> v; add(u, v); add(v, u); }

    int l = 0, r = 0;                            // BFS 得到父指针 + 遍历顺序
    parent[1] = -1; que[r++] = 1;
    while (l < r) {
        int u = que[l++];
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (v == parent[u]) continue;
            parent[v] = u; que[r++] = v;
        }
    }
    for (int i = 1; i <= n; ++i) sz[i] = 1;
    for (int i = n - 1; i >= 0; --i) {           // 逆 BFS 序：先孩子后父亲
        int u = que[i];
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (parent[v] == u) {                // v 是 u 的孩子
                sz[u] += sz[v];
                down[u] += down[v] + sz[v];
            }
        }
    }
    ans[1] = down[1];
    for (int i = 1; i < n; ++i) {                // BFS 序：父先于子，逐层换根
        int u = que[i];
        ans[u] = ans[parent[u]] + (ll)n - 2LL * sz[u];
    }
    int best = 1;
    for (int i = 2; i <= n; ++i)
        if (ans[i] > ans[best]) best = i;        // 取编号最小：严格大于才更新
    cout << best << '\n';
    return 0;
}
```

换根不是只能求距离和：凡是"以任意点为根的答案"能写成"父亲的答案 + 只和子树大小/子树信息有关的修正项"都可以。经典题 **CF 1324F Maximum White Subtree**（黑白树，问每个点所在最大白色连通块，用 ±1 权值 + 换根）。

### 3.4 基环树 DP（简介）

树上多一条边就成了**基环树**。套路是**先把环找出来**（拓扑删点即可），然后：
- 对环上每个点"挂着"的树做树形 DP；
- 再对环做一次 DP，通常需要**枚举环上某两个相邻点的取舍状态**（因为环会首尾相连），或"断环成链"把环拉成序列 DP。

代表题：洛谷 P2607 [ZJOI2008] 骑士（带权最大独立集 + 基环树，即"没有上司的舞会"的基环树版）。更进阶的树上大杀器（倍增/树剖维护 DP 转移、动态 DP）见第 10 章扩展：P5024 [NOIP2018 提高] 保卫王国 与 P4719 【模板】"动态 DP"。

## 4. 概率与期望 DP

### 4.1 触发信号与三条武器

**触发信号**：题面出现"期望 / 概率 / 随机"、求"平均需要多少次 / 期望得分 / 到达某状态的概率"。

**武器 1：期望的线性性** `E[X+Y] = E[X] + E[Y]`，**不要求 X、Y 独立**。凡是"把一个随机量拆成许多个 0/1 指示变量之和"就能用：期望 = Σ(某事件发生的概率)。例：随机游走中"某点被访问次数期望"可拆成每个时刻的指示变量；OSU! 类题把 (x+1)³−x³ 展开成关于 x 的多项式后逐项取期望。

**武器 2：全期望公式（设状态 + 逆推）**。设 `f[u] = 从状态 u 出发走到终点的期望`，则

```
f[u] = Σ (u → v 的概率) × (这一步的贡献 + f[v])
```

这就是一个"按拓扑序从后往前"递推的 DP：**先算靠后的状态，再算前面的**。若状态图是 DAG 直接逆拓扑；若出现环（随机游走可以走回头），每个状态写一个方程，变成**高斯消元**。

**武器 3：顺推求"概率"**。如果要求的是"到达某个状态的概率/期望次数"，且转移是 DAG，也可以顺推：`p[v] += p[u] × 转移概率`。逆推算"到终点的期望步数"、顺推算"从起点来的概率"，各有用处。

**精度**：用 `double`/`long double`；先列式子确认没有除零；浮点比较留 eps。

### 4.2 例：绿豆蛙的归宿（洛谷 P4316）

> n ≤ 1e5 个点 m ≤ 2e5 条边的 DAG，每条边有权 w。从 1 出发，每个点等概率随机走向一条出边，求走到 n 的**期望路径长度**。

设 `f[u] = 从 u 走到 n 的期望长度`，终点 `f[n] = 0`。u 的每条出边 (u→v, w) 等概率，所以：

```
f[u] = (1 / outdeg[u]) × Σ ( f[v] + w )
```

先求拓扑序，然后**按拓扑序倒序**计算（保证算 f[u] 时 f[v] 都已算好）。用迭代写法避免 1e5 递归爆栈：

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
const int MAXN = 100005;

vector<pair<int, ll>> g[MAXN];     // u 的出边
int indeg[MAXN];
double f[MAXN];

int main() {
    ios::sync_with_stdio(false); cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    for (int i = 0; i < m; ++i) {
        int u, v, w;
        cin >> u >> v >> w;
        g[u].push_back({v, w});
        ++indeg[v];
    }
    // Kahn 拓扑排序
    vector<int> topo;
    queue<int> q;
    for (int i = 1; i <= n; ++i) if (indeg[i] == 0) q.push(i);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        topo.push_back(u);
        for (auto &pr : g[u])
            if (--indeg[pr.first] == 0) q.push(pr.first);
    }
    // 逆拓扑序：先算靠后的状态
    for (int i = (int)topo.size() - 1; i >= 0; --i) {
        int u = topo[i];
        if (g[u].empty()) { f[u] = 0; continue; }
        double sum = 0;
        for (auto &pr : g[u]) sum += f[pr.first] + (double)pr.second;
        f[u] = sum / (double)g[u].size();
    }
    cout << fixed << setprecision(2) << f[1] << '\n';   // 输出位数按题目要求
    return 0;
}
```

## 5. DP 优化 ①：单调队列优化（滑动窗口最值）

### 5.1 触发信号与思想

**触发信号**：转移式长这样——`dp[i] = max/min over j ∈ [i−L, i−R] (dp[j]) + cost(i)`，即**最优候选来自一个随 i 单调移动的连续下标窗口**。朴素枚举是 O(n·窗口)，用单调队列把"窗口最值"维护成 O(1)，转移降到 O(n)。

**原理**：窗口右移时，用两个单调性把无用的候选丢掉：

```
deque<int> dq;   // 存下标；从队头到队尾，下标递增、dp 值单调（例：单调递减存“最大”）
for (int i = 起点; i <= n; ++i) {
    while (!dq.empty() && dq.front() < i - R) dq.pop_front();      // ① 过期的（太远）出队
    if (!dq.empty()) dp[i] = 转移(dq.front());                     // ② 队头就是窗口内最优
    while (!dq.empty() && dp[i] 比 dp[dq.back()] 更优) dq.pop_back(); // ③ 新元素更优则弹出队尾
    dq.push_back(i);                                               // ④ 当前下标入队
}
```

为什么 ③ 安全？只要窗口右端单调、新下标永远比旧下标"晚过期"，那么一个又老又差的候选永远不可能再赢过新来的，直接丢弃不后悔。**每个元素至多进出队一次，均摊 O(1)**。

### 5.2 例 1（滑动窗口型 DP 示意）：跳一步窗口转移

如果 dp[i] = a[i] + max{ dp[j] : i−k ≤ j < i }，核心循环就是：

```cpp
deque<int> dq;
for (int i = 1; i <= n; ++i) {
    while (!dq.empty() && dq.front() < i - k) dq.pop_front();   // 窗口左端
    if (!dq.empty()) dp[i] = a[i] + dp[dq.front()];
    while (!dq.empty() && dp[dq.back()] <= dp[i]) dq.pop_back(); // 维护单调减
    dq.push_back(i);
}
```

注意：这里的队头/队尾维护方向（求最大值时 dp 值单调递减、下标递增）要写熟，画一条数轴验证一次就不容易错。

### 5.3 例 2（更高级用法）：单调队列优化多重背包（洛谷 P1776 宝物筛选）

> n ≤ 100 种物品，第 i 种体积 w、价值 v、**数量有限 c 件**，背包容积 m ≤ 4×10^4，求最大价值。朴素转移 O(n·m·c) 会超时。

设 f[j] 为"上一物品处理完、容量为 j 的最大价值"。对当前物品，把容量按 **模 w 的余数 r 分组**：容量 j = r + k·w，在这一组里选 u 件该物品（0 ≤ u ≤ min(c, k)），则

```
f_new[r + k·w] = max_{u} ( f_old[r + (k-u)·w] + u·v )
                = k·v + max_{q ∈ [k-c, k]} ( f_old[r + q·w] - q·v )      // q = k-u
```

对每组余数 r，`f_old[r+q·w] − q·v` 恰好是一个"随 k 滑动、长度 c"的窗口最值 → 单调队列。总复杂度 **O(n·m)**。

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
const int MAXM = 100005;

ll f[MAXM];
int qpos[MAXM];
ll qval[MAXM];

int main() {
    ios::sync_with_stdio(false); cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    for (int i = 0; i < n; ++i) {
        int w, v, c;                    // 体积、价值、数量
        cin >> w >> v >> c;             // 若题面顺序是“价值 体积 数量”，把变量对应调换即可
        for (int r = 0; r < w && r <= m; ++r) {      // 枚举余数 r
            int head = 0, tail = -1;
            int maxk = (m - r) / w;
            for (int k = 0; k <= maxk; ++k) {
                int j = r + k * w;
                ll cur = f[j] - 1LL * k * v;         // 入队值：f_old[r+qw] - q·v
                while (head <= tail && qval[tail] <= cur) --tail;
                ++tail; qpos[tail] = k; qval[tail] = cur;
                while (qpos[head] < k - c) ++head;   // 最多选 c 件 ⇔ q >= k-c
                f[j] = qval[head] + 1LL * k * v;     // 注意 f[j] 先取值后覆盖，天然是上一层的值
            }
        }
    }
    cout << f[m] << '\n';
    return 0;
}
```

自测样例：输入 `3 10`，三种物品 `(w=3,v=6,c=2)`、`(w=4,v=5,c=3)`、`(w=8,v=9,c=1)` → 输出 `17`（选 2 件第一种 + 1 件第二种：体积 3×2+4=10，价值 12+5=17）。

**为什么 f[j] 原地更新是正确的？** 同一余数组 r 内，k 从小到大处理，写 f[r+k·w] 时只会覆盖本组里下标更小的位置（r+k'·w, k'<k），而当前 `cur` 已经在覆盖前取好了旧值；不同余数组的窗口互不相交。这就是"利用结构原地滚动"的典型例子。

## 6. DP 优化 ②：斜率优化（凸壳优化 / CHT）

### 6.1 触发信号与几何直觉

**触发信号**：O(n²) 转移中交叉项与 i、j 的**二次/乘积**有关，典型形如：

```
dp[i] = min over j<i ( dp[j] + (a[i] − b[j])² )
dp[i] = min over j<i ( dp[j] + a[i]·b[j] )        // 或 max
```

n 到 1e5 ~ 1e6，且 **a[i] 有单调性**（转移点可以只增不减）。

**关键一步是代数变形**：以 `dp[i] = min_j dp[j] + (a[i]−b[j])²` 为例：

```
dp[i] = a[i]² + min_j ( dp[j] + b[j]² − 2·a[i]·b[j] )
```

令点 `(x_j, y_j) = (b[j], dp[j] + b[j]²)`，则"−2·a[i]·x_j + y_j"是**过点 (x_j,y_j)、斜率为 2·a[i] 的直线在 y 轴上的截距**。于是 dp[i] 的转移就是在平面点集上做**斜率为固定值的切线**：答案只可能落在点集的**凸壳**上，而且随着斜率（a[i]）单调变化，最优点的编号也单调移动——于是可以用**双端队列维护凸壳 + 队头指针**，每个点进出一次，总复杂度 O(n)。

### 6.2 例：[HNOI2008] 玩具装箱（洛谷 P3195，斜率优化入门第一题）

> n ≤ 5×10^4 个玩具，长度 c[i]，可连续分组。一组 [j+1..i] 的代价 = (Σc + (组内个数−1) − L)²。求分组最小总代价。

设前缀和 S：一组 [j+1..i] 代价 = (S[i]−S[j] + (i−j−1) − L)²。令

```
A[i] = S[i] + i
B[j] = S[j] + j + L + 1
```

则代价 = (A[i] − B[j])²，转移 `dp[i] = min_{0≤j<i} dp[j] + (A[i]−B[j])²`。B[j] 随 j 严格递增（可作凸壳横坐标），A[i] 随 i 单调递增（查询斜率单调，可用指针）。比较凸壳上两点的优劣时用**叉积写法避免浮点**，乘积用 `__int128` 防溢出：

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
const int MAXN = 50005;

ll S[MAXN], A[MAXN], B[MAXN], dp[MAXN];
int q[MAXN];                       // 手写双端队列（存下标 j）

ll X(int j) { return B[j]; }
ll Y(int j) { return dp[j] + B[j] * B[j]; }

int main() {
    ios::sync_with_stdio(false); cin.tie(nullptr);
    int n; ll L;
    cin >> n >> L;
    for (int i = 1; i <= n; ++i) {
        ll c; cin >> c;
        S[i] = S[i - 1] + c;
        A[i] = S[i] + i;
        B[i] = S[i] + i + L + 1;
    }
    B[0] = L + 1;                  // j=0：S[0]+0+L+1

    int head = 0, tail = 0;        // 初始只有一个点 j=0
    q[0] = 0;
    for (int i = 1; i <= n; ++i) {
        // 1) 队头指针前进：斜率(q[head], q[head+1]) <= 2*A[i] 时 q[head] 不再可能最优
        while (head < tail) {
            __int128 lhs = (__int128)(Y(q[head + 1]) - Y(q[head]));
            __int128 rhs = (__int128)2 * A[i] * (X(q[head + 1]) - X(q[head]));
            if (lhs <= rhs) ++head; else break;
        }
        // 2) 用队头转移
        int j = q[head];
        ll d = A[i] - X(j);
        dp[i] = dp[j] + d * d;
        // 3) 插入 i，维护下凸壳：斜率(q[tail-1], q[tail]) >= 斜率(q[tail], i) 时弹出队尾
        while (head < tail) {
            __int128 l = (__int128)(Y(q[tail]) - Y(q[tail - 1])) * (X(i) - X(q[tail]));
            __int128 r = (__int128)(Y(i) - Y(q[tail])) * (X(q[tail]) - X(q[tail - 1]));
            if (l >= r) --tail; else break;
        }
        q[++tail] = i;
    }
    cout << dp[n] << '\n';
    return 0;
}
```

**配套小抄（做题时对着检查）**：
- 求 min → 下凸壳；求 max → 上凸壳（把式子乘 −1 变成 min 也行）；
- 凸壳内相邻点斜率单调 → 插入时用"叉积符号"判断是否该弹队尾；
- 查询斜率（这里是 2·A[i]）单调 → 队头指针只前进不回头；不单调就要用**平衡树/李超树/CDQ**（见 6.4）；
- 所有比较都用 `__int128` 做乘法，别用 double 求斜率。

### 6.3 常见套路

1. **先把能去掉的项处理掉**：比如 [USACO08MAR] Land Acquisition（洛谷 P2900）：按 w 排序后，被别的矩形完全覆盖的矩形可以直接删掉，剩下的 w 递增而 h 递减，代价 w_i·h_j 天然适合斜率优化。
2. **一维带个数限制的 DP 常常 = 斜率优化 + WQS**（见第 8 章）。
3. **dp 值与横坐标都要开 long long，交叉乘积可能到 1e24 以上**——比较一律 __int128。

## 7. DP 优化 ③：决策单调性与四边形不等式

### 7.1 概念与触发信号

很多 DP 的转移是枚举"上一个断点 j"：

```
dp[i] = min over j<i ( dp[j] + w(j+1, i) )     // 或 max
```

记 `opt[i]` 为让 dp[i] 取到最优的（最小的）j。如果 **opt[i] 随 i 单调不减**，就说这个 DP 有**决策单调性**。一旦成立，转移就不必每次扫全部 j。

**怎么快速知道有没有决策单调性？** 两个途径：
1. 理论判定：若 w(l, r) 满足**四边形不等式**（对 a ≤ b ≤ c ≤ d：w(a,c)+w(b,d) ≤ w(a,d)+w(b,c)）以及区间包含单调（w(b,c) ≤ w(a,d)），则 opt 单调。常见"长得像距离/平方/绝对值"的代价函数都满足。
2. **暴力打表验证（最实用）**：写一个 O(n²) 的朴素 DP，打印出每个 dp[i] 的最优转移点 opt[i]，看是否单调不减。是 → 放心用优化；不是 → 别硬套。

### 7.2 三种实现方式（按适用场景选）

| 实现 | 适用场景 | 复杂度 |
| --- | --- | --- |
| **分治优化（D&C）** | dp 按层转移 `dp[k][i] = min_j dp[k-1][j] + w(j+1,i)`，且 w 能 O(1)/O(log) 求出 | O(k·n·log n) |
| **Knuth 优化** | 区间 DP `dp[l][r] = min_k (dp[l][k]+dp[k+1][r]) + w(l,r)`，w 满足四边形不等式 | 石子合并 O(n³) → O(n²) |
| **二分队列（决策单调栈）** | 一维 dp 决策单调，但 w 计算慢，只能逐点验证 | O(n log n) |

D&C 优化是最常用、最好写的：要算一层的 dp[l..r]，每次都取中点 mid，**在 opt 上下界内暴力找 mid 的最优转移点 best**，然后递归处理左右两半，把 best 作为左右子区间的 opt 边界（决策单调性保证了这一点）。每层每个 mid 的暴力扫描范围被 opt 界收住，总代价 O(n log n)。

### 7.3 例：[IOI2000] 邮局（洛谷 P4767）

> n 个村庄在一维直线上，位置 x[1..n]（递增）。建 k 个邮局，每个村庄去最近的邮局，最小化距离总和。

经典做法：把村庄按顺序连续分组，每组共用一个邮局；一组 [l..r] 的最佳邮局位置是中位数。`w(l,r) = Σ |x[t] − x[中位数]|` 可用前缀和 O(1) 求出，且 w 满足四边形不等式 → 决策单调 → D&C 优化：

```
dp[k][i] = min over j< i ( dp[k-1][j] + w(j+1, i) )
```

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
const ll INF = (ll)4e18;

int main() {
    ios::sync_with_stdio(false); cin.tie(nullptr);
    int n, p;
    cin >> n >> p;                      // n 个村庄，p 个邮局（若题面两数顺序不同请调换）
    vector<ll> x(n);
    for (int i = 0; i < n; ++i) cin >> x[i];
    sort(x.begin(), x.end());

    vector<ll> pref(n + 1, 0);
    for (int i = 1; i <= n; ++i) pref[i] = pref[i - 1] + x[i - 1];

    // w(l, r)：区间 [l, r]（1-based）共用一个邮局的最小距离和，邮局放在中位数
    auto w = [&](int l, int r) -> ll {
        if (l > r) return 0LL;
        int mid = (l + r) >> 1;
        ll m = x[mid - 1];
        return m * (mid - l) - (pref[mid - 1] - pref[l - 1])       // 左侧
             + (pref[r] - pref[mid]) - m * (r - mid);              // 右侧
    };

    vector<ll> prev(n + 1, INF), cur(n + 1, INF);
    prev[0] = 0;                        // 0 个邮局覆盖 0 个村庄
    for (int k = 1; k <= p; ++k) {
        fill(cur.begin(), cur.end(), INF);
        // 分治：填第 k 层的 cur[l..r]，转移点 j 的理论范围 [optl, optr]
        function<void(int, int, int, int)> dc = [&](int l, int r, int optl, int optr) {
            if (l > r) return;
            int mid = (l + r) >> 1;
            int best = optl;
            ll bestv = INF;
            int lo = max(optl, k - 1), hi = min(mid - 1, optr);    // 前 k-1 个邮局至少覆盖 k-1 个村庄
            for (int j = lo; j <= hi; ++j) {
                if (prev[j] >= INF / 2) continue;
                ll val = prev[j] + w(j + 1, mid);
                if (val < bestv) { bestv = val; best = j; }
            }
            cur[mid] = bestv;
            dc(l, mid - 1, optl, best);      // 左半：转移点 ≤ best
            dc(mid + 1, r, best, optr);      // 右半：转移点 ≥ best
        };
        dc(k, n, k - 1, n);
        prev = cur;
    }
    cout << prev[n] << '\n';
    return 0;
}
```

### 7.4 Knuth 优化（复习你会的区间 DP）

你已经会石子合并（洛谷 P1880）O(n³) 的写法。当代价满足四边形不等式时，最优断点满足

```
s[l][r-1] ≤ s[l][r] ≤ s[l+1][r]
```

于是枚举 k 时范围从 [l, r−1] 缩到 [s[l][r−1], s[l+1][r]]，均摊 O(1) 每状态 → 整题 O(n²)。这是"区间 DP 的专属优化"，证明略，直接用 + 打表验证即可。

## 8. DP 优化 ④：WQS 二分（凸优化 / Aliens Trick / 带权二分）

### 8.1 触发信号与思想

**触发信号**：题目额外要求"**恰好选 k 个 / 分成恰好 k 段 / 至多 k 条**"，去掉这个限制后 DP 会变得非常简单（如 O(n)），但 n 和 k 都很大，没法把 k 塞进状态。

观察：如果设 `F(c)` = "不限个数，最优解恰好用了 c 个时"的最优值，且 **F(c) 关于 c 是凸（或凹）函数**，就能用 WQS 二分：

1. 给"每选一个"附加一个惩罚 λ（求最大时是 −λ，求最小时是 +λ）。这样目标变成 `原价值 ∓ λ × 个数`，**不再限制个数**，可以用一个简单的 DP（甚至贪心）求出"最优值 g(λ) 和此时选了几个 cnt(λ)"；
2. λ 越大，惩罚越重，最优解的个数越少：**cnt(λ) 关于 λ 单调**；
3. 二分 λ，使 cnt(λ) 恰好跨过 k，则
   `答案 = g(λ) + λ × k`（把惩罚加回去）。

**为什么凸性够用？** 最优值随惩罚 λ 的斜率恰是 −cnt(λ)，cnt 单调意味着 F 的斜率单调，即 F 凸。

### 8.2 骨架与坑

```cpp
// 前提：写一个 check(penalty)，内部做“不限个数”的 DP（或贪心）
// 返回 pair<该 λ 下的最优值, 方案实际用的个数>。记录个数时注意方向：
// 平局时要么永远取“尽量少选”，要么永远取“尽量多选”，二分才稳定。
pair<ll, int> check(ll penalty);

ll lo = -INF, hi = INF;
while (lo < hi) {
    ll mid = (lo + hi) >> 1;
    if (check(mid).second >= k) lo = mid + 1;   // 按你 check 的方向调整
    else hi = mid;
}
ll ans = check(lo).first + lo * k;              // 注意符号
```

常见坑：
- **多个最优解平局**导致 cnt(λ) 跳跃 → 转移时用"价值相同时选/不选"的 tie-break 规则固定住方向；
- λ 的值域与答案可能到 ±1e15，用 long long / __int128；
- 次数一般二分 40~60 次（值域大时）；
- WQS 的 check 往往本身就需要 **斜率优化 / 堆 / 贪心**，所以它是"优化之上的优化"，等前几章熟了你再学它最顺。

### 8.3 经典题（由易到难）

- **CF 802O April Fools' Problem (hard)**：wqs + 反悔堆，能体会到"惩罚项把二维压成一维"的威力。
- **CF 739E Gosha is Hunting**：带概率的最大化，两维限制中有一维用 WQS 消掉。
- **洛谷 P4383 [八省联考2018] 林克卡特树**：wqs + 树形 DP（链剖分计数），NOI 难度，量力而行。
- 找手感小技巧：先把**无个数限制**版本 AC 了，再加 WQS 二分外壳，分步提交，出错时好定位是 check 的问题还是二分的边界问题。

## 9. 计数 DP 与组合技巧

### 9.1 触发信号与三条经验

**触发信号**：问"方案数 / 有多少种"，输出对 MOD 取模。

1. **状态里尽量只放"对以后有影响"的信息**，把计数变成递推；方案数往往比最值更容易写出错误的重叠——写之前先问"我这样分会不会把同一个方案数两遍"。
2. **用"定序"去重**：枚举子集/划分时固定"最小元素"或"最后一件的编号"，是保证唯一分解的万能方法。
3. **计数 + 容斥**：条件多且互相纠缠时，"总方案 − 违反某个条件的方案"经常远简单于直接计数。求"恰好/每个都"时尤其常见。

### 9.2 例：[HAOI2008] 硬币购物（洛谷 P1450，完全背包 + 容斥）

> 4 种硬币面值 c[1..4]（固定），每次询问给每种硬币的数量上限 d[i] 和要凑的面额 s，问凑出 s 的方案数（q ≤ 1000）。

没有上限就是**完全背包**预处理 f[x] = 凑 x 的方案数，O(1e5)。上限约束用容斥处理：枚举"哪些硬币超限了"，超限第 i 种至少用 d[i]+1 枚，于是"第 i 种超限"的方案数 = f[s − Σ(d[i]+1)·c[i]]，套 4 个集合的容斥（16 个子集，奇加偶减）：

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
const int MAXS = 100000;
ll f[MAXS + 1];
int c[4];

int main() {
    ios::sync_with_stdio(false); cin.tie(nullptr);
    int q;
    cin >> c[0] >> c[1] >> c[2] >> c[3] >> q;
    f[0] = 1;
    for (int i = 0; i < 4; ++i)                 // 完全背包：不限数量
        for (int x = c[i]; x <= MAXS; ++x)
            f[x] += f[x - c[i]];
    while (q--) {
        int d[4], s;
        cin >> d[0] >> d[1] >> d[2] >> d[3] >> s;
        ll ans = f[s];
        for (int mask = 1; mask < 16; ++mask) { // 容斥：枚举哪些硬币“超限”
            int over = 0, bits = 0;
            for (int i = 0; i < 4; ++i)
                if (mask >> i & 1) { over += (d[i] + 1) * c[i]; ++bits; }
            if (over > s) continue;
            ans += (bits & 1) ? -f[s - over] : f[s - over];
        }
        cout << ans << '\n';
    }
    return 0;
}
```

> 这一题是"你学过的背包 DP + 组合数学"的直接缝合：先想简单版本（无限量），再想怎么用容斥把限制补回去。计数题大多是这个思路。

### 9.3 常用组合模型速查

- **组合数表**：`C[n][k] = C[n-1][k] + C[n-1][k-1]` 预处理到 n ≤ 5000；n 大时要阶乘 + 逆元（MOD 为质数时用费马小定理）。
- **卡特兰数**：`Catalan[n] = Σ Catalan[i]·Catalan[n-1-i]`（或 C(2n,n)/(n+1)）。典型：n 个元素进出栈序列数（洛谷 P1044 栈）、括号序列、二叉树计数、凸多边形三角剖分。
- **"先分配结构、再分配元素"**：树上/堆上计数题往往 = 一个结构 DP × 组合数选元素。例：洛谷 P2606 [ZJOI2010] 排列计数（符合小根堆性质的排列数）。

## 10. 再往后看什么（扩展方向速览）

## 附录 A：DP 调试与对拍套路（最重要的一节）

1. **分段打印**：写完后先打印小数据的 dp 表，对照手算的 3~4 个状态。
2. **对拍脚本骨架**：

```
loop 500 次:
    随机生成小数据（n ≤ 10~15，值域小，保证暴力能跑）
    运行 暴力程序 (朴素 O(n²)/O(n³) 或直接枚举)
    运行 优化程序
    比较输出；不一致 → 打印该数据，缩小范围找 bug
```

3. **边界用例清单**：n=1；链/环/星形树；全部相同值；递增/递减序列；答案达到 long long 上限；0 与负值混入；重复元素。
4. **性能自查**：能过样例不代表能过大数据——优化题务必构造 n = 上限的随机数据测 3~5 秒内跑完，再用 `time` 或计时函数确认。
5. **WA 常见原因优先级**（按概率排）：没开 long long → 状态初值/INF 错 → 下标偏移（1-based/0-based）→ 转移漏情况（尤其 tight、前导零、-inf 加值）→ 用了双精度求斜率/比较。

## 结语

DP 进阶没有"背模板"的捷径，它的核心能力是**两件事**：① 看出题目要记住什么信息 → 设计状态；② 看出转移里的结构（单调性 / 凸性 / 几何意义）→ 选择优化。本文每一章都尽量按"触发信号 → 思想 → 可提交代码 → 练习"组织，就是为了让你在**刷题前**能先形成"识别"的肌肉记忆。

送给你三条检查：

1. 状态设计完，先问"丢掉的信息真的不影响转移吗"；
2. 优化前，先用暴力数据**证明单调性/凸性真的成立**；
3. 每章练习至少独立 AC 2~3 道，再进下一章。

祝你刷题顺利，省选 / ICPC 拿牌。
